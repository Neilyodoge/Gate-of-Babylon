# n的TA绝学

以目标画面和实际资源为依据做渲染决定。先确认游戏镜头、目标设备、现有 Shader 与材质状态，再判断视觉收益和采样、带宽、透明覆盖等成本。用户已有明确效果方向时，直接做出可检查的版本，并在实际材质和场景里验证。

## 判断方法

- 区分低频形状和高频细节。顶点色适合确定区域和大轮廓；贴图适合给边缘、内部纹理或动画增加像素级变化。混合时先说明每个信号负责什么，以及全遮挡和全透明处是否应保持稳定。
- 使用贴图通道前，检查**实际引用的每张贴图**及导入设置。源文件有 Alpha、运行时材质取到 Alpha、Alpha 有足够变化是三个不同问题。缺少 Alpha 的材质应有明确的退化表现；需要同样效果时再补贴图数据。
- 复用已经发生的纹理采样及其 RGBA 通道时，记录节省了哪些采样；同时注意多一层透明云雾带来的覆盖率和排序成本。移动端性能结论以目标设备上的 GPU 测量为准。
- 对边缘扰动，优先把贴图变化限制在顶点掩码的过渡带，检查掩码为 0 和 1 时的结果，避免整片材质因乘上噪声 Alpha 而变薄。放大观察边缘，再回到实际玩法视距确认效果。
- 验证 Shader 导入/编译消息，比较代表性材质、无 Alpha 材质、溶解开启与关闭的画面。说明哪些平台或质量档还未实测。

## 已验证案例：TLCloud 云雾边缘

2026-11-14，TopHeroes 的 `TLCloud.shader` 使用顶点色 R 规定迷雾范围；同一张噪声贴图以不同平铺和相反流向采样两次，取 RG 平均用于云色与溶解。此处让两次采样的 Alpha 平均值只削弱边缘过渡带，保留顶点掩码两端，不增加片元纹理采样。参考文章的双层混合式为 `(sampleA + sampleB) / 2`：[SLG 大地图迷雾实现思路](https://www.bilibili.com/opus/885595730732908563)。

实际使用的 `t_noise_VP_260514_2.png` 有 Alpha，值约在 0.49–1.0，整体偏亮，边缘变化需要看真实画面确认。另有 TLCloud 材质引用的 `t_noise_why_260525_1.png` 源文件没有 Alpha；在这套做法里它保持原有顶点渐变，不会出现贴图边缘变化。若那些材质也需要同样效果，应先为贴图准备有意义的 Alpha，并检查其他使用者。
