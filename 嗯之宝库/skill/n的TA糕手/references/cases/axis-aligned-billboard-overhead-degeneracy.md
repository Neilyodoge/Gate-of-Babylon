# TA-112 · 俯视时轴对齐粒子的翻转

**制作决定。** 单张卡片在正俯视附近突然换朝向，先查固定轴和视线是否近乎平行；回退能让朝向计算稳定，但一直保持竖直的卡片仍会在顶视缩成线。顶视也必须有轮廓时，单独比较水平片、允许俯仰的相机向卡片或有厚度的替代物。

## 公开证据

- [Godot 4.4-stable · material.cpp](https://github.com/godotengine/godot/blob/4.4-stable/scene/resources/material.cpp) 生成 Shader 的 `BILLBOARD_FIXED_Y` 分支把世界 Y 设为上轴，用 Y 与 `MAIN_CAM_INV_VIEW_MATRIX[2].xyz` 的叉积取卡片横轴，再直接归一化；本分支归一化前没有近零判断。它用主相机的逆视图矩阵，源码注释说明阴影通道也按主相机朝向。这个结论针对 Fixed Y 材质分支，并不等于 Godot 所有粒子朝向模式。
- [MonoGame v3.8.2 · Matrix.CreateConstrainedBillboard](https://github.com/MonoGame/MonoGame/blob/v3.8.2/MonoGame.Framework/Matrix.cs) 用物体与相机位置差求方向，和固定转轴点积的绝对值大于 `0.9982547` 时，改用物体前向或不平行的固定方向创建基底；固定轴没有随之放开。若输入均归一化，阈值相当于距轴线约 3.39°。这说明可以在退化前换参考方向；固定回退与原方向相差很大时，阈值附近仍可能跳变。
- [Unity 6000.0 · ParticleSystemRenderMode](https://docs.unity.com/en-us/engine/6000.0/script-reference/unityengine/particlesystemrendermode) 分别定义默认面向相机、始终向上的 Horizontal Billboard 和不俯仰的 Vertical Billboard。三种模式改变的是几何朝向。选哪个取决于效果要像竖直烟柱、地面水花，还是只要一直看见图形。

## 最小对照

1. **固定顺序先验基底。** 用一张带左右标记的无光照不透明片，临时关闭背面剔除；锁时间和大小，让相机从 5° 斜视扫到正顶再越过。记录视线、叉积长度、算出的横轴与轮廓。设上轴为 (0,1,0)，两侧单位视线的 Z 分量若从正变负，叉积横轴也反向；恰在轴线上时没有可归一化的方向。先在归一化前做近零判断；对照物体固定参考方向与带滞回的回退。双向扫能查阈值抖动，再开背面剔除以区分绕序消失。最后加第二张透明片确认是否还有独立的排序问题。
2. **另量轮廓面积。** 正交镜头与上轴夹角为 θ 时，任何保持竖直、且朝向同一水平投影方向的平面，最佳投影面积也只有正面面积的 `sin(θ)`。1° 时约 1.75%，正顶时为零。两张交叉的竖直卡片在正顶同样没有面面积；只加稳定轴没有补回顶视形状。在同镜头对比竖直片、水平或倾斜片、全朝相机。横向烟火和贴地水花可以直接选不同几何；混用时要看切换是否突然把小轮廓放大。短时叠两张片时，另外在玩法分辨率下量透明覆盖。
3. **验每个实际视图。** Godot 这一分支用相机基向量，MonoGame 用相机到物体的位置关系，正交、偏轴透视和相机滚转下不要预设边界一致。做了回退后，再查颜色、深度与投影阴影是否使用预期的相机基底，尤其是有第二镜头或反射视图时。
