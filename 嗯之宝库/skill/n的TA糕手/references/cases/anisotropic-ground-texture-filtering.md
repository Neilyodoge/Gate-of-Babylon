# TA-57 · 斜视地表的贴图模糊与闪烁

**制作决定。** 石砖或路面的细节只在低角度消失时，先保持 mip 偏移不变，试给这类材质开 2× 或 4× 各向异性。移动端可把“2× 各向异性＋只取一层 mip 的双线性”纳入对照，别直接把所有贴图的 mip 调细。改动后既要看远处细节，也要用慢移镜头看闪烁及 mip 换级线，再用目标机决定档位。

## 证据

- **同画面原图。** [Lampak 的石板路对照（基于 THOMAS 的石板纹理）](https://en.wikipedia.org/wiki/Anisotropic_filtering#/media/File:Anisotropic_filtering_en.png)左侧标为三线性，右侧标为各向异性。近处两侧石缝都可辨；中远处左侧石缝明显变淡，右侧保留到更远。原图没有给设备、各向异性倍率、mip 偏移或运动序列，只支持静态清晰度差异。
- **Arm 对照及反例。** [Arm GPU Best Practices Developer Guide 4.0，Anisotropic filtering，图 1](https://support.arm.com/documentation/101897/0400/Textures/Anisotropic-filtering)的两张木箱图里，右图的斜向侧面能分出更多木纹。作者给出的左图是三线性、各向异性 1×，右图是双线性、最近 mip、各向异性 2×。两个采样设置一起变，无法用这张图隔离其中任何一个变量。Arm 建议试用 2× 双线性各向异性替代普通三线性，指出前者平均开销可能更低，但有可见 mip 换级缝的材质仍需比较三线性；该页没有提供设备和场景帧时。
- **Arm 成本模型。** 同页的 Optimizing 小节把三线性估成每个子采样两次双线性工作：三线性 4× 在最斜的像素上可达普通双线性 1× 的 **8 倍过滤工作**。这是模型里的上限，不是每像素固定 tap 数，也不是 GPU 帧时或外部流量倍数。Profiling 小节建议用 Streamline 看每次采样的过滤周期；[Arm Mali G2 计数参考](https://arm-software.github.io/libGPUCounters/mali_g2_counter_reference.html#c_803)另提供纹理单元每线程周期，需配合实际外部读取和各 pass 时间判断。

## 用法与边界

1. **先隔离观察角度。** 用同一地面、相机轨迹、输出分辨率、自动曝光、TAA、采样偏移与贴图驻留，先关掉法线与高光，只看底色。选三线性 1×、三线性 2×/4×，再加双线性 2×；只有最后一组改变 mip 混合方式。近到远慢移，分别看石缝失去的位置、闪烁程度和是否出现一条跟着相机走的换级线。
2. **再试偏移与素材。** 理想化算例：一个输出像素映射到 8 × 2 个源纹素时，按长边选各向同性的 mip 3 会一起抹掉短边细节；减 1 档改用 mip 2，短边会清晰一些，长边仍可能欠滤波。一种各向异性做法是在更细的层沿长轴取多个样本，保住短边并覆盖长边。这个算例只说明为什么偏移无法替代方向性过滤。若只开回法线/高光才闪，优先查[法线 mip 和粗糙度](normal-map-mips-and-roughness-prefilter.md)；若纹理最细层未驻留，先查流送。
3. **真机选档。** 固定镜头轨迹、分辨率、覆盖率和热状态，同时记 GPU 地面 pass、整帧、纹理单元周期与外部读取。近景不普遍用满各向异性倍率，因此不要从设置中的 2×、4× 直接推算带宽。先按地面与斜视道具启用达到目标的最低倍率，而后再比较不同滤波组合的稳定性。

**验证状态。** 已目视两份公开静图，并核对 Arm 设置和滤波成本模型；未取得同一移动设备上的性能 A/B，也未在本地运行慢移镜头。后续若取得目标档的帧时或换级反例，补到本卡。
