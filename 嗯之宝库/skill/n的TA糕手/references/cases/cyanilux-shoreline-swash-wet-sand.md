# VFX-07 · Cyanilux 岸线 Shader：来浪、回水与湿沙各说一件事

**问题与结论。** 风格化岸线怎样看起来既在流动，又让人一眼知道水到了哪里？用外侧逐条向岸推进的白浪交代流向，用贴岸白沫的上冲和回退交代当前水边，用较暗的湿沙保留刚退水的范围。三层的亮度和节奏各有职责；若俯视远景只够看清一条边，优先留贴岸白沫轮廓和湿沙明度差，再减泡沫内部花纹。

## 画面观察

Cyanilux [X 原发合成演示](https://x.com/Cyanilux/status/1567248922975916033)（2022），后台静音原速播放，抽看约 0.4–7.0 秒内的多处画面。外侧的窄白浪逐条靠岸；贴岸的白沫往沙地上推，随后回退，露出比干沙暗的带状区域。外浪和贴岸白边的运动有区别，湿沙在白边撤开后仍能交代刚刚发生过的事。这是这段固定示范镜头的观感，未核对普通玩法视距、角色或 UI 同屏，也不由画面倒推出 Shader 做法。

**按「n的美术祖谱」的初判。** 好看且可借鉴的是明度与运动分工：最亮的白边让人追到水舌的位置，暗一点的湿沙给退潮留余韵，外浪的重复细线补充方向。若用在玩家需要识别可走浅滩或战斗危险边缘的地点，泡沫把相邻浅滩连成一条白带、或比角色提示更亮时，这套氛围可能干扰信息。先在目标机位压低外浪亮度或减少条数，再评估贴岸轮廓是否独立成立。没有证据证明原作白边是可走边界。

## 作者明确公开的做法

- [2022 年来浪分层帖](https://x.com/Cyanilux/status/1567248954823249923)：作者用重建位置的 Y 进入正弦函数，以 Y 范围限定波浪，并用世界坐标 XZ 平面噪声错开白线；作者提示地形需要较平顺。
- [2024 年重写的 Shader Graph 拆解](https://www.cyanilux.com/tutorials/shoreline-shader-breakdown/)的 [Approaching Waves](https://www.cyanilux.com/tutorials/shoreline-shader-breakdown/#waves) 与 [Swash Wave](https://www.cyanilux.com/tutorials/shoreline-shader-breakdown/#swash)：来浪沿岸向梯度单向滚动；贴岸层另用余弦往返，两者共享滚动速度和波数得到相同周期，再单独用时间偏移调相位。周期相同不代表逐帧位置相同。作者也指出对称余弦只是近似，自然退水可能比上冲更慢。两层泡沫用 Maximum 合并遮罩。
- [Wet Sand](https://www.cyanilux.com/tutorials/shoreline-shader-breakdown/#wet-sand)：在贴岸水线外用低 Alpha 的黑色压暗底材，模拟湿沙；这是透明混合做出的视觉层。文中的高光调整是建议，没有证据表明演示改变了实际沙地材质或模拟了积水。
- 同篇对比了从场景深度重建世界位置得到岸向梯度，和给专用岸线网格布 UV 的做法。深度版容易把白线投到底下的表面，浅坡和俯视较适合；有深度的交叉物也可能带泡沫。自定义 UV 可把白线放在水面并控制纹样，需要额外维护网格与 UV。后写的教程合并改写了两个旧版拆解，不能据此认定原帖所有节点与新版相同。

## 可借鉴做法与最小对照

**实现候选。** 水平水面、浅坡且主要俯视时，可先用场景深度求岸向梯度；有低机位、陡岸或要求白浪沿海湾精确过渡时，优先做一条有明确岸向 UV 的岸线网格对照。先单显贴岸线、外浪、湿沙三层，调清周期与相位，再加小尺度破碎。低档先试减花纹及外浪数量并缩小透明覆盖，保留贴岸轮廓与湿沙差；场景深度成本和透明覆盖代价须另外测。

**最小对照。** 固定岸线几何、曝光、泡沫峰值亮度、相机和周期：A 让所有白线同向滚动；B 只把贴岸线改为往返。确认 B 能独立读出推进和回退后，在 B 里单独开关湿沙层，看退水后是否还能读到先前的上冲范围。各用低机位和目标玩法视距看至少两个周期，加入石头穿水和角色过岸各一次，检查白线是否贴错表面、退潮后湿沙是否与水面边界混淆。高低档同屏对比后，再在目标机测 GPU 帧时和透明叠层。**状态**：已抽看原发动态并核对作者文字；未在本地复现、未做玩法同屏或真机性能验证。
