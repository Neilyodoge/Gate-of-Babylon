# VFX-03 · 慧的被动：预警圈、爆发与消散

**问题与结论**：一次延迟爆炸怎样同时告诉玩家“哪里要避开”“什么时候爆”“现在是否还能进去”？让相对稳定的边界负责范围，让局部明度峰值负责命中；生效结束后，边界也要明确进入退场状态，碎屑可继续收尾。

## 来源与画面

Riot Games，[Hwei Abilities Rundown](https://www.leagueoflegends.com/en-us/event/hwei-abilities-rundown/)，作者 Myles “Riot Emizery” Salholm，面向 13.24 版本。正文说两次伤害技能命中后，会在目标脚下留签名，稍后对范围内敌人爆炸。已在后台静音播放并抽查同页轮播第一项「Passive: Signature of the Visionary」（7.63 秒）。以下是约略的片段时间，不是游戏参数或伤害事件时间。

| 片段定位 | 实际看到的画面 |
| --- | --- |
| 1.2、2.1 秒 | 先有一团红橙色冲击，之后目标脚下可见较小的金色弧与暗色墨迹。它们与稍后展开的大圈在尺寸、形状上有差别。 |
| 2.6、3.2 秒 | 目标周围已有细红外圈与分段金弧；约 3.2 秒中央能辨认完整的金色签名，暗紫底衬托其形。 |
| 3.4–3.6 秒 | 签名位置出现更亮的金色竖向冲击，暗紫和金色的尖笔触向外张开；零星笔触跨过外圈，细红圈仍能辨认。 |
| 3.9–5.7 秒 | 3.9、4.1 秒时密集笔触已退，地面仍留细圈及少量碎片；约 5.7 秒取样已看不到圈。 |

## 美术判断与候选做法

按「n的美术祖谱」分段评审：在该斜俯视示范里，前段小弧和后段大圈能传达不同进度；大圈给出范围线索，爆发把峰值留给中心和少量尖笔触，容易和预警阶段区分。值得保留这三层之间的职责差异，尤其别用穿出边界的碎片暗示更大的判定。原片里尖笔触退得比细圈快；在拥挤团战或小屏，玩家会不会把仍可见的圈当成持续危险，需要另测，不能从演示认定有误读。

**TA 候选**：范围边界跟实际玩法事件走，签名/爆发和余迹独立。在伤害结束后先让功能圈明显转弱或断开，保留少量碎屑和余光。A 保持圈形直到统一渐隐，B 只改变伤害结束时的圈形，固定真实半径、时序、爆发、余迹和相机。用出圈、进圈两种视角在原速下判断何时该避让与何时可重入，并对照伤害事件和范围。未核实原作品的判定帧、材质实现、团战表现、声音或实机性能；未运行 A/B。
