# VFX-06 · Iso 的护盾消耗：先拿掉保护轮廓，再留碎片

**问题与结论。** 一次性护盾消耗后，画面里仍有碎片、爆炸和技能计时，玩家从哪里确认保护没了？让持盾视角的屏边框和对手视角的包身轮廓只表达有效保护。余效可以继续存在，但用断开、偏移或散开的形状，别再拼出一层完整的盾。

## 美术判断与候选做法

按「n的美术祖谱」把状态、反馈、退场分开看。这个案例可借鉴的是**形状的连续性**：自己看屏幕边缘，对手看人身附近，护盾有效时都有可辨认的连贯轮廓；结束后，留下的是没有围合关系的余光、碎片或其他冲击效果。对手视角里爆炸能短时盖住状态变化，所以爆炸散开后的无盾形状也要成立。近距离不宜用整屏亮闪盖住瞄准；复杂背景优先验边缘与目标是否还分得开。提前碎裂的裂纹也不能像失效：耐久型护盾可以在闭合外缘内警示低耐久，只有实际失效才断开外缘。这是迁移建议，原片是一击消耗型护盾。

**TA 候选与最小对照。** 把有效边框／包身壳和破裂粒子分开，由已确认的消耗事件关闭有效层并触发短反馈；持续技能计时使用另一形状或位置，不跟护盾共用一个提示。固定伤害事件、机位、颜色、爆发强度和碎片，在 A 版保留完整轮廓直到随余效渐隐，B 版先撤轮廓只留碎片。用持盾者和对手两段镜头加上无遮挡和爆炸遮挡两组，原速问「此刻是否还有保护」，用事件日志及后续伤害核对误判和读懂耗时。未在本地运行对照；未核实碰撞判定、声音、视距与配色可读性、目标设备性能，也不能把两段剪辑当作同帧双视角。
