# 自动 LOD：保住看得见的边，再看能减多少面

**一句话结论**：对有贴图接缝或硬边的资产，同一减面率可以有很不同的画面结果。先守住在切换视距还看得见的轮廓、接缝和高光，再为剩余边分配减面预算。锁边界和给属性加误差权重是两种控制。

## 两组原始图：外轮廓相近，表面已经变样

- [Bistro 木椅，meshoptimizer 原始报告 #158，第二、三张图](https://github.com/zeux/meshoptimizer/issues/158#issue-643911762)（2020-06-23）：发帖者称第一次减到一半保住了共享顶点的圆角；继续折叠直角之间的圆角后，共享法线不再适合两侧面。实际看到较低档椅面明显变暗，远不如色差显眼的是外轮廓变化。这是同模型不同减面档的法线问题；没有当前版本的属性开关 A/B 或距离结论。
- [Bo 等，Scientific Reports 2026，图 8](https://www.nature.com/articles/s41598-026-43736-w/figures/8)和[图 12](https://www.nature.com/articles/s41598-026-43736-w/figures/12)：图 8 同一只狐獴在标为 60% 简化率的一排里，T-QEM 的鼻口和额头出现明显锯齿状纹带；显式处理接缝的方案没有这类大条纹，MeshLab 和 MSADO 也保留了相近的大形和大部分纹理。图 12 的雕像底座中，T-QEM 的横向接缝有明显锯齿状破碎，其他三种明显轻。论文方法同时改了接缝折叠、尖锐度与纹理代价；能看出多策略相同标称简化率的差别，不能把差别归给某个单独开关，也未核验最终面数是否逐个一致。
- [同文实验 §Experimental evaluation on textured models](https://www.nature.com/articles/s41598-026-43736-w#Sec19)：作者用六方向图像亮度 RMS 辅助比较“纹理误差”，并另记平均几何距离。按作者报告，简化率超过 60% 后，新方法的平均几何误差可比部分基线略高，画面纹理误差仍更低。亮度 RMS 也受轮廓和照明影响，不能当成 UV 偏移量；论文没有做游戏镜头下的切换或设备帧时 A/B。

## 导入工具怎么设、怎么验

1. 先标记硬约束：模块与相邻块对接的外边界、不可跨越的材质分区、必须保持的少数 UV 接缝和刻意做出的硬边。区分“这条缝不能跨”和“这条边一个点也不能折”；[meshoptimizer 文档](https://meshoptimizer.org/#advanced-simplification)中 Protect、Lock、以及带属性值的误差评分各有用途。锁定顶点可能让简化停在目标面数之前；遇到这种情况，先检查是否锁了太多次要边，并报告实际输出面数。
2. 在相近实际三角形数下对照默认、属性感知、再加关键边保护三组。固定纹理、光照、相机和分辨率；用纯色轮廓看几何、无光照贴图看错位、固定斜光看法线与高光。若法线或 UV 权重加大后轮廓坏了，回调权重或提高该档面数，别通过统一的误差数字替代目测。
3. 回到实际切换视距和运动路线，验最坏掠角、贴图接缝、关键轮廓和相邻 LOD 跳变。记录屏幕占用、实际面数和顶点数，再谈设备收益。若 LOD 改用独立顶点流或重算属性，还要单独核对额外内存和切线空间。
