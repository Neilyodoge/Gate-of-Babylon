# TA 研究队列

## 当前续接点

**TA-02 · 透明特效的成本主要来自哪里。** 先找 Unity、Arm 或其他 GPU 厂商的公开文档，核对透明叠层的覆盖率、片元处理和混合成本；设计固定 Shader、只改变屏幕覆盖与叠层数的 A/B。未做设备测量前不判断哪个瓶颈占主导。

## 待研究

| 主题 | 问题 | 复核重点 |
| --- | --- | --- |
| TA-03 · 移动端贴图格式 | 打包数据、多张小图和减少采样各有什么代价？ | 对照格式、块尺寸、Alpha 支持和目标平台覆盖，不只比文件大小。 |
| TA-04 · 资产与工具管线 | 导入预检怎样发现通道误用而不污染资源？ | 先查导入回调、命名/元数据约定，列出只提示与可安全修复的边界。 |
| TA-05 · Shader 变体 | 如何区分变体数量、构建剔除和运行时缺失？ | 找一个官方可复核例子，验证实际 build 的剔除与回退。 |
| TA-06 · 远景高光与光晕 | 怎样保住效果辨识度，同时减少亚像素闪烁？ | 找制作拆解，比较同曝光下的静图与实际移动镜头，区分采样与后处理。 |
| TA-07 · VFX 系统方案 | 同屏大量粒子时，怎样选择实例化、网格动画或 GPU 粒子？ | 区分 CPU 提交、模拟、填充率、透明排序和设备支持。 |

做完一个题后补下一项，持续轮换；同一方法有新反例或测量时更新原卡。
