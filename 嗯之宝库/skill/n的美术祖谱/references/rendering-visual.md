# 美术渲染：整幅画面的材质、光影与气氛

用于游戏画面风格与整合评审：判断材质受光、阴影、雾、曝光、调色和后期合在一起后，形、色、明度、深度与玩法信息怎样被看见。单件模型与材质制作读 [3D 资产与场景](assets-3d.md)，跨区域或剧情节点的色彩节奏读 [色彩脚本](color-key.md)。本专项以美术结果和可执行的画面修改为目标；光追算法、显卡与硬件规格不是默认学习范围。

## 固定观看条件

先注明画面的性质：概念稿、离线渲染、引擎展示、宣传截图，还是普通玩家镜头；再记录版本、相机高度与视距、背景、天气/时段、玩法状态及目标显示尺寸。指出玩家此时要辨认的角色、敌人、通路、交互物、UI 或 VFX，以及画面希望建立的情绪。不同机位、构建或玩法状态的两张图可以比较观感，不能直接当作某个渲染层的单因子实验。

## 从合成结果拆解视觉层级

| 画面层 | 观察与美术决定 | 归因边界 |
| --- | --- | --- |
| 材质表观 | 看大色区、粗糙与高光、透明/发光区域在目标光下是否保留体块、材料身份和重要边缘；细纹只在实际视距能读到时才影响优先级。 | 材质球或孤立转台不能代替关卡同屏；仅从最终图不能断定底色、粗糙度或贴图各自贡献。 |
| 光与影 | 看主明暗组、投影、局部反差怎样建立焦点、深度和可行动线索；亮的装饰是否压过角色、路径或危险信息。 | 明暗分离是画面事实，不等于玩家已识别，也不证明用了哪种灯或阴影实现。 |
| 雾与空气 | 看近中远景是否分开，远处地标、敌人和通路是否被软边雾层吞掉；比较同一相机移动或天气变化时的遮挡。 | 单幅静图不证明动态稳定性，也不能把远景变淡全归因于雾。 |
| 曝光、调色与后期 | 看逆光、夜景、室内外过渡以及辉光、景深、运动模糊后的功能色、轮廓和 HUD/VFX 优先级。 | 要论某一层造成了变化，需同机位同状态的开关、分层图或作者明确拆解；没有时只描述最终合成画面。 |

先定位画面里最亮、最暗与色相最突出的区域，再检查它们是否服务任务。若亮天空、发光装饰或反射比真正通路/目标更抢眼，把冲突写成待试的画面修改，而不从亮度单独推断可走性。静图里评估地面开放带的可见边界时，除局部明度差，还连看纹理疏密、植被或碎石的轮廓、地形起伏与遮挡；相近色值的边界可能依靠形与密度分开，也可能在阴影和叶屑中并合。[《ARC Raiders – The Blue Gate》](https://www.artstation.com/artwork/mAe2JY) #6/#7/#12 与 [《Riven Tides》](https://www.artstation.com/artwork/3EArGJ) #7/#9/#11 的两位作者精选静图只支持这种静态边界检查，不能证明玩家可走路线或材质、灯雾、曝光各自的成因。风格化轮廓、色阶与高光也要在不同背景、距离、转身和动作中复查；同一静帧的清楚轮廓不能证明正常速度玩家辨认。

## 交接与验证

交付带注释的目标相机画面，标出预期视线顺序、材质大区、主光/阴影、雾层和后期各自的美术职责，以及会失效的背景或玩法状态。能取得可控画面时固定几何、相机、状态和曝光，逐层比较；取得不了时把“原因未核”留在结论里。最终在目标设备与普通玩法视距检查角色、通道、危险信号、UI/VFX 同屏，动态问题用正常速度片段验证。

研究时，获准的 [80 Level 文章列表](https://80.lv/articles)或榜单只用于找具体案例；热度和标题不证明方法有效。优先近年已发行作品的制作拆解，实际打开图文并核作者职责，再找原作及可用的游戏画面。分别记录可见画面、作者自述、自己的推断和仍缺的玩家验证；只有多例可比或真实资产试评支持复用时才把新观察升为稳定规则。已有 [《Risk of Rain 2: Alloyed Collective》作者静图](https://www.artstation.com/artwork/Z0gg9Z)中，小角色在暗轨车前局部并入背景、在较亮水面前较清楚；这是不同背景下的静态对照，不证明材质、灯、雾或后期哪一层单独造成差别，也不证明玩家动态读速。
