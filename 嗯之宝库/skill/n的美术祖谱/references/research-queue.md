# 持续学习队列

这份队列是首轮选题，不是固定课表。每次从尚未解决的问题续接；记录已看来源和实际接触范围，避免每半小时重复刷相同作品。用户常用 ArtStation 和 80 Level，但题目需要时应扩展到作者原文、引擎画面与不同作者的反例。

## 待研究

1. **2D 概念如何转成可用游戏资产。** 选角色、场景、道具各一类，比较展示图与正交/转面、材质拆分、动画或引擎结果。候选：[80 Level 的像素拼贴项目访谈](https://80.lv/articles/how-medium-rare-uses-pixel-art-collages-to-evoke-dread-of-industrialized-cannibalism)。需核对它的叙事情绪是否在实际玩法尺寸仍可辨认，不从静图推断玩家效果。
2. **3D 场景从概念到引擎。** 已读 [80 Level 地中海废屋场景拆解](https://80.lv/articles/building-an-abandoned-the-last-of-us-inspired-mediterranean-house-with-custom-materials)文字，并目视其灰盒走廊；已目视它引用的 [ArtStation 原概念](https://www.artstation.com/artwork/0nnkVG)两幅画。作者的最终场景图及游戏内玩法效果尚未核对。下一轮找对应最终视角，对照参考、blockout、模块、材质、植被、灯光各自改变什么；不把个人练习作品当作已上线游戏。
3. **3D 生物的展示精度与实时使用。** 候选：[The Rookies 生物角色制作拆解](https://www.therookies.co/blog/breakdowns/realistic-3d-creature-character-art-breakdown)。文章是高写实离线角色；下一轮找实时项目的多角度、动作、LOD 与目标镜头，对照哪些造型原则可迁移，哪些技术规格不可迁移。
4. **UI 的视觉语言与实际操作。** 用 [Interface In Game](https://interfaceingame.com/) 按菜单、Overlay、Inventory 等元素找多款游戏截图，再找对应项目的官方 UI 设计说明、动态录屏或操作测试。比较图标形态、字体、状态与世界画面的关系；不要仅凭截图断言可用性。
5. **Color key 的跨镜头连续性。** 找包含完整场景序列、变化原因及最后引擎灯光结果的原始案例。研究情绪节奏、玩法路径、日夜变化如何共存，而不是搜集单张漂亮色稿。
6. **VFX 的时间与战斗信息。** 找作者公开的序列帧/视频与游戏内镜头，对照预警、生效、反馈、消散以及叠加时的可读性；静帧只能用于形色观察。

## 轮换与记录

在 2D、3D、UI、color key、VFX 之间轮换，按实际薄弱处改变顺序。每轮将已读 URL、作者、日期、接触范围、得到的条件判断和下一问题写到学习日志；只看见标题、封面或搜索摘要时保持“待读”。同一来源失败后改用其他合法入口，不逐轮重试。只在有助于制作或评审时更新 skill 的稳定资料。
