# 色彩脚本：从画面节奏到引擎呈现

用于单场景的关键色彩画面，也用于把多个 key 排成章节情绪、昼夜变化、过场与可玩区域的色彩脚本。连续的 color key 表达的是玩家经历中的**画面关系**，不是一组孤立的好看配色。概念图、3D 灯光、后处理与 UI/VFX 都要接受同一节奏检验。

## 先确定序列

- 列出玩家实际会经过的节点、镜头和停留方式：进入、探索、冲突、休息、揭示、退出。同一区域若因战斗、净化或剧情触发改变主明度、焦点或功能色，把触发前后及必要的过渡状态纳入序列，并注明能否回退；单一截图不能代表该区域的所有状态。若只做单幅 key，也要看进入前后或可能的光照变体。开放世界要列典型路线与可能的非线性顺序，而不是假设所有玩家只走一条线。
- 每个节点写清希望玩家先看见什么、要识别什么、情绪如何相对上一节点变化。把导航、敌我、可交互物和叙事焦点作为色彩与明度的功能约束。
- 区分作品的固有材质色、场景照明色、雾/空气透视、曝光与调色。概念图里一个暖色块，可能来自灯、材质或后期；传给 3D 时必须说明是哪一种。

## 制作与评审

1. 根据用途画小幅 key：章节、关卡或生物群落的情绪脚本按玩家会遇到的节点或区域排序，可保持布局粗略；若 key 已指定制作镜头，再统一构图比例。先组织主明度组与焦点，再比较相邻节点的最亮/最暗区域、留白密度和色彩变化；重复与反差要服务节奏。
2. 给每幅 key 标注对应区域/场景、时间天气、主要光源、玩家路线、视觉焦点、关键色的用途及前后关系；镜头级 key 再标具体机位。写相对关系即可；没有显示设备、色彩空间和项目规范时，不凭空指定最终 HEX 值。
3. 同屏查看所有 key，并单独抽出灰度版。检查关键交互与危险信息在不同色调环境仍可被识别；若信息只靠色相区分，增加形、亮度、运动或文字等独立线索。
4. 引擎落地时按 key 的用途对照：镜头级 key 用目标相机复拍；抽象色彩脚本在对应区域和实际路线中核主色关系、焦点与人物/敌人对比，不强求逐帧同机位。再查材质受光、反射、雾、曝光、色调映射和自发光怎样改变层级。夜景、逆光、室内外过渡、动态天气要看过渡过程，不只看单帧。
5. 同时检查 UI 与 VFX 是否夺走或支持焦点。想要压暗环境营造情绪时，仍须保证可玩区域的导航、攻击预警和文本信息可读。

## 交付形态

最小交付是一幅 key 或按体验顺序排列的一组 key，并为每幅写一句视觉意图；制作交接再附光源/材质/后期的来源说明；镜头级 key 给同机位对照，抽象脚本给对应区域的实景与连续路径对照。若关键节奏尚未实际试玩，标为视觉假设，安排目标显示设备、玩法视距和真实转场下的验证。

这一区分有明确的制作案例：[Julien Fenoglio 的《En Garde!》色稿说明](https://www.instagram.com/p/C3SLLYwqjrb/)说粗缩略图刻意不锁关卡布局；[Jemma Salume 的《Beast Breaker》访谈](https://www.gamedeveloper.com/art/how-color-scripting-conveyed-the-emotional-arcs-of-beast-breaker)及[原作序列](https://www.jemmasalume.com/art/games)把生物群落与故事节拍、角色和敌人色彩连在一起；[Matt Nava 的《Journey》回顾](https://mattnava.com/Journey-10th-Anniversary-Behind-the-Scenes-Retrospective)说明塔楼为接续雪山而改色。公开图与作者自述支持按用途交接，不证明玩家在正常速度下已经读懂这些转场。

这一状态检查有两种不同证据：[Jemma Salume 的《Beast Breaker》色脚本与采访](https://www.gamedeveloper.com/art/how-color-scripting-conveyed-the-emotional-arcs-of-beast-breaker)配合[发售后沼泽玩法录像](https://www.youtube.com/watch?v=KXca0iVrsrg)，可见同一沼泽的追踪画面与战斗画面有不同的功能色占比；大面积洋红来自兽体、攻击区域和战斗界面，不等于沼泽固有底色。[Ember Lab 技术美术 Nolan Carnahan 的 GDC 拆解](https://www.youtube.com/watch?v=bpFdfrg8SvY)说明《Kena》的 Dead Zone 清理由材质、植被、灯光与雾分层过渡；[发售后水神龛片段](https://www.youtube.com/watch?v=DFX9E5kp3G8)只显示局部红色腐化退去与蓝光出现，不能据此声称整片森林同步换色。这些案例支持按玩法状态与颜色来源核 key，不证明玩家在正常速度下感到预设情绪或准确识别危险。
