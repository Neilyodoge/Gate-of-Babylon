# 游戏 VFX 美术方向

用于技能、攻击预警、命中、状态、环境与 UI 特效。先问效果要传递什么信息：危险范围、攻击方向、命中确认、角色身份、强度变化，或纯氛围。特效的形、亮度和运动应服从这个任务及项目的视觉语言。

## 按事件评审

1. 写清触发条件与玩家必须作决定的时刻，把效果拆为预备、爆发/生效、反馈、消散。检查每一段是否来得及被看见；不能只用最终爆炸帧代替预警。
2. 记录形状、扩张方向、速度、明度峰值、色彩角色、粒子密度、余迹和声音/震动的配合。2D 逐帧/序列帧检查笔触与帧间节奏；3D 粒子/网格检查空间体积、相机角度、贴地关系与深度遮挡。
3. 区分友方、敌方、环境与 UI 特效在同屏时的层级。危险信息不能被更亮的装饰粒子、泛光、镜头震动或伤害数字淹没；同类技能可共用语法，但不同作用范围应能分辨。
4. 若视觉强度与实际判定范围或生效时间不一致，优先修正误导玩家的部分。绚丽程度、屏幕占有率和清晰度需要在真实战斗密度中取舍，性能预算则以目标平台测试为准。

## 验证与交接

用正常速度的实机录像，在最复杂的背景、典型相机距离和多个特效叠加时检查；慢放用于定位时序问题，不能替代正常速度判断。截帧看形与明度，完整片段看预警、命中和消散。快速闪烁、强光或镜头运动涉及舒适度与无障碍时，按目标平台要求和实际测试调整，不凭单帧宣称安全。

交接规格至少说明用途、触发与时序、各阶段的形/亮度/颜色、场景与角色的遮挡关系、音画同步点、可复用变体和待验证场景。没有项目数据时，不编造通用时长、粒子数或性能上限。
