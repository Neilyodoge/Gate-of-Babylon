苔间 4.16 · 卡牌远征试玩

1. 完整解压，打开「卡牌试玩.exe」。先看到一只桌宠，点「点这里，去冒险」或「展开」，再点「带泡泡出发」。
2. 试玩入口不读写平时存档，退出就结束。想长期保存，改用 TataFarmAdventure.exe / Launch.cmd。
3. 初次可先泼水，再打小小电花，再试泡泡盾；每次点牌底部「打出」。看敌人意图，自己决定何时结束回合。
4. 首战选牌后再选厚/脆泡泡分支；第二场就能试。厚泡泡保盾一次，脆泡泡破盾反击并让下回合多抽。蜗牛第一次挨打会缩壳，赤钳连攻两回合后休息，首领重击可用 12 实际伤害打断。战后选一张牌，或选择不加牌；普通路与险路各有取舍。休息与强化二选一，看过强化可以取消。
5. 共 5 场战斗，最后挑战苔冠守门人。结算显示本趟实际出牌、连招、战斗和收集记录。
6. 随时「缩成宠物」，不操作就不推进战斗。正常入口会自动保存完整回合，重新打开能接着玩。
7. Aa 调字号。Tab 选择、Enter/空格执行、Esc 返回/收起。旧小院在开场折叠项或「怎么玩」里。
8. 这是离线卡牌原型，目前只有泡泡的牌组。还没有联网收藏、玩家交易和真人对战。

请优先体验：第一组水电连招是否看得懂；拿到新卡后是否想试另一套组合；收起再打开是否能自然接着玩。
实际鼠标、系统缩放、游玩时长与真人理解未由后台验证替代。交付目录只保留最新通过验收的版本。

4.16：选牌提示能识别强化小雨点、强化深呼吸的加盾效果，补齐它们与泡泡冲撞的搭配。只展示当前牌组已有的搭档，不自动选牌。

4.15：试玩入口只识别同一包内的 TataFarmAdventure.exe，目录中残留的旧版文件不会阻止最新版启动。文件缺失或版本不匹配时，会提示重新完整解压最新包。

4.14：修正旧存档小物说明。电花每段加 2 伤害的旧效果，不再被显示成树叶帽的开局护盾；查看牌组与战利品都跟随实际状态。

4.13：营地满体力时，会突出「查看可强化的几张牌」，不再引导你去恢复 0 体力。查看后仍可返回，也能明确选择直接继续。受伤时显示实际恢复量，全部强化过时会说明。

能量足够时，手牌的「预计伤害」就是这次预计扣掉的敌人体力，已扣除护盾、计入当前连招。两段攻击显示合计；「敌盾挡住」说明被吸收的部分。出牌后会立即按新状态重算，查看不会出牌。能量不足时保留原说明。

敌人行动后的反击总伤害、保留护盾和破盾额外抽牌数会保留在上方，动作消失或看完牌组返回仍能回看。抽牌括号里的数字是实际总张数；牌不够时不会虚报额外收获。

战斗上方会保留「当前效果」，显示还在生效的保盾、破盾反击、受击反击和敌人减伤。再打其他牌也不会丢失；触发或到期后自动清除，没有效果时不占位置。

用键盘选中一张牌，再用鼠标看另一张，鼠标移开后会恢复键盘所选牌的提示。反过来也一样；战斗预测与战后搭配说明都支持。查看仍不替你出牌或领牌。

打出辅助牌后，会看到实际恢复体力、增加护盾/能量、抽到几张牌。满血不再笼统写“已生效”；手牌满或无牌可抽会解释结果。动作消失后，上方仍保留刚才的结果。超过 3 点的能量会标出额外量。

首次战斗提示跟随实际手牌和能量。先打盾或先打电花，也会给出当前能做的下一步；绿色按钮与提示对应，不强制按推荐顺序出牌。

牌组分区切换、返回后重新打开，会记住当前战斗状态里的阅读位置；营地强化列表也能恢复位置，返回营地按钮始终可见。出牌或进入下一场后重新从顶部看。

战后选牌时，移到牌上或 Tab 选中按钮，看看已经有几张同名牌、能接哪些现有招式。缺少潮湿或护盾铺垫时也会提示。查看不会领取，仍要点「加入牌组」。

打开「牌组」，查看想要的牌还没抽到、已经用过，还是本场用尽。重复牌显示数量，强化牌单列；查看和返回都不消耗。抽牌堆不展示先后顺序。长列表用滚轮或 PgUp / PgDn 翻页，Home / End 跳到首尾。

结束回合旁先看预计损失；鼠标移到牌上或 Tab 选中按钮，看看先打这张能否保护自己或击败敌人。预览不出牌，点击「打出」才执行。

能量在手牌正上方，三格圆点随出牌消耗。攻击有前冲、受击与数值反馈；用完能量可结束回合补满，有零费牌时仍可打出。
