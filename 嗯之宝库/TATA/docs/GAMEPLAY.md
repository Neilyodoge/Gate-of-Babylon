# 苔间 4.16 · 口袋远征

平时是一只桌宠，展开后陪泡泡打一趟五战卡牌冒险。无需账号、联网或出发材料。

## 操作与玩法

1. 打开卡牌试玩入口，先看到单只桌宠。点击冒险入口，再点「带泡泡出发」。
2. 观察敌人头顶的下一步意图。能量在手牌上方，数字与三格圆点同时表示剩余量；每张牌底部显示费用，点「打出」才使用。能量足够时，攻击牌显示本次预计扣掉的敌人体力，已扣除敌盾并计入当前连招；两段攻击显示合计，也计算蜗牛中途缩壳。被盾挡住的量单独列出。能量不足时保留原卡牌说明，不能出牌。
3. 每回合补到 3 能量，抽 4 张牌。回能牌可以让本回合超过 3 点，额外量会单独显示，下回合仍回到 3 点。能量用完可点「结束回合」，手里有零费牌时仍能打出。敌人只在明确结束回合时行动。结束按钮旁会显示现在结束预计掉多少体力；鼠标移到牌上或用 Tab 选中其按钮，会改为预览「先打这张再结束」的结果。鼠标与键盘交替查看时，显示最近查看的那张牌；移开后，另一张若仍被悬停或键盘选中，就恢复它的提示。预览不消耗，仍要点「打出」才执行。
4. 首次战斗的第一回合只提示一个当前能做的动作，并强调对应按钮。先出其他牌也能继续；没有可打的牌才提示结束回合。第二回合起自行选择。泼水让敌人潮湿，接电花造成额外伤害；护盾接泡泡冲撞也能形成组合。攻击前冲、受击轻晃、伤害与挡伤数值说明刚才发生的事。回血、加盾、回能和抽牌也显示实际变化；满血或手牌满时会说明。短暂动作结束后，最近一次出牌结果仍留在战斗上方，直到下一次行动。
5. 首战选牌后可把本局全部泡泡盾改成厚泡泡或脆泡泡，也能保持原样。第二场首手保证有变化后的盾。
6. 生效中的保盾、破盾反击、受击反击和敌人减伤会留在「当前效果」行，后续出牌不会把它们盖掉；触发或到期后清除。厚泡泡给 7 护盾并保留剩余护盾到下一回合一次；脆泡泡给 4 护盾，当回合破盾反击 8、下回合多抽 1 张，每回合至多触发一次。敌人行动后会留下实际反击总伤害、保留的护盾和破盾额外抽牌数；括号内是这一回合实际抽到的总张数。可抽牌不足时会说明，浏览牌组再返回仍可回看。
7. 蜗牛每回合第一次受到直接攻击后加盾，赤钳进攻两回合再休息，首领每第三回合的重击可用 12 点当回合实际伤害打断。
8. 战后把鼠标移到奖励牌上，或用 Tab 选中其按钮，可查看本局已有的同名牌数量，以及能与它配合的现有牌。强化小雨点和强化深呼吸的加盾也能配合泡泡冲撞，会计入真实搭档数量；基础版本不会误算。强化小雨点优先举已有的潮湿搭配，没有潮湿搭档但有冲撞时说明加盾搭配。没有对应搭档时会说明缺少铺垫；查看不会领取，点「加入牌组」才生效。战后可选牌或跳过，路线可走普通或险路，营地选择休息或强化。满体力时突出查看可强化的牌，并显示实际张数；也可以直接继续。受伤时显示实际恢复量，最多 16。全部牌都强化过时会说明。看牌、取消和返回不会替你选择或消耗。

点「牌组」可看整套牌；战斗时还能切换手牌、抽牌堆、弃牌和本场用尽。重复牌合并显示数量，强化牌单独列出。抽牌堆按种类排列，不是下一张牌的顺序；用尽的牌下一场才回来。长列表可用滚轮或 PgUp / PgDn 翻页、Home / End 到首尾，返回不会出牌或结束回合。同一战斗状态内切换牌堆、返回再打开会恢复滚动位置；出牌或进入下一场后重新从顶部开始。营地强化列表同样支持键盘翻页和位置恢复，返回营地按钮固定可见。

随时缩回桌宠。卡牌试玩不保存；正常程序保存手牌、牌堆、意图和本局进度。4.0 未结束的旧局仍按旧规则走完，新局启用当前规则。牌组页与战利品页按实际小物显示效果：树叶帽每场开局加 4 护盾；旧局已有的电花加成使小小电花、双生电花每段加 2 伤害，不提供开局护盾。旧小院作为次要玩法保留。

Aa 切换 100% / 115% / 130% 字号。Tab / Shift+Tab 选择按钮，Enter / 空格执行，Esc 返回或收起。关闭「播放桌宠动作」后保留静态数值反馈。

## 当前范围

一位冒险角色泡泡、15 种卡牌及强化版本、一条五战旅程；尚未加入联网收藏、交易和玩家对战。短局是设计目标，实际时长、理解度与耐玩性需要真人试玩验证。
