# 苔间 4.1 · game-ux-review

2026-09-29。模式 B，Windows 键鼠，单人短局卡牌与桌宠陪伴。依据用户已确认的设计方向，在当前项目实现卡牌分支和敌人习惯；文档见 design/口袋远征-玩法演进.md。上一轮为 4.0，本次新增教学选择与敌人机制，提前完整复核。继续使用 game-ux-review 的八项标准，已有实现与本地验证授权，不再逐项询问是否继续。

## 实现与检查发现

- 首战选牌后单独出现盾牌分支，明确作用于本局所有泡泡盾，也允许保持原样。选择不收费、不重抽、不自动出发。第二场首手保证一张变化后的盾，避免拿到新机制却试不到。
- 厚泡泡获得 7 护盾，打出当回合结束后保留剩余护盾一次；脆泡泡获得 4 护盾，本回合破盾反击 8，下回合多抽 1 张。多张脆盾和敌人多段攻击仍只触发一次；强化版保留额外 3 护盾。
- 蜗牛每回合第一次直接被攻击后缩壳加 5 护盾，第一击先结算，多段牌后续伤害能被护盾吸收，反击不触发缩壳。
- 赤钳连续进攻两回合后休息；路线预告这个节奏。守门人每第三回合重击，实际伤害 12 可打断，文字及进度条共同显示。护盾吸收不计入打断。
- 初次截图发现新增习惯提示挤压手牌区域，已缩小有习惯时的战斗插画，保留四张牌和结束回合的可见性。长牌组、抽到超过四张牌仍可滚动。
- 凉凉雾写的是“下次攻击”，原实现会在敌人任何回合结束时清除。新规则下改为真正攻击后清除，休息与架盾时保留。旧 4.0 局继续使用原行为。
- 整局规则版本、分支、待触发盾牌、蜗牛本回合缩壳与首领打断进度均保存。旧 4.0 未完局无新字段时仍按旧规则走完，新开局启用 4.1。

2. HUD 8.5/10，持平。体力、护盾、能量、意图、回合和场次持续可见；敌人习惯按当前敌人出现。首领打断使用数字和条长。遮去文字仍无法知道准确的卡牌与敌人规则，HUD 必不可少；濒败判断所需体力、盾和意图均可找到。
3. 菜单 8.5/10，持平。桌宠到战斗仍为展开、出发两步。分支是玩法选择，可保持原样；看牌与返回保留刚才状态。取消强化、收起和重开不解除暂停或追加消费。长列表重建后不记忆滚动位置仍是次要摩擦。
4. 商店 N/A。没有付费、账户、交易或联网发卡。免费的选牌不能算作商业购买退款能力。
5. 引导 7.5/10，持平。第一场仍先学水、电、盾；结束后才分两种盾，遇到对应敌人时才出现习惯。允许不改盾，出别的牌不会软锁。分支屏需要阅读两种规则和取舍，未证明首次玩家都能理解。
6. 输入 7.5/10，持平。实际 WPF 按钮完成分支、返回、出发，旧按钮重复事件无效；既有键鼠、Tab/Enter/Esc 与字号回归同次通过。真实鼠标移动、系统焦点、托盘、全局快捷键按用户限制未操作；没有重映射。
7. 可访问性 7.5/10，持平。100/115/130% 字号按最小内容 764×680 绘制，分支和战斗主按钮在实际视口。形状、文字和条长共同表达，灰度可辨；可关闭角色动作，回合无操作计时惩罚。无关键音频，字幕 N/A；真实 DPI 和辅助技术未测。
8. 一致性 8.5/10，持平。盾牌在手牌、牌组、强化预览和回执使用相同名称与准确效果；敌人意图与执行伤害相符。新旧小院结构仍不同，未在本轮重做旧菜单。
