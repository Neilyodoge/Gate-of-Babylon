# 风暴试场 / Stormfield

用于验证第三人称机动战斗、构筑和环境互动的 C# 几何原型。使用 .NET 9 与 Raylib-cs，不需要 Unity、商店资产或额外编辑器。

## 启动

双击本目录的 `Launch.cmd`，或直接运行 `build/Stormfield.exe`。按 Enter 进入安全区，再按 F 出发。初次试玩建议先用默认「脉冲枪 / 破阵」熟悉移动。

当前构建依赖 Windows x64 的 .NET 9 运行时，本机已经安装。复制给别的电脑时需安装 .NET 9，或运行 `Build.ps1 -SelfContained` 生成自包含构建。

## 操作

- WASD：相对镜头移动。鼠标：旋转镜头。滚轮：调整镜头距离。
- 鼠标左键：普通攻击，可持续按住。1：脉冲枪。2：弧光刃。
- Space：方向闪避，共两段，逐段恢复；闪避中短暂无敌。
- Q：冲击波。破阵构筑额外获得短时护盾，回路构筑范围更大。
- E：引力场，持续牵引、减速敌人，方便制造范围伤害机会。
- Tab：切换破阵 / 回路构筑。试玩版全部开放，便于直接比较。
- T：立即切换晴天 / 风暴，并固定天气。F2：恢复或停止自动天气循环。
- F：在安全区出发；在试场靠近中继塔后激活。
- H：返回安全区；当前已修复的中继会保留。
- R：同种子重新试验，**重置本轮的敌人、中继和计时**，保留累计完成记录。
- N：仅在安全区可用。生成新布局，**重置地区中继**，保留累计记录。
- V：切换近景 / 高位镜头。F6：慢动作。F8：无敌测试。
- F1：帮助。Esc：暂停并释放鼠标。Alt+Enter：无边框窗口切换。
- F4：截图，保存在 `build/data/`。

失去窗口焦点时会自动暂停，避免切换应用时被敌人击倒。

## 一次完整试验

1. 在安全区按 F 出发。
2. 清除入口平台的敌人，靠近黄色中继塔按 F，恢复部分生命并保存进度。
3. 沿连接桥继续前往导电中庭、守卫平台。右侧小地图显示路径、玩家和当前地区敌人。
4. 修复三个中继完成试验。按 H 返回，或 R 用同样布局换武器 / 构筑再试。

地图由三个手工区域的掩体变体及受约束的连接方向组合。同一个种子保持布局一致。这个版本验证的是区域组合的雏形，不代表完整的程序化关卡生成器。

## 构筑与风暴规则

- **破阵**：直接攻击伤害更高；Q 提供 24 点、持续 3 秒的护盾。适合主动贴近、闪避和近战尝试。
- **回路**：单次直接伤害较低，攻击可连锁附近两个敌人，晴天也有效；Q 范围更大。
- **风暴**：蓝色湿地区域导电。回路攻击命中水中的敌人，以及回路 Q 波及水面，会触发整片湿地放电；同片湿地中的玩家也会受伤。
- 落雷会先显示黄色收缩圆预警，再触发湿地放电。导电有短暂冷却，避免递归连锁无限触发。
- 普通敌人的红色近战圈、射手的瞄准线和守卫的范围圈都对应攻击前摇。闪避可以规避命中时机。

建议先固定晴天测试近战与远程，再用同一套装备切换风暴。重点判断：环境是否改变你的站位和目标选择；引力场是否带来聚怪机会；近战是否有足够接近和撤离空间。

## 修改参数

编辑根目录 `tuning.json`，重新运行 `Launch.cmd` 即可生效，无需重新编译。启动脚本会把根目录参数同步到 `build/tuning.json`。

- `MoveSpeed`：移动速度，世界单位 / 秒。
- `DashSpeed`、`DashDuration`、`DashRecharge`：闪避速度、持续秒数、每段恢复秒数。
- `MouseSensitivity`：鼠标灵敏度。
- `ProjectileDamage`、`MeleeDamage`：基础攻击伤害，构筑倍率另算。
- `EnemyDamageScale`：敌人及环境伤害倍率。
- `ClearDuration`、`StormDuration`：自动晴天 / 风暴的持续秒数。

## 源码与构建

- `Simulation.cs`：战斗、碰撞、敌人、区域生成、构筑、天气与存档；不依赖图形 API。
- `Program.cs`：窗口、输入、第三人称镜头和暂停菜单。
- `Renderer.cs`：几何角色、场景、攻击预警及中文 HUD。
- `SelfTests.cs`：布局、碰撞、闪避、导电、攻击、目标及存档边界测试。

安装 .NET 9 SDK 后，在本目录运行：

```powershell
dotnet run -c Release
dotnet run -c Release -- --self-test
./Build.ps1
```

发布后的数据位于 `build/data/progress.json`。保存地图种子、三个中继的修复状态、累计完成记录及解锁标记。角色位置、敌人血量、临时效果不保存；重新启动后从安全区继续。格式损坏的旧存档会保留为 `.invalid-时间` 文件。

中文字体在运行时读取本机黑体，不复制或重新分发系统字体。Raylib-cs 使用公开 NuGet 包，许可见 `THIRD_PARTY_NOTICES.md`。

## 当前边界

这是供实际手感测试的灰盒：没有商用角色动画、复杂连招、跳跃攀爬、联机、背包装备生成和完整长期经济。敌人使用简单的区域守卫与避障逻辑。几何近战只能测试攻击范围、移动和技能配合，不能代表动画驱动近战的最终打击感。

无敌、慢动作、随时换武器 / 构筑和手动天气属于试玩工具，未按正式游戏的解锁或平衡规则限制。
