# ProjectR CHANGELOG

> 仅记录 2026-09-02 ProjectR 产品重置后的有效变更，最新在上。旧产品历史通过版本控制追溯。

## P3.16 新手序章灵宠退场边界（2026-09-08）

- 初契确认后三只场景选择实体均退场：所选灵宠由技能栏／HUD表示已附着，另外两只由照料员带走。
- 序章战斗与回家路段不制作世界空间灵宠跟随，也不增加护送队伍或相关失败条件。
- 删除短暂加入的白盒同行组件与恢复逻辑；场景跟随留到局外家园阶段再评估。
- Unity编译和146项ProjectR契约测试通过。

## P3.15 新手序章救援／回家双检查点（2026-09-08）

- 序章进度升级为schema v9五态：未初契、已初契、已附着、救援完成、序章完成。
- 失控宿主结算后只提交`RescueCompleted`并开放回家路径；玩家抵达家园终点后才提交`Completed`。
- 战后退出或死亡可从新增`RescueResolvedMarker`恢复，并重建昏厥人宠占位，不再重打宿主。
- schema v8中数值3的旧完成档迁移时直接映射为v9正式完成，避免错误回退。
- 增加回家终点触发合同和迁移测试；Unity编译、146项ProjectR契约测试与战后恢复烟测通过。

## P3.14 新手序章白盒构图与镜头（2026-09-08）

- 将照料员和三幼宠从横向一排调整为面向玩家来路的三角构图，提高首次进入救援空地时的角色辨识。
- 初契选择、失控宿主登场和人宠分离加入短暂场景聚焦；镜头使用非缩放时间并自动恢复玩家跟随。
- 修正初契后的场景实体状态：所选灵宠离开选择位，另外两只留在照料员身边，符合后续随照料员回家的策划。
- 选择界面打开时隐藏常驻目标条，确认后恢复首次附着目标，避免模态标题与HUD重叠。
- 救援完成后回家终点显示轻量圆环与光束引导；Unity编译和ProjectR 145项契约测试通过。

## P3.13 新手序章引导与战斗边界（2026-09-08）

- 新增序章专用紧凑目标条，按进度显示救援、首次附着、两波战斗与回家目标，并显示目标距离。
- 救援战开始时按三处出生位建立低干扰圆环软边界；玩家越界只被放回边缘内侧并收到提示，不扣血或重置遭遇。
- 保留死亡后重载独立序章场景和`AttachmentChosen`检查点恢复，不重复开场、初契或首次附着。
- 实机确认目标条避开顶部区域标题、目标与距离正常更新、软边界可稳定放回玩家；ProjectR 145项契约测试与Unity编译通过。

## P3.12 失控宿主专属战斗（2026-09-08）

- 新增 `StarterProloguePossessedHost`，替换序章第二波的通用 `EnemyRanged`占位。
- 接入专属稳定值条、0.7秒直线能量波、约7秒一次冲步斩和半稳定值仅一次的近身溢出环。
- 稳定值归零通过序章专用回调完成人宠分离，不发布普通`EnemyKilled`，不触发掉落或人类死亡叙事。
- 白盒武器只显示蓝色属性能量流动，不在角色或武器上增加灵宠图标。
- Unity编译、145项ProjectR契约测试通过；实机确认三招执行、溢出环仅一次及非致死回调。

## P3.11 新手序章V2救援白盒（2026-09-08）

- 将序章战斗从“三训练靶→2近战＋1远程”改为“2只躁动近战灵宠→1名失控远程宿主”，删除训练靶和额外机关包装。
- `StarterPrologueTrainingRuntime`改为2目标与1目标的两阶段合同；失败仍按已附着检查点重载，完成后写入序章完成状态。
- 失控宿主结算后生成分离并双双昏厥的人宠白盒占位，不触发对话、逃跑或普通人类死亡叙事。
- 白盒Prefab区域改为家园外缘、救援空地、失控区和回家路径；加入照料员占位并保留三宠实体选择。
- 序章场景复用 `DungeonNavMeshRuntime`运行时构建导航，实机确认两只躁动灵宠均正常落在NavMesh。
- 更新Prefab与纯状态契约；ProjectR 145项契约测试、Unity编译和首波运行烟测通过。

## 摘星队、敌对单位与灵宠变体定案（2026-09-08）

- 首个人类团体暂定名为“摘星队”：追逐稀有灵宠、遗物与异常现象，前期制造麻烦，但成员立场不完全一致，为后续反转留空间。
- 敌对单位分为野生灵宠、由灵宠强化动作的敌对结契者、意识被异常灵宠／失衡回路压住的失控附身者三类。
- 失控附身被限定为罕见危险异常，不作为灵宠普遍天性，避免破坏伙伴定位。
- 同种灵宠可有普通花色与特殊变体；特殊变体最多改变1项技能侧重和1项性格权重，不形成全面更强的稀有上位。
- 新手序章改为摘星队强行共鸣造成能量倒流：成员与受困灵宠均失去自主，玩家三选一完成首次附着，先击退两只躁动灵宠，再直接打断失控者；连接断开后人宠分离并双双昏厥。
- 灵宠附着的世界空间视觉收敛为动作部位属性流动，不在角色或武器上显示灵宠图标；灵宠归属沿用现有技能栏／HUD挂件，失控仅增加属性流动异常、能量溢出和人物异常。
- 序章首战不增加额外机关或可破坏节点；失控者只使用直线波、冲步斩和一次溢出环，稳定值归零触发非致死人宠分离结算。

## 世界结构与家园术语收敛（2026-09-07）

- 采用单一自然幻想世界，只保留家园、秘境区域和当地异常。

- 主角旧设定撤回；只保留“主角独立战斗，灵宠附着动作并改变显化”的玩法关系。
