# ProjectR CHANGELOG

> 仅记录 2026-09-02 ProjectR 产品重置后的有效变更，最新在上。旧产品历史通过版本控制追溯。

## P3.49 初契序章V5开场与揭示节拍（2026-09-09）

- 新增非阻塞`StarterPrologueDialogueHUD`与`StarterPrologueOpeningBeat`：全新序章取得操作权后显示“主角｜照料员怎么还没来……”，目标同步改为“沿林间小路去看看”；已有初契检查点不会重播开场。
- `StarterPrologueChoiceTrigger`加入可序列化`revealFocus`。玩家进入低坡落地后的选择区时，先聚焦照料员并显示“先别过来！它们被失控的能量惊到了！”，再沿用0.7秒失控宿主预告并打开三宠选择；全程不暂停移动，只有选择界面打开后暂停。
- 在`StarterPrologueLayoutV5_BlockoutGuide.prefab`新增`MARKER_RevealLanding_ChoiceTriggerCenter`与挂接备注，建议在局部坐标`(0,-0.92,50)`放置选择触发器并把镜头焦点指向`MARKER_Caretaker`；仍不向范围Prefab加入玩法脚本或碰撞。
- Unity编译错误为0，155项ProjectR契约测试通过。临时新档烟测确认开场字幕、39米移动目标、照料员警告、异常预告到初契选择的顺序正常，退出PlayMode后正式存档恢复。

## P3.48 初契序章独立家园转场合同（2026-09-09）

- 新增`StarterPrologueHomeTransition`：宿主救援后先保存`RescueCompleted`，短暂展示收尾反馈后加载独立`ProjectRHome`；从救援检查点重进序章会自动重试转场，加载失败时不提前提交完成。
- 新增最小技术落点场景`Assets/1Game/Scenes/ProjectRHome.unity`与`ProjectRHomeSceneBootstrap`，只提供30×30米可替换地面、玩家出生、相机和公共系统，不冻结家园布局；只有该场景成功启动并确认玩家落点后才幂等写入`Completed`。
- V5目标HUD将救援后阶段改为“转场·家园”，开发计时器跨场景保留并将新档目标从旧7～9分钟调整为6～7.5分钟，以家园到达提交作为结束节点。
- 修正序章场景契约对当前`StarterPrologueLayoutV3.prefab`依赖的过期断言。Unity编译错误为0，154项ProjectR契约测试通过；临时新档烟测确认`StarterPrologue→ProjectRHome`、`RescueCompleted→Completed`、玩家／相机生成及退出PlayMode后正式存档恢复均正常。

- 按玩家草图将开场改为主角自言自语“照料员怎么还没来……”后直接取得操作权，沿两列树群之间的唯一道路完成移动与镜头教学。

- 新手序章改为摘星队强行共鸣造成能量倒流：成员与受困灵宠均失去自主，玩家三选一完成首次附着，先击退两只躁动灵宠，再直接打断失控者；连接断开后人宠分离并双双昏厥。
- 灵宠附着的世界空间视觉收敛为动作部位属性流动，不在角色或武器上显示灵宠图标；灵宠归属沿用现有技能栏／HUD挂件，失控仅增加属性流动异常、能量溢出和人物异常。
- 序章首战不增加额外机关或可破坏节点；失控者只使用直线波、冲步斩和一次溢出环，稳定值归零触发非致死人宠分离结算。
