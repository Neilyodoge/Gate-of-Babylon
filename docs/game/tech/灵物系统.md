## 3. 背包 ItemInventory

代码：`Babylon/Assets/1Game/Scripts/Items/ItemInventory.cs`

### 3.1 核心职责

1. 管理灵物持有列表（`Dictionary<ItemData, int>`）
2. 每次灵物变化时**重算所有属性**（`RecalculateStats`）
3. 检测质变阈值并调用 `ApplyQualitativeEffect`
4. 提供特殊效果查询（灼烧总 DPS、冻结概率、击杀回复）

### 3.2 RecalculateStats 流程

```text
1. 记录当前血量比例 hpRatio = currentHp / maxHp
2. 重置 _playerStats 为 _baseStats（一份 Clone）
3. 遍历所有灵物，累加：
   attackFlatBonus, attackPercentBonus
   hpFlatBonus, hpPercentBonus
   moveSpeedPercentBonus
   damageReductionBonus
   critRateBonus
   attackSpeedPercentBonus
   pierceBonus
   projectileSpeedPercentBonus
4. 应用最终公式：
   final = (base + Σflat) × (1 + Σpercent)
   damageReduction / critRate 用 Clamp01
5. 恢复血量比例：currentHp = maxHp × hpRatio
6. 发布 HealthChanged 事件
```

### 3.3 属性公式

| 属性 | 公式 |
|------|------|
| attackDamage | `(base + Σflat) × (1 + Σpct)` |
| maxHp | `(base + Σflat) × (1 + Σpct)` |
| moveSpeed | `base × (1 + Σpct)` |
| damageReduction | `Clamp01(base + Σflat)` |
| critRate | `Clamp01(base + Σflat)` |
| attackSpeed | `base × (1 + Σpct)` |
| pierceCount | `base + Σflat` |
| projectileSpeed | `base × (1 + Σpct)` |

### 3.4 质变检测

```csharp
// 在 AddItem 中
foreach (int threshold in item.qualitativeThresholds)
{
    if (count == threshold)
    {
        string effectDesc = ApplyQualitativeEffect(item, count);
        GameEvents.Publish(new GameEvents.QualitativeTriggered { ... });
    }
}
```

`ApplyQualitativeEffect` 内部：
- 对**有专属机制**的灵物（如火灵珠、玉佩、风灵珠、锈铁飞剑、回灵丹）→ 调用 `QualitativeEffectRunner.ActivateEffect("焚天"/"玉碎"/...)`
- 对**只有数值加成**的灵物（如破镜碎片、灵藤草、星辰尘、引魂灯）→ 直接修改 `_playerStats`（⚠️ 见第 8 节）
- 对未单独定义的灵物 → 走"分类共鸣"通用规则

## 4. 槽位 SpiritSlotSystem

代码：`Babylon/Assets/1Game/Scripts/Items/SpiritSlotSystem.cs`

### 4.1 槽位结构（梦之形风格）

```text
6 个灵物槽位，每个技能下方 2 个：
  Q 槽位 → SpiritSlot 0, 1
  E 槽位 → SpiritSlot 2, 3
  R 槽位 → SpiritSlot 4, 5
```

灵物拾取后**默认进入背包**，玩家可手动拖拽到槽位中。

### 4.2 在槽位中的额外效果

- **全局攻防血速等词条**：只按**背包持有数量**由 `ItemInventory.RecalculateStats` 聚合一次；槽位**不再二次叠加**同名数值（避免与背包重算冲突）。
- **槽位独占词条**（仅在槽位中生效，仍走增量 API）：
  - `skillChargeBonus`：通过 `PlayerCombat.AddChargeBonus` 增加对应技能的充能上限
  - `chargeSpeedBonusPercent`：通过 `GetSkillChargeSpeedBonus(skillSlotIdx)` 提供
  - `chargeDamageBonusPercent`：通过 `GetSkillChargeDamageBonus(skillSlotIdx)`（仅 Lv2/Lv3 生效）
  - `cooldownReductionPercent`：通过 `GetSkillCooldownReduction(skillSlotIdx)`（最高 100%）
  - `burnDamagePerSecond`：通过 `GetSlotBurnDPS` / 槽位查询（技能侧按需）
  - `freezeChance`：通过 `GetSlotFreezeChance(slotIdx)`

### 4.3 应用方式

`ApplyItemEffect` / `RemoveItemEffect` **仅处理槽位专属逻辑**（当前主要是 `skillChargeBonus` → `PlayerCombat` 充能层）。不再直接修改 `_playerStats` 的全局数值字段。

## 5. 协同 SynergySystem

代码：`Babylon/Assets/1Game/Scripts/Items/SynergySystem.cs`，静态类。

### 5.1 检测机制

`ItemInventory.AddItem / RemoveItem` 调用 `CheckSynergies(_items)`（不写 `CombatStats`）：

1. 统计每个 `ItemCategory` 的灵物数量
2. 遍历预定义 `SynergyDef`，检查 `requiredCategories + requiredCounts` 是否满足
3. 状态切换：
   - 满足且未激活 → 登记 `_activeSynergies` + `ActivateSynergyMechanism`（火墙 / 嗜血 / 元素爆发等）+ 发布 `SynergyActivated`
   - 不满足且已激活 → 移除登记 + `DeactivateSynergyMechanism`
4. `ItemInventory.RecalculateStats` 末尾调用 `SynergySystem.ApplyActiveSynergyStatModifiers(_playerStats)`，一次性施加当前激活组合的**数值**加成。

### 5.2 当前已注册的 10 个组合

| 名称 | 触发 | 主要效果 |
|------|------|---------|
| 风火轮 | 攻伐 ×3 + 身法 ×2 | 冲刺留火墙 + 移速 ×1.1 |
| 金刚不坏 | 护体 ×5 | 受击 30% 概率格挡反弹 + 减伤 +0.15 + maxHp ×1.1 |
| 天人合一 | 5 种分类各 ×2 | 每 30s 随机元素爆发 + 全属性 ×1.08 |
| 嗜血狂魔 | 攻伐 ×3 + 丹药 ×2 | 击杀后嗜血 5s（攻速 ×2 + 持续掉血） |
| 冰火两重天 | 攻伐 ×2 + 异变 ×2 | 暴击率 +0.1（灼烧+冻结描述未完全实现） |
| 灵龟护体 | 护体 ×3 + 丹药 ×2 | 减伤 +0.1 + maxHp ×1.15 |
| 疾风骤雨 | 身法 ×3 + 攻伐 ×2 | 攻速 ×1.3 + 移速 ×1.2 + 攻击 ×1.15 |

代码：`Babylon/Assets/1Game/Scripts/Items/QualitativeEffectRunner.cs`，挂在玩家身上的单例。

### 6.1 已实现的机制效果

| 效果 ID | 触发 | 行为 |
|---------|------|------|
| 焚天 | 火灵珠 ×5 | 每 5 次玩家攻击触发火焰冲击波（半径 4，伤害 15 + atk × 0.5），附加灼烧 |
| 玉碎 | 玉佩 ×5 | 致命伤害免疫，恢复 10% 血量 + 击退周围敌人，CD 60s |
| 御风 | 风灵珠 ×5 | 闪避后留下残影，持续 3s，每 0.8s 自动攻击最近敌人（伤害 = atk × 0.3） |
| 剑阵 | 锈铁飞剑 ×5 | 3 把飞剑环绕玩家，每 1s 对周围敌人造成伤害（8 + atk × 0.2） |
| 涅槃 | 回灵丹 ×5 | 死亡时消耗所有回灵丹原地复活，3s 无敌 |

### 6.2 协同机制效果

| 效果 ID | 触发 | 行为 |
|---------|------|------|
| 嗜血 | 嗜血狂魔协同 | 击杀后激活 5s：攻速 ×2，每秒掉血 2（最低保留 1HP） |
| 火墙 | 风火轮协同 | 冲刺起点→终点之间生成持续 2s 的火墙，0.5s 一跳，伤害 5 |
| 元素爆发 | 天人合一协同 | 每 30s 随机触发火/冰/风/雷 AOE（半径 5，伤害 25 + atk × 0.4） |

### 6.3 调用约定

- `OnPlayerAttackHit()`：每段攻击的 `OnSlashVFX` 动画事件触发，焚天计数
- `OnPlayerDash()`：闪避执行时调用，御风残影
- `OnPlayerDashForFireTrail(start, end)`：闪避执行时调用，火墙协同
- `TryJadeShield()`：玩家受致命伤前调用，返回 true 表示免疫
- `TryNirvana()`：玩家死亡前调用，返回 true 表示复活

## 8. 属性聚合管线（P0 已修复）

### 8.1 单一写入入口 + 槽位作为唯一来源

`CombatStats` 的全局战斗字段（攻、血、速、暴击等）**仅由** `ItemInventory.RecalculateStats()` 写入。**全局数值的来源是"当前在 `SpiritSlotSystem` 槽位中的灵物"**，背包仅记录"持有数量"作为相同灵物的叠加层数；不在槽位的灵物（未来用于特殊道具）不参与战斗数值聚合。

顺序：

1. 从 `_baseStats` 重置字段
2. 遍历 `SpiritSlotSystem.Slots` 中的灵物（同名去重），用其在 `_items` 中的持有数量聚合 flat + 百分比
3. `ApplyQualitativeStatModifiers()`：仅对**当前在槽位**的灵物，按"持有数量达阈值"施加质变**数值**（焚天大成、万剑归宗等）
4. `SyncQualitativeMechanisms()`：同步机制性质变（焚天 / 玉碎 / 御风 / 剑阵 / 涅槃），槽位条件不满足则调用 `DeactivateEffect`
5. `SynergySystem.ApplyActiveSynergyStatModifiers()`：按当前激活 Synergy 施加数值（CheckSynergies 同样以"槽位灵物字典"为输入）
6. 钳制 `damageReduction` / `critRate`，按血量比例写回 `currentHp`

`ApplyQualitativeEffect` 仅负责阈值提示与一次性满血标记；机制是否生效由 `SyncQualitativeMechanisms` 按槽位状态统一决定。质变乘区数值由第 3 步统一计算，不再在阈值回调里直接写 `_playerStats`。

### 8.2 槽位变更触发重算

`SpiritSlotSystem.SetSlot` / `SwapSlots` 在写入新槽位状态后会调用 `ItemInventory.RecalculatePlayerStats()`：

- 把灵物从槽位拖出 / 替换 → 该灵物对全局数值的贡献立刻为 0；
- 协同、质变数值、机制类质变随之失效；如剑阵会销毁环绕飞剑，焚天会清空攻击计数，玉碎 / 涅槃会关闭可触发状态。

### 8.3 背包的角色

- **数量表**：记录玩家拾取的"层数"，供槽位灵物的属性按 `flat * count` 与 `percent * count` 聚合，以及给协同 / 质变阈值判定使用。
- **未来特殊道具**：背包还可承载不放入槽位的特殊道具（如剧情触发物、消耗品），这些不会参与战斗数值聚合。

### 8.4 扩展：未来的 StatsCalculator

可将上述步骤抽成独立 `StatsCalculator` 类；当前逻辑已在单一方法内完成等价管线。历史背景见 [复查 P0-1](../../reviews/2026-04-28-战斗系统阶段性复查.md#p0-1-三套加成同时改-_playerstats互相覆盖属性系统不稳定)。

## 9. 扩展指南

### 9.1 新增灵物属性词条

1. 在 `ItemData` 中添加新字段
2. 在 `ItemInventory.RecalculateStats` 的**槽位聚合循环**中累加新字段（`GetSlotItemsWithCount`）；若为质变乘区，同步在 `ApplyQualitativeStatModifiers` 中按数量判定
3. 若协同需要数值，在 `SynergySystem.ApplyActiveSynergyStatModifiers` 中增加对应 `case`
4. 在 `CombatStats` 中添加对应属性（如需要）

### 9.2 新增机制类质变效果

1. 在 `ItemData` 中保留 `qualitativeThresholds`
2. 在 `QualitativeEffectRunner.ActivateEffect` 中加入新的 `case "效果ID"`
3. 在 `QualitativeEffectRunner.DeactivateEffect` 中加入对应退出逻辑
4. 在 `ItemInventory.AddDesiredQualitativeEffect` 中写入"槽位灵物 + 持有数量阈值 → 效果ID"映射
5. 在 `ItemInventory.ApplyQualitativeEffect` 中仅返回提示文字 / 一次性标记，不直接激活机制
6. 实现具体机制：触发时机由 `OnPlayerAttackHit / OnPlayerDash / OnEnemyKilled / TryJadeShield / TryNirvana` 等钩子提供

### 9.3 新增协同组合（Synergy）

在 `RegisterDefaultSynergies` 中追加 `SynergyDef`（名称、描述、条件、`displayColor`）；在 `ActivateSynergyMechanism` / `DeactivateSynergyMechanism` 中接线机制；在 `ApplyActiveSynergyStatModifiers` 中写数值分支。

### 9.4 新增特殊效果（如冻结、连锁）

1. 在 `ItemData` 中添加效果参数字段（如 `freezeChance`、`chainLightningCount`）
2. 在 `ItemInventory` 或 `SpiritSlotSystem` 中添加查询方法（如 `GetFreezeChance()`）
3. 在 `Projectile.OnTriggerEnter` 或 `PlayerCombat.CheckMeleeHit` 中使用查询结果
