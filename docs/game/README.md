### 快速开始

1. 在 Unity 中创建新场景 → 保存到 `Assets/1Game/Scenes/Demo1.unity`
2. 创建空 GameObject → 挂载 `Demo1Setup` 组件
3. （可选）右键 Create → 仙途梦境 → 灵物数据/功法数据，配置后拖入 Inspector
4. 点击 Play 即可运行
