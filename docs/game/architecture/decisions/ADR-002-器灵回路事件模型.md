# ADR-002：器灵回路采用事件与因果链模型

- 状态：已接受
- 日期：2026-09-02

## 背景

旧模块链按单个技能编译 Trigger、Effect 和 Modifier。ProjectR 要求多只器灵跨武器、术法和身法相互产生、响应和转化结果。

## 决策

回路运行时采用带标签的事件模型。每个 `CircuitEvent` 携带来源、载体、器灵、因果链、深度和预算；器灵通过“源／应／化”规则订阅和派生事件。

## 约束

- 同类事件在同一因果链中限制重复次数。
- 链深、单帧派生数和自动触发频率有硬上限。
- 派生事件保留完整来源，支持HUD和战后分析。
- 通用标签规则覆盖大部分组合；招牌融合是显式内容。
- 配置不能直接执行任意代码。

## 后果

- 可以复用 `GameEvents`、`ModuleChain` 和 Proc / Consume 经验。
- 需要独立的回路模拟、校验和调试视图。
- 伤害数字必须能追溯到最终器灵和载体。
- 性能预算应以事件派生数而非器灵数量衡量。
