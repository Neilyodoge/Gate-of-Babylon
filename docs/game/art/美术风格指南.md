# 🎨 美术风格指南

## 视角

- **Top-down 3D**，参考《梦之形》（Dreamscaper）视角风格
- 固定俯视角，相机跟随玩家

## 整体风格（待定）

### 方案 A：水墨仙侠
- 水墨渲染风格（Toon Shading + 墨迹边缘）
- 淡雅配色，留白意境
- 特效以水墨晕染为主

### 方案 B：赛博仙侠
- 古风 + 霓虹光效混搭
- 暗色调 + 高饱和度发光
- 特效以粒子光效为主

### 方案 C：低多边形仙侠
- Low-poly 风格，简洁几何
- 明快配色
- 开发效率最高
