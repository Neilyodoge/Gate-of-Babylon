# ProjectR 游戏测试清单

> 每轮测试只验证少量明确假设。记录行为、犹豫点和误解，不用口头解释替代游戏反馈。  
> 验证范围：[ProjectR GDD](../design/GDD_秘境探索.md) · [垂直切片](../delivery/垂直切片计划.md)

## 测试前

- [ ] 记录版本、Seed、配置和测试设备。
- [ ] 开发期点击工具栏“启动游戏”或`ProjectR/开发工具/新手序章/临时新档测试`会无确认框直接创建全新序章档；退出PlayMode后确认正式槽位已恢复且测试进度不会带入下次。
- [ ] 明确本轮最多3个验证问题。
- [ ] 清空或固定测试存档。
- [ ] 确认伤害来源、回路事件和区域状态日志可导出。
- [ ] 确认撤离、死亡和强退恢复路径。

## 新手序章

- [ ] 玩家在离开林间会合点前理解“今天原本要和三只幼宠见面，主角想找到共同探索的伙伴”，不会把初契理解成路边随机捡宠。
- [ ] 玩家能看出出生地是旅途中的会合点而非家园，不会寻找种植、整备、居民或室内入口。
- [ ] 主角说完“照料员怎么还没来……”后，玩家不看箭头也会进入两列树群之间的唯一道路，并在前半段自然完成移动与镜头试操作。
- [ ] 玩家越下低坡前只能听见事故，落地后才第一次完整看见照料员、三宠与远端异常；“先别过来”警告、照料员聚焦和宿主短预告顺序清楚，约1米自动越坡不会被误解为新增跳跃操作。
- [ ] 战后转场清楚表达即将前往家园，玩家不会在序章地图寻找回程道路、尝试逆向跳坡或等待新出口开放。
- [ ] 用全新存档从取得操作权玩到家园转场，总时长控制在6～7.5分钟、初契不晚于2分30秒；保存日志中的初契、首次附着、救援完成和家园加载完成时间。
- [ ] 救援完成后先安全存档；家园加载失败或中途退出时能从救援结果继续转场，不重打宿主、不重复初契。
- [x] 程序烟测确认临时档可从`StarterPrologue`加载`ProjectRHome`，到达前保持`RescueCompleted`、家园启动后提交`Completed`，并生成玩家与主相机；退出PlayMode后测试存档自动恢复。仍需在V5白盒上人工验证失败／中退恢复体验。
- [ ] 照料员迟到后，唯一出口、远处异响与3点自然微光能把玩家从等待地点引向救援空地，不会被误解为可收集物、技能资源或必须逐个触碰的目标。
- [ ] 初契弹窗前的短镜头足以说明远处存在失控者和蓝色能量异常，但不会让玩家误以为此时已经进入战斗。
- [ ] 选宠前不出现可攻击目标；玩家能理解“先邀请一只灵宠合作，再进入第一次战斗”。
- [ ] 顶部阶段标签能让玩家分清约定／寻找、遇险、初契、躁动灵宠、失控宿主和归途；0.22秒切换反馈不会遮挡战斗或被误认成新弹窗。
- [ ] 序章只显示生命、技能栏、灵宠附着和阶段目标；不出现探索区域、房间进度、敌人／碎片计数或小地图等未使用信息。
- [ ] 60度斜俯视能同时看清角色动作、前方道路和敌人预警；近侧墙体不持续遮挡玩家，远侧目标不会因透视缩小而难以辨认。
- [ ] 救援战软边界在场地中央不制造常驻视觉噪声，接近边缘时足够醒目；越界回推不会被误解为受击或瞬移技能。
- [ ] 玩家无需额外说明也能理解摘星队强行共鸣造成能量倒流，人和受困灵宠都失去自主，照料员正保护三只幼宠。
- [ ] 玩家能看出野生灵宠、由灵宠强化的人类和被失控能量占据意识的人类之间的区别。
- [ ] 玩家能结合武器／动作部位的属性流动与技能栏／HUD挂件识别附着关系；角色和武器上不需要额外灵宠图标。
- [ ] 失控附身的属性流动异常、能量溢出、失焦目光和僵硬动作足以区别正常结契，但不会制造过量视觉噪声。
- [ ] 初契确认在60秒内完成，玩家知道另外两只只是离开、以后仍可能遇见。
- [ ] 首次附着三动作卡不遮挡关键场景，44度聚焦构图不引起突兀缩放或眩晕，决策不超过45秒；玩家能预判LMB、Q灵息弹、SPACE三种时机差异，并理解数字键只是快捷选择。
- [ ] 初契确认后Q槽立即显示灵息弹；选择附着Q并命中敌人时能触发所选灵宠显化，不出现空槽、空附着或必须重进场景才生效。
- [ ] 首次附着后，两只低威胁躁动灵宠能让三只首发灵宠的任一附着在10秒内出现一次清楚显化。
- [ ] 弹弹胶附着身法时，终点脉冲的推开距离清楚但不过强；打断躁动灵宠和失控宿主预警后，原攻击不会继续命中玩家。
- [ ] `2只受失衡刺激的近战灵宠＋1名失控附身者`会促使玩家使用移动、普攻、Q和闪避，但不会形成失败墙。
- [ ] 两只躁动灵宠与失控宿主共用24×20米空地仍能形成清楚的阶段变化；中间10～15秒喘息足以让玩家恢复视线，但不会误以为战斗已经全部结束。
- [ ] 直线能量波、冲步斩和一次溢出环的预警互不混淆，不依赖额外机关或节点解释战斗。
- [ ] 战斗结束后玩家能理解目标是击散倒流能量并救回双方，而不是杀死摘星队成员或受困灵宠。
- [ ] “失控解除”与“初契完成”里程碑卡能确认救援和回家结果，但2.4秒显示不会遮挡移动、目标或后续操作。
- [ ] 人宠分离后双双昏厥且生命状态清楚；不触发苏醒、逃跑、跟随或额外摘星队剧情。
- [ ] 失败重试不重播开场、不重复初契、不重复授予灵息弹。
- [ ] 初契确认后三只选择实体均自然退场；玩家能从HUD确认所选灵宠已附着，并理解另外两只由照料员带走。
- [ ] 结尾明确是带新伙伴回家；首区尚未制作时不会出现错误跳转或空承诺。

## 首次理解

- [ ] 玩家能在5分钟内解释玩家动作与灵宠显化的区别。
- [ ] 玩家能指出一条“源—应—化”关系。
- [ ] 玩家知道灵宠不额外占技能按钮。
- [ ] 玩家知道新结契灵宠必须撤离才能永久获得。

## 构筑

- [ ] 玩家主动尝试过让灵宠改附动作。
- [ ] 玩家能看懂改附后保留了什么。
- [ ] M键回路总览能让玩家在10秒内指出“哪只灵宠附在哪个动作、负责什么”；统计页中的伤害／治疗／防御／资源来源与实战反馈一致。
- [ ] 三宠分别改为 `1＋1＋1／2＋1／3＋0` 后，玩家能从实际输入次数和动作顺序感到结构差异；拖拽预演与提交后的真实回路一致，战斗中改附必定被阻止。
- [ ] 长回路中玩家能借助P2.20D的中间状态文字、待接动作高亮和到期提示，分清当前等待响响鸮还是弹弹胶。
- [ ] P2.20D提示验证：12秒火花和10秒复响是否过紧或过松；玩家能否在不读长文字时仅凭槽位高亮完成接续；倒计时是否遮挡敌人预警，状态到期是否有足够明确但不吵闹的反馈。
- [ ] 玩家形成至少一条两段互动。
- [ ] 玩家在中后期形成三灵回路。
- [ ] `1＋1＋1`、`2＋1`、`3＋0`至少各被一名测试者主动选择。
- [ ] 玩家能从反馈判断是哪只灵宠触发了结果。
- [ ] 可选战斗统计中的动作、灵宠、回路数值与玩家主观理解一致，且没有重复计入总量。

## 探索与生态

- [ ] 玩家根据模糊情报做过路线选择。
- [ ] 玩家观察到一个区域行为改变邻区。
- [ ] 玩家能在结果出现前形成基本预测。
- [ ] 风痕林谷第一次缩短探索能在清理倒木坡后找到静风空地并主动撤离，不误以为必须寻找Boss。
- [ ] 完整探索中，玩家在旧导流槽选择前能预测“湿苔窝／蓄水坑／盘根团块”至少两处变化；选择后水面、通路、灵宠、地图情报和Boss外壳结果一致。
- [ ] 两个短环至少促成一次先后顺序选择，而不是让玩家始终沿唯一方向清图。
- [ ] 秘境躁动产生压力但没有让玩家停止思考。
- [ ] 玩家能找到撤离点和候选出口。
- [ ] 玩家理解Boss不是唯一进度钥匙。

## 结契与伙伴

- [ ] 玩家理解至少两种结契方式。
- [ ] 玩家能解释某只灵宠的性格。
- [ ] 玩家能区分普通花色与特殊变体，不把特殊变体理解为必然更强的稀有上位。
- [ ] 同种特殊变体的1项技能偏移和1项性格偏移可被感知，但仍明显属于同一灵宠种族。
- [ ] 玩家在成熟回路与新灵宠之间做过真实取舍。
- [ ] 玩家记得至少一只具体灵宠，而非只记得颜色或强度。

## 灾相

- [ ] 玩家能识别Boss的产生、响应或转化节点。
- [ ] 探索准备明确改变Boss机制。
- [ ] 盘根团块的三处根结可被辨认；改水冲开根结与温和结契救援结局不表现成隐藏伤害加成。
- [ ] 直接挑战和准备后挑战都可完成。
- [ ] 不存在必须携带指定器灵的硬锁。
- [ ] Boss战不退化成纯血量检验。

## 家园与结算

- [ ] 正常整备时间为3–5分钟。
- [ ] 玩家能完成编队、查看灵宠天赋树开放进度和3项准备。
- [ ] 已拥有器灵不会因失败丢失。
- [ ] 新器灵只在成功撤离后进入永久契匣。
- [ ] 玩家能说清本局获得和失去的内容。

## 技术观察

- [ ] 无无限递归、事件风暴或明显掉帧。
- [ ] 无伤害来源缺失。
- [ ] 同一Seed能复现关键地图和生态状态。
- [ ] 回访房间不重新抽取遭遇。
- [ ] 门、碰撞、NavMesh和场景状态一致。
- [ ] 强退恢复不会复制结契灵宠或奖励。

## P2.19F2 自动训练采样（2026-09-08）

条件：攻击力10、目标防御0、每组18次已结算玩家命中；分别使用1个高血量目标和4个邻近高血量目标。记录真实MonoBehaviour、Physics、协程、投射物与结构化伤害归因链；它验证数值与触发，但不替代人工操作手感。

- 无天赋基准：单目标27伤害，4目标45.9伤害。
- 火花狸：速燃为2.02×／2.59×，爆火为2.88×／3.26×，蓄热为1.33×／1.49×。
- 响响鸮：清响为3.12×／1.84×，远听为1.00×／1.92×，留声为1.00×／1.24×。
- 弹弹胶：连弹为1.00×／1.85×，重击为1.00×／3.36×，回弹为2.22×／1.60×。
- 首轮曾出现爆火4目标4.31×、重击4目标4.90×、清响单目标3.88×；已把爆芯范围倍率0.55→0.35、砸坑倍率0.60→0.35、裹火倍率0.18／0.24→0.12／0.18、只说重点集中倍率1.80→1.35。
- 修正后路线角色已分开：清响偏单体，远听／连弹偏多目标，蓄热／留声偏资源与后续状态，重击保持多目标爆发但不提高无第二目标时的基础伤害。
- 待人工验证：蓄热与留声的低即时伤害是否能被资源收益感知；重击3.36×群伤是否仍抢占爆火定位；所有路线的屏幕反馈是否与统计来源一致。
- 人工手感测试延期到高阶单宠路径和战斗反馈稳定后进行；届时额外记录输入节奏／响应延迟、触发来源辨识、范围效果视觉噪声、自动选敌可信度、天赋重选负担，以及键鼠和手柄的操作差异。
- 单宠高阶专项：确认火轨／隔次连燃／留火种能区分“本次触发”和“储存后消费”；满谷回响／只说重点／留一句能从范围、集中和延后三种反馈上被立即分辨；回起点的目标选择可信，五连弹不会拖慢输入节奏，裹火／砸坑叠加时不遮挡敌人预警，逐跳加速能被看见但不过快丢失目标。
