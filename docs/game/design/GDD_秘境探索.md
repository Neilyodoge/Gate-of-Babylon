## 1. 游戏概述

### 1.1 一句话描述

> 一款冒险题材的 Roguelike Top-down 3D ARPG（参考《梦之形》视角风格），玩家扮演立志终极挑战成功的冒险者，在基地休整修炼与关卡历练之间循环，通过拼装触发器、效果器和改造件构建无限可能的 Build，探索秘境探索的终极真相。

### 1.2 参考作品分析

**《Shape of Dreams / 梦之形》的不足（我们要解决的问题）：**

| 问题 | 我们的解决方案 |
|------|--------------|
| Build 多样性有限，几局后见过所有东西 | 150+ 模块 + 100+ 隐藏组合，理论 Build 数近乎无限 |
| 宝石系统偏数值，缺乏机制深度 | 不做独立宝石系统；将其降级为"模块改造件 / 符文"，作为触发器和效果器的第三层修饰 |
| 叙事/世界观薄弱 | 冒险世界观 + 意志/威胁度 + 多结局抉择，碎片化剧情 + 终极悬念 |
| 缺乏长期目标（Meta Progression） | 完整的局外成长系统：模块解锁 + 触发器强化 + 起始模板 + 前哨蓝图 / 寿命强化 |
| 重玩价值低 | 起始模板 × 随机模块 × 隐藏组合 = 每局体验差异化 |

### 1.3 文档制作规范
目前随着策划的加入，对表格的需求也愈发重要，因此在此设计好一系列规范和准则，让整个流程可以更好地与其他人协调制作，下面进行说明；
- **关于表格的制作说明**：
大部份设计会添加表格进行控制，控制范围会针对每项功能进行定制；
未提及表格的功能则默认不制作表格；
制作表格时，可根据说明的核心需求自行判断是否增加表格的控制范围，但需要在每次更新后进行详细说明（可直接修改文档进行说明）；
设计表格目的是为了可以在各个功能中进行灵活的控制和调整，方便策划或其他人进行修改；

## 2. 世界观与叙事

玩家扮演一名进入危险关卡探索的冒险者。基地是玩家的休整、配置与长期成长场所；关卡是玩家进行长局构筑、挑战 Boss、获取经验值和解锁线索的主要场景。

叙事目标是服务 Roguelite 循环：每一次死亡、返回或通关都会让玩家更理解世界、更接近终局真相。剧情通过 Boss、事件、记忆碎片、基地 NPC 和多结局逐步展开。

## 3. 核心循环

```text
基地
  → 结算经验值
  → 提升模块熟练度 / 解锁起始模板 / 配置前哨与补给
  → 选择起始模板进入关卡

关卡
  → 获取触发器 / 效果器 / 改造件
  → 拼出本局 Build
  → 阶段返回、死亡或通关
  → 按不同倍率结算经验值
```

**结算结果**：

| 结果 | 经验倍率 | 设计目的 |
|------|---------|---------|
| 死亡 | 0.5x | 失败也能推进局外成长，但收益明显低于主动返回 |
| 阶段返回 | 1.0x | 玩家主动收手，保守结算 |
| 通关 | 2.0x | 奖励完整长局与高风险挑战 |
| 完美通关 | 3.0x | 额外奖励无死亡 / 高难度挑战表现 |

**局外成长**：
- 经验值是唯一通用局外资源。
- 来源标签只影响经验转化方向，例如战斗、模块、触发器流派、探索、情报、Boss。
- 成长出口包括模块熟练度、起始模板、前哨蓝图、寿命强化和剧情推进。

### 3.1 基础数值系统

模块系统必须建立在统一基础数值上，后续所有模块只修改这些字段。

| 字段 | 初始值 | 规则 |
|------|-------|------|
| **生命值 HP** | 100 | 归零后进入死亡结算；可被治疗、护盾和复活类模块影响 |
| **护盾 Shield** | 0 | 先于生命承伤，默认不自然回复，只由模块或房间奖励提供 |
| **移动速度 MoveSpeed** | 5.0 单位 / 秒 | 可被模块临时修改，上限 150% |
| **攻击速度 AttackSpeed** | 100% | 影响普攻动作时长，上限 150%，不压缩输入缓冲到 150ms 以下 |
| **暴击率 CritRate** | 5% | 默认暴击伤害为 150% |
| **技能冷却 Cooldown** | 由模块定义 | 冷却缩减上限 50% |
| **闪避充能 DodgeCharge** | 2 层 | 可被模块临时提高，上限 4 层 |

生命、护盾、攻速、移速和冷却是模块平衡的基础字段；没有写入这些字段的模块，不应直接修改底层战斗表现。

## 4. 触发器流派系统

### 4.1 起始模板：教学方向，不是职业锁定

起始模板只负责解决两个问题：
1. **新手方向感**：开局知道自己这一局大概围绕什么逻辑玩。
2. **早期可玩性**：开局至少拥有一组能运转的触发器 / 效果器 / 改造件。

模板提供的是**起始装配方案**，不是把效果预接进触发器。触发器、效果器、改造件仍然是三个独立模块。模板不限制后续 Build，玩家在局内可以捡到其他模块并完全转向。

| 模板 | 起始触发器 | 起始效果器 / 改造件 | 教学目标 |
|------|-----------|-------------------|---------|
| **播种者** | 种子生成、种子引爆 | 毒雾 / 扩散符文 | 教玩家理解状态载体与状态消耗 |
| **刺客** | 闪避后、背击标记 | 突刺 / 连击符文 | 教玩家理解位置与窗口 |
| **指挥者** | 傀儡计数、傀儡协同 | 护盾 / 分流符文 | 教玩家理解多单位协作 |
| **雷行者** | 移动 X 米、闪避成功 | 落雷 / 连锁符文 | 教玩家理解移动触发与连锁 |
| **守卫者** | 受击时、护盾破裂 | 冲击波 / 延时符文 | 教玩家理解防御反击和延迟收益 |
| **炼金师** | 时间间隔、拾取后 | 治疗 / 范围符文 | 教玩家理解节奏触发和续航 |

### 4.2 模块熟练度：取代天赋树

| 成长对象 | 解锁内容 | 示例 |
|---------|---------|------|
| **触发器熟练度** | 状态展示强化、条件降低、触发变体 | 种子上限 +1；背击标记持续更久；移动触发距离降低 |
| **效果模块升级** | 解锁新的技能效果或强化已有效果 | 毒雾可治疗玩家；护盾破裂爆炸；突刺可穿透 |
| **改造模块升级** | 强化技能的形态变化 | 扩散范围扩大；连锁次数 +1；延迟爆炸范围扩大 |
| **起始模板熟练度** | 开局替换推荐模块或增加备选项 | 播种者可把毒雾替换为治疗，或在开局奖励池中提高 Seed 标签权重 |

这样保留长期成长，但不再增加"独立天赋树"这一层 UI 和规则。

### 4.3 熟练度升级字段映射

| 模块对象 | 可升级字段 | 不可升级字段 |
|---------|-----------|-------------|
| **条件型触发器** | 触发阈值、冷却、窗口时间、计数上限 | 直接伤害、治疗量 |
| **状态型触发器** | 状态上限、持续时间、可见性、状态消耗规则 | 直接伤害、持续伤害、治疗量 |
| **效果器** | 伤害、治疗量、范围、持续时间、目标逻辑、冷却 | 触发条件 |
| **改造件** | 范围、次数、连锁、延迟、代价比例、槽位读取范围 | 独立触发条件 |
| **起始模板** | 初始模块替换、备选模块数量、推荐掉落权重 | 局内强制锁定流派 |

起始模板升级分为两种：**替换**表示把已有初始模块换成同定位模块；**新增备选**表示开局多一个选择入口，但同一局仍只装配固定数量的初始模块。

## 5. 模块化技能系统（Trigger + Effect + Modifier）

### 5.1 核心逻辑：[触发] → [执行] → [改造]

技能不再是一个整体，而是由三类模块拼装而成：
1. **触发器 (Trigger)**：定义"什么时候"发动。
2. **效果器 (Effect)**：定义"发动什么"效果。
3. **改造件 (Modifier)**：定义"这个效果如何变形"。

```
[触发器：移动 10 米] + [效果器：落雷] + [改造件：连锁]
  = 跑动中自动落雷，命中后连锁到附近敌人

[触发器：种子引爆] + [效果器：毒雾] + [改造件：扩散]
  = 引爆已存在的种子状态，生成毒雾并扩散一次
```

### 5.2 模块分类总规则

所有局内 Build 部件统一叫**模块**，只分三大类：

| 大类 | 负责问题 | 设计边界 | 例子 |
|------|---------|---------|------|
| **触发器** | 什么时候发动 / 用什么状态承载 | 不负责主要伤害，只提供条件、节奏或状态载体 | 移动 X 米、攻击 X 次、种子生成、背击标记 |
| **效果器** | 发动后具体做什么 | 不改变触发条件，只定义伤害、位移、治疗、召唤、控制等结果 | 落雷、毒雾、突刺、护盾、召唤傀儡 |
| **改造件** | 这个效果如何变形 | 不单独成为技能，必须依附触发器或效果器生效 | 连锁、扩散、延迟、分裂、左侧强化 |

每个模块都必须有标签，标签用于掉落权重、兼容判断、隐藏组合和局外升级。

| 标签维度 | 用途 | 示例 |
|---------|------|------|
| **模块大类** | 判断槽位位置 | Trigger / Effect / Modifier |
| **功能标签** | 判断玩法类型 | Damage / Defense / Heal / Mobility / Summon / Control / State |
| **触发标签** | 判断启动来源 | Attack / Move / Hit / Kill / Time / Dodge / State |
| **形态标签** | 判断改造兼容性 | Projectile / Area / Melee / Aura / Chain / Object |
| **节奏标签** | 判断主动或被动 | Passive / Active / Charge / Cooldown / Proc |
| **流派标签** | 用于推荐掉落和隐藏组合 | Seed / Backstab / Puppet / Lightning / Poison |

### 5.3 触发器分类 (Trigger Types)

触发器决定技能启动条件或状态载体。触发器只分两层：**条件型**和**状态型**。

| 子类 | 说明 | 示例 | 必填字段 |
|------|------|------|---------|
| **战斗行为触发** | 根据攻击、命中、暴击、连击等行为触发 | 攻击 X 次、暴击后、连击第 3 段 | 行为类型、计数阈值、冷却、是否消耗层数 |
| **移动 / 闪避触发** | 根据移动距离、冲刺、闪避窗口触发 | 移动 X 米、闪避成功、冲刺结束 | 距离阈值、窗口时间、冷却、方向限制 |
| **受击 / 防御触发** | 根据受到伤害、格挡、护盾破裂触发 | 受击时、护盾破裂时、低血量时 | 伤害条件、生命阈值、冷却、防重复触发规则 |
| **时间 / 节奏触发** | 根据固定时间、蓄力、房间节奏触发 | 每 X 秒、蓄力满、进入新房间 | 时间阈值、是否受冷却缩减影响、初始延迟 |
| **击杀 / 事件触发** | 根据击杀、拾取、开箱、Boss 阶段等事件触发 | 击杀后、精英死亡、Boss 进入二阶段 | 事件来源、目标限制、触发次数上限 |
| **状态型触发** | 创建标记、层数、召唤物或计数器 | 种子生成、种子引爆、背击标记、傀儡计数 | 状态名、层数上限、持续时间、默认状态展示 |

条件型触发器包含战斗行为、移动 / 闪避、受击 / 防御、时间 / 节奏、击杀 / 事件五个子类；状态型触发器单独作为第六类。

状态型触发器只提供**无伤害状态展示**，例如种子落点、破绽标记、傀儡计数 UI、蓄力层数。它们不造成伤害、不治疗、不控制敌人；主要强度必须来自接上的效果器和改造件。

### 5.4 效果器分类 (Effect Types)

效果器定义触发后的具体结果。效果器需要声明自己能被哪些改造件影响。

| 子类 | 说明 | 示例 | 常用标签 |
|------|------|------|---------|
| **伤害输出** | 造成直接伤害、持续伤害或爆发伤害 | 剑气、落雷、火球、毒雾、冲击波 | Damage / Projectile / Area / DoT |
| **控制 / 状态** | 改变敌人行动或附加状态 | 减速、眩晕、击退、标记、易伤 | Control / State / Debuff |
| **防御 / 回复** | 提供生存能力 | 护盾、回血、净化、短暂无敌 | Defense / Heal / Buff |
| **位移 / 位置** | 改变玩家或敌人的位置 | 突刺、拉拽、传送、击飞 | Mobility / Melee / Position |
| **召唤 / 场物** | 生成持续存在的单位或区域 | 傀儡、炮台、毒池、陷阱 | Summon / Object / Area |
| **资源 / 状态操作** | 消耗、转化或刷新已有状态 | 引爆种子、刷新层数、消耗破绽、获得充能 | State / Consume / Charge |

### 5.5 改造件分类 (Modifier Types)

改造件是原"宝石 / 槽位修饰"的重定位。它们不作为独立系统出现，而是作为模块化技能的第三层。

| 子类 | 作用 | 示例 | 兼容规则 |
|------|------|------|---------|
| **形态改造** | 改变效果覆盖方式 | 火球 → 火墙；毒雾 → 毒环；落雷 → 雷域 | 需要 Area / Projectile / Object 标签 |
| **目标改造** | 改变目标选择逻辑 | 最近敌人 → 最远敌人；单体 → 链锁；前方 → 环绕 | 需要 Targetable 或 Projectile 标签 |
| **数量改造** | 改变次数、投射物或召唤数量 | 额外触发 1 次；投射物 +2；召唤物 +1 | 需要可重复执行的效果 |
| **节奏改造** | 改变释放时机或持续方式 | 瞬发 → 延迟爆炸；一次性 → 持续；自动 → 蓄力 | 需要 Cooldown / Duration / Charge 字段 |
| **状态改造** | 附加元素、异常或状态交互 | 火焰、寒冰、雷击、毒蚀、击退、易伤 | 需要 Damage / Control / State 标签 |
| **槽位改造** | 根据模块相邻位置改变收益 | 左侧强化、右侧强化、双重投射、上下联动 | 属于环境型改造件，需要读取槽位布局和相邻模块标签 |
| **代价改造** | 用风险换强度 | 消耗生命提高伤害；延长冷却换范围；降低防御换连锁 | 必须明确代价、上限和 UI 提示 |

**设计边界**：
- 改造件不提供独立长期成长，长期强化交给模块熟练度 / 解锁节点。
- 改造件不单独占用一个系统入口，统一在技能模块界面内配置。
- 改造件可以来自局内掉落、模块经验标签解锁、前哨改造或特殊事件。
- 如果一个改造件只能写成 `伤害 +10%`，它就不该成为改造件；至少要改变形态、目标、节奏或策略。
- 改造件分为**依附型**和**环境型**。依附型只读取被连接模块；环境型可以读取相邻模块或槽位布局，但必须在 UI 上高亮影响范围。

### 5.6 执行模式规则

执行模式属于**模块链属性**，不是效果器分类。

| 模式 | 触发后表现 | 槽位占用 | 是否可切换 | 适用模块 |
|------|-----------|---------|-----------|---------|
| **被动模式** | 条件满足后立即自动释放 | 占用一个被动模块链槽 | Demo 阶段不可切换 | 高频、低爆发、辅助或自动循环 |
| **主动模式** | 条件满足后技能图标亮起，玩家按 Q / E / R 释放 | 占用一个主动技能槽 | Demo 阶段不可切换 | 爆发、大范围、位移、保命或高风险收益 |

同一条模块链在设计表中必须声明默认模式。是否允许切换由字段 `ModeSwitchRule` 控制；Demo 阶段默认不开放局内自由切换，避免 UI 和数值复杂度失控。

### 5.7 模块配置字段规范

后续策划表中，每个模块至少需要配置以下字段：

| 字段 | 说明 |
|------|------|
| **ID / 名称** | 唯一 ID 和展示名 |
| **模块大类** | Trigger / Effect / Modifier |
| **子类** | 使用上文分类，例如战斗行为触发、伤害输出、目标改造 |
| **标签** | 用于兼容、掉落、推荐和隐藏组合 |
| **稀有度** | Common / Rare / Epic / Legendary，用于掉落价值和强度预期 |
| **基础参数** | 伤害、范围、持续时间、层数、冷却、触发阈值等 |
| **兼容条件** | 可连接哪些模块标签，不能连接哪些模块标签 |
| **掉落来源** | 普通房间、精英房、商店、事件、Boss、前哨补给 |
| **解锁条件** | 默认开放、经验值解锁、Boss 解锁、剧情解锁 |
| **升级项** | 局外升级后改变的字段 |
| **执行模式** | Passive / Active，以及是否允许切换 |
| **UI 描述** | 玩家能直接看懂的一句话效果 |

### 5.8 插槽与组合逻辑 (Socket Logic)

插槽布局由起始模板、局外解锁和本局事件共同决定。基础规则只允许一条清晰的模块链：

```text
[触发器 Trigger] → [效果器 Effect] → [改造件 Modifier 0-2 个]
```

| 连接方式 | 规则 | 是否属于基础规则 |
|---------|------|----------------|
| **主链连接** | 1 个触发器连接 1 个效果器，形成可执行技能 | 是 |
| **改造连接** | 0-2 个改造件依附在触发器或效果器上，改变其行为 | 是 |
| **环境读取** | 环境型改造件读取相邻模块标签或槽位位置 | 是，但仅限明确标注的改造件 |
| **双效果器组合** | 2 个效果器合并成复合效果 | 否，Demo 阶段不作为基础规则；如需要，做成隐藏组合或特殊模块 |

普通模块链只产生模块描述中的基础效果。隐藏组合必须在普通链之外附加额外条件或额外质变，不能与普通三件组合完全同义。

### 5.9 操作模型

```
【近战普攻】—— 鼠标左键，三段连招
  → 三段连招：Attack1 → Attack2 → Attack3
  → 段伤害倍率：1.0 / 1.2 / 1.5
  → 基础动作时长：0.4s / 0.4s / 0.5s
  → 攻速加成上限：150%
  → 扇形判定：半径 2.5，角度 120°
  → 攻击中"霸体"：轻击受击不打断连招
  → 250ms 输入缓冲：流畅连段
  → 每段带前冲 Lunge 位移

【模块化技能】—— Q / E / R 三个槽位
  → 每个槽位可配置一个 [触发器] + [效果器] + [改造件] 组合
  → 主动模式下，满足触发条件后按键释放
  → 被动模式下，满足触发条件后自动释放

【闪避】—— Space 键
  → 距离 5 单位，持续 0.2s
  → 无敌帧共 0.3s：闪避前摇 0.05s + 闪避持续 0.2s + 收尾 0.05s
  → 2 层充能，每层 CD 1.5s；模块可临时提高到最多 4 层
```

## 6. 隐藏组合系统（Synergy）

### 6.1 设计哲学

> 隐藏组合不再围绕旧式掉落部件堆叠，而是围绕模块链的行为变化。
> 普通模块链负责基础效果；隐藏组合负责在满足额外条件时产生质变。

### 6.2 组合触发规则

| 触发类型 | 说明 | 示例 |
|---------|------|------|
| 模块链触发 | 指定合法模块链存在，并满足额外标签或行为条件 | Seed 标签 ≥ 3，且毒雾链击杀 10 个敌人 |
| 状态消耗 | 某个状态被另一个模块消费时触发 | 背击标记被突刺消耗 |
| 行为条件 | 玩家连续完成某种操作 | 连续 3 次从背后释放主动模块 |
| 高风险组合 | 强收益伴随明确代价 | 低血量时双倍爆炸，但持续掉血 |

**链长度规则**：
- 普通链固定为 `1 触发器 + 1 效果器 + 0-2 改造件`。
- 隐藏组合最短 3 个模块，最长 5 个模块。
- 隐藏组合不能只复述普通链效果，必须额外满足标签数量、房间行为、状态消耗次数、生命阈值或 Boss 阶段等条件。

### 6.3 隐藏组合列表

| 组合名 | 触发条件 | 额外质变 |
|--------|---------|---------|
| 百草齐放 | 种子引爆 + 毒雾 + 扩散符文，且本房间毒雾击杀 ≥ 10 | 毒雾击杀敌人后生成 1 个新种子状态，形成可继续引爆的循环 |
| 荆棘回春 | 种子生成 + 治疗 + 扩散符文，且 Seed 标签 ≥ 3 | 种子被消耗时产生小范围治疗脉冲 |
| 无影连杀 | 背击标记 + 突刺 + 连击符文，且连续背击击杀 ≥ 3 | 刷新一次短距离闪避，并提高下一次背击窗口 |
| 破绽雷击 | 背击标记 + 落雷 + 连锁符文，且目标身上有破绽 | 落雷优先命中破绽目标，并对破绽目标额外连锁 1 次 |
| 傀儡护阵 | 傀儡协同 + 护盾 + 分流符文，且场上傀儡 ≥ 2 | 护盾在傀儡之间分流，并在破裂时产生小范围冲击 |
| 跑雷 | 移动 X 米 + 落雷 + 连锁符文，且 5 秒内未停止移动 | 连锁次数 +1，并在玩家路径上留下短暂电痕 |
| 延时爆破 | 受击时 + 冲击波 + 延时符文，且生命值低于 35% | 延迟爆炸范围扩大，但触发后 3 秒内受到治疗降低 |

### 6.4 Synergy 发现与展示

**首次触发时：**
- 屏幕提示组合名。
- 模块链高亮。
- 图鉴解锁完整描述。

**重复触发时：**
- 只显示小提示，避免打断战斗。

## 7. 关卡设计

### 7.1 房间类型

| 房间 | 作用 | 主要产出 |
|------|------|---------|
| **普通战斗房** | 基础战斗与模块掉落 | 普通模块、经验值 |
| **精英房** | 高风险高收益挑战 | 高稀有度模块、Boss 来源标签经验 |
| **事件房** | 提供取舍、代价、隐藏组合线索 | 特殊模块、情报标签经验 |
| **商店房** | 消耗局内货币换模块或治疗 | 指定模块、回血、刷新机会 |
| **休息房** | 低压恢复和调整 Build | 治疗、模块替换、前哨补给 |
| **Boss 房** | 阶段目标和通关门槛 | 高倍率结算、Boss 标签经验、剧情推进 |

### 7.2 层级结构

一局暂定 6 层，每 2 层出现一次阶段返回点，第 6 层为 Boss 突破挑战。玩家可以在阶段返回点按 1.0x 结算离开，也可以继续推进获取更高通关倍率。

### 7.3 难度递增

- 敌人生命、伤害、数量随层数递增。
- 精英和 Boss 优先投放能反制玩家当前 Build 的机制。
- 难度增长应主要来自行为变化，而不是单纯数值膨胀。

## 8. 经济与资源

### 8.1 资源层级

| 资源 | 类型 | 是否带出本局 | 用途 |
|------|------|-------------|------|
| **经验值** | 局外通用资源 | 是，按结算倍率折算 | 模块升级、模板升级、剧情推进 |
| **来源标签** | 经验值标签 | 是 | 决定经验值倾向，例如模块、探索、Boss、情报 |
| **局内货币** | 本局临时资源 | 否 | 商店购买、刷新、治疗 |
| **模块** | 本局 Build 部件 | 默认否 | 构成本局技能链 |
| **情报** | 线索型来源标签 | 是 | 解锁 Boss 线索、隐藏组合提示、剧情节点 |

### 8.2 模块掉落与推荐

模块掉落采用“基础权重 + Build 相关性 + 保底修正”的方式：

```text
最终权重 = 基础权重 × 稀有度权重 × 来源权重 × Build 相关性 × 保底修正
```

| 因素 | 规则 |
|------|------|
| **基础权重** | 每个模块表内配置 |
| **稀有度权重** | Common 高、Legendary 低 |
| **来源权重** | 普通房偏基础模块，精英 / Boss 偏高稀有度模块 |
| **Build 相关性** | 当前已装配标签越匹配，权重越高，但不超过 2.0x |
| **保底修正** | 连续 3 次未出现可用效果器时，提高效果器权重 |

推荐逻辑只影响候选池权重，不强制玩家进入固定流派。

## 9. 术语表

| 术语 | 定义 |
|------|------|
| **模块** | 局内 Build 部件总称，只分触发器、效果器、改造件 |
| **触发器** | 定义发动条件或状态载体，不提供伤害、治疗、控制 |
| **效果器** | 定义发动后的结果，例如伤害、治疗、位移、控制 |
| **改造件** | 改变触发器或效果器的形态、目标、数量、节奏、代价 |
| **隐藏组合** | 合法模块链在额外条件下触发的质变规则 |
| **前哨** | 局外配置、局内消耗的临时支援点，用于补给、休息或调整模块 |
| **寿命强化** | 提高单局容错的局外成长项，例如复活次数、死亡后保留部分结算倍率 |
| **情报** | 来源标签之一，来自事件、Boss 线索、隐藏房和剧情节点 |
| **阶段返回** | 关卡中途主动结束本局并按 1.0x 结算 |
