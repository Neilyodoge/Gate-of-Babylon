# 载体与回路

> 状态：垂直切片设计  
> 上位文档：[ProjectR GDD](../GDD_秘境探索.md)

## 核心关系

载体负责“执行什么动作”，器灵负责“动作触发什么规则”。

```text
玩家输入
  → 载体动作
  → 器灵产生“源”
  → 其他器灵以“应”观察
  → 以“化”改写结果
  → 新事件可继续进入回路
```

## 动作载体

- 武器：普通攻击与特殊攻击。
- 术法：两个主动能力。
- 身法：闪避、格挡、瞬移或钩索。

载体必须独立可用。器灵附着后改变规则和表现，但不能用自动战斗取代玩家操作。

## 器灵回路语言

每种器灵由以下能力组成：

1. 核心产物：狐火、护甲、标记、回声、召唤物等。
2. 响应条件：命中、暴击、穿越、聚集、破碎、受伤、消耗等。
3. 转化结果：爆炸、传导、复制、治疗、固化或再生。
4. 载体显化：附着于不同载体时怎样改变动作。
5. 性格偏置：触发时机、目标和风险收益变化。

所有运行时事件至少记录来源实体、载体、器灵、标签、深度和因果链 ID，防止无法追踪的递归触发。

## 附着结构

- `1＋1＋1`：三只器灵分居三个载体，适合长回路。
- `2＋1`：两只器灵叠契形成融合能力，另一只辅助。
- `3＋0`：三只器灵共居一个载体，形成极端构筑。

同一载体上的第一只器灵负责主要显化，其余器灵响应或转化其产物。三种结构应改变操作和构筑关系，而不是只改变数值效率。

## 局内成长

### 更换载体

改变动作形态。迁灵后，器灵本局获得的悟法不丢失。

### 器灵悟法

- 源：改变产生什么。
- 应：改变响应什么。
- 化：改变最终转化成什么。

每只器灵的临时悟法数量受限，避免回路不可读。

### 载体铭刻

只改变载体动作，例如范围终结、跟随旋涡、碎盾投射和蓄力反击。

### 联契反应

当一只器灵持续消费另一只的产物时累积共鸣，解锁保留产物、回路再触发、双灵合击或三灵闭环。

## 构筑节奏

- 0–10分钟：选定载体，形成两段互动。
- 10–25分钟：接通三灵回路，获得联契。
- 25–35分钟：闭环、三灵共器或终结强化。

成熟路径应是：

```text
能互动 → 能连锁 → 能闭环 → 能产生受控的失控爆发
```

## 防爆与可读性

- 每条事件链限制最大深度和同类重复次数。
- 自动触发必须有频率或预算上限。
- 回路UI显示产物、响应、转化和断点。
- 战后分析能追溯主要伤害、防御和资源来源。
- 器灵触发必须有轮廓、笔触、音效或短暂显形。
- 通用规则覆盖约80%组合，招牌融合只覆盖少量高契合组合。

## 垂直切片范围

- 2种武器、4种术法、2种身法。
- 4只器灵和源／应／化悟法。
- `1＋1＋1`、`2＋1`、`3＋0`都能完成有效构筑。
- 1套回路预览、实时触发反馈和战后来源分析。

## 验收标准

- 玩家能在5分钟内解释“源—应—化”。
- 同一器灵换载体后明显改变玩法。
- 换载体不会抹掉器灵成长投资。
- 三种附着结构都有独立使用理由。
- 任意回路不会产生无限递归或不可解释伤害。

## 未决问题

- 每只器灵的悟法槽数和重抽规则。
- 首批标签字典与禁止组合。
