# 灵宠与结契

> 状态：垂直切片设计  
> 上位文档：[ProjectR GDD](../GDD_秘境探索.md)
> 路径暂不重命名以避免链接与 `.meta` 断裂；程序内部继续使用 `Spirit*`。

## 目标

- 让灵宠成为具有永久身份的伙伴，而不是可替换的数值词条。
- 让获取过程体现灵宠性格、生态和玩家选择。
- 建立局内临时使用与撤离后永久获得之间的风险。

## 非目标

- 不做个体值、完美胚子和强制繁殖。
- 不让稀有灵宠全面强于普通灵宠。
- 不设置永久死亡、现实时间伤病或强制休息。
- 不把灵宠做成第二套主动技能栏；灵宠没有独立施法按键，战斗效果必须经所附着动作显化。

## 永久身份

每只灵宠实例拥有稳定 GUID，并保存：

- 种族配置 ID
- 主、次性格倾向
- 与玩家的羁绊
- 与其他灵宠的关键关系
- 已解锁的动作适应（程序字段暂保留载体适应命名）
- 天赋树永久开放范围与解锁进度
- 外观与故事状态

种族决定核心机制，性格改变触发时机、风险偏好和操作方式，关系解锁默契效果与招牌合击。

## 获取路径

所有普通野生灵宠原则上都能战斗和结契。

### 新手初契

- 新手关卡开局从火花狸、响响鸮、弹弹胶中选择1只；选择前只展示名字、性格短句和战斗倾向，不安排三宠试玩。
- 选择后立即成为永久灵宠并设为出战成员，不经过撤离提交；这是教学保底的唯一例外。
- 另外2只不会自动赠送，后续通过常规结契路径获得。
- 初始个体暂使用默认性格占位，具体性格表现待首批性格设计确认。
- 初契后赠送可替换的基础Q术法“灵息弹”，再引导玩家将已选灵宠附着到当前有效的武器、Q术法或身法。
- 初契对象永久确定，第一次附着不锁死；玩家可在安全处重新换挂。
- 三只灵宠各自在武器、术法和身法上拥有可独立启动的显化，不依赖玩家尚未获得的其他灵宠。

完整流程与三宠三动作规则见：[新手关：初契序章](../levels/新手关_初契序章.md)。

### 强制降服

通过战斗削减灵识完成结契。获取稳定，战斗过程可以影响性格倾向。

### 性格结契

完成符合个体倾向的目标，例如决斗、保护、献物、欺骗或探索。

### 解谜与剧情结契

发现隐藏区域并解决灵宠过去的问题。奖励特殊外观、固定性格、天赋节点开放或支线内容，不提供全面数值优势。

### 腐化净化

玩家可以击杀腐化灵宠换取即时收益，也可以破坏污染源并避免致命攻击，将其净化为永久伙伴候选。

### 灵卵与残器

在家园孵化或修复。培育环境影响性格和外观，不产生需要反复刷取的个体值。

## 结契状态机

```text
发现
  → 满足战斗／性格／解谜条件
  → 临时结契
  → 收入契匣或本局借契
  → 成功撤离
  → 写入永久灵宠实例
```

未撤离的新灵宠不会进入永久存档，但已发现的图鉴知识可以保留。

## 本局借契

- 新灵宠可以替换一只出战灵宠。
- 被替换的已有灵宠安全返回契匣。
- 新灵宠按当前探索进度获得补偿局内等级或待分配天赋点。
- 玩家需要在成熟旧回路与未知新伙伴之间做取舍。

## 天赋成长

每只灵宠拥有固定天赋树。局外通过共同探索、关系、专属事件和关键战斗永久开放更多可选节点；局内通过杀敌、战斗地点和区域目标升级，只点亮有限节点形成当局构筑。

局内等级和点亮状态在单局结束后清空，不采用“每局保留一项随机悟法进入永久池”的成长方式。详细规则见：[灵宠天赋树](灵宠天赋树.md)。

## 垂直切片范围

- 首先验证火花狸、响响鸮、弹弹胶3只工作名灵宠，再扩至4只；最终每只2种性格表现。
- 战斗降服、性格结契和解谜结契各1个实例。
- 临时借契与撤离提交。
- 腐化净化、灵卵、繁殖和大规模家园生态不进入首个切片。

## 验收标准

- 玩家能解释为什么该灵宠愿意结契。
- 同种不同性格能改变战斗使用方式。
- 新灵宠未撤离时不会写入永久契匣。
- 已有灵宠在死亡、替换和读档后不会丢失。
- 玩家不会只依据稀有度判断灵宠价值。

## 未决问题

- 首批三宠的性格差异、外形细节与最终名称。
- 普通材料死亡保留比例。
- 解谜个体的特殊内容是否可被同种其他个体学习。
