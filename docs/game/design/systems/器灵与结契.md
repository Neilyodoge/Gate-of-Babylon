# 器灵与结契

> 状态：垂直切片设计  
> 上位文档：[ProjectR GDD](../GDD_秘境探索.md)

## 目标

- 让器灵成为具有永久身份的伙伴，而不是可替换的数值词条。
- 让获取过程体现器灵性格、生态和玩家选择。
- 建立局内临时使用与撤离后永久获得之间的风险。

## 非目标

- 不做个体值、完美胚子和强制繁殖。
- 不让稀有器灵全面强于普通器灵。
- 不设置永久死亡、现实时间伤病或强制休息。

## 永久身份

每只器灵实例拥有稳定 GUID，并保存：

- 种族配置 ID
- 主、次性格倾向
- 与玩家的羁绊
- 与其他器灵的关键关系
- 已解锁的载体适应
- 可配置的悟法池
- 外观与故事状态

种族决定核心机制，性格改变触发时机、风险偏好和操作方式，关系解锁联契与招牌融合。

## 获取路径

所有普通野生器灵原则上都能战斗和结契。

### 强制降服

通过战斗削减灵识完成结契。获取稳定，战斗过程可以影响性格倾向。

### 性格结契

完成符合个体倾向的目标，例如决斗、保护、献物、欺骗或探索。

### 解谜与剧情结契

发现隐藏区域并解决器灵过去的问题。奖励特殊外观、固定性格、可学习悟法或支线内容，不提供全面数值优势。

### 腐化净化

玩家可以击杀腐化器灵换取即时收益，也可以破坏污染源并避免致命攻击，将其净化为永久伙伴候选。

### 灵卵与残器

在洞府孵化或修复。培育环境影响性格和外观，不产生需要反复刷取的个体值。

## 结契状态机

```text
发现
  → 满足战斗／性格／解谜条件
  → 临时结契
  → 收入契匣或本局借契
  → 成功撤离
  → 写入永久器灵实例
```

未撤离的新器灵不会进入永久存档，但已发现的图鉴知识可以保留。

## 本局借契

- 新器灵可以替换一只出战器灵。
- 被替换的已有器灵安全返回契匣。
- 新器灵按当前区域深度获得一次补偿悟法。
- 玩家需要在成熟旧回路与未知新伙伴之间做取舍。

## 垂直切片范围

- 4只器灵，每只2种性格表现。
- 战斗降服、性格结契和解谜结契各1个实例。
- 临时借契与撤离提交。
- 腐化净化、灵卵、繁殖和大规模洞府生态不进入首个切片。

## 验收标准

- 玩家能解释为什么该器灵愿意结契。
- 同种不同性格能改变战斗使用方式。
- 新器灵未撤离时不会写入永久契匣。
- 已有器灵在死亡、替换和读档后不会丢失。
- 玩家不会只依据稀有度判断器灵价值。

## 未决问题

- 首批4只器灵及完整机制。
- 普通材料死亡保留比例。
- 解谜个体的特殊内容是否可被同种其他个体学习。
