# 洞府与局外成长

> 状态：垂直切片设计  
> 上位文档：[ProjectR GDD](../GDD_秘境探索.md)

## 目标

洞府服务于伙伴关系、队伍配置和下一局准备。单次停留目标为3–5分钟。

## 非目标

- 不做持续维护的自动化流水线。
- 不做现实时间等待。
- 不通过无限数值成长替代本局构筑。
- 不将重复器灵融合成经验材料。

## 核心功能

### 编队

从永久契匣中选择3只器灵，查看性格、关系、适应载体和悟法池。

### 悟法池

每只器灵可以沉淀本局真正发挥作用的一项临时悟法。入局前只配置有限候选，防止永久池不断扩张并稀释随机结果。

### 三项准备

每轮最多选择3项：

- 探路：提前显示一个稀有栖息地。
- 锻器：选择一件起始武器。
- 研法：提高某类术法载体出现概率。
- 温养：让一只器灵开局获得额外悟法选择。
- 联训：两只器灵更快触发首次共鸣。
- 建设：解锁洞府区域与互动。

准备必须改变开局方向或信息，不直接交付成熟闭环。

### 关系事件

器灵在洞府中生活、工作和交流。关键关系变化通过明确事件交由玩家确认，不能在后台悄悄覆盖性格。

## 永久成长

- 前期生命和基础伤害总成长约10%–15%，快速封顶。
- 长期成长以载体适应、悟法、联契、故事、设施和外观解锁为主。
- 新器灵可以较快进入现有队伍。
- 已拥有器灵永远不会因单局失败丢失。

## 重复器灵

重复个体可以：

- 留在洞府承担轻量工作。
- 组成探索队。
- 迁居不同环境。
- 自愿归野，推进生态研究。

重复个体的价值来自身份、性格和关系，不来自分解经验。

## 撤离与失败

- 新结契器灵：成功撤离后永久获得。
- 普通材料：失败保留一部分，比例待定。
- 灾相核心与特殊蓝图：需要成功撤离。
- 地图知识与图鉴信息：永久保留。
- 本局载体与临时悟法：默认不直接带回。

## 存档边界

永久存档：

- 器灵实例和契匣
- 悟法池与载体适应
- 关系和故事状态
- 洞府设施
- 图鉴、蓝图和货币

本局存档：

- 当前层、Seed和区域状态
- 出战器灵与附着
- 临时悟法、载体和铭刻
- 新结契候选
- 暂存材料和撤离要求

## 垂直切片范围

- 契匣和3灵编队。
- 每只器灵有限悟法池。
- 3项出发准备。
- 少量洞府互动。
- 新结契提交、材料提交和失败清理。

暂不制作完整栖息模拟、自动工作链和大规模建设。

## 验收标准

- 一次正常整备能在5分钟内完成。
- 永久成长主要增加选择，不持续堆叠强度。
- 新结契器灵只有撤离后写入永久存档。
- 失败不会丢失已有器灵。
- 玩家能从洞府行为识别器灵身份，而不只看到菜单数据。
