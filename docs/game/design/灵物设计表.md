## 叠加规则

### 线性叠加
每获得一个相同灵物，效果线性增加。

### 质变叠加
达到特定数量时触发质变，效果发生质的飞跃：
- **x3**：第一次质变
- **x5**：第二次质变（更强）

### 属性计算公式
```
最终值 = (基础值 + 绝对加成总和) * (1 + 百分比加成总和)
```
