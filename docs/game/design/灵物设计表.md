# ⚔️ 灵物设计表

> **文档版本**：2026-04-28
> 所有灵物统一叫"灵物"。**捡到自动进入背包并立即生效**；放入"灵物槽位"还会获得专属加成。

## 4. 叠加规则

### 4.1 线性叠加

每获得一个相同灵物，词条值线性增加（按 `count` 累加）：
```text
Σflat   = Σ (item.attackBonus × count)
Σpct    = Σ (item.attackBonusPercent × count)
```

### 4.2 质变阈值

达到 `qualitativeThresholds` 中的某个数量时，触发该灵物的"质变效果"。质变可分两类：
- **机制类**（焚天 / 玉碎 / 御风 / 剑阵 / 涅槃）：通过 `QualitativeEffectRunner` 跑特殊机制
- **数值类**（焚天大成 / 万剑归宗 / 灵藤缠身 / ... / "分类共鸣"）：直接改 `_playerStats`

> ⚠️ 数值类质变当前会被下一次 `RecalculateStats` 覆盖（详见 [复查 P0-4](../../reviews/2026-04-28-战斗系统阶段性复查.md#p0-4-质变乘法效果在重算时丢失)）。修复后再正式发布版本。

### 4.3 槽位独占词条

只有把灵物拖入"灵物槽位"才生效的词条（不在背包中生效）：
- `skillChargeBonus`：对应技能槽位的充能上限 +N
- `chargeSpeedBonusPercent`：蓄力速度加成
- `chargeDamageBonusPercent`：蓄力伤害加成（仅 Lv2/Lv3）
- `cooldownReductionPercent`：CD 缩减
- 灼烧 DPS（`SpiritSlotSystem.GetTotalBurnDPS` 仅取槽位灵物，不含背包）

详见[灵物系统（程序文档）](../tech/灵物系统.md#4-槽位-spiritslotsystem)。

### 4.4 属性计算公式

```text
最终值 = (基础值 + Σ绝对加成) × (1 + Σ百分比加成)
       ↑（来自 ItemInventory 整体重算）
       ⚠️ SpiritSlotSystem 的增量、SynergySystem 的增量、质变的乘性会被这次重算覆盖
```

> 📌 多源叠加冲突详见 [`docs/game/tech/灵物系统.md` 第 8 节](../tech/灵物系统.md#8-️-多源叠加冲突重要)。

当某个灵物没有定义专属质变效果时，会走通用"分类共鸣"（数量 ≥ 5）：

| 分类 | x5 共鸣效果 |
|------|-----------|
| 攻伐（Attack） | "攻伐灵力共鸣，攻击附带灵力余波"（描述，未实现机制） |
| 护体（Defense） | "护体灵力共鸣，受击概率格挡"（描述，未实现机制） |
| 身法（Movement） | "身法灵力共鸣，移动留下残影"（描述，未实现机制） |
| 异变（Anomaly） | ⚠️ critRate +15%（仅数值生效） |
| ~~丹药（Pill）~~ | ~~v0.5.1 移除~~ |

> 这些共鸣大多只是描述，未真正实现机制，待 Demo1+ 补齐。
