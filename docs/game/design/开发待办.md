## 当前设计基线

- **核心循环**：入关卡拼 Build → 打得更深 → 死亡 / 阶段返回 / 通关均结算经验值，只是倍率不同。
- **局外资源**：统一叫“经验值”，来源标签只影响转化方向，不再拆成多种货币。
- **角色入口**：删除独立职业；开局选择“起始模板”，后续可在局内完全转向。
- **长期成长**：删除独立天赋树；改为模块熟练度 / 解锁节点。
- **模块系统**：触发器、效果器、改造件三层组合。原宝石系统并入改造件。
- **旧实现回收**：旧化身控制器、GrowthUITK、洞府模块、技能表、灵物表可作为实现素材，但文案和系统语义需按 v0.6 重命名。
