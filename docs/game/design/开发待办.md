# 开发待办（Backlog）

> **用途**：跟踪 v0.6 之后“做了哪些 / 还差哪些”。完整设计以 [主 GDD](GDD_秘境探索.md) 为准，阶段规划见 [Demo 路线图](Demo路线图.md)。
> **v0.6 方向**：长局模块化 Build + Hades 式局外结算；技能系统为 `Trigger + Effect + Modifier`；独立职业 / 天赋树 / 宝石系统 / 秘术系统不再作为当前系统推进。

---

## 当前设计基线

- **核心循环**：入关卡拼 Build → 打得更深 → 死亡 / 阶段返回 / 通关均结算经验值，只是倍率不同。
- **局外资源**：统一叫“经验值”，来源标签只影响转化方向，不再拆成多种货币。
- **角色入口**：删除独立职业；开局选择“起始模板”，后续可在局内完全转向。
- **长期成长**：删除独立天赋树；改为模块熟练度 / 解锁节点。
- **模块系统**：触发器、效果器、改造件三层组合。原宝石系统并入改造件。
- **旧实现回收**：旧化身控制器、GrowthUITK、洞府模块、技能表、灵物表可作为实现素材，但文案和系统语义需按 v0.6 重命名。

## P1 · 模块化技能系统

- [ ] 建立模块数据模型：
  - `TriggerModule`：纯条件触发器 / 状态型触发器。
  - `EffectModule`：伤害、治疗、护盾、位移、召唤、控制等执行效果。
  - `ModifierModule`：范围、次数、连锁、目标、元素、执行方式等行为改造。
- [ ] 状态型触发器必须自带弱默认效果：
  - `种子生成`：挂低伤 DoT。
  - `种子引爆`：达到阈值时弱爆炸。
  - `背击标记`：挂破绽。
  - `傀儡计数`：记录傀儡对象或攻击次数。
- [ ] 支持两种执行模式：
  - 被动：条件满足后自动触发。
  - 主动：条件满足后点亮 Q/E/R，玩家手动释放。
- [ ] 从旧技能与化身控制器中回收素材：
  - 青囊种子 → `种子生成 / 种子引爆`。
  - 影刃位移 / 背击 → `闪避后 / 背击标记`。
  - 御物傀儡 → `傀儡计数 / 傀儡协同`。
  - 剑魄完美时机 → 可回收为通用时机触发器，不再作为职业。

## P1 · 局外结算与模块熟练度

- [ ] 统一经验值结算池：
  - 死亡：低倍率。
  - 阶段返回：中倍率。
  - 通关：高倍率。
- [ ] 来源标签只作为经验转化提示：
  - 战斗 / 模块 / 触发器流派 / 探索 / 情报 / Boss。
- [ ] 模块熟练度替代天赋树：
  - 触发器熟练度：降低条件、强化默认效果、解锁变体。
  - 效果器熟练度：解锁新形态、目标逻辑或质变效果。
  - 改造件熟练度：扩大范围、增加次数、开放组合规则。
  - 起始模板熟练度：开局可替换模块、携带更多初始模块或提高推荐掉落权重。
- [ ] 旧 GrowthUITK 可回收为模块熟练度 UI，但文案和数据结构需重命名。
