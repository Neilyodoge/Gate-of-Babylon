## 关卡机制

### 时限采集与追猎者

- **状态**：草案
- **核心循环**：玩家在规定时间内收集指定数量的目标材料，并携带材料穿过传送门即可通关。
- **失败转折**：倒计时结束时若仍未穿过传送门，追猎者出现并开始追击玩家。
- **特殊变体**：部分关卡的追猎者替换为专属 Boss，而非普通追猎单位。
- **待验证**：
  - 材料是否需要全部收集，或允许达到最低数量后提前撤离。
  - 追猎者出现后是否仍允许通过传送门通关，以及是否给予额外奖励。
  - 追猎者/Boss 的追击范围、强度曲线与玩家 Build 成型速度如何匹配。
  - 该机制适合作为独立特殊关、事件房，还是常规关卡的可选挑战。
