# 区域可刷 ARPG · 方向草案

> **状态**：`草案`（2026-07-22）  
> **未并入 GDD**：确认前不要按本文改权威设计或大规模推倒现有关卡循环。  
> **战斗系统**：沿用现行「核心技能 × 增幅器/模块链」；本文主要改**世界结构与成长/刷宝节奏**。

---

## 1. 一句话定位

> **遗迹 2 式可刷区域结构 + 暗黑式刷宝爽感 + 当前技能/增幅器 BD。**  
> 去掉「秘境单局」主概念，改为可反复进入的**区域**；变化带来新遭遇与掉落；基地是短打造与休整，不是第二套重游戏。

### 1.1 参考权重

| 参考 | 学什么 | 不学什么 |
|------|--------|----------|
| 遗迹 2 | 区域模板、随机遭遇、短事件/解密、多 Boss 线、偶发特殊内容 | 电影级主线剧情（MVP 不依赖大剧情） |
| 暗黑 | 刷怪/Boss 掉 BD 件、可重复刷、难度档拉开掉落 | 完整防具栏与庞杂词缀生成（MVP） |
| 泰拉瑞亚 | 「打完有反馈 / 材料短线」的节奏感 | 自由挖建、大科技树、真家园塔防 |
| 当前项目 | 技能 × 触发/效果/改造/万能件战斗 | — |

### 1.2 要解决的体感问题

- 纯肉鸽：内容少时局同质，Boss 反复打同一套没意思。  
- 想要：遭遇更有变化、Boss/解密/特殊关能推进「世界一点变化」，掉落直接服务 BD。  
- 不想要：整盘做成传统数值 RPG，或做成泰拉级沙盒。

## 2. 主循环

```text
营地（仓库装配 / 短打造 / 可选假入侵短战）
  → 选择区域出击
  → 进区 roll：常规随机区域 | 偶发特殊关 | 条件关
  → 刷怪 / 短事件 / 解密 / 材料
  → 游荡遇到 Boss 或凑材料召唤
  → 掉落：技能、增幅器（主）+ 材料（辅）
  → 变化写世界状态：开旁路、亮祭坛、解锁特殊关等
  → 回程卷轴 / 安全点回城（或死亡按规则结算）
  → 回营地重组 Build，再刷更高难度或另一条 Boss 线
```

**验收口语**：玩家说「再刷一趟赌那件 / 去解那个机关开旁路」，而不是「通关了一局秘境」。

## 3. 要 / 不要（非目标）

### 3.1 要做

- 区域概念（持久可刷，非秘境单局清空世界）  
- 关卡/房间随机生成（模板 + 池）  
- 多 Boss 线；Boss **可游荡遇到，也可召唤**  
- 世界反馈**多源**：Boss / 解密 / 短事件 / 偶发特殊关（不必全靠 Boss）  
- 轻开路：每区少量持久开关（看得见、立刻能走）  
- Boss/特殊关等高价值掉 **技能与增幅器** 供 BD  
- 关卡收集材料；回程回家；**短打造**  
- 变化带来的掉落与意外进特定关  
- 假入侵（轻压力，见 §6）  

### 3.2 明确不做（本草案范围）

- 真·家园塔防式入侵与可破坏大基地  
- 大开路 / 生态污染模拟 / 持久整图体素  
- 泰拉级打造科技树；打造不是主 BD 轴  
- 电影级主线剧情（短事件文案即可）  
- 联机（后置；设计时少做强单机绑定的家园破坏）

## 4. 系统拆解

### 4.1 区域与随机

- **骨架半固定**：区域模板 + 障碍槽 / Boss 候选点 / 事件槽。  
- **内容高随机**：房间敌人、掉落、事件、新开口袋奖励。  
- **不随机**：已开通的持久通路是否保留；某 Boss 线「专属掉落主题」宜固定。  
- **可随机**：未开障碍具体表现、Boss 游荡位置、本趟是否偶发特殊关。

### 4.2 变化系统（核心设计意图）

目标不是「三个重系统」，而是：

> **变化 → 新遭遇 / 新掉落。**  
> 开路、解密、偶发特殊关、短打造、假入侵，都是变化的开关。

| 来源 | 例子 | 带来的变化 / 掉落 |
|------|------|-------------------|
| Boss | 击败 / 召唤真身 | 开一条路、解锁下一线索/祭坛、专属技能或高稀有增幅器 |
| 解密 / 探索 | 机关、隐藏墙、解谜房 | 旁路、特殊口袋、稀有箱、材料、推进 Boss 线 |
| 短事件 | 二选一、救人、赌箱 | 临时词缀、精英、改本趟掉落倾向、线索 |
| 偶发入口 | 进区时概率进「特定关」 | 独立掉落池、高风险高回报、可写世界状态 |
| 回城压力 | 回城遇袭 / 据点被占 / 野外侵染 | 短战奖励或轻惩罚（替真入侵） |

原则：**每个变化都要立刻对应「能去的新地方」或「能掉的新东西」**，否则不做。

### 4.3 轻开路 / 世界状态

- 每区仅 **2～3 个持久开关**（旁路开、祭坛亮、某特殊关解锁等）。  
- 触发者可以是 Boss、解密、特殊关结算、关键事件。  
- 日常新鲜感主要靠：房间随机、事件、偶发特殊关；开路是调味不是主业。

### 4.4 多 Boss 线

```text
线索：地图标记 / 事件提到 / 解密见到封印
  → 游荡体（随机点）或凑材料召唤真身
  → 打赢：专属掉落 + 可选写世界状态
  → 未处理：可挂轻世界压力（侵染/回城事件），非必须
```

每条线尽量同时有：

1. 一点战斗/场地差异（可小）  
2. 掉落（技能或高稀有增幅器；材料若有只服务短线）  
3. 可选世界反馈（开路 / 解锁特殊关 / 亮祭坛）——**也可由解密单独推进同一条线**

### 4.5 短事件与解密

- 遗迹式：**卡片短文案 + 选项**，改奖励/旁路/线索，不是章节剧情。  
- 解密房可半固定布局，好控体验，可推进 Boss 线或开路开关。  
- **无大剧情也能成立**；故事感靠碎片与 Boss 设定即可。

### 4.6 偶发特殊关

```text
进区 roll
  ├─ 常规随机区域（大概率）
  ├─ 特殊关（小概率）：半固定布局 + 独立掉落池
  └─ 条件关（需钥匙 / 解密进度 / Boss 线状态）
```

特殊关可推动世界状态（例如解开后，常规区域多一条旁路或某 Boss 可召唤）。

### 4.7 掉落与 BD（主轴）

- 小怪：低稀有增幅器。  
- 精英：中稀有增幅器 / 技能。  
- Boss / 特殊关：高价值 **技能或高稀有增幅器**（可带专属主题）。  
- **主 BD 靠掉落拼装**；与现行模块系统一致。  
- 材料为辅：召唤、开门工具、极短打造。

### 4.8 回程、材料、短打造

- 回程卷轴 / 安全点回城；死亡规则待确认（见 §8）。  
- 关卡可收集材料。  
- 打造：**短线**——召唤物、开门工具、1～2 个 BD 向蓝图/成品；不做永久攻击力主成长轴。

### 4.9 假入侵（替代真家园防守）

优先顺序（MVP 只做一种即可）：

1. **回城遇袭**：回城时概率短战（守仓库/铁匠感）。  
2. **据点被占**：外出后回家需清一小波才能用打造。  
3. **野外侵染**：区域词缀变差，清事件后恢复。  

暂不解决「真入侵」；等刷宝循环与（可选）联机稳定后再议。

### 4.10 联机

后置。现阶段少做：复杂可破坏家园、强绑定单机的进度假设。事件结果宜简单可判定。

## 5. MVP（最小可玩）

### 5.1 必做 5 块

1. **1 个可重复进入的区域**（模板 + 房间/遭遇随机）  
2. **现有战斗与装配**（技能 + 增幅器；出击前/营地可改 Build）  
3. **掉落闭环**（怪/精英/Boss → 技能与增幅器；拾取进仓库或等价持久）  
4. **2～3 条 Boss 线**（游荡或召唤至少一种完整；专属或高价值掉落）  
5. **轻量持久**：仓库/Build 保存 + 2 档难度（可选）+ **2～3 个世界状态开关**  

### 5.2 MVP 一并做轻的

- 短事件若干 + 少量解密房  
- 偶发特殊关 ≥ 1  
- 回程 + 材料短线 + 极简打造（每 Boss 线 ≤ 1 配方也可）  
- 假入侵一种（回城遇袭或据点被占）  

### 5.3 MVP 不做

真家园塔防、大开路模拟、多区域、大剧情、联机、完整暗黑装备位。

### 5.4 建议内容量（验证向）

| 类型 | 数量 |
|------|------|
| 区域模板 | 1 |
| 房间/遭遇 | 6～8 |
| Boss 线 | 2～3 |
| 短事件 | 若干 |
| 解密房 / 特殊关 | 各 ≥ 1 |
| 持久开路开关 | 2～3 |
| 可掉落技能 | 6～8 |
| 增幅器 | 12～20 |
| 难度 | 2（可选） |

### 5.5 阶段建议

| 阶段 | 内容 |
|------|------|
| A | 区域可刷 + 多 Boss 线 + 短事件/解密 + 掉落 BD + 轻开路 + 回城 |
| B | 材料短线 + 极简打造 + 游荡/召唤双遭遇 |
| C | 假入侵一种 |
| D | 真入侵 / 联机（远景） |

## 7. 随机怎么记（备忘）

| 适合随机 | 不宜随机 |
|----------|----------|
| 房间怪物、掉落、事件 | 已打开的持久通路是否还在 |
| 障碍槽表现、Boss 游荡位 | Boss 专属掉落主题（宜稳定可刷） |
| 进区是否进特殊关 | 整区拓扑每次大洗牌（成本高） |
| 新开口袋内奖励 | — |

口诀：**骨架固定，内容随机；因果清晰，遭遇多变。**
