## 0. 项目一句话（v0.6 重写）

> **一款"逻辑拼装"驱动的 Roguelite ARPG —— 玩家用"起始模板"入局，再通过拼装"触发器"、"效果器"与"改造件"创造每局不同的 Build，在长局探索中打得更深，并把死亡、返回或通关都结算为局外成长。**

定位：核心冒险主轴（70%）+ 动作元素（30%）。

**类型**：Roguelike · Top-down 3D · 近战 ARPG（Hades 派系）
**平台**：PC / Steam
**引擎**：Unity URP
**参考作品**：《Shape of Dreams（梦之形）》 / 《以撒的结合》 / 《地牢100》 / 《Hades》

## 1. 五大卖点（v0.6 升级）

| 卖点 | 一句话 |
|------|--------|
| **模块化技能系统** | 废弃固定技能，玩家自由拼装"触发器"（如：移动10米）、"效果器"（如：落雷）与"改造件"（如：连锁符文） |
| **触发器流派系统** | 删除独立职业；开局只选起始模板，原职业能力拆成状态型触发器和模块熟练度 |
| **长局构筑 + 局外结算** | 入关卡拼 Build → 打得越深倍率越高 → 死亡 / 返回 / 通关都转化为局外成长 |
| **自适应怪物生态** | 怪物会根据玩家的 Build 进化出对抗机制（如：自动闪避远程投射物） |
| **机制型协同** | 不做独立宝石系统；宝石降级为模块改造件 / 符文，回报是行为变化而非数字 |

## 3. 系统总览

### 3.1 触发器流派系统 · 起始模板与状态触发

**意义**：删除独立职业系统，避免多一层规则。玩家开局选择的是"起始模板"，后续 Build 完全由触发器、效果器和改造件决定。

**方向**：起始模板提供一组初始触发器 / 效果器 / 改造件，只负责教学和开局方向，不锁死后续流派。

**示例（播种者模板）**：
- 起始触发器：【种子生成】、【种子引爆】。
- 默认状态展示：种子生成只显示种子落点和层数，种子引爆只消耗种子状态；伤害来自接上的效果器。
- 推荐组合：毒雾、治疗、扩散符文。

**起始模板一览**：
- **播种者**：种子生成 / 种子引爆。节奏循环、铺垫后收割。
- **刺客**：闪避后 / 背击标记。位置判断、爆发窗口。
- **指挥者**：傀儡计数 / 傀儡协同。多单位协作、阵地构筑。
- **雷行者**：移动 X 米 / 闪避成功。移动触发、连锁清场。
- **守卫者**：受击时 / 护盾破裂。防御反击、延迟爆发。
- **炼金师**：时间间隔 / 拾取后。节奏触发、治疗续航。

---

### 3.2 模块化技能系统 · [触发] → [执行] → [改造]

**意义**：废弃固定技能，让玩家自由拼装"触发逻辑"、"执行效果"与"行为改造"。

**核心组件**：
1. **触发器 (Trigger)**：
   - 条件型：战斗行为、移动 / 闪避、受击 / 防御、时间 / 节奏、击杀 / 事件。
   - 状态型：种子生成、种子引爆、背击标记、傀儡计数等。状态型触发器只提供无伤害状态展示，不承担伤害、治疗或控制。
2. **效果器 (Effect)**：
   - 伤害输出、控制 / 状态、防御 / 回复、位移 / 位置、召唤 / 场物、资源 / 状态操作。
3. **改造件 (Modifier)**：
   - 原宝石系统降级而来，不再作为独立系统存在。
   - 作用：改变效果器或触发器的形态、目标、数量、节奏、状态、槽位关系或代价。

**落表规范**：
- 每个模块必须配置大类、子类、标签、基础参数、兼容条件、掉落来源、解锁条件、升级项和 UI 描述。
- 标签用于掉落权重、推荐组合、隐藏组合和局外升级。

**执行模式**：
- **被动**：满足条件立即自动触发。
- **主动**：满足条件后图标亮起（Proc），玩家手动按 Q/E/R 释放。
- Demo 阶段一条模块链的主动 / 被动模式由设计表决定，不开放局内自由切换。

**例子**：
- `[移动 10 米]` + `[向最近敌人落雷]` = 跑动中自动落雷。
- `[移动 10 米]` + `[向最近敌人落雷]` + `[连锁符文]` = 跑动中自动落雷，并连锁到附近敌人。
- `[种子引爆]` + `[毒雾]` + `[扩散符文]` = 大范围持续收割。

---

### 3.3 协同系统 · 玩家发现的"惊喜"

**意义**：让普通模块链在满足额外标签、行为或状态条件时产生质变。

**例子**：
- `[种子引爆]` + `[毒雾]` + `[扩散符文]` 是普通链；如果本房间毒雾击杀达到阈值，则触发"百草齐放"，毒雾击杀后生成新种子。

---

### 3.4 局外成长 · 模块熟练度取代天赋树

**意义**：删除独立天赋树后，局外成长直接落到玩家真正使用的模块上，减少一层 UI 和规则。

**经验值用途**：
- **触发器熟练度**：降低触发条件、强化状态展示或状态上限、解锁触发变体。
- **效果模块升级**：解锁新的技能效果、目标逻辑或质变效果。
- **改造模块升级**：强化技能的形态变化，例如范围、次数、连锁或延迟。
- **起始模板熟练度**：开局可替换模块、携带更多初始模块或提高推荐掉落权重。

**设计边界**：模块熟练度提供长期目标，但不锁死 Build。玩家仍可在局内捡到其他流派模块并转向。

## 4. 关键设计决策记录

| 版本 | 决策 | 含义 |
|------|------|------|
| **V.06** | **全面模块化技能系统** | 废弃固定技能，改为触发器 + 效果器 + 改造件组合 |
| **V.06** | **宝石系统降级** | 不保留独立宝石系统，改为模块改造件 / 符文 |
| **V.06** | **删除独立职业** | 原职业拆成起始模板、状态型触发器和模块熟练度 |
| **V.06** | **删除独立天赋树** | 长期成长改为模块熟练度 / 解锁节点，不再维护职业天赋树入口 |
| **V.06** | **状态型触发器无伤害展示** | 种子生成、背击标记等触发器只提供状态载体，主要强度来自效果器 |
| **V.06** | **弱化撤离核心** | 撤离改为阶段返回；死亡、返回、通关都进入局外结算，只是倍率不同 |
