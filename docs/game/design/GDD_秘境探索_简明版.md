## 0. 项目一句话（v0.8 重写）

> **一款"技能 × 增强"驱动的 Roguelite ARPG —— 玩家带入一组初始模块入局，通过拼装"触发器"、"效果器"、"改造件"与"万能件"为手中的核心技能装配增强链；战斗中走位 / 攻击 / 闪避让某条技能链"上膛"（Proc），玩家在最合适的时机按下该技能释放带加成的爆发（Consume），非战斗时随时重组换链，长局探索打得更深，并把死亡、返回或通关都结算为局外解锁成长。**

定位：核心冒险主轴（70%）+ 动作元素（30%）。

**类型**：Roguelike · Top-down 3D · 近战 ARPG（Hades 派系）
**平台**：PC / Steam
**引擎**：Unity URP
**参考作品**：《Shape of Dreams（梦之形）》 / 《以撒的结合》 / 《地牢100》 / 《Hades》

## 1. 五大卖点（v0.8 升级）

| 卖点 | 一句话 |
|------|--------|
| **核心技能 × 模块增强** | 玩家始终主动按 Q/E/R 释放核心技能；模块链挂在技能上做"增强器"，Trigger 决定何时上膛、Effect 决定加什么、Modifier 决定怎么变形 |
| **Proc → Consume 节奏** | 走位/攻击/受击让技能图标"冒火"就绪，玩家选择最佳时机按下消费增强——操作感与 Build 深度同时保留 |
| **自由拼装 + 局内重组** | 增强链各部分非战斗时随时换位 / 扔地上 / 捡回，拼错零惩罚；一个技能最多挂一条链，裸技能也能用 |
| **长局构筑 + 局外结算** | 入关卡拼 Build → 打得越深倍率越高 → 死亡 / 返回 / 通关都转化为局外解锁 |
| **自适应怪物生态** | 怪物根据玩家 Build 标签投放反制机制，但不免疫，推动动态换链 |

## 3. 系统总览

### 3.1 初始配置与局外成长

**意义**：删除固定流派模板和模块熟练度，开局不再选职业方向；局外成长只解锁、不升级数值。

**方向**：
- 测试版开局直接给一套"种子"初始模块（触发器+效果器+改造件各一），旁边配置 NPC 处可手动替换 / 调整带入局内的模块。
- 后续版本用新手教学关卡引导，不依赖模板流派。
- 局外成长以**解锁新模块**为主，三类模块 + 万能件**均不可数值升级**；解锁后可在 NPC 处选入带入组合，每局带入数量有限。

**设计边界**：初始模块只解决"开局有一组能用的东西"，不限制局内发展——玩家在关卡中可捡到其他模块并完全转向。

---

### 3.2 模块化技能系统 · 核心技能 × 增强链（Proc → Consume）

**意义**：把战斗的主导权还给玩家的按键。核心技能是玩家主动释放的招式；模块链不再"自己打人"，而是给技能装配增强——什么时候上膛、上膛后加什么、加成怎么变形。

**核心技能（Q/E/R 三个槽位）**：
- 起始固定 3 个核心技能（保证开局即可玩，无空窗）。
- 关卡内通过 SkillPickup 可**替换**某个槽位的技能。
- 一个技能**最多挂一条增强链**；裸技能（无链）也可正常使用，只是没有加成。

**增强链 = [触发器] → [效果器] → [改造件 0-2]（+ 万能件）**：

1. **触发器 (Trigger)** —— 决定**什么时候把增强上膛（Proc）**，并自带 `consumeKind` 声明消费模型：
   - 条件型：战斗行为、移动 / 闪避、受击 / 防御、时间 / 节奏、击杀 / 事件。
   - 状态型：种子生成、种子引爆、背击标记、傀儡计数等，只提供无伤害状态展示。
2. **效果器 (Effect)** —— 决定**消费时多出来的东西**，分两个子类：
   - **增强型**：改这次按键的核心技能本身（+120% 伤害、改火属性、单体→链锁、释放时回血）。
   - **附加型**：核心技能命中时额外 spawn 一个独立效果（附加范围爆炸、附加落雷、附加召唤、附加位移）。
   - `damage` 字段双语义：增强型=伤害倍率，附加型=附加效果自身伤害。
3. **改造件 (Modifier)** —— 调整**增强的形态与强度**：蓄力等级、爆炸半径、Proc 概率、层数上限、附加层数、元素追加。
4. **万能件 (Universal)** —— 第四类模块，无固定职责，放入哪个槽就当哪个；双面配置、槽位决定能力。

**消费模型（由 Trigger 的 `consumeKind` 决定，装配 UI 直接标注）**：

| consumeKind | 行为 | 典型 Trigger |
|---|---|---|
| `Single` | 下次按下生效 1 次，用完重新 Proc | 受击时、暴击时、击杀时、每 N 秒 |
| `Window` | 就绪后 N 秒内按下都生效，窗口结束重新 Proc | 长 CD 周期、移动 N 米后 |
| `Stacks` | Proc 可叠层（上限 M），每按一次消耗 1 层 | 连击 N 次、命中累加、持续战斗 |
| `Auto` | Proc 即自动释放绑定的核心技能（带增强），无需按键 | 挂机 build、辅助光环类 |

**增强就绪视觉标识（角色旁三竖条）**：
- 角色右侧浮空 3 个竖条（左→右对应 Q/E/R），World Space Canvas billboard 始终面向摄像机。
- `Single` 就绪 → 整条亮起（Effect 元素色）+ 呼吸光；`Window` → 填充随倒计时下沉；`Stacks` → 按层数分段填充；`Auto` 触发 → 闪亮一次后熄灭；未 Proc / 无链 → 暗灰。
- 余光可一眼看出"哪个技能可以爆了"，实现成本低（3 个 Image.fillAmount + 键名 Text）。

**例子**：
- 核心技能「剑气」+ `[触发器: 暴击时·Single]` + `[效果器: +120% 伤害]` = 暴击后剑气图标冒火，下次按 Q 释放 +120% 伤害剑气。
- 核心技能「落雷」+ `[触发器: 移动 10 米·Stacks(3)]` + `[效果器: 附加范围爆炸]` + `[改造件: 爆炸半径 +50%]` = 跑动累层（最多 3 层），每按一次落雷附带一次放大爆炸，消耗一层。
- 核心技能「突刺」+ `[万能件(当触发器: 闪避后·Window 5s)]` + `[万能件(当效果器: 改为火属性)]` = 闪避后 5 秒内按下突刺附带火属性，整条链全由万能件组成。

### 3.3 局内重组 · 自由拼装

**意义**：拼错零惩罚。让玩家大胆尝试任意增强组合，不满意的随时换、随时扔、随时捡回，鼓励自由探索而非保守取舍。

**规则**：
- 增强链上任意模块可在**非战斗状态**（含休息房）取出到背包、替换为同类模块、或扔到地上。
- 扔到地上的模块作为可拾取场物保留，玩家可随时走过去捡回。
- 进入战斗后链锁定，避免战斗中临时换链破坏节奏。
- 槽位职责约束：触发器槽只接受触发器或万能件，效果器槽只接受效果器或万能件。
- 链 ↔ 技能绑定：一条增强链挂在一个核心技能槽位上；一个技能最多挂一条链；裸技能（无链）可正常使用。

---

### 3.4 自适应怪物生态 · 反制系统

**意义**：让"自适应怪物"成为推动玩家**用自由拼装动态应对**的压力源，凸显局内重组的价值，但不让 Build 直接报废。

**反制判定**：系统读取玩家当前装配模块的标签（伤害来源、形态、节奏），从反制池挑匹配机制投放，随层数加强。

| 玩家 Build 特征 | 可能反制 |
|----------------|---------|
| 远程 / 投射物 | 自动闪避投射物、近身冲锋 |
| 召唤 / 场物 | 范围清场、召唤物上限削减 |
| 持续伤害 / DoT | 高频净化、移除状态 |
| 高爆发 / 蓄力 | 打断施法、强制位移 |
| 依赖触发条件 | 反触发、降低有效触发次数 |

**三条边界**：
1. **反制 ≠ 免疫**：只压制效率，不让某类 Build 0 伤害。
2. **有预告与窗口**：怪物行为预告反制，玩家可主动规避，非隐形惩罚。
3. **反反制手段**：靠局内重组换链应对，不要求预先堆抗性。

---

### 3.5 局内协同（预留）

本版**暂不设独立的隐藏组合系统**。原"隐藏组合/Synergy"机制已移除，组合质变后续可通过**特殊道具**（触发并升级特定组合）或**装备系统**（特殊机制产生质变）承载，具体设计待定。

### 3.6 关卡 A · 无暮王城

**一句话**：同一座 12 房王城先经历白昼表象，再经历永夜真相；白昼选择会在永夜形成可见后果。

- 首次固定进入白昼，击败白昼 Boss 后可直接追入永夜并保留 Build，也可返回基地安全结算，下次从永夜重新构筑。
- 永夜死亡或返回不会要求重打白昼；击败永夜 Boss 才算完整通关。
- 无论直接追入还是经基地再次进入，永夜都从原出生区安全降落端重新落地，不从白昼 Boss 房原地续跑。
- 昼夜保持同一 Layout Seed、出生区、Boss 节点、拓扑与整体旋转，复用大部分地图几何；主要替换整体色彩与光照、两组敌人池，以及关键地标 / 事件模块变体。
- 永夜左下角长期显示最多两条“上次行动”；若经基地再次进入，入口传送门会提示当前为永夜、上次变化及本次继续阶段。
- 事件按主要影响分为 Strength（玩家 / Boss 单局强度）、Layout（关卡布局）与 Item（道具获取）。当前完整昼夜循环固定包含：白昼 Layout“断裂巡礼桥”（先清桥卫，再决定稳定开桥 / 临时放桥后破坏机构 / 保持封锁）与永夜 Strength“禁卫召集阵”（Boss 无召唤 / 只召队长 / 召普通小队）；Item 类延后。
- 白昼 Boss 是“最后摄政官”，50% 生命固定召 2 名普通禁卫；永夜 Boss 是“无暮王残念”，在 70% / 35% 生命节点读取召集阵结果。当前只冻结身份与召唤差异，其他招式允许后续调整。
- 永夜通关后清除本轮结果并重置为白昼；下一次挑战重新生成新循环，首版不开放自由选阶段。

## 4. 关键设计决策记录

| 版本 | 决策 | 含义 |
|------|------|------|
| **V.08** | **模块 = 技能增强器** | 模块链不再自行释放，而是挂在核心技能上做增强；Trigger 决定 Proc 时机、Effect 决定加成、Modifier 决定变形 |
| **V.08** | **核心技能回归 Q/E/R** | 起始固定 3 个核心技能，关卡内 SkillPickup 可替换；一个技能最多挂一条链，裸技能可用 |
| **V.08** | **Proc → Consume 消费模型** | Trigger 自带 consumeKind（Single/Window/Stacks/Auto），Proc 自动、Consume 由玩家按键决定（Auto 例外：自动消费），操作感回归 |
| **V.08** | **Effect 二分：增强型 + 附加型** | Effect 不再是技能本体，改为"消费时多出来的东西"；增强型改核心技能、附加型 spawn 独立效果；纯 build 原型回归核心技能承载 |
| **V.08** | **增强就绪视觉标识** | 角色旁 3 个竖条（Q/E/R）按 Effect 元素配色亮起，余光可一眼看出哪个技能 Proc 了 |
| **V.07** | **删除起始模板** | 不再选流派模板；测试版给种子初始模块 + 配置 NPC 手动带入 |
| **V.07** | **删除模块熟练度** | 触发器/效果器/改造件/万能件均不可数值升级；局外只解锁 |
| **V.07** | **新增万能件** | 第四类模块，放哪个槽当哪个，双面配置、槽位决定职责 |
| **V.07** | **局内自由重组** | 非战斗时随时换链 / 扔地上 / 捡回，拼错零惩罚 |
| **V.07** | **删除隐藏组合系统** | 暂不做 Synergy，质变留待特殊道具 / 装备系统 |
| **V.07** | **自适应怪物落地** | 反制按 Build 标签投放，但不免疫、有预告、可换链破解 |
| **V.06** | **全面模块化技能系统** | 废弃固定技能，改为触发器 + 效果器 + 改造件组合 |
| **V.06** | **宝石系统降级** | 不保留独立宝石系统，改为模块改造件 / 符文 |
| **V.06** | **状态型触发器无伤害展示** | 种子生成、背击标记等触发器只提供状态载体，主要强度来自效果器 |
| **V.06** | **弱化撤离核心** | 撤离改为阶段返回；死亡、返回、通关都进入局外结算，只是倍率不同 |
