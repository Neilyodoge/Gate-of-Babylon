## 0. 项目一句话（v0.7 重写）

> **一款"逻辑拼装"驱动的 Roguelite ARPG —— 玩家带入一组初始模块入局，通过拼装"触发器"、"效果器"、"改造件"与"万能件"创造每局不同的 Build，非战斗时随时重组换链应对自适应怪物，在长局探索中打得更深，并把死亡、返回或通关都结算为局外解锁成长。**

定位：核心冒险主轴（70%）+ 动作元素（30%）。

**类型**：Roguelike · Top-down 3D · 近战 ARPG（Hades 派系）
**平台**：PC / Steam
**引擎**：Unity URP
**参考作品**：《Shape of Dreams（梦之形）》 / 《以撒的结合》 / 《地牢100》 / 《Hades》

## 1. 五大卖点（v0.7 升级）

| 卖点 | 一句话 |
|------|--------|
| **模块化技能系统** | 废弃固定技能，玩家自由拼装"触发器"（如：移动10米）、"效果器"（如：落雷）、"改造件"（如：连锁符文）与"万能件"（放哪个槽当哪个） |
| **自由拼装 + 局内重组** | 技能链各部分非战斗时随时换位 / 扔地上 / 捡回，拼错零惩罚 |
| **长局构筑 + 局外结算** | 入关卡拼 Build → 打得越深倍率越高 → 死亡 / 返回 / 通关都转化为局外解锁 |
| **自适应怪物生态** | 怪物根据玩家 Build 标签投放反制机制（如：远程 build 遇到闪避投射物），但不免疫，推动动态换链 |
| **万能件自由度** | 第四类模块无固定职责，放入触发器槽当触发器、放入效果器槽当效果器，双面配置、槽位决定能力 |

## 3. 系统总览

### 3.1 初始配置与局外成长

**意义**：删除固定流派模板和模块熟练度，开局不再选职业方向；局外成长只解锁、不升级数值。

**方向**：
- 测试版开局直接给一套"种子"初始模块（触发器+效果器+改造件各一），旁边配置 NPC 处可手动替换 / 调整带入局内的模块。
- 后续版本用新手教学关卡引导，不依赖模板流派。
- 局外成长以**解锁新模块**为主，三类模块 + 万能件**均不可数值升级**；解锁后可在 NPC 处选入带入组合，每局带入数量有限。

**设计边界**：初始模块只解决"开局有一组能用的东西"，不限制局内发展——玩家在关卡中可捡到其他模块并完全转向。

---

### 3.2 模块化技能系统 · [触发] → [执行] → [改造]（+ 万能件）

**意义**：废弃固定技能，让玩家自由拼装"触发逻辑"、"执行效果"、"行为改造"与"万能件"。

**核心组件**：
1. **触发器 (Trigger)**：
   - 条件型：战斗行为、移动 / 闪避、受击 / 防御、时间 / 节奏、击杀 / 事件。
   - 状态型：种子生成、种子引爆、背击标记、傀儡计数等。状态型触发器只提供无伤害状态展示，不承担伤害、治疗或控制。
2. **效果器 (Effect)**：
   - 伤害输出、控制 / 状态、防御 / 回复、位移 / 位置、召唤 / 场物、资源 / 状态操作。
3. **改造件 (Modifier)**：
   - 原宝石系统降级而来，不再作为独立系统存在。
   - 作用：改变效果器或触发器的形态、目标、数量、节奏、状态、槽位关系或代价。
4. **万能件 (Universal)**：
   - 第四类模块，无固定职责，放入哪个槽就当哪个。
   - 双面配置：同一件内部同时声明"作为触发器时如何"与"作为效果器时如何"，只有匹配当前槽位的那段生效。
   - 当触发器时仍遵守触发器边界（不负责主要伤害），当效果器时遵守效果器边界——槽位裁剪其能力，不破坏分类规则。
   - 默认偏高稀有度（Rare 起），不能放入改造件槽。

**执行模式**：
- **被动**：满足条件立即自动触发。
- **主动**：满足条件后图标亮起（Proc），玩家手动按 Q/E/R 释放。
- Demo 阶段一条模块链的主动 / 被动模式由设计表决定，不开放局内自由切换。

**例子**：
- `[移动 10 米]` + `[向最近敌人落雷]` = 跑动中自动落雷。
- `[移动 10 米]` + `[向最近敌人落雷]` + `[连锁符文]` = 跑动中自动落雷，并连锁到附近敌人。
- `[万能件(当触发器: 闪避后)]` + `[万能件(当效果器: 落雷)]` = 闪避后落雷，整条链全由万能件组成。

---

### 3.3 局内重组 · 自由拼装

**意义**：拼错零惩罚。让玩家大胆尝试任意组合，不满意的随时换、随时扔、随时捡回，鼓励自由探索而非保守取舍。

**规则**：
- 链上任意模块可在**非战斗状态**（含休息房）取出到背包、替换为同类模块、或扔到地上。
- 扔到地上的模块作为可拾取场物保留，玩家可随时走过去捡回。
- 进入战斗后链锁定，避免战斗中临时换链破坏节奏。
- 槽位职责约束：触发器槽只接受触发器或万能件，效果器槽只接受效果器或万能件。

---

### 3.4 自适应怪物生态 · 反制系统

**意义**：让"自适应怪物"成为推动玩家**用自由拼装动态应对**的压力源，凸显局内重组的价值，但不让 Build 直接报废。

**反制判定**：系统读取玩家当前装配模块的标签（伤害来源、形态、节奏），从反制池挑匹配机制投放，随层数加强。

| 玩家 Build 特征 | 可能反制 |
|----------------|---------|
| 远程 / 投射物 | 自动闪避投射物、近身冲锋 |
| 召唤 / 场物 | 范围清场、召唤物上限削减 |
| 持续伤害 / DoT | 高频净化、移除状态 |
| 高爆发 / 蓄力 | 打断施法、强制位移 |
| 依赖触发条件 | 反触发、降低有效触发次数 |

**三条边界**：
1. **反制 ≠ 免疫**：只压制效率，不让某类 Build 0 伤害。
2. **有预告与窗口**：怪物行为预告反制，玩家可主动规避，非隐形惩罚。
3. **反反制手段**：靠局内重组换链应对，不要求预先堆抗性。

---

### 3.5 局内协同（预留）

本版**暂不设独立的隐藏组合系统**。原"隐藏组合/Synergy"机制已移除，组合质变后续可通过**特殊道具**（触发并升级特定组合）或**装备系统**（特殊机制产生质变）承载，具体设计待定。

## 4. 关键设计决策记录

| 版本 | 决策 | 含义 |
|------|------|------|
| **V.07** | **删除起始模板** | 不再选流派模板；测试版给种子初始模块 + 配置 NPC 手动带入 |
| **V.07** | **删除模块熟练度** | 触发器/效果器/改造件/万能件均不可数值升级；局外只解锁 |
| **V.07** | **新增万能件** | 第四类模块，放哪个槽当哪个，双面配置、槽位决定职责 |
| **V.07** | **局内自由重组** | 非战斗时随时换链 / 扔地上 / 捡回，拼错零惩罚 |
| **V.07** | **删除隐藏组合系统** | 暂不做 Synergy，质变留待特殊道具 / 装备系统 |
| **V.07** | **自适应怪物落地** | 反制按 Build 标签投放，但不免疫、有预告、可换链破解 |
| **V.06** | **全面模块化技能系统** | 废弃固定技能，改为触发器 + 效果器 + 改造件组合 |
| **V.06** | **宝石系统降级** | 不保留独立宝石系统，改为模块改造件 / 符文 |
| **V.06** | **状态型触发器无伤害展示** | 种子生成、背击标记等触发器只提供状态载体，主要强度来自效果器 |
| **V.06** | **弱化撤离核心** | 撤离改为阶段返回；死亡、返回、通关都进入局外结算，只是倍率不同 |
