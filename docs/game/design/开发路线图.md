## Demo1 — 核心战斗验证（当前阶段）

> **目标**：纯 CD 模型，验证战斗手感 + 灵物叠加机制 + 完整游戏循环

### ✅ 已完成

#### 框架
- [x] 项目基础架构（事件总线、对象池、配置 SO）
- [x] 场景快速搭建器（`Demo1Setup` 运行时生成所有对象）
- [x] 后处理（Bloom + Vignette 受击脉冲）
- [x] Debug 控制台（Tab 呼出，无敌 / 锁血 / 秒杀 / 房间跳转）

#### 玩家
- [x] 角色移动（WASD + 鼠标瞄准）
- [x] **闪避系统**（Space + 多层充能 + 250ms 输入缓冲 + 全程无敌帧 0.3s）
- [x] **三段近战连招**（鼠标左键，扇形判定 + 段倍率 1.0/1.2/1.5）
- [x] **动画优先级系统**（Hades 风格：Die > Evade > HeavyHit > Skill > Attack > LightHit > None）
- [x] **霸体机制**（攻击/技能中轻击不打断）
- [x] **攻击前冲（Lunge）** + 朝向锁定 + 连招窗口短暂解锁
- [x] **顿帧（HitStop）**：普通 / 击杀两级
- [x] 受击表现：闪白、硬直、击退、屏幕脉冲、伤害飘字（暴击 / 普通 / 治疗 / 灼烧 / 格挡 / 反弹 / 玉碎 / 涅槃 等多种 Tag）

#### 功法（技能）
- [x] **三槽位 Q/E/R**（旧版"仅 Q 槽位"已废弃）
- [x] 多种技能类型：AreaDamage / Projectile / Dash / Buff / Heal / Summon
- [x] **充能层系统**（1~3 层，灵物可加充能上限）
- [x] **蓄力系统**（Lv1/2/3：伤害 + 范围倍率 + 蓄力期间减速）
- [x] 释放速度倍率（GameConfig + 灵物加成）
- [x] CD 缩减（来自槽位灵物）
- [x] Debug VFX（无 prefab 时落石 / 护盾 / 治疗 / 位移 / 召唤物 自动用 `CreatePrimitive` 生成）

#### 灵物
- [x] 数据驱动（`ItemData` ScriptableObject）
- [x] 拾取 & 自动生效（`ItemInventory.AddItem`）
- [x] 属性叠加计算（绝对值 + 百分比分层）
- [x] **灵物槽位系统 `SpiritSlotSystem`**（6 个槽位：Q/E/R 各 2 个）
- [x] 槽位独占词条：充能上限、蓄力速度、蓄力伤害、CD 缩减
- [x] **质变阈值检测 + 机制效果**（焚天 / 玉碎 / 御风 / 剑阵 / 涅槃，详见 `灵物系统.md`）
- [x] **协同（Synergy）系统**：10 个组合（风火轮 / 金刚不坏 / 天人合一 / 嗜血狂魔 / 冰火两重天 / 灵龟护体 / 疾风骤雨 / 万毒归宗 / 铜墙铁壁 / 暗影刺客）
- [x] 协同附加机制效果：火墙、嗜血、元素爆发
- [x] 创建测试灵物 SO（火灵珠 / 风灵珠 / 玉佩 / 锈铁飞剑 / 回灵丹 / 寒冰玉髓 / 血珊瑚 / 破镜碎片 / 灵藤草 / 星辰尘 / 引魂灯）
- [x] 创建测试功法 SO（落石术 / 金钟罩 等）

#### 敌人
- [x] **基础近战敌人** `EnemyBase`（追踪 + Strafe + 攻击预警 + 概率闪避）
- [x] **远程弓箭手** `EnemyRanged`（Kite + 红色预警线 + 投射物 + 概率后跳）
- [x] **冲锋敌人** `EnemyCharger`（蓄力 + 范围预警 + 撞击）
- [x] **法师** `EnemyMage`（魔法弹 + 爆炸）
- [x] **精英怪** `EnemyElite`
- [x] **Boss** `EnemyBoss`（多阶段 + 特殊技能）
- [x] 敌人 Layer 设置（Enemy 层 + 递归子物体）
- [x] 敌人投射物 / 玩家投射物 与墙壁碰撞回收

#### 房间
- [x] 战斗房间（波次生成 + 清完奖励）
- [x] 商店房间（NPC + 购买 / 出售）
- [x] 休息房间（回血泉水）
- [x] 宝箱房间（开箱掉落）
- [x] 关卡过渡（传送门）
- [x] 境界推进（练气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫，6 层）

#### UI
- [x] HUD（血条 / 境界 / CD / 消息）
- [x] **技能栏 UI**（图标 + 灵物槽位 + 悬停提示 + 拖拽）
- [x] 背包面板（灵物列表 + 详情）
- [x] 小地图（房间类型标记）
- [x] 伤害飘字（多种 Tag 样式）
- [x] 敌人血条（世界空间跟随）

#### 音频
- [x] 音效系统框架（`AudioConfig` + `AudioManager` + 事件自动播放）

### 🔲 待完成 / 优化
