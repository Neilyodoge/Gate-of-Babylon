## 1. 游戏概述

### 1.1 一句话描述

> 一款冒险题材的 Roguelike Top-down 3D ARPG（参考《梦之形》视角风格），玩家扮演立志终极挑战成功的冒险者，在基地休整修炼与关卡历练之间循环，通过自由组合增强道具和技能构建无限可能的 Build，探索秘境探索的终极真相。

### 1.3 参考作品分析

**《Shape of Dreams / 梦之形》的不足（我们要解决的问题）：**

| 问题 | 我们的解决方案 |
|------|--------------|
| Build 多样性有限，几局后见过所有东西 | 150+ 增强道具 + 100+ 隐藏组合，理论 Build 数近乎无限 |
| 宝石系统偏数值，缺乏机制深度 | 不做独立宝石系统；将其降级为"模块改造件 / 符文"，作为触发器和效果器的第三层修饰 |
| 叙事/世界观薄弱 | 冒险世界观 + 意志/威胁度 + 多结局抉择，碎片化剧情 + 终极悬念 |
| 缺乏长期目标（Meta Progression） | 完整的局外成长系统：模块解锁 + 触发器强化 + 起始模板 + 前哨蓝图 / 寿命强化 |
| 重玩价值低 | 起始模板 × 随机增强道具 × 隐藏组合 = 每局体验差异化 |

### 1.4 制作时表格的设计准则与规范：
目前随着策划的加入，对表格的需求也愈发重要，因此在此设计好一系列的规范和准则用来让整个流程可以更加符其他人协调制作，那么下面进行说明；
- **关于表格的制作说明**：
大部份设计会添加表格进行控制，控制范围会针对每项功能进行定制；
未提及表格的功能则默认不制作表格；
制作表格时，可根据说明的核心需求自行判断是否增加表格的控制范围，但需要在每次更新后进行详细说明（可直接修改文档进行说明）；
设计表格目的是为了可以在各个功能中进行灵活的控制和调整，方便策划或其他人进行修改；

## 2. 世界观与叙事

玩家扮演一名进入危险关卡探索的冒险者。基地是玩家的休整、配置与长期成长场所；关卡是玩家进行长局构筑、挑战 Boss、获取经验值和解锁线索的主要场景。

叙事目标是服务 Roguelite 循环：每一次死亡、返回或通关都会让玩家更理解世界、更接近终局真相。剧情通过 Boss、事件、记忆碎片、基地 NPC 和多结局逐步展开。

---

## 3. 核心循环

```text
基地
  → 结算经验值
  → 提升模块熟练度 / 解锁起始模板 / 配置前哨与补给
  → 选择起始模板进入关卡

关卡
  → 获取触发器 / 效果器 / 改造件 / 增强道具
  → 拼出本局 Build
  → 阶段返回、死亡或通关
  → 按不同倍率结算经验值
```

**结算结果**：

| 结果 | 经验倍率 | 设计目的 |
|------|---------|---------|
| 死亡 | 低 | 失败也能推进局外成长 |
| 阶段返回 | 中 | 玩家主动收手，保守结算 |
| 通关 | 高 | 奖励完整长局与高风险挑战 |

**局外成长**：
- 经验值是唯一通用局外资源。
- 来源标签只影响经验转化方向，例如战斗、模块、触发器流派、探索、情报、Boss。
- 成长出口包括模块熟练度、起始模板、前哨蓝图、寿命强化和剧情推进。

## 4. 触发器流派系统

### 4.1 起始模板：教学方向，不是职业锁定

起始模板只负责解决两个问题：
1. **新手方向感**：开局知道自己这一局大概围绕什么逻辑玩。
2. **早期可玩性**：开局至少拥有一组能运转的触发器 / 效果器 / 改造件。

模板不限制后续 Build。玩家在局内可以捡到其他触发器并完全转向。

| 模板 | 起始触发器 | 起始效果器 / 改造件 | 教学目标 |
|------|-----------|-------------------|---------|
| **播种者** | 种子生成、种子引爆 | 毒雾 / 扩散符文 | 教玩家理解状态层数与引爆 |
| **刺客** | 闪避后、背击标记 | 突刺 / 连击符文 | 教玩家理解位置与窗口 |
| **指挥者** | 傀儡计数、傀儡协同 | 护盾 / 分流符文 | 教玩家理解多单位协作 |

### 4.2 模块熟练度：取代天赋树

| 成长对象 | 解锁内容 | 示例 |
|---------|---------|------|
| **触发器熟练度** | 默认效果强化、条件降低、触发变体 | 种子默认 DoT 提升；种子上限 +1；背击标记持续更久 |
| **效果器熟练度** | 新效果变体、数值基线、特殊目标逻辑 | 毒雾可治疗玩家；护盾破裂爆炸；突刺可穿透 |
| **改造件熟练度** | 改造范围、次数、组合规则 | 扩散符文范围扩大；连锁符文多跳 1 次 |
| **起始模板熟练度** | 开局可携带更多模块或替换起始模块 | 播种者开局可在毒雾 / 治疗 / 荆棘中选 1 个 |

这样保留长期成长，但不再增加"职业天赋树"这一层 UI 和规则。

## 5. 增强道具系统（道具体系）

### 5.1 设计哲学

> **所有东西统一叫"增强道具"，获取后自动生效，没有装备栏的概念。**
> 就像以撒一样：捡到就生效，叠加就完事。
> 没有"装备"和"套装"的区分——增强道具可以无限叠加（技能除外，最多3个）。

### 5.2 增强道具分类

分类仅用于内部标签和掉落权重，玩家不需要关心分类，；

| 分类 | 说明 | 示例 |
|------|------|------|
| ⚔️ 数值堆叠类 | 基础数值强化 | 增加攻击力、增加生命值等 |
| 🛡️ 机制增强类 | 强化机制类的数值 | 增加技能释放速度、增加供给速度等 |
| 👟 机制修改类 | 从根本逻辑上修改机制 | 投射物分裂、攻击带顺劈等 |

### 5.3 增强道具品阶

| 品阶 | 颜色 | 出现概率 | 强度 | 数量目标 |
|------|------|---------|------|---------|
| 凡品 | ⚪白 | 50% | 基础 | 60+ |
| 灵品 | 🟢绿 | 30% | 中等 | 40+ |
| 玄品 | 🔵蓝 | 15% | 强力 | 25+ |
| 地品 | 🟣紫 | 4% | 极强 | 15+ |
| 天品 | 🟡金 | 1% | 改变玩法 | 8+ |

> **目标增强道具总数：150+**

### 5.4 增强道具设计示例

#### ⚔️ 数值堆叠类

| 名称 | 品阶 | 效果 |
|------|------|------|
| 药蛇之血 | 凡品 | 增加5%生命值 |
| 朱睛冰蟾 | 灵品 | 增加10%攻击力 |
| 化界石 | 灵品 | 增加增强道具10%的攻击力 |

#### 🛡️ 机制增强类

| 名称 | 品阶 | 效果 |
|------|------|------|
| 岩甲符 | 凡品 | 护盾回复量额外增加50% |
| 寒玉髓 | 灵品 | 冰冻持续时间额外增加0.5秒 |

#### 🔮 机制修改类

| 名称 | 品阶 | 效果 |
|------|------|------|
| 磨剑石 | 凡品 | 每次攻击可以发射一道剑气（最多5层）剑气只能命中一个单位 |
| 威胁度丝 | 灵品 | 释放技能时命中目标额外增加1个（最多10层） |

### 5.5 叠加规则

根据修改，现在叠加不在进行限制，不同类型的增强道具也可以进行叠加，例如磨剑石*2+威胁度丝*2，那么一次普通攻击可以射出2道剑气并且可以对4个敌对单位造成伤害；
叠加规则不会有特殊限制，只是会有叠加上限，例如目前磨剑石和威胁度丝都会有上限，但后续可能会有其他机制修改不会设定上限，因此在其基础上，还需要规范好新的掉落规则来完善整个体验；


---

### 5.6 掉落规则
- 数值堆叠类：通过表格控制权重，与现在掉落逻辑相同，可以打小怪或商店等一系列方式产出；
- 机制增强类：与数值堆叠相同，但掉落权重比数值堆叠类小，产出进行一定程度压缩；
- 机制修改类：不会通过击杀小怪方式掉落，而是通过事件或战斗房挑战结束以及商店产出，下面进行详细说明；
> 事件掉落：与房间中事件绑定，用于产出一些专属机制修改类增强道具，一般会设的比较强；
战斗房间挑战：现在每次战斗结束需要新增一个选牌机制，玩家完成当前关卡的战斗后就会出现三选一，三选一中会出现所有类型的增强道具（包括机制修改类）
商店产出：后续在商店添加增强道具的产出即可；

## 6. 模块化技能系统（Trigger + Effect + Modifier）

### 6.1 核心逻辑：[触发] → [执行] → [改造]

技能不再是一个整体，而是由三类模块拼装而成：
1. **触发器 (Trigger)**：定义"什么时候"发动。
2. **效果器 (Effect)**：定义"发动什么"效果。
3. **改造件 (Modifier)**：定义"这个效果如何变形"。

```
[移动 10 米] + [向最近敌人落雷] + [连锁符文]
  = 跑动中自动落雷，命中后连锁到附近敌人

[种子引爆] + [毒雾] + [扩散符文]
  = 引爆种子时生成毒雾，并向周围扩散
```

### 6.2 触发器分类 (Trigger Types)

触发器决定了技能的启动条件或状态载体，分为**纯条件触发器**和**状态型触发器**。不再存在"职业专属触发器"，只有起始模板推荐触发器。

#### 6.2.1 纯条件触发器 (Condition Triggers)
所有模板均可获得的模块：
- **攻击触发**：每进行 X 次普攻触发。
- **位移触发**：每移动 X 米触发。
- **受击触发**：受到伤害时触发（有冷却）。
- **击杀触发**：击败敌人时触发。
- **时间触发**：每隔 X 秒自动触发。
- **闪避触发**：成功进行闪避动作时触发。

#### 6.2.2 状态型触发器 (State Triggers)
状态型触发器会创建标记、层数、召唤物或计数器，因此必须自带默认轻量效果：

| 触发器 | 默认轻量效果 | 主要用途 |
|--------|-------------|---------|
| **种子生成** | 普攻命中挂 1 颗种子，种子造成极低 DoT | 给种子引爆、毒雾、治疗等效果器提供状态载体 |
| **种子引爆** | 种子达到阈值时可触发一个小范围弱爆炸 | 把种子层数转化为主效果器收益 |
| **背击标记** | 背后命中挂"破绽"，下一次命中小幅增伤 | 给突刺、斩击、连击等效果器提供爆发窗口 |
| **傀儡计数** | 生成低伤傀儡计数器或记录傀儡攻击次数 | 给协同施法、护盾、分流等效果器提供对象 |
| **蓄力层数** | 行为满足条件时累积层数，满层后强化下一次模块 | 给主动爆发、护盾、召唤等效果器提供节奏 |

默认效果的强度必须低，主要强度来自接上的效果器和改造件。

### 6.3 效果器分类 (Effect Types)

效果器定义了触发后的具体表现，分为**主动执行**和**被动执行**。

#### 6.3.1 执行模式
- **被动模式 (Passive)**：一旦触发器条件满足，立即自动执行效果。适合高频、辅助类组合。
- **主动模式 (Active)**：触发器条件满足后，技能图标亮起（Proc），玩家必须手动按下对应按键（Q/E/R）才能释放效果。适合爆发、大招类组合。

#### 6.3.2 效果模块示例
- **攻击类**：发射剑气、召唤陨石、喷射火焰、释放冲击波。
- **辅助类**：获得护盾、瞬间位移、回复生命、增加攻速。
- **逻辑强化类 (Dungeon 100 风格)**：
    - **左侧强化**：使该模块左侧的效果器伤害 +100%。
    - **右侧强化**：使该模块右侧的效果器冷却时间 -50%。
    - **双重投射**：使相连的效果器额外触发一次。

### 6.4 改造件分类 (Modifier Types)

改造件是原"宝石 / 槽位修饰"的重定位。它们不作为独立系统出现，而是作为模块化技能的第三层：

| 类型 | 作用 | 示例 |
|------|------|------|
| **形态改造** | 改变效果器的外形和覆盖方式 | 火球 → 火墙；落石 → 陨石；毒雾 → 毒环 |
| **目标改造** | 改变目标选择逻辑 | 最近敌人 → 最远敌人；单体 → 链锁；前方 → 环绕 |
| **次数改造** | 改变触发次数或投射数量 | 额外触发 1 次；投射物 +2；每第 3 次触发强化 |
| **元素改造** | 给效果器附加元素或状态 | 火焰、寒冰、雷击、毒蚀、击退 |
| **执行改造** | 改变主动 / 被动手感 | 自动触发改为蓄力释放；瞬发改为延迟爆炸 |

**设计边界**：
- 改造件不提供独立长期成长，长期强化交给模块熟练度 / 解锁节点。
- 改造件不单独占用一个系统入口，统一在技能模块界面内配置。
- 改造件可以来自局内掉落、模块经验标签解锁、前哨改造或特殊事件。
- 如果一个"宝石"只能写成 `伤害 +10%`，它就不该成为改造件；至少要改变形态、目标、节奏或策略。

### 6.5 插槽与组合逻辑 (Socket Logic)

每个职业提供不同的**插槽布局 (Socket Layout)**，玩家通过上下或左右连接模块。

- **上下组合**：上层为触发器，下层为效果器。
- **改造连接**：改造件挂在效果器或触发器侧边，改变相邻模块的行为。
- **放飞设计**：两个效果器可以组合成一个复合效果。例如：[火球] + [分裂] = 分裂火球。
- **麦卡贡模式**：[触发：移动 10 米] + [效果：向最近敌人落雷]。

### 6.6 操作模型

```
【近战普攻】—— 鼠标左键，三段连招
  → 三段连招：Attack1 → Attack2 → Attack3
  → 段伤害倍率：1.0 / 1.2 / 1.5
  → 扇形判定：半径 2.5，角度 120°
  → 攻击中"霸体"：轻击受击不打断连招
  → 250ms 输入缓冲：流畅连段
  → 每段带前冲 Lunge 位移

【模块化技能】—— Q / E / R 三个槽位
  → 每个槽位可配置一个 [触发器] + [效果器] + [改造件] 组合
  → 主动模式下，满足触发条件后按键释放
  → 被动模式下，满足触发条件后自动释放

【闪避】—— Space 键
  → 距离 5 单位，持续 0.2s
  → 全程无敌帧 0.3s
  → 2 层充能，每层 CD 1.5s
```

## 7. 隐藏组合系统（Synergy）

### 7.1 设计哲学

> **没有"流派"这个概念。没有"你是剑修"这种标签。**
> 只有：增强道具 + 增强道具 = 效果，效果 + 效果 = Build。
> 玩家的 Build 是自然涌现的，不是选择出来的，而是"拼"出来的。

### 7.2 组合触发规则

| 触发类型 | 说明 | 示例 |
|---------|------|------|
| 特定道具触发 | 指定的2-4件增强道具同时持有 | 锈铁飞剑+磨剑石→"十年磨一剑" |
| 标签触发 | 集齐特定五行标签组合 | 5种五行各1件→"五行归一" |
| 数量触发 | 同类增强道具达到一定数量 | 4件飞剑→"万剑归宗" |
| 条件触发 | 满足某种游戏状态 | 连续3房间没拿增强道具→"否极泰来" |

### 7.3 隐藏组合列表

> 目标总数：**100+**，以下为已设计的核心组合。

#### 🗡️ 飞剑相关

| 组合名 | 触发条件 | 效果 | 暗示文本 |
|--------|---------|------|---------|
| 万剑归宗 | 持有4件以上飞剑类增强道具 | 所有飞剑自动追踪，飞剑数量=持有数x2 | 锈铁飞剑："剑在精不在多……真的吗？" |
| 十年磨一剑 | 锈铁飞剑 + 磨剑石 | 锈铁飞剑进化为"无名神剑"，伤害x10 | 磨剑石："再平凡的铁，也能磨出锋芒" |
| 剑气长河 | 任意飞剑 + 水灵珠 + 御剑术 | 飞剑攻击留下水属性剑气轨迹，持续伤害+减速 | 水灵珠："剑意如水，绵绵不绝" |
| 雷霆剑域 | 紫霄雷印 + 任意2件飞剑 | 飞剑之间产生闪电链，连锁电击 | 紫霄雷印："雷霆之下，万剑臣服" |

#### 🔥 元素互动

### 7.4 Synergy 发现与展示

**获取增强道具时：**
- 如果与已有增强道具形成组合，弹出金色提示："✨ 协同触发：万剑归宗！"
- 屏幕短暂闪光 + 特殊音效，给予强烈正反馈

**技能图录（道具图鉴）：**
- 古籍卷轴风格的 UI
- 已发现的组合显示完整描述
- 未发现的显示为"此页残缺，尚需机缘..."
- 收集进度称号：散修 → 内门弟子 → 长老 → 掌门 → 仙人

**暗示系统：**
- 增强道具描述中用 flavor text 暗示可能的组合
- 例：紫霄雷印描述"雷霆之下，万剑臣服"→ 暗示与飞剑有协同
