# ✨ 隐藏组合表（Synergy）

> 没有"流派"这个概念。没有"你是剑修"这种标签。
> 只有：灵物 + 灵物 = 效果，效果 + 效果 = Build。
> 玩家的 Build 是自然涌现的，不是选择出来的，而是"拼"出来的。

---

## 触发规则

| 触发类型 | 说明 | 示例 |
|---------|------|------|
| 特定道具触发 | 指定的 2~4 件灵物同时持有 | 锈铁飞剑+磨剑石→"十年磨一剑" |
| 标签触发 | 集齐特定五行标签组合 | 5 种五行各 1 件→"五行归一" |
| 数量触发 | 同类灵物达到一定数量 | 4 件飞剑→"万剑归宗" |
| 条件触发 | 满足某种游戏状态 | 连续 3 房间没拿灵物→"否极泰来" |

## 发现与展示

**获取灵物时：**
- 如果与已有灵物形成组合，弹出金色提示："✨ 协同触发：万剑归宗！"
- 屏幕短暂闪光 + 特殊音效，给予强烈正反馈

**功法图录（道具图鉴）：**
- 古籍卷轴风格的 UI
- 已发现的组合显示完整描述
- 未发现的组合显示暗示文本（如"此剑虽锈，剑意犹存"）
