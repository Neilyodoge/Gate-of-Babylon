# 隐藏组合表（Synergy）

> v0.6 起，隐藏组合不再围绕“灵物分类 / 五行标签 / 职业变体”设计，而是围绕 **触发器 + 效果器 + 改造件 + 增强道具** 的行为协同。

---

## 1. 设计目标

隐藏组合要让玩家产生这种反馈：

> “这两个模块放一起，规则居然变了。”

而不是：

> “这两个道具放一起，数字变高了。”

---

## 2. 触发类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **模块链协同** | 指定触发器、效果器、改造件形成特殊规则 | 种子引爆 + 毒雾 + 扩散符文 |
| **状态协同** | 某个状态被另一个模块消费 | 背击标记被突刺消耗后刷新闪避 |
| **增强道具协同** | 增强道具改变模块链表现 | 护盾回响 + 傀儡协同 |
| **行为条件协同** | 玩家行为满足额外条件 | 连续 3 次主动 Proc 都在背后释放 |
| **高风险协同** | 强收益伴随代价 | 低血量时触发双倍爆炸，但持续掉血 |

---

## 3. 首批组合候选

| 组合名 | 条件 | 效果 |
|--------|------|------|
| 百草齐放 | `[种子引爆] + [毒雾] + [扩散符文]` | 种子爆炸后生成毒雾，毒雾击杀敌人会继续扩散 |
| 荆棘回春 | `[种子生成] + [治疗] + 肥沃土壤` | 种子被引爆时为玩家回复少量生命 |
| 无影连杀 | `[背击标记] + [突刺] + [连击符文]` | 背击突刺击杀后刷新一次短距离闪避 |
| 破绽雷击 | `[背击标记] + [落雷]` | 落雷优先命中带破绽的目标，并小范围溅射 |
| 傀儡护阵 | `[傀儡协同] + [护盾] + [分流符文]` | 傀儡协同时给附近单位刷新护盾 |
| 炮台毒云 | `[傀儡计数] + [毒雾] + 分流核心` | 傀儡攻击累计后在目标处释放毒雾 |
| 跑雷 | `[移动 X 米] + [落雷] + 疾行靴` | 移动触发距离降低，落雷频率提高 |
| 延时爆破 | `[受击时] + [冲击波] + [延时符文]` | 受击后延迟爆炸，延迟期间再次受击会扩大范围 |
| 护盾反响 | `[护盾] + 护盾回响 + [扩散符文]` | 护盾破裂冲击波会向周围敌人扩散 |
| 双发毒雷 | `[击杀时] + [落雷] + [双重投射] + 毒性培养皿` | 击杀后双雷命中目标，留下短暂毒区 |

---

## 4. 发现与展示

**发现前**：
- 图鉴只显示暗示文本，例如“种子不是只会爆炸，也可以开花。”

**首次触发时**：
- 屏幕提示组合名。
- 模块链高亮。
- 图鉴解锁完整描述。

**重复触发时**：
- 只显示小提示，避免打断战斗。

---

## 5. 与模块熟练度的关系

隐藏组合不是永久成长，但可以成为模块熟练度的解锁条件：

| 行为 | 解锁 |
|------|------|
| 首次触发某组合 | 解锁图鉴记录 |
| 同一组合触发 N 次 | 解锁对应模块熟练度节点 |
| 用某组合通关 | 解锁起始模板替换模块 |

---

## 6. 设计边界

- 不做独立“五行组合”系统。
- 不做职业限定组合。
- 尽量避免“仅数值 +X%”的组合奖励。
- 强组合要有可见行为变化，最好能一眼看懂。
