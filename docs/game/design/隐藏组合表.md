# 隐藏组合表（Synergy）

> **状态：旧《秘境探索》协同表，2026-09-02 起冻结。**  
> 旧表围绕触发器、效果器和改造件；ProjectR现行组合见[载体与回路](systems/载体与回路.md)，历史背景见[统一归档 §3](旧版秘境探索归档.md)。

---

## 1. 设计目标

隐藏组合要让玩家产生这种反馈：

> “这两个模块放一起，规则居然变了。”

而不是：

> “这两个道具放一起，数字变高了。”

---

## 2. 触发类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **模块链协同** | 合法模块链满足额外标签或行为条件后形成特殊规则 | 种子引爆 + 毒雾 + 扩散符文，且本房间毒雾击杀 ≥ 10 |
| **状态协同** | 某个状态被另一个模块消费 | 背击标记被突刺消耗后刷新闪避 |
| **行为条件协同** | 玩家行为满足额外条件 | 连续 3 次主动 Proc 都在背后释放 |
| **高风险协同** | 强收益伴随代价 | 低血量时触发双倍爆炸，但持续掉血 |

---

## 3. 首批组合候选

| 组合名 | 条件 | 额外质变 |
|--------|------|---------|
| 百草齐放 | `[种子引爆] + [毒雾] + [扩散符文]`，且本房间毒雾击杀 ≥ 10 | 毒雾击杀敌人后生成 1 个新种子状态 |
| 荆棘回春 | `[种子生成] + [治疗] + [扩散符文]`，且 Seed 标签 ≥ 3 | 种子被消耗时产生小范围治疗脉冲 |
| 无影连杀 | `[背击标记] + [突刺] + [连击符文]`，且连续背击击杀 ≥ 3 | 刷新一次短距离闪避 |
| 破绽雷击 | `[背击标记] + [落雷] + [连锁符文]`，且目标身上有破绽 | 落雷优先命中破绽目标，并额外连锁 1 次 |
| 傀儡护阵 | `[傀儡协同] + [护盾] + [分流符文]`，且场上傀儡 ≥ 2 | 护盾在傀儡之间分流，破裂时产生小范围冲击 |
| 炮台毒云 | `[傀儡计数] + [毒雾] + [分流符文]`，且傀儡攻击累计达到阈值 | 在傀儡目标处释放毒雾 |
| 跑雷 | `[移动 X 米] + [落雷] + [连锁符文]`，且 5 秒内未停止移动 | 连锁次数 +1，并在玩家路径上留下短暂电痕 |
| 延时爆破 | `[受击时] + [冲击波] + [延时符文]`，且生命值低于 35% | 延迟爆炸范围扩大，但触发后 3 秒内受到治疗降低 |

---

## 4. 发现与展示

**发现前**：
- 图鉴只显示暗示文本，例如“种子不是只会爆炸，也可以开花。”

**首次触发时**：
- 屏幕提示组合名。
- 模块链高亮。
- 图鉴解锁完整描述。

**重复触发时**：
- 只显示小提示，避免打断战斗。

---

## 5. 与模块熟练度的关系

隐藏组合不是永久成长，但可以成为模块熟练度的解锁条件：

| 行为 | 解锁 |
|------|------|
| 首次触发某组合 | 解锁图鉴记录 |
| 同一组合触发 N 次 | 解锁对应模块熟练度节点 |
| 用某组合通关 | 解锁起始模板替换模块 |

---

## 6. 设计边界

- 不做独立“五行组合”系统。
- 不做职业限定组合。
- 尽量避免“仅数值 +X%”的组合奖励。
- 强组合要有可见行为变化，最好能一眼看懂。
