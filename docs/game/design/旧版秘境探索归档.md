# 《秘境探索》旧版统一归档

> 状态：历史归档  
> 冻结日期：2026-09-02  
> 替代方向：[ProjectR GDD](GDD_秘境探索.md)

本文集中记录 ProjectR 立项前《仙途秘境／秘境探索》的设计演变、已实现系统和可复用技术。以下内容不再构成当前产品规则；需要追溯完整原文时，以 Git 历史和本文末尾列出的历史快照为准。

## 1. 历史产品定位

旧版是一款 Roguelike Top-down 3D ARPG。玩家从基地进入区域式地牢，通过主动技能和模块增强链构筑 Build，击败阶段 Boss 后结算经验、材料和剧情进度。

设计经历过以下阶段：

1. 修仙搜打撤、洞府种田与道伤惩罚。
2. 御灵五系、化身、灵物和独立天赋树。
3. 去修仙化后的通用冒险题材。
4. Trigger / Effect / Modifier / Universal 模块增强链。
5. Silverua 线性路线图。
6. Edgar Grid3D 区域式地牢。
7. 无暮王城白昼／永夜双阶段。

2026-09-02 起，产品方向由 ProjectR 全面替代。旧版只保留技术资产、实现经验和历史参考价值。

## 2. 旧版核心循环

```text
基地
  → 选择初始技能或配置
  → 进入秘境
  → 获取技能与模块
  → 拼装本局增强链
  → 战斗、事件、商店与 Boss
  → 死亡、阶段返回或通关
  → 结算经验与材料
```

旧结算档位：

- 死亡：低倍率结算。
- 阶段返回：安全结算并保留阶段状态。
- 通关：击败 Boss 后高倍率结算。
- 完美通关：额外挑战收益。

ProjectR 不再沿用“Boss 是唯一通关钥匙”和“模块首次发现即永久解锁”的主循环。

## 3. 旧模块增强系统

旧战斗由主动核心技能和增强链组成：

```text
核心技能
  ← Trigger：何时上膛
  → Effect：消费时增加什么
  → Modifier：怎样改变形态、数量、目标或节奏
```

主要规则：

- Q/E/R 各装备一个核心技能。
- 每个技能最多绑定一条模块链。
- Trigger 支持 Single、Window、Stacks 和 Auto 四种消费节奏。
- Effect 分为增强技能本体和附加独立世界效果。
- Modifier 改变范围、目标、数量、节奏、状态或代价。
- Universal 可以放入 Trigger 或 Effect 槽承担对应职责。
- 非战斗状态下可以免费重组模块。

已实现的代表能力包括：

- 暴击、命中、闪避、移动、受击、击杀和时间触发。
- 种子、背击标记等状态型触发。
- 投射物追加、链锁、环绕、持续区域和延迟爆炸。
- Proc 就绪 HUD、技能槽覆盖层和消费反馈。

ProjectR 复用其事件驱动、Proc / Consume、标签兼容和可读反馈思想，但废弃四类模块作为玩家可见领域模型：

- 状态产物与部分 Trigger 思想迁移为器灵“源”。
- 行为 Trigger 思想迁移为器灵“应”。
- Effect 思想迁移为器灵“化”。
- Modifier 思想拆分为器灵悟法与载体铭刻。
- SkillData 逐步包装为动作载体。
- 三条独立技能链改为跨器灵、跨载体回路。

## 4. 旧关卡 A：无暮王城

无暮王城采用白昼／永夜双阶段：

- 白昼表现永恒秩序与加冕循环。
- 永夜揭示亡者收容设施和被掩盖的历史。
- 白昼 Boss 后可以直接追入永夜或返回基地。
- 永夜复用同一 Seed、布局、出生区和 Boss 节点。
- 白昼事件结果会在永夜形成实体或机制后果。
- 永夜 Boss 击败后完整结算并重置到下一轮白昼。

四项主要事件：

1. 断裂巡礼桥：改变封藏室支路是否开放。
2. 冠光仪：禁用或偏转白昼 Boss 的冠光裁决。
3. 禁卫召集阵：改变永夜 Boss 的召唤规模。
4. 狱城升降井：生成双向、单向或无快捷通道。

该故事与双阶段规则不再作为 ProjectR 垂直切片现行设计。是否将无暮王城改造成首个蜂巢生态区仍是开放决策。

## 5. 已实现的区域地图基础

以下技术资产继续保留并作为 ProjectR 蜂巢秘境底座：

- Edgar PRO Grid3D 运行时实体生成。
- Layout A/B/C/D 多 Flow 与 Seed 复现。
- 13 个基础节点及可选连接段伸缩。
- 建筑池、特殊房注入和受控捷径。
- 外环、连接区、内环分区与房间标签。
- `Dormant → Armed → Active → Completed` 房间生命周期。
- 房间回访不重新抽取遭遇。
- 战斗封门、NavMesh carving 与运行时重建。
- 安全出生点、Doorway 通行和胶囊净空校验。
- 内容 Socket、怪物刷新区域和固定 Encounter Seed。
- 布局模板与故事模板正交。
- 事件结果同步改变模型、碰撞、提示和寻路。

ProjectR 将在此基础上新增区域状态、邻接传播、器灵迁移、污染／净化、秘境躁动、模糊情报、多目标出口和中途撤离。

## 6. 旧敌人、精英与 Boss 基础

可复用能力：

- 近战攻击名额与攻击后让位。
- 远程、法术、冲锋和精英行为。
- NavMesh Agent 寻路与 CharacterController 技能位移。
- 精英受控闪避和闪避反击。
- `EnemyAbilityProfile / Planner / Executor` 条件式技能选择。
- Boss 生命阶段、距离、昼夜、Flag、冷却和次数条件。
- 攻击预警、Boss 血条、HitStop、震屏和伤害反馈。

ProjectR 不再沿用旧 Boss 身份和强制结算门。首个切片 Boss 改为可观察、可拆解回路的失控聚合体灾相。

## 7. 旧局外、存档与结算

曾经实现或讨论过：

- 模块与技能永久发现。
- 三槽玩家进度存档。
- Build 不带出、局内运行态清空。
- 洞府材料本局缓冲和结算提交。
- 藏经阁、阵法台和基地五类功能插槽。
- 白昼／永夜阶段 Seed 与事件结果保存。
- 死亡、阶段返回和通关结算面板。

已删除或退出主路径：

- 灵脉、闭关石室、灵兽园、机缘、灵田和炼器房。
- 道伤、心魔、渡劫、秘境异象与境界压制。
- 职业、化身、灵物、独立天赋树与大秘境。
- Build 快照、Build 背包和局外 Build 装备。

ProjectR 保留三槽存档、洞府素材缓冲、基地插槽和撤离提交思想，新增永久器灵实例、性格、关系、悟法池和出发准备。

## 9. ProjectR 复用边界

### 继续使用

- URP 与PC主动战斗输入。
- 基础数值、伤害、投射物、状态和战斗反馈。
- Edgar空间生成、Seed、房间状态与NavMesh。
- 事件Flag、场景结果和Boss条件技能框架。
- 三槽存档、基地Prefab插槽和撤离材料缓冲。
- CSV／配置数据库与编辑器关卡工具。

### 适配后使用

- `PlayerCombat` 拆分为载体执行和薄协调层。
- `SkillData` 包装为武器、术法和身法载体。
- `GameEvents` 扩展为带来源与因果链的回路事件。
- 模块装配UI改为器灵附着和回路预览。
- 地图Provider增加蜂巢状态与能力接口。
- Boss事件改为灾相回路和非强制目标。

### 冻结并最终删除

- Trigger / Effect / Modifier / Universal 玩家可见模块体系。
- Q/E/R 三条彼此独立的一技能一链规则。
- 无暮王城双阶段强制Boss推进。
- 旧技能／模块永久发现主循环。
- Silverua、TreeMap和其他旧地图死路径。
- 旧故事、奖励和孤儿UI。

删除必须发生在 ProjectR 对应切换闸门通过之后，不能先清理再补功能。
