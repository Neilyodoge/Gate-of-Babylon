## 📌 项目整体定位（v0.5 修订）

```
《仙途秘境》= 玄幻修真主轴 (70%) + 武侠辅料 (30%)
            + Roguelite 战斗 + 搜打撤式秘境探索 + 洞府种田 meta progression
```

**单局节奏**：1~30 分钟（短局只闯 1~2 层撤离，长局完整通关 6 层）
**战斗 vs 洞府比重**：约 **7:3**（战斗为主，洞府是补给 + 长线成长）

| 子系统 | 描述 | 依赖 |

| 系统 | 修仙原型 | 最小可用版（Demo2 必做） |

## 📌 决策点（Demo2 启动前需确认）

1. **洞府 6 模块全部做 vs 只做最重要的 4 个**？
   - 全部做 → 玩家体验完整修仙循环
   - 只做 4 个（灵田 / 炼器房 / 悟道蒲团 / 阵法台） → 工期缩短 30%
   - **推荐**：全部做"最小可用版"，每个只做 ~30% 深度

2. **撤离时间**：5s 蓄力 / 10s 蓄力 / 立即撤离？
   - 5s → 紧张感强
   - 10s → 太长，挫败感
   - 立即 → 失去搜打撤精髓
   - **推荐**：5s 蓄力 + 期间被发现可被攻击中断

3. **死亡惩罚力度**：
   - 100% 失去洞府素材（最严厉）
   - 100% 失去 + 10% 残念补偿（**推荐**）
   - 50% 失去（温和）
   - **推荐**：100% + 10% 残念补偿（保留搜打撤紧张感 + 不让玩家完全绝望）

4. **现实时间挂机 vs 游戏内时间**：
   - 真实时间（玩家不在线时也涨） → P2W 风险 / 反人性
   - 游戏内时间（玩家在线时才涨） → 推荐
   - 加速按钮（消耗灵气立即完成）→ 都需要
   - **推荐**：游戏内时间 + 加速按钮

5. **火属性化身重设计时机**：
   - Demo2 一起做 → 时间紧
   - Demo2 后单独做 → 推荐
   - **推荐**：Demo2 上线后用新机制（天劫 / 心魔劫 / 灵脉 / 机缘事件）作为载体重新设计火属性化身的玩法
