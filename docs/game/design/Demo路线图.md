## 📌 项目整体定位（v0.6 修订）

```
《仙途梦境》= 玄幻修真主轴 (60%) + 武侠辅料 (25%) + 现代凡人入梦框架 (15%)
            + Roguelite 战斗 + 搜打撤式秘境探索 + 洞府种田 meta progression
            + 法宝养成 + 因果轮转 + 仙山舆图 + 机缘叙事（v0.6 新增）
```

**单局节奏**：1~30 分钟（短局只闯 1~2 层撤离，长局完整通关 6 层）
**战斗 vs 洞府比重**：约 **7:3**（战斗为主，洞府是补给 + 长线成长）

## 🎯 当前下一步行动建议（v0.6 修仙原生重构）

> Demo2 (v0.5) 已全部完成。当前进入 Demo2.5 (v0.6) 阶段——修仙原生重构。

按"法宝先行 → 因果联动 → 内容填充"的原则：

### Week 1~2：法宝系统 MVP

1. **`TreasureData` SO 设计**：法宝名 / 品阶 / 槽位类型 / 主动技配置 / 被动效果 / 认主度
2. **法宝装备 UI**：替换原化身选择界面 → 洞府中 3 槽法宝选择
3. **G/H/J 法宝主动技**：输入系统扩展 + 法宝技能释放管线
4. **法宝被动效果**：装备时持续 StatusEffect
5. **首批 5 件法宝 SO**：青锋飞剑 / 噬灵蛊 / 玄龟壳 / 风羽履 / 水影匕
6. **原化身机制迁移**：完美收刀 → 青锋飞剑被动；播种收割 → 噬灵蛊被动 等

**成果**：玩家在洞府选 3 件法宝 → 入梦 → G/H/J 释放法宝技能 → 法宝被动生效。"法宝 = 我的身份"体验跑通。

### Week 3：法宝深度

1. **祭炼升阶**：炼器房扩展 + 灵气 + 素材 → 升品阶
2. **认主度**：使用累积 + 阈值效果（30%/60%/80%/100%）
3. **性命相连**：100% 认主 → 致死伤害法宝代主受劫

### Week 4：因果系统

1. **SaveData 扩展**：善因 / 业力 / 因果债列表
2. **当局触发**：阈值判定 → NPC 行为 / 商人态度 / 法宝叛主概率
3. **跨局触发**：上局因果 → 下局开局讯息 + 追杀 NPC
4. **视觉**：头顶光环 / 红雾 / 紫链

### Week 5：机缘叙事 3 个原型

1. **机缘事件 UI 框架**：通用展示 + 选项 + 因果写入
2. **古洞遗骸 / 散修结义 / 悬崖灵芝** 3 个原型
3. **机缘 → 因果系统联动**验证

### Week 6：Boss 因果变体

1. **BossSnapshot 生成器**：读因果 → 动态修饰 HP/攻击
2. **台词条件拼接**：优先级规则 + 因果台词库
3. **简单援军**：因果债触发时 spawn 追杀 NPC

### Week 7：仙山舆图 Phase 1

1. **拓扑生成**：多路径节点图 + 9 种地点
2. **御剑移动 + 随机遭遇**
3. **渡劫地点选择**
4. **简易 2D 地图 UI**

## 📌 决策点（Demo2 启动前需确认）

1. **洞府 7 模块全部做 vs 只做最重要的 4 个**？
   - 全部做 → 玩家体验完整修仙循环
   - 只做 4 个（灵田 / 炼丹房 / 悟道蒲团 / 阵法台） → 工期缩短 30%
   - **推荐**：全部做"最小可用版"，每个只做 ~30% 深度

2. **撤离时间**：5s 蓄力 / 10s 蓄力 / 立即撤离？
   - 5s → 紧张感强
   - 10s → 太长，挫败感
   - 立即 → 失去搜打撤精髓
   - **推荐**：5s 蓄力 + 期间被发现可被攻击中断

3. **死亡惩罚力度**：
   - 100% 失去洞府素材（最严厉）
   - 100% 失去 + 10% 残魂补偿（**推荐**）
   - 50% 失去（温和）
   - **推荐**：100% + 10% 残魂补偿（保留搜打撤紧张感 + 不让玩家完全绝望）

4. **现实时间挂机 vs 游戏内时间**：
   - 真实时间（玩家不在线时也涨） → P2W 风险 / 反人性
   - 游戏内时间（玩家在线时才涨） → 推荐
   - 加速按钮（消耗灵气立即完成）→ 都需要
   - **推荐**：游戏内时间 + 加速按钮

5. **火属性化身重设计时机**：
   - Demo2 一起做 → 时间紧
   - Demo2 后单独做 → 推荐
   - **推荐**：Demo2 上线后用 4 大新机制（顿悟 / 天劫 / 心魔 / 灵气浓度）作为载体重新设计火属性化身的玩法
