> 状态：玩法骨架、序章恢复、三宠选择UI、连续空间白盒、首批三宠单宠三动作原型及固定验证战已确定；主角与叙事开场已撤回，等待重新设计

## 1. 关卡目标

初契序章只教四件事：

1. 移动、镜头与普攻。
2. 从火花狸、响响鸮、弹弹胶中选择第一只灵宠。
3. 同一只灵宠附着到不同动作会以不同方式显化。
4. 使用选择结果完成第一场短战斗。

本关不教授三宠回路、完整天赋树、关系、区域生态、随机构筑、撤离提交或家园经营。玩家应该先喜欢并用懂一只灵宠，再在后续探索中理解多宠联动；若需要升级反馈，只允许一次无分支的示范点亮。

以上是玩法目标，不代表玩家开场后立刻看见操作教程。正式流程必须先用日常、人物关系或一个小事件建立情绪和行动理由，再把移动、攻击与初契自然嵌入事件。

## 2. 体验原则

- **凭第一印象选择**：选择前只给少量性格和战斗倾向，不安排三宠试玩，不展示成长树和完整技能表。
- **选择后立即验证**：初契后不进入长对话，玩家在两分钟内完成附着并开打。
- **灵宠决定效果，动作决定时机**：玩家理解的是同一只伙伴如何借不同动作显化，而不是背诵九个无关技能。
- **第一次附着可改**：初契对象永久确定，附着位置不是永久选择；玩家可在安全处重新换挂。
- **少文字、强反馈**：同屏最多出现两个新提示，第一次触发必须有清楚的动作、声音和HUD挂件反馈。

## 3. 空间结构

序章由四段连续空间组成，不使用“层”概念：

```text
开场安全区
  → 初契小坛
  → 训练场
  → 秘境出口
```

- **开场安全区**：安全、温暖、低信息密度；具体生活空间、日常目标和基础操作引导等待主角重新设计。
- **初契小坛**：三只灵宠围绕低矮稳定标记活动；三者必须同时可见，避免选择被界面抽象成纯卡牌。三宠如何到场等待叙事开场重写。
- **训练场**：一间可封门的小型战斗院落，先展示机制，再进行混合敌人验证。
- **秘境出口**：通往“风痕林谷”的普通出口，战斗结束后开放，只提示“前往风痕林谷；灵宠可在安全处重新附着”。现有白盒中的完成门只承担区域入口功能，不建立界门设定。

场景采用轻松、温暖的二维动画背景气质，以自然重新占据的木石设施为主，不使用固定地域的传统建筑符号。初契不是庄严审判，而是玩家角色与三个陌生小生命第一次互相打量。

## 4. 分段流程

### 4.1 叙事开场：等待主角重新设计

本段此前的“见习寻路者整理路径标片、调查失效通路”方案已撤回，不再作为正式流程或美术依据。

新开场必须在主角背景确认后重新回答：

1. 主角是谁，为什么此刻位于开场安全区。
2. 玩家通过什么符合人物日常的行为学习移动、镜头与交互。
3. 什么事件自然引出第一次基础攻击。
4. 火花狸、响响鸮和弹弹胶为何同时出现。
5. 玩家为何必须先从三只灵宠中选择一只。

重新设计前不制作路径标片、寻路站职业物件、主角专属台词或相关演出。灵宠终极起源和区域异常的幕后原因仍不在第一段对白中集中解释。

### 4.2 初契选择：到达小坛后约60秒

玩家接近任意灵宠时，只显示名字、性格短句和战斗倾向：

- **火花狸**：急性，爱凑热闹。越连续进攻越来劲。
- **响响鸮**：安静，爱模仿动静。擅长让动作再次发生。
- **弹弹胶**：活泼，总想把东西弹开。擅长扩散和位移。

玩家按交互键选择，再进行一次简短确认，防止误触。确认后：

- 该灵宠立即成为永久实例并进入契匣。
- 该灵宠成为唯一出战成员。
- 另外两只离开，后续通过常规结契获得，不自动赠送。
- 初契结果立即存档，不依赖序章最终通关。

选择前不展示精确倍率、悟法、其他性格或三宠回路定位。

### 4.3 获得基础术法：1:45～2:15

初契小坛残留的灵息凝成基础Q术法 **“灵息弹”**：

- 无元素、直线飞行、单次命中。
- 伤害和冷却只需保证教学清楚，不承担正式构筑强度。
- 作为所有新档的基础术法永久获得，可以在后续被其他术法替换。
- 它的目的不是提供奖励惊喜，而是让武器、术法和身法三类动作在第一次附着时都有可用入口。

此时有效动作为：

- `LMB`：基础武器攻击。
- `Q`：灵息弹。
- `SPACE`：基础身法。

`E / R`保持锁定，只提示“获得新术法后开放”，不让玩家把灵宠附着到空动作上。

### 4.4 第一次附着：2:15～3:00

HUD放大已选灵宠挂件，只高亮 `LMB / Q / SPACE`三个现有动作。玩家可拖动挂件，或依次切换三个动作预览。

悬停时只显示一句结果说明：

- `LMB武器动作`：频繁触发，单次效果较轻。
- `Q灵息弹`：随术法命中集中显化，频率较低、反馈更强。
- `SPACE身法动作`：在位移起点或终点产生保护、控场或位置效果。

确认附着后训练场开门。首次选择不锁死，战斗结束后可在安全处换挂。

## 5. 三宠附着到三类动作的显化

以下为新手关规则目标。具体倍率、内部冷却和表现资源后续配表。

### 5.1 火花狸：产生火花

- **挂LMB**：连续直接命中积累热度，第3次命中产生小火花。
- **挂Q**：灵息弹命中时集中产生一颗较明显的火花。
- **挂SPACE**：闪避终点留下短暂火花，对接近敌人造成一次小范围效果。

无论挂在哪里，玩家都能认出“火花狸会把动作变成火花”。

### 5.2 响响鸮：复响动作

- **挂LMB**：每隔若干次直接命中，弱化复响最近一次普攻。
- **挂Q**：灵息弹命中后，延迟复响一发弱化灵息弹。
- **挂SPACE**：闪避起点留下短暂回声，延迟产生一次小范围脉冲。

无论挂在哪里，玩家都能认出“响响鸮会让刚才的动作再次发生”。

### 5.3 弹弹胶：扩散动作

- **挂LMB**：普攻周期性弹向附近第二目标。
- **挂Q**：灵息弹命中后额外弹射一次。
- **挂SPACE**：闪避终点产生小范围弹力冲击，推开或打断附近普通敌人。

无论挂在哪里，玩家都能认出“弹弹胶会把动作弹到别处”。

### 5.4 安全约束

- 任何单宠效果都必须能独立启动，不依赖玩家尚未拥有的其他灵宠。
- 追加伤害不能反向触发自身并形成无限循环。
- 低频动作可以提高单次表现，但不能成为明显唯一正确答案。
- 三种动作选择都必须能独立完成序章验证战。

## 6. 验证战

### 6.1 第一波：机制展示

- 生成3个近距离、低威胁目标。
- 目标站位需让单体、延迟和弹射效果都能清楚发生。
- 玩家进入战斗后10秒内应触发一次所选灵宠效果。
- 首次触发时只做短促HUD提亮和灵宠反应，不暂停战斗弹说明窗。

### 6.2 第二波：操作验证

- 生成2名近战敌人与1名远程敌人。
- 敌人攻击前摇明显、伤害偏低，促使玩家自然使用移动、普攻、Q和闪避。
- 不要求玩家在本关更换附着，也不教授三宠回路。
- 清场后打开秘境出口，不发随机奖励，不设置Boss。

### 6.3 失败处理

- 序章战斗失败只重置训练场敌人与玩家状态。
- 已确认的初契灵宠和基础灵息弹不得回滚、重复赠送或再次选择。
- 重试直接回到附着确认或训练场入口，不重播醒来与初契演出。

## 7. 存档与续玩

至少需要区分以下序章检查点：

1. 尚未初契。
2. 已初契，尚未完成第一次附着。
3. 已附着，尚未完成验证战。
4. 序章完成。

重进时按schema v7检查点恢复；`starterSpiritSpeciesId`继续作为初契唯一性权威。`starterPrologueStep`只允许按“未初契→已初契→已附着→已完成”单调推进，`starterPrologueCarrier`只保存验证战前的首次附着恢复值，`starterTechniqueUnlocked`保证灵息弹不会回滚或重复授予；不得通过“契匣非空”猜测整段序章是否完成。

## 8. 验收标准

- 首次初契在开局2分钟内完成。
- 第一次附着决策平均不超过45秒。
- 战斗开始后10秒内能看到所选附着效果。
- 火花狸、响响鸮、弹弹胶分别附着在LMB、Q、SPACE时均可独立通关。
- 全程不同时展示超过两个新提示；从初契选择到开放秘境出口的玩法段控制在5～8分钟，叙事开场另行计时。
- 退出重进不会重复初契、丢失灵宠、重复赠送灵息弹或跳过未完成的验证战。

## 9. 实现边界

本文件冻结正式新手关目标。当前首批三宠已在Demo1中完成LMB／Q／SPACE三动作原型、基础灵息弹和临时脱战改附；程序内部仍使用载体合同，这不等于玩家需要理解“载体”。后续仍按程序模块规划拆分为：

1. ~~序章进度与恢复合同。~~ 已完成。
2. ~~三选一场景实体适配及确认UI。~~ 程序已完成，正式模型、摆位与离场演出随场景制作接入。
3. 基础灵息弹。
4. 单宠×三动作显化规则。
5. 附着引导与安全处换挂。
6. 两波验证战及秘境出口。
