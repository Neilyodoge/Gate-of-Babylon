## 1. 关卡目标

初契序章只教四件事：

1. 移动、镜头与普攻。
2. 从火花狸、响响鸮、弹弹胶中选择第一只灵宠。
3. 同一只灵宠附着到不同动作会以不同方式显化。
4. 使用选择结果完成第一场短战斗。

本关不教授三宠回路、完整天赋树、关系、区域生态、随机构筑、撤离提交或家园经营。玩家应该先喜欢并用懂一只灵宠，再在后续探索中理解多宠联动；若需要升级反馈，只允许一次无分支的示范点亮。

以上是玩法目标，不代表玩家开场后立刻看见操作教程。正式流程必须先用日常、人物关系或一个小事件建立情绪和行动理由，再把移动、攻击与初契自然嵌入事件。

## 2. 体验原则

- **先学会赋予，再自由比较**：不强迫玩家依次试玩三只灵宠；只要求亲手完成一次赋予和一次切换赋予，随后由玩家决定是否比较其他候选。
- **选择后立即验证**：初契后不进入长对话，玩家在两分钟内完成附着并开打。
- **灵宠决定效果，动作决定时机**：玩家理解的是同一只伙伴如何借不同动作显化，而不是背诵九个无关技能。
- **第一次附着可改**：初契对象永久确定，附着位置不是永久选择；玩家可在安全处重新换挂。
- **少文字、强反馈**：同屏最多出现两个新提示，第一次触发必须有清楚的动作、声音和HUD挂件反馈。

## 3. 本版故事前提

主角一直生活在家园，也早就想找到一位愿意与自己共同探索的灵宠伙伴。序章不要求先确定主角职业、血统或宏大使命，只确认这个朴素目标。

今天，照料员原本约好把火花狸、响响鸮和弹弹胶三只幼年灵宠带到一处林间会合点，让双方进行第一次正式见面。三只幼宠原本跟随照料员同行，事故后受惊散开到她身前的草地。主角带着旅行包先到，但照料员迟迟没有出现。序章出生点不是家园，也不展示两地之间的连续地理关系。

照料员途中意外遇到一只近期闯入道路的凶性大型灵宠。它暂以现有Ronin模型表现，策划工作名为**刃铠灵**：类人轮廓，甲片、面具状脸壳与刃器都属于物种特征；它不是人类武士，也没有被附身或操控。该物种独居、领地性强，会先以刃光、踏地和逼近驱赶入侵者，确认对方不退后才攻击；“凶”是行为倾向，不代表邪恶。

刃铠灵突然截住去路，附近两只Monkey也被它的威吓和动静刺激得躁动。照料员在躲避时摔倒，行囊翻开，三只幼宠受惊散在身前的草地上；她只能蜷身护住头部并盯着刃铠灵，不敢贸然起身。序章不解释它为何迁入此处、不引入幕后组织，也不把本次遭遇扩写成生态谜团。

主角因约定时间已过而沿会合点后的唯一小路寻找照料员，在安静通道中完成基础移动教学；越下道路末端的小坡后最初只看见侧倒在地的照料员。玩家进入剧情触发区后，三只受惊躲开的幼宠依次现身，远处刃铠灵随后进入视线，再打开初契选择。玩家从中邀请一只附着到自己的动作，三只场景候选随即退场；之后先击退两只躁动Monkey，再削弱刃铠灵的凶势并迫使其撤离。

所选灵宠由HUD和附着系统表示与主角结伴；另外两只不再留在当前场景，之后通过正式探索再次相遇，不自动赠送。

这段开场只表达：

1. 灵宠既可能是野外对手，也可能成为伙伴。
2. 同是灵宠也有不同性情与危险程度；领地性强的个体需要保持距离或被击退。
3. 初契是双方在危险中决定一起行动，不是主角领取一件装备。
4. 战斗默认采用非致死结果：躁动小型灵宠被赶散，凶性大型灵宠判断风险后撤离。
5. 主角并非偶然得到灵宠，而是本来就在等待第一次见面；遭遇让双方提前通过行动确认了选择。

## 4. 空间结构

序章只使用一条主路和两个功能空地，不使用“层”概念：

```text
林间会合点
  →
林间移动教学路
  → 约1米低坡揭示
  → 救援空地〔选择／附着〕
  → 遭遇空地〔两阶段击退战〕
  → 救援收尾
  → 玩家走到固定回家点
  → 淡出并加载独立家园场景
```

- **林间会合点**：约18×14米，只放石壁／浅洞出口、简易路标和主角的旅行包，说明这是旅途中的约定地点而非住处。借鉴《Kena》从受控陌生空间开始的节奏，但不增加脉冲机关、收集或解谜教学。
- **林间移动教学路**：两侧树群形成6～7米宽、约38米长的清楚通道。主角说“照料员怎么还没来……”后取得操作权；玩家先学习移动和镜头，只听见前方动静，看不清事故现场。
- **低坡揭示**：道路末端下降约1米。玩家持续向前即可自动越下，不增加跳跃按键；落地第一眼只显示侧倒照料员，进入触发区后再按“三只幼宠依次现身→远端异常”推进。
- **救援空地**：约20×15米，承担人物构图、靠近三宠、赋予教学和自由试玩；只生成两个不死木靶，不生成敌人或显示战斗边界。
- **遭遇空地**：约24×20米，在同一场地先完成基础三动作、击退2只躁动Monkey，留约2.5秒节奏缓冲后再面对刃铠灵；不增加额外房间、机关或可破坏节点。
- **转场家园**：刃铠灵凶势归零后受挫撤离，不死亡、不昏厥，也不转为可结契对象。照料员确认道路暂时安全后，玩家沿开放的短出口走到固定回家点，画面才淡出并加载独立家园场景；序章地图不制作完整回家道路，也不解释两张地图的精确连接。

场景采用轻松、温暖的二维动画背景气质，以林地、小坡和少量便携工具为主，不使用固定地域的传统建筑符号。危险保持动画冒险尺度，不出现虐待特写；刃铠灵的威胁通过低伏蓄力、刃器敲地、短促吼声和明确的领地驱赶动作表达，不使用人类台词、失焦目光或附身能量。

### 4.1 场景视觉设计

概念图与生成规范见：[ProjectR美术风格基准](../art/ProjectR_美术风格基准.md)。

开场从独立林间会合点进入单向主路，不展示家园。道路两侧使用连续树群形成方向，低坡承担唯一一次重大空间揭示；不再通过多次折线、回家捷径或多组环境陈设制造关卡层次。

- **林间会合点——旅途停顿**：石壁或浅洞口压住出生镜头后方，简易路标和旅行包说明主角主动赴约。画面从较窄、较暗的前景逐步朝明亮林地打开，借鉴《Kena》“受控通道→自然开阔地”的明暗节奏。
- **林间小路——移动教学**：道路沿用户草图所示方向夹在两列疏密不同的树群之间，整体向前上方延伸。出口、道路中心线和远端亮区保持同向，不依赖发光点或UI箭头逐点带路。
- **低坡与救援空地——事件揭示**：坡上视线被地形和树冠下缘挡住，玩家只能听见声音；越坡落地后只先读到侧倒照料员的惊慌状态，三只幼宠保持隐藏。玩家进入共同触发区后，中景三宠依次现身，远景才展示刃铠灵的类人兽形剪影，最后打开选择界面。
- **遭遇区——凶性轮廓**：草地后方通过两块圆润苔石和一段下坡收束成椭圆战斗区；远端斜树干框住刃铠灵剪影，外围灌木代替实体围墙。刃器反光和踏地扬尘集中在它周围，避免用全场异常色暗示幕后魔法。
- **救援转场——情绪释放**：刃铠灵停止进攻、后撤警戒再跃入林地；紧张音效随距离快速减弱，金绿斜光重新成为最大亮面。所选灵宠确认留下后，目标指向固定回家点；玩家走入后淡出，下一镜在独立家园场景恢复操作。

### 4.2 路径、遮挡与战斗轮廓

- 可行走主路径在常用游戏镜头下保持约画面宽度的四分之一到三分之一，不靠路牌或箭头解释方向。
- 前景树冠只压住画面边角，不遮住玩家、三宠选择位、两只躁动灵宠的入场方向或刃铠灵三招预警。
- 移动教学路末端的低坡高差目标为0.8～1.2米；向前移动时自动越下，不要求玩家掌握不存在的跳跃操作，也不得造成跌落伤害。
- 低坡可以是本场景的单向空间门槛；救援后使用遭遇空地侧面的短出口抵达固定回家点，不需要补完整回程道路、捷径或第二条长路径。
- 救援空地与遭遇区通过立石、树缘和地表变化分段，不增加门、结界、星结或可破坏节点；首次附着顺序由流程状态控制，不显示实体门。
- 遭遇区采用不规则椭圆轮廓；长轴顺着直线刃风方向，横向留出冲步斩与弹弹胶推开的空间。
- 软边界的正式表现优先借用草丛、石缘和冷色能量散光；程序圆环只作为接近边缘时的二级提示。
- 场景只放少量能解释事件的便携物：照料员翻倒的布包、小水壶和软质垫布。三只帕鲁原型初到时隐藏，进入共同触发区后才在照料员身前依次显现；单只场景模型不承担独立流程触发。

#### 旧实现回退边界

- `StarterPrologueLayoutV3.prefab`、原`StarterPrologueWhitebox.prefab`与环境V10只保留为程序和资源回退，不再定义新版空间。
- V5必须新建纯白盒Prefab副本验证林间会合点、低坡揭示、两个功能空地和家园转场；不得直接在环境V10上移动资产拼出新布局。
- 旧环境各轮实现细节只在CHANGELOG追溯。V5白盒通过前，不迁移HIGHLANDS植被、软边道路、风动Shader或生活陈设。

### 4.3 色彩脚本与视觉叙事

1. **安全绿**：出生至第一次看见照料员，以苔藓绿、暖灰和斜向黄绿色阳光建立轻松感。
2. **警戒橙红**：威胁预告至刃铠灵战，暖橙红只出现在刃器反光、攻击预警和被踏起的尘叶上，让玩家把危险归因于这只凶性灵宠，而不是整片区域异常。
3. **救援金绿**：刃铠灵撤入林地后立即停止新增警戒色，暖光重新成为最大亮面；短暂确认伙伴后淡出转场。

全程保持二维动画背景式的大块明暗分组。近景植物使用清楚剪影，中景地表使用宽松色块，远景树群只保留层叠轮廓；不堆叠碎叶、微小石子、瓶罐和高频贴花。

### 4.4 本轮美术边界

- 本轮环境概念图可以使用无特征小型人形占位确认主角与照料员比例；刃铠灵沿用现有Ronin模型轮廓作内部原型，但策划上明确属于灵宠物种，不据此冻结正式外形。
- 不使用中式、日式或其他固定现实地域建筑；不出现牌坊、竹林、樱花、灯笼、符纸或书法。
- 不把家园画成私人庄园，也不提前展示风痕林谷、秘境入口或大型遗迹。
- 概念图只确定空间、色彩、材质和自然形态；角色、正式动画与战斗特效分别立项。

## 5. 分段流程

### 5.1 等待第一次见面：0:00～0:15

镜头先展示林间会合点的简易路标、主角旅行包和空着的会面位置。主角自言自语：“照料员怎么还没来……”

随后立即取得操作权，目标更新为“沿林间小路去看看”。会合点没有房屋、居民或可用设施，唯一开放方向就是两列树群之间的林间道路。

本段只建立三件事：

1. 主角本来就想找到共同探索的伙伴。
2. 今天原本只是一次双方见面，不是领取装备或接受组织任命。
3. 这里是旅途中的会合点，不是家园；玩家此时无需理解局外功能。

### 5.2 移动教学与越坡揭示：0:15～0:55

玩家沿约38米的林间通道前进。道路先保持平缓，让玩家学习移动与镜头；接近末端时才听见呼救、惊鸟和灵宠动静。不播放世界观旁白，不要求玩家先认识任何专有名词。

行进中依次学习：

1. 沿道路和声音向前移动。
2. 调整镜头观察道路尽头，但坡上无法看清事故全貌。
3. 继续向前自动越下约1米低坡，不出现跳跃键教学或精确起跳要求。
4. 落地镜头先停在照料员身上：她蜷身护住头部，呼吸急促，想起身靠近幼宠又被远处动静吓退。
5. 顺着照料员的视线只看到翻倒行囊，三只幼宠此时仍未出现；玩家进入触发区后，火花狸、响响鸮、弹弹胶才依次显现并以短促动作回应主角。
6. 最后短暂展示远端刃铠灵用刃器敲地、压低身体并朝这边警戒的轮廓，然后立刻把镜头控制权还给玩家。
7. 目标更新为“去看看三只幼宠”。玩家仍需主动向前走近，不在落地镜头结束时自动打开选择界面；选宠前不生成可战斗目标。

照料员先喊“别过来！那只大家伙会冲过来！”玩家输入继续后，镜头再转向三只幼宠；她发现它们正回应主角，语气稍微稳定：“等等……它们在回应你。”每句先逐字显示，第一次按任意键盘键、鼠标按钮或手柄按钮可补全文字，再次输入继续；不解释刃铠灵生态或更大的世界事件。

### 5.3 赋予与切换赋予教学：0:55～3:35

三只幼宠的显现点以照料员为后方锚点，在其身前约2～4米处呈不规则扇形散开，彼此相距约1.5～2.5米；初到时Renderer与Collider均关闭，玩家进入共同区域后按顺序显现。试玩阶段只创建临时灵宠运行态，不写入契匣、出战GUID或序章存档。

玩家进入三只幼宠共同覆盖的接近区域后：

1. 三只幼宠依次做短促回应，照料员说“它们在回应你”。
2. 镜头轻微收紧到散落区域，不锁住玩家超过0.7秒。
3. 在玩家正前方生成两个不会被摧毁的练习木靶，开始“赋予灵宠”操作教学。
4. 候选资料只显示名字、性格短句和被赋予当前动作后的效果：

- **火花狸**：急性，爱凑热闹。越连续进攻越来劲。
- **响响鸮**：安静，爱模仿动静。擅长让动作再次发生。
- **弹弹胶**：活泼，总想把东西弹开。擅长扩散和位移。

必修不再自动轮换三只灵宠，而是用三步操作依次证明三条核心规则。每一步只改变一个变量：

1. **第一次赋予**：
   - 玩家从三只候选中任选一只。
   - 界面高亮`LMB / Q / SPACE`三个可赋予动作；玩家任选一个并查看该组合的触发条件与效果。
   - 玩家点击“确认赋予”，HUD明确显示“{灵宠名}已赋予{动作名}”。
   - 玩家按对应动作攻击木靶，必须真实触发一次灵宠显化才算完成，不能只检测按键。
2. **同一灵宠，切换动作**：
   - 引导玩家点击当前灵宠挂件，重新打开赋予界面。
   - 三只灵宠和三个动作始终可点，玩家可浏览任意组合说明；只有保持当前灵宠并选择不同动作时，“确认切换”才可用。
   - 界面先显示“从{旧动作}切换到{新动作}”，再由玩家使用新动作触发一次显化。
   - 完成后并排回顾两次结果，明确提示“同一只灵宠，赋予不同动作会产生不同效果”。
3. **同一动作，切换灵宠**：
   - 三只灵宠和三个动作仍可自由浏览；只有保持第2步动作并选择另一只灵宠时，“替换灵宠”才可用。
   - 玩家必须任选另一只灵宠并点击“替换灵宠”；系统不得指定固定候选或自动切换。
   - 玩家再次使用同一动作触发新灵宠显化；完成后并排回顾前后两只灵宠的效果。
   - 明确提示“同一个动作，赋予不同灵宠也会产生不同效果”。

三步必修完成后开放非暂停自由试玩：

- 玩家可自由切换火花狸、响响鸮、弹弹胶，并把当前灵宠赋予`LMB / Q / SPACE`中的任一动作。
- 面板逐组合显示“怎样触发”和“会产生什么效果”；不展示倍率和内部冷却。
- 两个木靶同时保留，使单体、延迟、第二目标和身法近身效果都能实际发生。
- “与当前灵宠结契”按钮此时出现；玩家可以立刻结束，也可以继续试玩第三只灵宠或其他动作。
- 结契使用二次点击确认；切换灵宠或动作会取消待确认状态，防止误触。
- 自由试玩不要求三只灵宠或九种组合全部完成，也不设置强制倒计时。

#### 5.3.1 赋予界面信息结构

- 顶部显示`赋予教学 1/3、2/3、3/3`和当前规则目标，不使用“载体”一词。
- 左列是三只灵宠卡；中列是`LMB武器动作 / Q术法动作 / SPACE身法动作`；右列只显示当前组合的触发条件和结果。
- 未确认时，灵宠与动作之间使用虚线预览；确认后改为实线并短促发光，同时收起大面板。
- 第2、3步不硬锁任何卡片：所有组合均可预览效果，但确认按钮只在满足本步单变量目标时启用，并明确提示需要保持的灵宠或动作。
- 第2、3步右侧增加“刚才／现在”双栏，只比较本步唯一变化的变量，不同时展示九种组合。
- 按钮文案依次为“附着到{动作}”“改附到{动作}”“替换为{灵宠}”；避免使用方向含糊的“赋予”单按钮。
- 大面板打开时释放鼠标并屏蔽战斗输入；世界、幼宠待机和木靶保持运行。确认后恢复角色输入，大面板折叠为右侧单行操作目标。

#### 5.3.2 九种组合的验证条件

- `LMB`：必须在主木靶上产生真实直接命中；火花狸累计到火花生成，响响鸮等到延迟复响发生，弹弹胶必须实际命中第二木靶。
- `Q`：灵息弹必须命中木靶；火花狸确认火花反馈，响响鸮等到延迟复响命中，弹弹胶必须实际弹向第二木靶。
- `SPACE`：玩家需在木靶周围的淡色训练圈内完成身法；火花狸确认终点火花，响响鸮确认起点延迟脉冲，弹弹胶确认终点冲击影响木靶。
- 只按下按键、攻击落空、Q撞到场景石块或身法发生在训练圈外均不算完成。
- 主木靶位于玩家前方约5米，第二木靶距主靶约2.5米；两者和身法训练圈必须同时处于镜头内。

#### 5.3.3 提示与防卡

- 8秒未产生有效进度：只重复当前组合的触发条件。
- 15秒未产生有效进度：高亮对应按键和有效目标／训练圈。
- 25秒未触发显化：显示一步式示例，例如“连续命中主木靶3次”或“站进光圈后按SPACE”。
- 45秒仍未完成：不自动替玩家切换或判定完成；将下一次有效动作降为必定触发教学显化，保证玩家仍亲手完成最后一步。
- 玩家可在确认前返回重选；确认后必须先完成当前显化，避免通过反复切换绕过教学。
- 退出场景或结束Play时不保存临时试玩状态；重新进入从第1步开始。正式结契前不得污染契匣、出战GUID或序章检查点。

### 5.4 临时使用并正式获得基础术法：赋予教学期间～3:45

第一次赋予开始前临时开放最基础的护身术法 **“灵息弹”**，确保玩家从第一次操作起就能在`LMB / Q / SPACE`之间选择并学习切换赋予；确认结契时再将它正式写入新档：

- 无元素、直线飞行、单次命中。
- 飞行中使用清楚的蓝白灵息粒子核心；命中墙体、石块或敌人立即消失并播放落点反馈，未命中最多保留3秒。
- 伤害和冷却只需保证教学清楚，不承担正式构筑强度。
- 作为所有新档的基础术法永久获得，可以在后续被其他术法替换。
- 它的目的不是提供奖励惊喜，而是让武器、术法和身法三类动作在第一次附着时都有可用入口。

此时有效动作为：

- `LMB`：基础武器攻击。
- `Q`：灵息弹。
- `SPACE`：基础身法。

`E / R`保持锁定，只提示“获得新术法后开放”，不让玩家把灵宠附着到空动作上。

### 5.5 确认初契与正式附着：3:35～4:05

玩家完成“第一次赋予＋同宠换动作＋同动作换宠”并二次确认当前候选后：

- 当前临时灵宠转换为唯一永久实例并进入契匣，初契与灵息弹立即存档。
- 另外两只幼宠立即退场；所选灵宠短暂靠近主角后由HUD表示。
- 最后一次已确认的赋予位置直接作为救援战初始位置；结契确认层必须同时写明灵宠和动作，避免玩家不知道将带入哪种效果。
- 首次正式附着仍可在之后的安全状态重新换挂。

确认附着后，救援空地通往遭遇区的自然开口成为唯一前进方向；玩家进入场地后，两只躁动灵宠才开始战斗。首次选择不锁死，战斗结束后可在安全处换挂。

## 6. 三宠附着到三类动作的显化

以下为新手关规则目标。具体倍率、内部冷却和表现资源后续配表。

### 6.1 火花狸：产生火花

- **挂LMB**：连续直接命中积累热度，第3次命中产生小火花。
- **挂Q**：灵息弹命中时集中产生一颗较明显的火花。
- **挂SPACE**：闪避终点留下短暂火花，对接近敌人造成一次小范围效果。

无论挂在哪里，玩家都能认出“火花狸会把动作变成火花”。

### 6.2 响响鸮：复响动作

- **挂LMB**：每隔若干次直接命中，弱化复响最近一次普攻。
- **挂Q**：灵息弹命中后，延迟复响一发弱化灵息弹。
- **挂SPACE**：闪避起点留下短暂回声，延迟产生一次小范围脉冲。

无论挂在哪里，玩家都能认出“响响鸮会让刚才的动作再次发生”。

### 6.3 弹弹胶：扩散动作

- **挂LMB**：普攻周期性弹向附近第二目标。
- **挂Q**：灵息弹命中后额外弹射一次。
- **挂SPACE**：闪避终点产生小范围弹力冲击，推开或打断附近普通敌人。

无论挂在哪里，玩家都能认出“弹弹胶会把动作弹到别处”。

### 6.4 安全约束

- 任何单宠效果都必须能独立启动，不依赖玩家尚未拥有的其他灵宠。
- 追加伤害不能反向触发自身并形成无限循环。
- 低频动作可以提高单次表现，但不能成为明显唯一正确答案。
- 三种动作选择都必须能独立完成序章救援战。

## 7. 救援战

### 7.1 击退躁动Monkey：4:05～5:10

- 两阶段战斗共用同一块约24×20米遭遇空地，不在中途搬到第二个战斗房间。
- 玩家首次进入遭遇触发区时暂不生成敌人，右侧显示`LMB普攻 / Q灵息弹 / SPACE闪避`三行紧凑检查表；三项真实执行且可任意顺序完成，完成后短暂显示“基础动作已掌握”再生成敌人。30秒无操作自动放行，不能因教学面板或输入事件异常卡住主线。
- 两只低威胁近战灵宠从不同方向靠近，但不同时出手，给玩家观察所选灵宠显化的空间。
- 躁动Monkey使用1.0倍基础生命（当前单只30），伤害保持0.25倍；至少给玩家完成一轮普攻、Q与闪避并观察一次显化的时间，不以高伤害制造压力。
- 目标初始距离需让单体、延迟和弹射效果都能清楚发生，也允许身法附着在两者之间触发。
- Monkey出现后按当前首次附着只显示一个显化任务：武器累计3次命中、Q灵息弹命中敌人，或在敌人附近完成一次闪避。
- 玩家进入实战后10秒内应触发一次所选灵宠效果；超过10秒只补充一次当前附着的具体操作，不阻塞战斗、不重复轰炸提示。
- 首次触发时显示“灵宠显化成功”、提亮现有回路HUD并永久收起该任务，不暂停战斗弹说明窗。
- 两只灵宠被击败后只眩晕或逃散，不播放死亡表现。
- 刃铠灵从剧情预告开始始终留在远端可见位置；第一波期间不删除或隐藏。两只Monkey退开后留约2.5秒节奏缓冲，正式战斗体在原地接管预告体并立即进入镜头，不出现凭空消失再生成。

### 7.2 迫使刃铠灵撤离：5:10～6:40

- 两只躁动灵宠退场后，玩家单独面对刃铠灵。它先以刃器敲地和低吼再警告一次，随后主动逼近；不说人类语言，不表现为被控制。
- 入场只显示一次“削弱凶势，迫使它撤退”，不说明三招细节、不重复基础闪避提示，也不要求玩家按指定解法通过。
- 刃铠灵使用1.5倍基础凶势，伤害继续保持0.25倍；目标是延长招式辨识和操作窗口，不把战斗改成高风险生存考验。
- 敌人攻击前摇明显、伤害偏低，促使玩家自然使用移动、普攻、Q和闪避。
- 刃铠灵通过天然甲片、面具状脸壳、类人姿态和刃器构成物种特征；界面与剧情只把它识别为大型凶性灵宠，不使用“武士”“失控者”或人类称谓。
- 首版动作组沿用现有三招骨架，但改写语义：有0.7秒方向预警的直线刃风、约7秒一次的横向冲步斩、凶势过半时只释放一次的近身踏地震荡。
- 刃铠灵使用“凶势”作为Boss条，代表它继续争夺领地的意愿，而非生命或稳定值。凶势归零后镜头跟随它转身奔逃约8米并离开战场；不得触发死亡、掉落、昏厥或结契。
- 不要求玩家在本关更换附着，也不教授三宠回路。
- 救援完成后不出现随机三选一或稀有度教学。

### 7.3 救援收尾与家园转场：6:40～7:20

- 刃铠灵完成可见奔逃后不再停留；本关不追击，也不将其判定为死亡。
- 镜头紧接着转向照料员。照料员从倒地惊慌恢复站立，先说“它退走了……刚才真是吓死我了”，再根据实际选择说“多亏你和{灵宠名}。这里还不安全，我们先回去”。
- 两句由Yarn节点按实际所选灵宠分流，必须分别输入继续；键盘任意键、鼠标任意按钮或手柄按钮均可先补全文字、再推进。鼠标移动和摇杆漂移不触发，45秒无输入自动放行以避免软锁。
- 两段对话播放完毕后照料员才朝固定`HomeReturn`标记所指的小镇方向离开；三只候选已在初契确认时退场，不得在战斗收尾重新激活。
- 所选灵宠已由HUD表示结伴；对话结束后保存“救援完成”，顶部目标与世界引导改为固定回家点。战斗收尾本身不得调用自动转场。
- 玩家实际走入固定回家点后淡出并加载独立家园场景；家园确认玩家落点后才写入“序章完成”，显示“可以为下一次探索做准备”。不制作序章地图到家园的完整步行连接，也不直接打开秘境或风痕林谷介绍。

### 7.4 失败处理

- 序章战斗失败只重置两只躁动灵宠、刃铠灵与玩家状态。
- 已确认的初契灵宠和基础灵息弹不得回滚、重复赠送或再次选择。
- 重试直接回到附着确认或训练场入口，不重播醒来与初契演出。同一次运行会话中若基础三动作已经完成，则死亡重载后按灵宠实例GUID跳过；退出游戏后从`AttachmentChosen`重进可再次看到基础教学。

## 8. 存档与续玩

至少需要区分以下序章检查点：

1. 尚未初契。
2. 已初契，尚未完成第一次附着。
3. 已附着，尚未完成救援战。
4. 序章完成。

重进时按schema v9检查点恢复；`starterSpiritSpeciesId`继续作为初契唯一性权威。`starterPrologueStep`只允许按“未初契→已初契→已附着→救援完成→序章完成”单调推进：刃铠灵凶势归零并完成撤离后先写“救援完成”并恢复安全现场与固定回家点目标；玩家重新走入固定回家点后加载独立家园，家园成功启动并确认玩家落点后才写“序章完成”。若转场失败或中途退出，重进时从遭遇收尾点恢复并再次走到回家点，不重打刃铠灵，也不自动加载家园。`starterPrologueCarrier`只保存救援战前的首次附着恢复值，`starterTechniqueUnlocked`保证灵息弹不会回滚或重复授予；不得通过“契匣非空”猜测整段序章是否完成。schema v8中数值3代表的旧“已完成”迁移时直接映射为v9“序章完成”，不得倒退成“救援完成”。

## 9. 验收标准

- 玩家在离开林间会合点前理解“今天原本要与三只幼宠见面，主角期待找到第一位探索伙伴”。
- 玩家能看出出生地是旅途中的会合点而非家园，不会在此寻找种植、整备、居民或室内入口。
- 主角说完“照料员怎么还没来……”后，玩家无需箭头即可进入两列树群之间的唯一道路。
- 越下低坡前只能听见事故；越坡后玩家第一眼只读到侧倒照料员和翻倒行囊，进入剧情后才看见三只幼宠依次显现与远端异常。
- 玩家能自然靠近三宠共同区域并打开三卡选择界面，不会误以为靠近某一只就会绕过二次确认直接选中。
- 开场、事故揭示和战后对话均可由玩家控制阅读速度；第一句确认不会连带跳过下一句，对话结束后时间缩放和鼠标状态正确恢复。
- 战后目标清楚指向附近固定回家点，玩家能通过一次短移动主动触发转场，不会误以为刃铠灵倒下时就会自动切场景，也不会寻找完整物理回程路线。
- 玩家无需外部说明即可完成“任选灵宠→任选动作→确认赋予→使用动作触发显化”。
- 玩家能再次打开赋予界面，把同一只灵宠切换到不同动作并触发显化；系统不得自动代替玩家换宠或换位。
- 保持第二个动作不变时，玩家能主动换成另一只灵宠并说出效果发生了变化。
- 三步必修完成后可切换任意候选与`LMB / Q / SPACE`，并可随时二次确认结束，不要求看完第三只灵宠或全部九种组合。
- 常规玩家首次初契在取得操作权后4分钟内完成；主动跳过可选试玩的玩家不被强制拖延。
- 第一次附着决策平均不超过45秒。
- 教学检查表支持三项任意顺序；完成前敌人不生成，30秒兜底后仍能自动进入第一波。
- 战斗开始后10秒内能看到所选附着效果。
- 火花狸、响响鸮、弹弹胶分别附着在LMB、Q、SPACE时均可独立通关。
- 全程不同时展示超过两个新提示；从取得操作权到家园转场控制在6～7.5分钟。
- 玩家无需额外说明，也能说出“照料员被一只凶猛的大灵宠拦住，主角与一只幼宠合作把它赶走”。
- 玩家理解另外两只只是离开，后续仍可能遇见。
- 玩家能分辨“愿意结伴的幼宠”和“领地性强、需要被击退的野生灵宠”，不会把所有敌对灵宠理解为邪恶或必须杀死。
- 序章结束目标明确为“带新伙伴回家”，不会误以为必须立刻进入首个秘境。
- 退出重进不会重复初契、丢失灵宠、重复赠送灵息弹或跳过未完成的救援战。
