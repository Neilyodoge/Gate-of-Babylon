## 1. 关卡目标

初契序章只教四件事：

1. 移动、镜头与普攻。
2. 从火花狸、响响鸮、弹弹胶中选择第一只灵宠。
3. 同一只灵宠附着到不同动作会以不同方式显化。
4. 使用选择结果完成第一场短战斗。

本关不教授三宠回路、完整天赋树、关系、区域生态、随机构筑、撤离提交或家园经营。玩家应该先喜欢并用懂一只灵宠，再在后续探索中理解多宠联动；若需要升级反馈，只允许一次无分支的示范点亮。

以上是玩法目标，不代表玩家开场后立刻看见操作教程。正式流程必须先用日常、人物关系或一个小事件建立情绪和行动理由，再把移动、攻击与初契自然嵌入事件。

## 2. 体验原则

- **凭第一印象选择**：选择前只给少量性格和战斗倾向，不安排三宠试玩，不展示成长树和完整技能表。
- **选择后立即验证**：初契后不进入长对话，玩家在两分钟内完成附着并开打。
- **灵宠决定效果，动作决定时机**：玩家理解的是同一只伙伴如何借不同动作显化，而不是背诵九个无关技能。
- **第一次附着可改**：初契对象永久确定，附着位置不是永久选择；玩家可在安全处重新换挂。
- **少文字、强反馈**：同屏最多出现两个新提示，第一次触发必须有清楚的动作、声音和HUD挂件反馈。

## 3. 本版故事前提

主角一直生活在家园。序章发生在家园外缘，不要求先确定主角职业、血统或宏大使命。

一名灵宠照料员正把火花狸、响响鸮和弹弹胶三只幼年灵宠带往家园的临时照料点，途中遇到一名失控的**摘星队**新人。该新人此前试图与一只野生灵宠强行共鸣，连接发生能量倒流后压住了人的意识，也让受困灵宠只能凭本能操纵其身体。附近野生灵宠受到失衡回路刺激，照料员和三只幼宠因此被困。

摘星队追逐稀有灵宠、遗物和异常现象，部分成员会使用越界的强制共鸣。序章只通过制服、星形标志和特殊能量色交代身份，不让失去意识的成员发表反派宣言，也不据此断言整个组织都是纯粹恶人。

主角听见动静后介入，先依靠自己的基础动作处理一只受失衡刺激的小兽。三只幼年灵宠随后都愿意帮忙，玩家从中邀请一只附着到自己的动作，先击退另外两只躁动灵宠，再直接打断失控者身上的能量倒流。

所选灵宠在事件后主动留在主角身边；另外两只随获救照料员回家园接受照料，之后通过正式探索再次相遇，不自动赠送。

这段开场只表达：

1. 灵宠既可能是野外对手，也可能成为伙伴。
2. 人可以通过灵宠强化自身动作，但强行共鸣可能反向伤害人宠双方。
3. 初契是双方在危险中决定一起行动，不是主角领取一件装备。
4. 摘星队是可反复登场的人类对手，但真实目的和内部立场暂不一次讲完。

## 4. 空间结构

序章由四段连续空间组成，不使用“层”概念：

```text
家园外缘
  → 遭袭草地
  → 摘星队封锁区
  → 回家小径
```

- **家园外缘**：低信息密度的自然小径。远处呼救、惊鸟和晃动枝叶引导玩家学习移动与镜头。
- **遭袭草地**：照料员、三只幼年灵宠和一只受失衡刺激的低威胁小兽同时进入视野；玩家先用基础攻击解除眼前威胁。
- **摘星队失控区**：玩家完成初契与首次附着后，先处理2只躁动近战灵宠，再直接面对失控附身者；不增加额外机关或可破坏节点。
- **回家小径**：倒流停止后，摘星队成员与被困灵宠分离并双双昏厥。照料员确认双方仍有生命反应并留下求援标记，随后带另外两只幼宠离开；玩家带着已附着的所选灵宠返回家园，不直接进入风痕林谷。

场景采用轻松、温暖的二维动画背景气质，以林地、小坡和少量便携工具为主，不使用固定地域的传统建筑符号。危险保持动画冒险尺度，不出现虐待特写；失控只通过失焦目光、动作僵硬、附着部位能量溢出和属性流动异常表达。

## 5. 分段流程

### 5.1 听见遇险与基础战斗：0:00～1:20

玩家在家园外缘取得操作权，远处呼救和林间动静构成唯一目标。不播放世界观旁白，不要求玩家先认识任何专有名词。

行进中依次学习：

1. 沿声音向前移动。
2. 转动镜头看见被围住的照料员与三只幼年灵宠。
3. 一只受控小兽脱离敌群并扑向玩家。
4. 玩家用基础攻击将其击退；该目标不掉落、不弹成长提示。
5. 镜头轻推向摘星队成员持续流动异常能量的武器，以及人物失焦、僵硬的动作状态。

本段只用一句短对话交代：“能量倒流了，他本人也醒不过来。”不解释组织历史、首领或真正目的。

### 5.2 初契选择：1:20～2:30

玩家接近任意灵宠时，只显示名字、性格短句和战斗倾向：

- **火花狸**：急性，爱凑热闹。越连续进攻越来劲。
- **响响鸮**：安静，爱模仿动静。擅长让动作再次发生。
- **弹弹胶**：活泼，总想把东西弹开。擅长扩散和位移。

三只灵宠必须同时存在于场景中，并各有一个无需文字也能辨认的小动作：火花狸急着向前冲，响响鸮观察倒流能量的节拍，弹弹胶挡在照料员身前。玩家按交互键选择，再进行一次简短确认，防止误触。确认文案使用“和它一起救人”，不使用“领取”。

确认后：

- 该灵宠立即成为永久实例并进入契匣。
- 该灵宠成为唯一出战成员。
- 另外两只留在照料员身边；事件结束后随其回家园，后续通过常规结契再次获得。
- 初契结果立即存档，不依赖序章最终通关。

选择前不展示精确倍率、悟法、其他性格或三宠回路定位。

### 5.3 获得基础术法：2:30～2:50

照料员把最基础的护身术法 **“灵息弹”** 交给主角，用于应急远程反击：

- 无元素、直线飞行、单次命中。
- 伤害和冷却只需保证教学清楚，不承担正式构筑强度。
- 作为所有新档的基础术法永久获得，可以在后续被其他术法替换。
- 它的目的不是提供奖励惊喜，而是让武器、术法和身法三类动作在第一次附着时都有可用入口。

此时有效动作为：

- `LMB`：基础武器攻击。
- `Q`：灵息弹。
- `SPACE`：基础身法。

`E / R`保持锁定，只提示“获得新术法后开放”，不让玩家把灵宠附着到空动作上。

### 5.4 第一次附着：2:50～3:35

HUD放大已选灵宠挂件，只高亮 `LMB / Q / SPACE`三个现有动作。玩家可拖动挂件，或依次切换三个动作预览。

悬停时只显示一句结果说明：

- `LMB武器动作`：频繁触发，单次效果较轻。
- `Q灵息弹`：随术法命中集中显化，频率较低、反馈更强。
- `SPACE身法动作`：在位移起点或终点产生保护、控场或位置效果。

确认附着后，两只躁动灵宠进入战斗。首次选择不锁死，战斗结束后可在安全处换挂。

## 6. 三宠附着到三类动作的显化

以下为新手关规则目标。具体倍率、内部冷却和表现资源后续配表。

### 6.1 火花狸：产生火花

- **挂LMB**：连续直接命中积累热度，第3次命中产生小火花。
- **挂Q**：灵息弹命中时集中产生一颗较明显的火花。
- **挂SPACE**：闪避终点留下短暂火花，对接近敌人造成一次小范围效果。

无论挂在哪里，玩家都能认出“火花狸会把动作变成火花”。

### 6.2 响响鸮：复响动作

- **挂LMB**：每隔若干次直接命中，弱化复响最近一次普攻。
- **挂Q**：灵息弹命中后，延迟复响一发弱化灵息弹。
- **挂SPACE**：闪避起点留下短暂回声，延迟产生一次小范围脉冲。

无论挂在哪里，玩家都能认出“响响鸮会让刚才的动作再次发生”。

### 6.3 弹弹胶：扩散动作

- **挂LMB**：普攻周期性弹向附近第二目标。
- **挂Q**：灵息弹命中后额外弹射一次。
- **挂SPACE**：闪避终点产生小范围弹力冲击，推开或打断附近普通敌人。

无论挂在哪里，玩家都能认出“弹弹胶会把动作弹到别处”。

### 6.4 安全约束

- 任何单宠效果都必须能独立启动，不依赖玩家尚未拥有的其他灵宠。
- 追加伤害不能反向触发自身并形成无限循环。
- 低频动作可以提高单次表现，但不能成为明显唯一正确答案。
- 三种动作选择都必须能独立完成序章验证战。

## 7. 验证战

### 7.1 击退躁动灵宠：3:35～4:40

- 两只低威胁近战灵宠从不同方向靠近，但不同时出手，给玩家观察所选灵宠显化的空间。
- 目标初始距离需让单体、延迟和弹射效果都能清楚发生，也允许身法附着在两者之间触发。
- 玩家进入战斗后10秒内应触发一次所选灵宠效果。
- 首次触发时只做短促HUD提亮和灵宠反应，不暂停战斗弹说明窗。
- 两只灵宠被击败后只眩晕或逃散，不播放死亡表现。

### 7.2 打断失控附身：4:40～6:40

- 两只躁动灵宠退场后，玩家单独面对失控摘星队成员；对方被迫重复一个灵宠强化的远程动作。
- 敌人攻击前摇明显、伤害偏低，促使玩家自然使用移动、普攻、Q和闪避。
- 摘星队成员的武器持续流动对应属性能量，不在角色或武器上显示灵宠图标。失控时增加属性流动紊乱、能量越界溢出、人物失焦和动作僵硬；灵宠归属只由技能栏／HUD挂件显示。
- 首版动作组只保留三招：有0.7秒方向预警的直线能量波、约7秒一次的横向冲步斩、稳定值过半时只释放一次的近身溢出环。
- 失控附身者使用“稳定值”作为Boss条。稳定值归零后能量连接断开，人宠分离；底层可以暂复用生命结算，但不得触发普通人类死亡、掉落或击杀叙事。
- 不要求玩家在本关更换附着，也不教授三宠回路。
- 救援完成后不出现随机三选一或稀有度教学。

### 7.3 回家收尾：6:40～7:30

- 能量断开后，摘星队成员和受困灵宠分落两侧并双双昏厥；照料员只确认双方仍活着，不在此处唤醒或审问。
- 照料员留下醒目的求援标记，家园后续派人接回伤者；序章不继续展开摘星队剧情。
- 所选灵宠主动靠近主角，做一次能体现性格的短动作并明确选择留下。
- 回家小径解除封锁；照料员带另外两只幼宠离开，玩家带着已附着的所选灵宠走到终点并写入序章完成。
- 回到家园后才显示“可以为下一次探索做准备”，不直接打开秘境或风痕林谷介绍。

### 7.4 失败处理

- 序章战斗失败只重置两只躁动灵宠、失控附身者与玩家状态。
- 已确认的初契灵宠和基础灵息弹不得回滚、重复赠送或再次选择。
- 重试直接回到附着确认或训练场入口，不重播醒来与初契演出。

## 8. 存档与续玩

至少需要区分以下序章检查点：

1. 尚未初契。
2. 已初契，尚未完成第一次附着。
3. 已附着，尚未完成验证战。
4. 序章完成。

重进时按schema v9检查点恢复；`starterSpiritSpeciesId`继续作为初契唯一性权威。`starterPrologueStep`只允许按“未初契→已初契→已附着→救援完成→序章完成”单调推进：宿主稳定值归零后先写“救援完成”并恢复昏厥人宠与回家路径，玩家到达家园终点后才写“序章完成”。`starterPrologueCarrier`只保存救援战前的首次附着恢复值，`starterTechniqueUnlocked`保证灵息弹不会回滚或重复授予；不得通过“契匣非空”猜测整段序章是否完成。schema v8中数值3代表的旧“已完成”迁移时直接映射为v9“序章完成”，不得倒退成“救援完成”。

## 9. 验收标准

- 首次初契在取得操作权后2分30秒内完成。
- 第一次附着决策平均不超过45秒。
- 战斗开始后10秒内能看到所选附着效果。
- 火花狸、响响鸮、弹弹胶分别附着在LMB、Q、SPACE时均可独立通关。
- 全程不同时展示超过两个新提示；从取得操作权到回到家园控制在7～9分钟。
- 玩家无需额外说明，也能说出“摘星队在抢三只幼宠，主角与其中一只合作反击”。
- 玩家理解另外两只只是离开，后续仍可能遇见。
- 玩家能分辨玩家的自愿结契与敌人的强行共鸣，而不会误解为所有灵宠使用者都是坏人。
- 序章结束目标明确为“带新伙伴回家”，不会误以为必须立刻进入首个秘境。
- 退出重进不会重复初契、丢失灵宠、重复赠送灵息弹或跳过未完成的验证战。
