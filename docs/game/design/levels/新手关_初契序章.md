## 1. 关卡目标

初契序章只教四件事：

1. 移动、镜头与普攻。
2. 从火花狸、响响鸮、弹弹胶中选择第一只灵宠。
3. 同一只灵宠附着到不同动作会以不同方式显化。
4. 使用选择结果完成第一场短战斗。

本关不教授三宠回路、完整天赋树、关系、区域生态、随机构筑、撤离提交或家园经营。玩家应该先喜欢并用懂一只灵宠，再在后续探索中理解多宠联动；若需要升级反馈，只允许一次无分支的示范点亮。

以上是玩法目标，不代表玩家开场后立刻看见操作教程。正式流程必须先用日常、人物关系或一个小事件建立情绪和行动理由，再把移动、攻击与初契自然嵌入事件。

## 2. 体验原则

- **凭第一印象选择**：选择前只给少量性格和战斗倾向，不安排三宠试玩，不展示成长树和完整技能表。
- **选择后立即验证**：初契后不进入长对话，玩家在两分钟内完成附着并开打。
- **灵宠决定效果，动作决定时机**：玩家理解的是同一只伙伴如何借不同动作显化，而不是背诵九个无关技能。
- **第一次附着可改**：初契对象永久确定，附着位置不是永久选择；玩家可在安全处重新换挂。
- **少文字、强反馈**：同屏最多出现两个新提示，第一次触发必须有清楚的动作、声音和HUD挂件反馈。

## 3. 本版故事前提

主角一直生活在家园，也早就想找到一位愿意与自己共同探索的灵宠伙伴。序章不要求先确定主角职业、血统或宏大使命，只确认这个朴素目标。

今天，照料员原本约好把火花狸、响响鸮和弹弹胶三只幼年灵宠带到一处林间会合点，让双方进行第一次正式见面。主角带着旅行包先到，但照料员迟迟没有出现。序章出生点不是家园，也不展示两地之间的连续地理关系。

照料员途中遇到一名失控的**摘星队**新人。该新人此前试图与一只野生灵宠强行共鸣，连接发生能量倒流后压住了人的意识，也让受困灵宠只能凭本能操纵其身体。附近野生灵宠受到失衡回路刺激，照料员和三只幼宠因此被困。

摘星队追逐稀有灵宠、遗物和异常现象，部分成员会使用越界的强制共鸣。序章只通过制服、星形标志和特殊能量色交代身份，不让失去意识的成员发表反派宣言，也不据此断言整个组织都是纯粹恶人。

主角因约定时间已过而沿会合点后的唯一小路寻找照料员，在安静通道中完成基础移动教学；越下道路末端的小坡后才第一次看见事故现场与远处失控者。三只幼年灵宠原本就准备与主角见面，此时都愿意帮忙；玩家从中邀请一只附着到自己的动作，再击退两只躁动野生灵宠并直接打断失控者身上的能量倒流。

所选灵宠在事件后主动留在主角身边；另外两只随获救照料员回家园接受照料，之后通过正式探索再次相遇，不自动赠送。

这段开场只表达：

1. 灵宠既可能是野外对手，也可能成为伙伴。
2. 人可以通过灵宠强化自身动作，但强行共鸣可能反向伤害人宠双方。
3. 初契是双方在危险中决定一起行动，不是主角领取一件装备。
4. 摘星队是可反复登场的人类对手，但真实目的和内部立场暂不一次讲完。
5. 主角并非偶然得到灵宠，而是本来就在等待第一次见面；事故让双方提前通过行动确认了选择。

## 4. 空间结构

序章只使用一条主路和两个功能空地，不使用“层”概念：

```text
林间会合点
  →
林间移动教学路
  → 约1米低坡揭示
  → 救援空地〔选择／附着〕
  → 失控空地〔两阶段战斗〕
  → 救援收尾
  → 淡出并加载独立家园场景
```

- **林间会合点**：约18×14米，只放石壁／浅洞出口、简易路标和主角的旅行包，说明这是旅途中的约定地点而非住处。借鉴《Kena》从受控陌生空间开始的节奏，但不增加脉冲机关、收集或解谜教学。
- **林间移动教学路**：两侧树群形成6～7米宽、约38米长的清楚通道。主角说“照料员怎么还没来……”后取得操作权；玩家先学习移动和镜头，只听见前方动静，看不清事故现场。
- **低坡揭示**：道路末端下降约1米。玩家持续向前即可自动越下，不增加跳跃按键；落地镜头第一次完整展示照料员、三只幼宠和远端异常。
- **救援空地**：约20×15米，只承担人物构图、三选一和首次附着，不生成战斗目标、不显示战斗边界。
- **失控空地**：约24×20米，在同一场地先处理2只躁动近战灵宠，留约15秒喘息后再面对失控附身者；不增加额外房间、机关或可破坏节点。
- **转场家园**：倒流停止后人宠分离并双双昏厥。照料员完成最短确认，画面淡出并加载独立家园场景；序章地图不制作回家道路，也不解释两张地图的精确连接。

场景采用轻松、温暖的二维动画背景气质，以林地、小坡和少量便携工具为主，不使用固定地域的传统建筑符号。危险保持动画冒险尺度，不出现虐待特写；失控只通过失焦目光、动作僵硬、附着部位能量溢出和属性流动异常表达。

### 4.1 场景视觉设计

概念图与生成规范见：[ProjectR美术风格基准](../art/ProjectR_美术风格基准.md)。

开场从独立林间会合点进入单向主路，不展示家园。道路两侧使用连续树群形成方向，低坡承担唯一一次重大空间揭示；不再通过多次折线、回家捷径或多组环境陈设制造关卡层次。

- **林间会合点——旅途停顿**：石壁或浅洞口压住出生镜头后方，简易路标和旅行包说明主角主动赴约。画面从较窄、较暗的前景逐步朝明亮林地打开，借鉴《Kena》“受控通道→自然开阔地”的明暗节奏。
- **林间小路——移动教学**：道路沿用户草图所示方向夹在两列疏密不同的树群之间，整体向前上方延伸。出口、道路中心线和远端亮区保持同向，不依赖发光点或UI箭头逐点带路。
- **低坡与救援空地——事件揭示**：坡上视线被地形和树冠下缘挡住，玩家只能听见声音；越坡落地后，照料员与三宠位于近中景，失控者位于更远处，三层信息按距离一次读清。
- **失控区——局部异常**：草地后方通过两块圆润苔石和一段下坡收束成椭圆战斗区；远端斜树干框住失控者剪影，外围灌木代替实体围墙。冷青蓝只集中在武器、受压草叶和地面短痕，整体亮度不降成黑夜。
- **救援转场——情绪释放**：人宠分离后青蓝异常快速减少，金绿斜光重新覆盖失控空地；所选灵宠确认留下后淡出，下一镜直接在独立家园场景恢复操作。

### 4.2 路径、遮挡与战斗轮廓

- 可行走主路径在常用游戏镜头下保持约画面宽度的四分之一到三分之一，不靠路牌或箭头解释方向。
- 前景树冠只压住画面边角，不遮住玩家、三宠选择位、两只躁动灵宠的入场方向或失控宿主三招预警。
- 移动教学路末端的低坡高差目标为0.8～1.2米；向前移动时自动越下，不要求玩家掌握不存在的跳跃操作，也不得造成跌落伤害。
- 低坡可以是本场景的单向空间门槛；救援后直接转场家园，不需要为回程补缓坡、捷径或第二条道路。
- 救援空地与失控区通过立石、树缘和地表变化分段，不增加门、结界、星结或可破坏节点；首次附着顺序由流程状态控制，不显示实体门。
- 失控区采用不规则椭圆轮廓；长轴顺着直线能量波方向，横向留出冲步斩与弹弹胶推开的空间。
- 软边界的正式表现优先借用草丛、石缘和冷色能量散光；程序圆环只作为接近边缘时的二级提示。
- 场景只放少量能解释事件的便携物：照料员掉落的布包、小水壶或软质垫布。它们不能成为可交互物，也不形成新的收集暗示。

#### 旧实现回退边界

- `StarterPrologueLayoutV3.prefab`、原`StarterPrologueWhitebox.prefab`与环境V10只保留为程序和资源回退，不再定义新版空间。
- V5必须新建纯白盒Prefab副本验证林间会合点、低坡揭示、两个功能空地和家园转场；不得直接在环境V10上移动资产拼出新布局。
- 旧环境各轮实现细节只在CHANGELOG追溯。V5白盒通过前，不迁移HIGHLANDS植被、软边道路、风动Shader或生活陈设。

### 4.3 色彩脚本与视觉叙事

1. **安全绿**：出生至第一次看见照料员，以苔藓绿、暖灰和斜向黄绿色阳光建立轻松感。
2. **异常青蓝**：威胁预告至失控宿主战，青蓝色只侵入局部阴影、草叶边缘和攻击痕迹，让玩家把异常归因于失控能量而不是区域天气。
3. **救援金绿**：人宠分离后立即停止新增青蓝痕迹，暖光重新成为最大亮面；短暂确认伙伴后淡出转场。

全程保持二维动画背景式的大块明暗分组。近景植物使用清楚剪影，中景地表使用宽松色块，远景树群只保留层叠轮廓；不堆叠碎叶、微小石子、瓶罐和高频贴花。

### 4.4 本轮美术边界

- 本轮环境概念图可以使用无特征小型人形占位确认比例，但不得据此确定主角、照料员或失控者的服装、种族和脸部。
- 不使用中式、日式或其他固定现实地域建筑；不出现牌坊、竹林、樱花、灯笼、符纸或书法。
- 不把家园画成私人庄园，也不提前展示风痕林谷、秘境入口或大型遗迹。
- 概念图只确定空间、色彩、材质和自然形态；角色、正式动画与战斗特效分别立项。

## 5. 分段流程

### 5.1 等待第一次见面：0:00～0:15

镜头先展示林间会合点的简易路标、主角旅行包和空着的会面位置。主角自言自语：“照料员怎么还没来……”

随后立即取得操作权，目标更新为“沿林间小路去看看”。会合点没有房屋、居民或可用设施，唯一开放方向就是两列树群之间的林间道路。

本段只建立三件事：

1. 主角本来就想找到共同探索的伙伴。
2. 今天原本只是一次双方见面，不是领取装备或接受组织任命。
3. 这里是旅途中的会合点，不是家园；玩家此时无需理解局外功能。

### 5.2 移动教学与越坡揭示：0:15～0:55

玩家沿约38米的林间通道前进。道路先保持平缓，让玩家学习移动与镜头；接近末端时才听见呼救、惊鸟和灵宠动静。不播放世界观旁白，不要求玩家先认识任何专有名词。

行进中依次学习：

1. 沿道路和声音向前移动。
2. 调整镜头观察道路尽头，但坡上无法看清事故全貌。
3. 继续向前自动越下约1米低坡，不出现跳跃键教学或精确起跳要求。
4. 落地镜头先看见被困的照料员与三只幼年灵宠，再展示远端摘星队成员持续流动异常能量的武器及失焦、僵硬状态。
5. 镜头回到三只幼宠，直接进入初契选择；选宠前不生成可战斗目标。

落地后照料员只用一句行动提示：“先别过来！它们被失控的能量惊到了！”随后镜头短暂预告远端宿主异常并进入三选一；不解释组织历史、首领或真正目的。

### 5.3 初契选择：0:55～2:15

玩家接近任意灵宠时，只显示名字、性格短句和战斗倾向：

- **火花狸**：急性，爱凑热闹。越连续进攻越来劲。
- **响响鸮**：安静，爱模仿动静。擅长让动作再次发生。
- **弹弹胶**：活泼，总想把东西弹开。擅长扩散和位移。

三只灵宠必须同时存在于场景中，并各有一个无需文字也能辨认的小动作：火花狸急着向前冲，响响鸮观察倒流能量的节拍，弹弹胶挡在照料员身前。玩家按交互键选择，再进行一次简短确认，防止误触。确认文案使用“和它一起救人”，不使用“领取”。

确认后：

- 该灵宠立即成为永久实例并进入契匣。
- 该灵宠成为唯一出战成员。
- 另外两只留在照料员身边；事件结束后随其回家园，后续通过常规结契再次获得。
- 初契结果立即存档，不依赖序章最终通关。

选择前不展示精确倍率、悟法、其他性格或三宠回路定位。

### 5.4 获得基础术法：2:15～2:35

照料员把最基础的护身术法 **“灵息弹”** 交给主角，用于应急远程反击：

- 无元素、直线飞行、单次命中。
- 伤害和冷却只需保证教学清楚，不承担正式构筑强度。
- 作为所有新档的基础术法永久获得，可以在后续被其他术法替换。
- 它的目的不是提供奖励惊喜，而是让武器、术法和身法三类动作在第一次附着时都有可用入口。

此时有效动作为：

- `LMB`：基础武器攻击。
- `Q`：灵息弹。
- `SPACE`：基础身法。

`E / R`保持锁定，只提示“获得新术法后开放”，不让玩家把灵宠附着到空动作上。

### 5.5 第一次附着：2:35～3:15

HUD放大已选灵宠挂件，只高亮 `LMB / Q / SPACE`三个现有动作。玩家可拖动挂件，或依次切换三个动作预览。

悬停时只显示一句结果说明：

- `LMB武器动作`：频繁触发，单次效果较轻。
- `Q灵息弹`：随术法命中集中显化，频率较低、反馈更强。
- `SPACE身法动作`：在位移起点或终点产生保护、控场或位置效果。

确认附着后，救援空地通往失控空地的自然开口成为唯一前进方向；玩家进入场地后，两只躁动灵宠才开始战斗。首次选择不锁死，战斗结束后可在安全处换挂。

## 6. 三宠附着到三类动作的显化

以下为新手关规则目标。具体倍率、内部冷却和表现资源后续配表。

### 6.1 火花狸：产生火花

- **挂LMB**：连续直接命中积累热度，第3次命中产生小火花。
- **挂Q**：灵息弹命中时集中产生一颗较明显的火花。
- **挂SPACE**：闪避终点留下短暂火花，对接近敌人造成一次小范围效果。

无论挂在哪里，玩家都能认出“火花狸会把动作变成火花”。

### 6.2 响响鸮：复响动作

- **挂LMB**：每隔若干次直接命中，弱化复响最近一次普攻。
- **挂Q**：灵息弹命中后，延迟复响一发弱化灵息弹。
- **挂SPACE**：闪避起点留下短暂回声，延迟产生一次小范围脉冲。

无论挂在哪里，玩家都能认出“响响鸮会让刚才的动作再次发生”。

### 6.3 弹弹胶：扩散动作

- **挂LMB**：普攻周期性弹向附近第二目标。
- **挂Q**：灵息弹命中后额外弹射一次。
- **挂SPACE**：闪避终点产生小范围弹力冲击，推开或打断附近普通敌人。

无论挂在哪里，玩家都能认出“弹弹胶会把动作弹到别处”。

### 6.4 安全约束

- 任何单宠效果都必须能独立启动，不依赖玩家尚未拥有的其他灵宠。
- 追加伤害不能反向触发自身并形成无限循环。
- 低频动作可以提高单次表现，但不能成为明显唯一正确答案。
- 三种动作选择都必须能独立完成序章救援战。

## 7. 救援战

### 7.1 击退躁动灵宠：3:15～4:30

- 两阶段战斗共用同一块约24×20米失控空地，不在中途搬到第二个战斗房间。
- 两只低威胁近战灵宠从不同方向靠近，但不同时出手，给玩家观察所选灵宠显化的空间。
- 目标初始距离需让单体、延迟和弹射效果都能清楚发生，也允许身法附着在两者之间触发。
- 玩家进入战斗后10秒内应触发一次所选灵宠效果。
- 首次触发时只做短促HUD提亮和灵宠反应，不暂停战斗弹说明窗。
- 两只灵宠被击败后只眩晕或逃散，不播放死亡表现。
- 两只退场后保留约10～15秒喘息，宿主再从场地远端正式进入战斗；期间不弹新教学窗。

### 7.2 打断失控附身：4:30～6:40

- 两只躁动灵宠退场后，玩家单独面对失控摘星队成员；对方被迫重复一个灵宠强化的远程动作。
- 敌人攻击前摇明显、伤害偏低，促使玩家自然使用移动、普攻、Q和闪避。
- 摘星队成员的武器持续流动对应属性能量，不在角色或武器上显示灵宠图标。失控时增加属性流动紊乱、能量越界溢出、人物失焦和动作僵硬；灵宠归属只由技能栏／HUD挂件显示。
- 首版动作组只保留三招：有0.7秒方向预警的直线能量波、约7秒一次的横向冲步斩、稳定值过半时只释放一次的近身溢出环。
- 失控附身者使用“稳定值”作为Boss条。稳定值归零后能量连接断开，人宠分离；底层可以暂复用生命结算，但不得触发普通人类死亡、掉落或击杀叙事。
- 不要求玩家在本关更换附着，也不教授三宠回路。
- 救援完成后不出现随机三选一或稀有度教学。

### 7.3 救援收尾与家园转场：6:40～7:20

- 能量断开后，摘星队成员和受困灵宠分落两侧并双双昏厥；照料员只确认双方仍活着，不在此处唤醒或审问。
- 照料员留下醒目的求援标记，家园后续派人接回伤者；序章不继续展开摘星队剧情。
- 所选灵宠主动靠近主角，做一次能体现性格的短动作并明确选择留下。
- 照料员带另外两只幼宠照看现场；所选灵宠确认留下后先保存“救援完成”，随后画面淡出。
- 加载独立家园场景并确认玩家落点后才写入“序章完成”，显示“可以为下一次探索做准备”；不制作序章地图到家园的步行连接，也不直接打开秘境或风痕林谷介绍。

### 7.4 失败处理

- 序章战斗失败只重置两只躁动灵宠、失控附身者与玩家状态。
- 已确认的初契灵宠和基础灵息弹不得回滚、重复赠送或再次选择。
- 重试直接回到附着确认或训练场入口，不重播醒来与初契演出。

## 8. 存档与续玩

至少需要区分以下序章检查点：

1. 尚未初契。
2. 已初契，尚未完成第一次附着。
3. 已附着，尚未完成救援战。
4. 序章完成。

重进时按schema v9检查点恢复；`starterSpiritSpeciesId`继续作为初契唯一性权威。`starterPrologueStep`只允许按“未初契→已初契→已附着→救援完成→序章完成”单调推进：宿主稳定值归零后先写“救援完成”并恢复昏厥人宠与转场状态；独立家园场景成功加载并确认玩家落点后才写“序章完成”。若转场失败或中途退出，重进时从救援结果恢复并再次转场，不重打宿主。`starterPrologueCarrier`只保存救援战前的首次附着恢复值，`starterTechniqueUnlocked`保证灵息弹不会回滚或重复授予；不得通过“契匣非空”猜测整段序章是否完成。schema v8中数值3代表的旧“已完成”迁移时直接映射为v9“序章完成”，不得倒退成“救援完成”。

## 9. 验收标准

- 玩家在离开林间会合点前理解“今天原本要与三只幼宠见面，主角期待找到第一位探索伙伴”。
- 玩家能看出出生地是旅途中的会合点而非家园，不会在此寻找种植、整备、居民或室内入口。
- 主角说完“照料员怎么还没来……”后，玩家无需箭头即可进入两列树群之间的唯一道路。
- 越下低坡前只能听见事故，越坡落地后才第一次完整看见照料员、三宠与远端异常；自动越坡不被误解为需要跳跃按键。
- 战后转场清楚表达“接下来回家园”，不会让玩家在序章地图里寻找物理回程路线。
- 首次初契在取得操作权后2分30秒内完成。
- 第一次附着决策平均不超过45秒。
- 战斗开始后10秒内能看到所选附着效果。
- 火花狸、响响鸮、弹弹胶分别附着在LMB、Q、SPACE时均可独立通关。
- 全程不同时展示超过两个新提示；从取得操作权到家园转场控制在6～7.5分钟。
- 玩家无需额外说明，也能说出“前方有人因强行共鸣而失控，主角与一只幼宠合作救人”。
- 玩家理解另外两只只是离开，后续仍可能遇见。
- 玩家能分辨玩家的自愿结契与敌人的强行共鸣，而不会误解为所有灵宠使用者都是坏人。
- 序章结束目标明确为“带新伙伴回家”，不会误以为必须立刻进入首个秘境。
- 退出重进不会重复初契、丢失灵宠、重复赠送灵息弹或跳过未完成的救援战。
