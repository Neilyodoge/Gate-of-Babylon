# 技能模块设计表（原“功法设计表”）

> 文件名暂保留为 `功法设计表.md` 以免断链；当前设计语义为 **技能模块表**。
> 配套主 GDD：[GDD_秘境探索.md](GDD_秘境探索.md) §6。

---

## 1. 新模型

技能不再是固定 Q/E/R 技能列表，而是由三层模块拼装：

```text
[触发器 Trigger] -> [效果器 Effect] -> [改造件 Modifier]
```

**执行模式**：
- **被动**：条件满足后自动触发。
- **主动**：条件满足后点亮 Q/E/R，玩家手动释放。

---

## 2. 触发器（Trigger）

### 2.1 纯条件触发器

| 触发器 | 条件 | 推荐执行模式 |
|--------|------|-------------|
| 攻击 X 次 | 普攻命中累计 X 次 | 被动 / 主动 |
| 移动 X 米 | 累计移动距离达到阈值 | 被动 |
| 受击时 | 受到伤害后触发，有冷却 | 被动 |
| 击杀时 | 击败敌人后触发 | 被动 |
| 闪避后 | 完成闪避动作后触发 | 主动 / 被动 |
| 完美时机 | 在动作结束窗口内按键 | 主动 |

### 2.2 状态型触发器

状态型触发器会创建状态载体，因此必须自带弱默认效果。

| 触发器 | 默认轻量效果 | 推荐组合 |
|--------|-------------|---------|
| 种子生成 | 普攻命中挂 1 颗种子，低伤 DoT | 种子引爆 / 毒雾 / 治疗 |
| 种子引爆 | 种子达到阈值时弱爆炸 | 扩散 / 连锁 / 范围增强 |
| 背击标记 | 背后命中挂破绽，下次命中小幅增伤 | 突刺 / 连击 / 暴击 |
| 傀儡计数 | 生成或记录傀儡攻击次数 | 傀儡协同 / 护盾 / 分流 |
| 蓄力层数 | 行为满足条件后叠层，满层强化下一模块 | 爆发 / 护盾 / 召唤 |

---

## 3. 效果器（Effect）

| 效果器 | 类型 | 说明 |
|--------|------|------|
| 落雷 | 伤害 | 对最近敌人或目标点造成伤害 |
| 毒雾 | 持续伤害 | 区域 DoT，可被扩散 / 延长 |
| 突刺 | 位移伤害 | 向目标方向突进并造成伤害 |
| 冲击波 | 范围伤害 | 以玩家或目标为中心扩散 |
| 护盾 | 防御 | 吸收伤害，可被破裂改造 |
| 治疗 | 回复 | 回复玩家或召唤物 |
| 傀儡协同 | 召唤 / 协同 | 让傀儡同步执行弱化效果 |
| 黑洞 | 控制 | 聚怪、减速或打断 |

---

## 4. 改造件（Modifier）

| 改造件 | 作用 |
|--------|------|
| 连锁符文 | 效果命中后跳转到附近目标 |
| 扩散符文 | 区域扩大，或状态向附近敌人传播 |
| 双重投射 | 投射物数量 +1，但单发伤害下降 |
| 右侧强化 | Dungeon 100 风格，强化右侧相邻模块 |
| 左侧强化 | Dungeon 100 风格，强化左侧相邻模块 |
| 充能符文 | 主动模块可储存额外次数 |
| 分流符文 | 效果可由召唤物 / 傀儡执行 |
| 延时符文 | 效果延迟触发，提升威力或范围 |

---

## 5. 首批组合示例

| 组合 | 结果 |
|------|------|
| `[移动 10 米] + [落雷]` | 跑动时自动落雷 |
| `[移动 10 米] + [落雷] + [连锁符文]` | 跑动落雷并连锁附近敌人 |
| `[种子引爆] + [毒雾] + [扩散符文]` | 种子爆炸后生成扩散毒雾 |
| `[背击标记] + [突刺] + [连击符文]` | 背击后突刺并追加连击窗口 |
| `[傀儡协同] + [护盾] + [分流符文]` | 傀儡协同时给玩家或傀儡刷新护盾 |

## 6. 旧技能回收建议

| 旧技能 / 机制 | v0.6 回收方式 |
|--------------|---------------|
| 落石术 / 天雷引 / 烈焰掌 | 伤害类效果器 |
| 土遁术 / 缩地成寸 / 影步 | 位移类效果器或触发器 |
| 金钟罩 / 护盾类技能 | 防御类效果器 |
| 傀儡术 / 兵阵合一 | 召唤类效果器 + 傀儡协同触发器 |
| 青囊种子 | 状态型触发器 |
| 剑魄完美收刀 | 通用时机触发器素材 |
