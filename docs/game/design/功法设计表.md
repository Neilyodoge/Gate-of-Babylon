# 📜 功法设计表

> **文档版本**：2026-04-28
> 功法 = 主动技能，三个槽位 Q/E/R，每个槽位下方各 2 个灵物槽（共 6 个）
> Demo1 采用纯 CD + 充能 + 蓄力模型，**不涉及灵力消耗**（灵力资源系统延期到 Demo2，详见[开发路线图](开发路线图.md#demo2--资源系统--灵力觉醒)）

> ⚠️ 旧版本本文件描述的"普攻 = 灵力弹，按住连射 + 仅 Q 槽位"已废弃，请以本版本为准。

## 1. 操作模型

```text
【近战普攻】—— 鼠标左键
  → 三段连招（Attack1 → Attack2 → Attack3）
  → 段倍率：1.0 / 1.2 / 1.5（GameConfig 可调）
  → 扇形判定：默认半径 2.5，角度 120°
  → 动画播放速度受灵物攻速加成
  → 每段攻击带前冲位移（Lunge）
  → 攻击中拥有"霸体"：轻击不打断，但仍然扣血
  → 250ms 输入缓冲：上一段未结束按下也会进入下一段
  → 灵物可加灼烧 / 暴击 / 穿透 / 攻速等

【功法】—— Q / E / R 三个槽位
  → 充能层（1~3 层）+ CD（CD 一好恢复一层）
  → 灵物可提供：
       - 充能上限 +N
       - 蓄力速度加成
       - 蓄力伤害加成
       - CD 缩减
  → 部分功法支持蓄力（长按）：
       Lv1（默认）伤害 ×1.0,  范围 ×1.0
       Lv2（≥0.5s） 伤害 ×1.5,  范围 ×1.0~1.x
       Lv3（≥1.5s） 伤害 ×2.5,  范围 ×1.x~1.3
  → 蓄力期间移速 ×0.4，闪避 / 死亡会取消蓄力

【闪避】—— Space
  → 距离 5 单位，持续 0.2s（速度 25 单位/秒）
  → 全程无敌帧 0.3s
  → 2 层充能，每层 CD 1.5s
  → 可打断除"死亡"外的一切动作（最高优先级）
  → 充能耗尽时 250ms 输入缓冲，动作结束自动闪避
  → 灵物可附加效果（御风残影、火墙轨迹）
```

## 2. 技能类型（SkillType 枚举）

代码：`Babylon/Assets/1Game/Scripts/Combat/SkillData.cs`

| 类型 | 说明 | 关键参数 |
|------|------|---------|
| AreaDamage | 范围伤害（落石、寒冰、雷击） | `aoeRadius` |
| Projectile | 投射物（飞剑、火球） | `projectilePrefab / projectileSpeed / projectileCount / spreadAngle` |
| Dash | 位移（土遁、缩地） | `dashDistance / leaveTrail` |
| Buff | 增益（金钟罩） | `vfxDuration` |
| Heal | 治疗（回春术） | `healAmount / healScaling` |
| Summon | 召唤（傀儡术） | `summonDuration / summonDamage` |

技能伤害公式：
```text
基础伤害   = baseDamage + attackDamage × damageScaling
蓄力倍率   = GetChargeDamageMultiplier(level) × (1 + 灵物蓄力伤害加成)
最终伤害   = 基础伤害 × 蓄力倍率
```

## 6. 槽位灵物对功法的额外加成

任何灵物只要放在某个技能槽位下方的 2 个灵物槽中，就能给该技能提供专属加成：

| 灵物词条 | 效果 |
|---------|------|
| `skillChargeBonus` | 该技能的充能上限 +N |
| `chargeSpeedBonusPercent` | 该技能的蓄力速度加成 |
| `chargeDamageBonusPercent` | 该技能的蓄力伤害加成（仅 Lv2/Lv3 生效） |
| `cooldownReductionPercent` | 该技能的 CD 缩减 |

> 这是一个**梦之形（Shape of Dreams）风格**的核心 build 机制：同样的灵物，放在不同技能下方会改变完全不同的玩法。
