# 📜 功法设计表

> 功法 = 主动技能，有 CD，最多装备 3 个
> Demo1 采用纯 CD 模型，不涉及灵力消耗

---

## 操作模型

```
【普通攻击】—— 鼠标左键，按住连射
  → 默认法杖远程（发射灵力弹）
  → 灵物可改变攻击形态（穿透、分裂、连锁、追踪等）

【功法技能】—— 手动释放，有 CD
  → Q 槽位：攻击型
  → W 槽位：辅助/位移型（Demo2）
  → E 槽位：大招/终极技能（Demo2）

【闪避】—— Space，短距离闪避，有无敌帧
  → 灵物可附加闪避效果（火焰轨迹、冰冻轨迹等）
```

---

## ⚔️ 攻击型功法（Q 槽位）

| 名称 | 品阶 | 效果 | CD | 特殊交互 |
|------|------|------|----|---------|
| 落石术 | 凡品 | 指定位置召唤巨石砸落，AOE 伤害 | 8秒 | 冰冻目标→碎裂散射；火灵珠→陨石 |
| 天雷引 | 灵品 | 引天雷轰击一条直线 | 10秒 | 水面上→范围翻倍 |
| 三昧真火 | 玄品 | 释放扇形火焰，持续灼烧 | 12秒 | 风灵珠→火焰龙卷 |
| 万剑诀 | 地品 | 召唤剑阵，飞剑齐射 | 15秒 | 持有飞剑类灵物→剑数翻倍 |

## 功法之间的隐藏组合

| 组合名 | 触发条件 | 效果 |
|--------|---------|------|
| 天崩地裂 | 落石术 + 天雷引 | 两技能命中同一目标时伤害 x3 |
| 水火交融 | 三昧真火 + 冥河召唤 | 冥河变为岩浆河，伤害 x2 |
| 御剑飞行 | 缩地成寸 + 万剑诀 | 缩地变为骑乘飞剑移动，轨迹降下剑雨 |
| 真假难辨 | 水镜术 + 金蝉脱壳 | 场上同时存在2个分身+本体 |
| 地脉剑阵 | 土遁术 + 天罡北斗阵 | 土遁轨迹上自动布阵 |
