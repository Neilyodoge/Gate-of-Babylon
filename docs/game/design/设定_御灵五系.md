# 设定 · 御灵五系（历史素材库）

> **状态**：v0.6 已废弃为现行规则。
> **原因**：当前 GDD 已删除独立职业 / 化身系统，且起始模板与触发器流派由策划直接写效果，不再受“五系 / 亲和谱 / 背景设定”约束。
> **现行规则**：见 [GDD_秘境探索.md](GDD_秘境探索.md) 的“触发器流派 · 战斗与成长主轴”和 [GDD_秘境探索_简明版.md](GDD_秘境探索_简明版.md)。

## v0.6 处理结论

| 旧内容 | 当前处理 |
|--------|---------|
| 御灵五系 | 不作为玩法主轴，仅可作为视觉 / 命名 / 叙事素材 |
| 化身 | 删除独立系统，拆为起始模板 + 状态型触发器 |
| 系精通 | 删除，迁移为模块熟练度 / 解锁节点 |
| 化身天赋树 | 删除，迁移为模块熟练度 |
| 亲和谱 | 不再作为策划前置条件 |
| 五行合技 | 不做独立系统；若有价值，迁移为隐藏组合 |

## 可回收素材

| 旧设定 | 可回收方向 |
|--------|-----------|
| 青囊 · 种子 / 寄生 / 引爆 | `种子生成`、`种子引爆` 状态型触发器 |
| 影刃 · 位移 / 背击 / 标记 | `闪避后`、`背击标记` 触发器 |
| 御物 · 傀儡 / 阵地 / 协同 | `傀儡计数`、`傀儡协同` 触发器与召唤效果器 |
| 剑魄 · 完美时机 | 通用时机触发器素材，不再作为职业 |
| 业火 · 燃血爆发 | 高风险增强道具或效果器素材 |
| 神识 / 控场设定 | 控制类效果器或自适应怪物机制素材 |

---

## 使用原则

- 可以拿旧名字、视觉、台词做包装。
- 不要让五系决定模块规则。
- 不要恢复职业天赋树或亲和谱。
- 不要把玩家锁进某个背景身份。
- 玩法先成立，再补包装。
