# 设定 · 化身（历史素材拆解）

> **状态**：v0.6 已废弃为现行系统。
> **现行规则**：不再选择“化身 / 职业”，改为选择 **起始模板**；旧化身能力拆成 **状态型触发器 / 效果器 / 改造件 / 增强道具素材**。

---

## 新起始模板建议

| 起始模板 | 来源素材 | 起始模块 |
|----------|---------|---------|
| 播种者 | 青囊 | `种子生成 + 种子引爆 + 毒雾 / 扩散符文` |
| 刺客 | 影刃 | `闪避后 + 背击标记 + 突刺 / 连击符文` |
| 指挥者 | 御物 | `傀儡计数 + 傀儡协同 + 护盾 / 分流符文` |
| 待定高风险模板 | 业火 | `受伤 / 低血触发 + 爆发效果器 + 代价改造件` |
| 待定时机模板 | 剑魄 | `完美时机 + 剑气 / 冲击波 + 充能符文` |

首批建议只做前三个，避免重新变成“职业系统”。

---

## 拆解原则

- 只回收能改变操作或模块组合的机制。
- 纯数值被动不要作为模板核心。
- 起始模板不锁定后续掉落。
- 旧“角色感”可以留给名字、图标、动画和新手引导，不放进规则层。

---

旧版化身详述、亲和谱、节点图、系精通等内容不再作为当前策划依据。如需查阅完整旧案，请从 Git 历史恢复。
