## 一、化身要点 + 重构标注（🟢保留 / 🟡调整 / 🔴重写 / ➕新增）

### 🔥 业火 · 御灵·火 · 魔焰献祭
以生命/寿元为燃料的焚爆，越残血伤害/范围越高（刀尖跳舞），与青囊正交。
- 🔴 `业焰印`(叠印引爆，撞青囊) → 删，改"自身焰势"
- 🟡 `怒气/狂火` → "焰势/魔焰加身" + 燃血/燃寿充能 + 残血增伤曲线；满怒强爆 → "焰势满溢自燃"
- 🟢 `业火燎原`(结束引爆) 当大招
- ➕ 接 `寿元`(燃寿) / `心魔`(嗜血入魔)

### ⚔ 剑魄 · 御灵·金 · 金属控制
操控金属——飞金穿透、塑金为刃/甲(攻防切换)、磁力牵引(拉敌/聚物)。
- 🟢 `剑心通明`/灵压窗口/完美判定/`一念刹那` → 作"金锋时机"特色
- ➕ 主体新增：飞金碎片 / 塑金 / 磁力牵引

### 🌱 青囊 · 生灵（基本不动）
- 🟢 `寄生种子`(蛊毒DoT)→引爆、`枯荣逆旅`、`清房回血·最大血-20%`
- **守住"叠层引爆"专属权**（业火/御物的同类机制要让位）

### 🌀 影刃 · 空间（基本不动）
- 🟢 `息影瞬步`/`影息斩`(位移即输出)/`水痕印`(锚点)
- 🔴 `受击反伤`（后续重写）

### ⛰ 御物 · 召物（重心转移）
- 🟢 `兵阵合一`/傀儡(自律AI) → 升为主体（多种召物/成阵）
- 🔴 `地脉烙印`(叠印引爆，撞青囊+不合召物) / `扎根` / `地脉护盾`（后续重写）

> **全局动作**：把"普攻叠层→技能引爆"收敛为青囊专属（业火`业焰印`、御物`地脉烙印` 拿掉/重做）。
> **改动量排序**：御物（重心转移）≈ 业火（魔焰重做）＞ 剑魄（补金属控制）＞ 影刃 ＞ 青囊（基本不动）。

| 业火 | ★★★★(火) | ★★★ | ★ | — | ★★ | 越残越浪，学不会御心 |
