### Build 框架 · v0.6 重构

```
玩家 build 由 4 个来源构成（v0.6 法宝替代化身）：

  ① 法宝（洞府选定，3 件：攻/防/辅 · 跨局持久化 · 祭炼升阶）
  ② 功法（局内 Q/E/R 三槽，可装备/替换/升级）
  ③ 灵物（150+ 道具池，自由叠加 / 协同 / 质变）
  ④ 境界突破奖励 + 顿悟口诀 + 机缘收益

  耦合接口：
  - 法宝 × 功法：法宝被动对功法生效（如飞剑法宝 + 任意功法 = 功法后出灵压窗口）
  - 功法 × 灵物：6.5 槽位修饰（落石术 + 火灵珠 = 陨石术）
  - 灵物 × 灵物：协同 + 质变
  - 法宝 × 法宝：双修融合（洞府炼器房）
  - 因果 × Boss：当局行为动态影响 Boss 属性/招式/台词
```

## 3. 系统总览

### 3.1 法宝系统 · 玩法的"身份定义层"（v0.6 替代化身）

**意义**：修仙者的身份不是"出生选职业"，而是**手中法宝**决定的——"剑修之所以是剑修，因为他有飞剑"。

**方向**：
- **3 个法宝槽位**：攻（G）/ 防（H）/ 辅（J），每件同时提供主动技 + 被动效果
- **品阶系统**：凡器 → 灵器 → 玄器 → 地器 → 天器 → 仙器（洞府祭炼升阶）
- **认主度** 0~100%：越用越认你，100% 时"性命相连"——致死伤害法宝替你挡一次
- **双修融合**：炼器房中两件法宝融合成混合法宝（飞剑 + 火灵珠 = 焚天剑）
- **叛主风险**：业力过重 → 法宝拒绝认主 / 关键时刻罢工

**例子（青锋飞剑 · 攻击型法宝）**：
- **主动技（按 G）**：祭出飞剑直线斩击，命中敌人后飞剑回旋
- **被动效果**：继承原"剑魄"完美收刀机制——攻击后出现灵压窗口，窗口内再攻触发 ×1.5 爆发
- **祭炼升阶**：灵器 → 玄器后可命名（"无名剑"→"青霜"），天器后可寄魂
- **100% 认主**：玩家致死时，飞剑替你挡一击（退一阶，你活下来 30% HP）

**首批 5 件法宝**（Demo 验证用）：

| 法宝名 | 槽位 | 一句话 | 原型来源 |
|-------|------|--------|---------|
| 青锋飞剑 | 攻 | 灵压窗口 + 完美收刀 ×1.5 | 原剑魄 |
| 噬灵蛊 | 攻 | 普攻种寄生种子，主动技引爆 | 原青囊 |
| 玄龟壳 | 防 | 展开护盾 + 受击自动护体 | 新设计 |
| 风羽履 | 辅 | 瞬步位移 + 闪避充能 +1 | 新设计 |
| 水影匕 | 辅 | 闪避后影息斩 + 水痕印 | 原影刃 |

> **与化身系统的关键区别**：化身是"选 1 个固定职业"，法宝是"组合 3 件装备"——build 自由度指数级提升。且法宝跨局保留和成长，让"养一把好剑"成为长线目标。

### 3.2 因果系统 · 让选择有"修仙式的重量"（v0.6 新增）

**意义**：你做的每件事都会"种因"，因到了会找上门来。这是 Hades / 杀戮尖塔没有的修仙特色。

**方向**：
- **三条隐性记账**：善因 / 恶因（业力） / 因果债（跟特定 NPC 的牵连）
- **当局触发**：业力高 → 商人拒售；善因高 → NPC 送礼
- **跨局触发**（核心深度）：杀了宗门弟子 → 下一局师兄追杀；救了女修 → 下局道侣助阵
- **视觉表现**：头顶金光（善）/ 红雾（恶）/ 脚下紫链（因果债）
- 写入 SaveData 跨局持久化

**例子（跨局因果链）**：
1. 第 1 局：机缘事件"散修结义"，你选 C 暗算夺宝 → 业力 +25
2. 第 2 局开局：收到讯息"散修师门已派人追杀" → 第 2 房间刷出追杀精英
3. 第 2 局 Boss 战：Boss 台词变为"你身上煞气冲天……" → Boss 攻击 +40%

### 3.3 仙山舆图 · 修真界的飞剑旅程（v0.6 新增）

**意义**：把"节点图选路"从抽象几何变成**修仙世界的旅行体验**。玩家不是在点 dot，而是在御剑飞行。

**方向**：
- **拓扑**同节点图（多路径 + 分支选择），但视觉是**山水画风的修仙世界**
- **9 种地点类型**：凡间古镇 / 仙山宗门 / 秘境洞府 / 妖王巢穴 / 古修陵墓 / 东海玄关 / 机缘之地 / 山门撤离 / 境界关主
- **御剑移动**不是瞬移，飞行途中 15% 概率触发随机遭遇
- **渡劫地点影响强度**：东海（雷劫 ×2 但高奖励） / 山巅（最高回报） / 山谷（最安全但奖励减半）
- Phase 1 先做功能拓扑（简易 2D 地图 + 飞剑图标），Phase 2 再做视觉升级

**例子（路径选择）**：
- 路线 A：秘境洞府 → 机缘之地 → 仙山宗门 → 境界关主（低风险 + 叙事多）
- 路线 B：妖王巢穴 → 古修陵墓 → 东海玄关渡劫（高风险高回报 + 因果事件密集）

---

### 3.4 机缘叙事 · 修仙小说的桥段（v0.6 新增）

**意义**：每个事件都是修仙世界的故事片段，有人物 / 选择 / 因果链 / 跨局后果。不是"路边塞 buff"。

**方向**：
- 每个机缘**至少 3 个选项**，至少 1 个有跨局因果后果
- 不能有"纯 buff 无代价"选项——修仙世界没有白捡的便宜
- 首批做 **3 个代表性原型**验证机制

**例子（古洞遗骸）**：
- 情境："古洞深处发现白骨，旁边放着手抄经卷。"
- A 上香诵经 → 灵魂传授功法 + 善因 +20
- B 直接夺取 → 高品质残页 + 业力 +15 + 3 局内"白骨索命"追杀
- C 埋葬遗骸 → 无即时收益 + 善因 +30 + 下局古修灵魂赠送天器碎片

---

### 3.5 Boss 因果变体 · Boss 记住你做过的事（v0.6 新增）

**意义**：Boss 不是固定数据表，而是根据玩家当局行为**动态拼接**的变体。鼓励重玩探索不同因果路线。

**方向**：
- Boss spawn 时读取因果状态 + 机缘选择记录
- 动态修改：HP / 攻击 / 额外招式 / 援军 / 出场台词
- 台词是条件拼接的（按优先级取最高 1~2 条）

**例子**：
- 你杀了青云宗弟子 → Boss 大长老攻击 +40% + 召唤 2 名弟子援军 + 台词"受死！"
- 你救了道侣 → 道侣在 Boss 战中助阵 + 台词"倒也算个有情人"
- 你放走妖兽灵卵 → Boss 母妖主动让路（跳过战斗）

---

### 3.6 道行积分与渐进式解锁 · 平滑的入门曲线（v0.6 新增）

**意义**：新玩家不应该一上来面对所有系统的信息洪流。用"道行"积分驱动渐进解锁。

**方向**：
- 每局结算"道行"积分（撤离 / 通关 / 击杀 / 渡劫 / 机缘等都给道行）
- 道行到阈值 → 解锁新系统（法宝 / 洞府模块 / 因果可视化 / 仙山舆图等）
- 不弹教程面板，用**环境叙事**引导（新模块带光效 → 自然探索）
- 道行跨局永不减少

**例子（解锁路径）**：
- 0 道行：基础战斗 + 1 件法宝 + 灵田
- 100：炼丹房 + 携丹入梦
- 250：第 2 件法宝 + 法宝祭炼
- 500：悟道蒲团 + 仙山舆图
- 800：因果系统可见化 + 机缘事件
- 1200：第 3 件法宝槽位 + 法宝双修融合
- 3000+：Boss 因果变体全开 + 高级法宝池

### 3.7 灵物系统 · Build 的"乐高积木"

**意义**：放弃"固定流派"，让 build 从灵物叠加中**自然涌现**。

**方向**：
- 目标 **150+** 灵物（当前实现 30 个）
- **5 品阶**：凡（50%）/ 灵（30%）/ 玄（15%）/ 地（4%）/ 天（1%）
- **质变叠加**：锈铁飞剑 ×3 = 飞剑旋转护体 → ×5 = 召唤剑阵

---

### 3.8 功法 · 战斗的"爆发节奏"

**意义**：Q/E/R 不只是放伤害，更是 BD 策略 + 改变战场形状。

**方向**：
- **3 个槽位**：Q（攻击型）/ E（位移辅助）/ R（大招）
- **槽位修饰系统**：灵物插入槽位 → 改变技能机制（落石术 + 火灵珠 = 陨石术）

---

### 3.9 协同系统 · 玩家发现的"惊喜"

**意义**：让玩家突然发现"这两个灵物在一起怎么有特效？" → 推动探索 + 社区讨论。

**方向**：目标 **100+** 隐藏组合（当前 30 个）

---

### 3.10 境界突破 · 让每一层都有"决策的重量"

**意义**：避免"打通六层"变成纯刷数值。

**方向**：
- **6 层境界**：练气 → 筑基 → 金丹 → 元婴 → 化神 → 渡劫
- 每次过渡触发 **3 选 1 奖励**（数值/机制/风险/法宝天赋类）

---

### 3.11 普攻↔技能融合层 · 让普攻"值得做"

**意义**：三个维度让普攻和技能形成节奏循环。

**方向**：
- **资源循环**：Attack3 命中 → 随机减 1 个 CD 中技能 10%
- **状态钩子**：法宝专属"印记 + 引爆"（继承原化身设计）
- **动作衔接**：连招派生（Demo2+ 愿景）

---

### 3.12 战斗操作模型 · Hades 风格近战

```
【普攻】鼠标左键 → 三段连招（1.0 / 1.2 / 1.5 倍率）
【技能】Q / E / R 三槽位
【法宝】G / H / J 三件法宝主动技
【闪避】Space（2 层充能 · 无敌帧 0.3s）
```
