### Build 框架 · 5 个耦合接口（v0.4.1 / 2026-05-16 补充）

```
玩家 build 由 4 个来源 + 5 个耦合接口构成：

  ① 化身（局外选定，整局固定 / 4 个：剑魄/青囊/影刃/御物，火属性待重设计）
  ② 功法（局内 Q/E/R 三槽，可装备/替换/升级）
  ③ 灵物（150+ 道具池，自由叠加 / 协同 / 质变）
  ④ 化身天赋（洞府悟道蒲团永久点亮，v0.5.4 从局内境界突破解耦）
  
                    ┌─────── 化身 ───────┐
                    │                    │
            化身×功法                化身×灵物
            (普攻↔技能              (化身专属灵物
             融合点 4.3.x)           4.7)
                    │                    │
                    ▼                    ▼
            功法 ◀──6.5──▶ 灵物 ◀──5.5──▶ 灵物
                  槽位修饰         协同+质变
                    │                    │
                    └──── 4.4 ───────────┘
                       化身天赋节点
                       （悟道蒲团永久解锁）
```

**4 个耦合接口逐项**：
- 化身 × 功法：化身机制对所有 Q/E/R 都生效（剑魄技能后开窗口、青囊技能引爆种子、影刃技能命中水痕 ×1.5、御物傀儡同步技能 ×10%）
- 功法 × 灵物：6.5 槽位修饰（落石术 + 火灵珠 = 陨石术）
- 灵物 × 灵物：协同（7.x）+ 质变（5.5）
- 化身 × 灵物：化身专属灵物（4.7，如御物的炼魂蛊 / 御灵符 / 化形丹）
- 化身 × 化身天赋：洞府悟道蒲团永久解锁（v0.5.4 移除局内境界突破解锁路径）

**化身锁定原则**：每局开局选定化身后整局固定（不能换）。Roguelike 单局 30~60 分钟，整局保持一个角色身份让 build 投资聚焦、心流不被打断。后续可通过 Demo3 局外感悟系统解锁更多化身备选。

## 3. 系统总览

### 3.1 化身系统 · 玩法的"角色选择层"

**意义**：通过选化身，玩家选择的不是属性偏好，而是**玩法/流派**。

**方向**：5 个机制版化身，每个有 5~9 节点的小天赋树。每个化身必须满足"换了化身 = 玩家手指做的动作明显不同"。

**例子（剑魄 · 完美收刀）**：
- 三段连招每段收招瞬间，**头顶亮起金色剑形特效** + 刀身白光闪烁 0.15s。
- 窗口内按普攻 → 触发**灵压爆发**（×1.5 伤害 + 命中目标硬直 0.5s）。**[短期目标]**
- 连续 3 次完美 → 进入**剑心通明** 4s（普攻 +30%，每次完美额外溅射剑气）。**[中期目标]**
- 主动技能后 / 闪避后也会开窗口 → 即便没有任何技能也能频繁触发。
- 天赋树包含：大破 / 剑气波（小 AOE）/ 流星断（直线剑气）/ 御剑回锋（30% 重置 CD）/ 剑心永明 / 无意之意 / 窗口绵延 / 窗口共振。

**5 个化身一览**（v0.4.1 化身概念引入）：

化身 = 底层机制类别；**化身 = 化身的角色化包装**（名字 + 副标题 + 战斗幻想 + 视觉色调）。玩家在选择界面看到的是化身名，化身名只用于代码 / 协同条件 / 灵物 modTag。

| 化身 | 化身名 | 副标题 | 一句话玩法 |
|------|------|------|--------|
| ⚪ 金 | **剑魄** | 执剑而行 · 时机大师 | 抓【灵压窗口】按键触发完美收刀 ×1.5 + 连击进剑心通明 |
| 🟢 木 | **青囊** | 播种收割 · 蛊毒大师 | 普攻种【寄生种子】，技能命中引爆所有种子（×0.5/颗 AOE） |
| 🔵 水 | **影刃** | 凌波微步 · 闪避杀手 | 闪避后 0.4s 内攻击触发【影息斩】×2 + 前冲 + 水痕印 |
| 🔴 火 | *(待重新设计)* | 火属性化身于 2026-05-16 整体撤销 | — |
| 🟡 土 | **御物** | 万物执心 · 群战指挥官 | 固定 2 傀儡同步技能 ×10%；专属灵物（炼魂蛊 / 御灵符 / 化形丹）解锁傀儡军团扩张 |

> **设计原则**：副词条（v0.3 数值规则的弱化版）作为基础底座；核心机制改变玩法；天赋树深化变体。三者叠加形成"角色感"。
>
> **化身命名状态**：剑魄 / 青囊 / 影刃 / 御物 已定稿；火属性化身在 v0.4 实装"业火 · 狂战之火"后于 2026-05-16 整体撤销，留作未来重新设计。

### 3.2 灵物系统 · Build 的"乐高积木"

**意义**：放弃"固定流派"，让 build 从灵物叠加中**自然涌现**。

**方向**：
- 目标 **150+** 灵物（当前实现 17 个）
- **5 类**：攻伐 / 护体 / 身法 / 异变 / 功法（v0.5.4：法宝并入"机缘事件产物"，不作为独立分类）
- **5 品阶**：凡（50%）/ 灵（30%）/ 玄（15%）/ 地（4%）/ 天（1%）
- **自由叠加**两种模式：
  - **线性叠加**：火灵珠 ×1 = 每秒 5 灼烧 → ×3 = 每秒 15 灼烧 + 扩散周围敌人
  - **质变叠加**：锈铁飞剑 ×3 = 飞剑旋转护体 → ×5 = 召唤剑阵

**例子**：玩家本局拿到 5 把锈铁飞剑（质变剑阵环绕）+ 5 颗火灵珠（焚天大成）→ 飞剑环绕同时引爆灼烧周围敌人。没有任何"流派"标签，全靠捡到什么、拼出什么。

### 3.3 功法 · 战斗的"爆发节奏"

**意义**：在普攻基础上提供主动决策点 + 大爆发，按 Q/E/R 不只是放伤害，更是**BD策略 + 改变战场形状**。

**方向**：
- **3 个槽位**：Q（攻击型）/ E（位移辅助）/ R（大招）
- 每个槽位下方 **2 个灵物槽**（共 6 个）
- **充能层**（1~3 层，CD 一好恢复一层）+ **蓄力**（Lv1/2/3 → 伤害/范围倍率）
- 灵物插入槽位 → **改变技能机制**（不是数值加成）

**例子（落石术 + 火灵珠）**：
- 普通落石术：指定位置砸下巨石。
- 槽位插火灵珠 → 修饰为"**陨石术**"：落点留 3s 火焰地带（持续灼烧）。
- 同一件火灵珠插不同技能 → 不同变体（陨石 / 火遁震波 / 护火金钟）。
- 这个修饰是**纯 Inspector 配置**，不写代码，叫"槽位修饰系统"（GDD 6.5）。

> **与《梦之形》数值宝石的本质区别**：那里宝石是"+X% 数字"，这里灵物是"+一种行为"。

### 3.4 协同系统 · 玩家发现的"惊喜"

**意义**：让玩家在战斗中突然发现 "这两个灵物在一起怎么有特效？" → 推动**探索 + 社区讨论**。

**方向**：
- 目标 **100+** 隐藏组合（当前实现 10 个）
- 4 种触发方式：
  - 特定道具组合（如 锈铁飞剑 + 磨剑石）
  - 数量阈值（如 4 件不同飞剑）
  - 五行标签集齐
  - 条件状态（连续 3 房间没拿灵物）
- 触发时弹出**金色提示 + 强反馈**（屏幕闪光 + 音效）

**例子（万剑归宗）**：
- 持有 4 件不同的飞剑类灵物 → 自动触发"万剑归宗"
- 效果：所有飞剑自动追踪，飞剑数量 ×2
- 暗示（灵物 flavor text）："剑在精不在多……真的吗？"

> **暗示系统**：灵物描述里埋伏笔，玩家通过 flavor text 猜组合，配合古籍卷轴风格图鉴展示。

### 3.6 普攻↔技能融合层（v0.3.3 新增） · 让普攻"值得做"

**意义**：v0.3 发现"技能数值高 / 普攻成 CD 填充"的痛点。本层用**三个维度**让两者形成节奏循环。

**方向**（按实施阶段）：

| 维度 | 子方案 | 阶段 |
|------|--------|------|
| **资源循环** | 三段连招 Attack3 命中 → 随机减 1 个 CD 中技能 10%（全局通用） | 🔴 v0.4 优先 |
| **状态钩子** | 化身专属"印记 + 引爆"循环（5 化身各不同） | 🔴 v0.4 同步 |
| 状态钩子 | 技能附魔普攻（6.5 槽位修饰扩展） | 🟡 Demo1+ |
| 资源循环 | 灵力潮汐（普攻积攒灵力，技能消耗） | 🟢 Demo2 |
| **动作衔接** | 连招派生（Attack1 后接 Q = 不同派生招式） | 🟢 Demo2+ 愿景 |

**例子（青囊 · 持续寄生）**：
- 普攻命中 → 在敌人身上种【寄生种子】（持续 6s，单敌 ≤5 颗，自带 ×0.1 攻击/s 微量 DoT）
- 任意技能命中带种子敌人 → 引爆所有种子（每颗 ×0.5 攻击 AOE）
- 战斗循环：**普攻铺 5 颗种子 → 技能一波收割 → 普攻继续铺 → 再收割**

> 这是 1.7 痛点（功能缺口归档）的**样板解法**：技能数值不需要调，但"光按技能不打普攻"会直接损失 50%+ 爆发。

### 3.7 战斗操作模型 · Hades 风格近战

**意义**：与《梦之形》风格的远程射击区分开来；用近战的"输入感"建立战斗反馈。

**方向**：

```
【普攻】鼠标左键 → 三段连招
  - 段倍率 1.0 / 1.2 / 1.5
  - 扇形判定（半径 2.5、角度 120°）
  - 攻击中拥有霸体（轻击不打断）
  - 250ms 输入缓冲（流畅连段）
  - 每段带前冲 Lunge 位移

【技能】Q / E / R 三槽位
  - 充能层（1~3 层）
  - 蓄力（部分技能支持 Lv1/2/3）
  - 槽位灵物可加充能 / 缩 CD / 改机制

【闪避】Space
  - 距离 5、持续 0.2s、无敌帧 0.3s
  - 2 层充能，每层 CD 1.5s
  - 最高优先级（可打断除"死亡"外一切动作）
  - 输入缓冲 250ms
```

> **不做**：弹反 / 完美格挡 / 主动格挡 / 独立重击键（已在 GDD 6.7.3 明确）。

### 3.8 洞府修炼系统（v0.5.2 升级）

**意义**：让洞府不只是"加工素材的基地"，而是**真正的修炼之所**。回府闭关修炼是修仙者的核心日常。

**三大核心**：

**🧘 闭关修炼**（历练值 → 修为 → 本体境界）`[v0.5.4 重设计：纵向成长]`
- 秘境中战斗/探索积累**历练值**（死亡保留 30%，撤离 100%）
- 回府闭关消耗历练值 → 提升**本体境界**（炼气→筑基→金丹→元婴→化神→渡劫，6 阶纵向轴）
- 本体境界**不是方向、不是数值加点**（方向归化身、深度归天赋），它回答"**能走多深 / 根基多稳**"：
  - **境界压制**：本体境界低于秘境层环境境界 → 受减益（越级越险）；够了才稳吃深层
  - **渡劫底力**：本体境界高于当前层 → 天劫更稳
  - **道伤减免**：本体境界越高 → 死亡后道伤时间越短
- 化身=怎么打（横向），本体境界=能走多深（纵向），职能不撞
- **突破 = 渡劫战**（替换无聊雷劫）：洞府冲击境界 → 天劫环境 + 心魔镜像同场战斗；前易后难、后期随机
- **境界成色**（瑕品/凡品/上品/完美）：渡劫表现定成色，"完美金丹"远强于"凡品金丹"
- **死亡 = 身死道消**：本体境界+修为归零、转世重修，但洞府家业（灵脉/天赋/解锁池/库存）传承保留
- **心魔（乱入）= 抉择之债**：作恶/滥杀/选邪道（因果↑）或功利背信（道心↓）攒满心魔值 → Boss 战中心魔分身乱入；**惩罚的是"道"不是"技"**（又肉又稳但从不作恶的玩家心魔值恒为 0）

**💎 灵脉系统**（历练值 / 灵脉道具 → 收益品质）
- 5 级灵脉：枯脉 → 凡脉 → 灵脉 → 福地 → 洞天
- 灵脉聚焦"**每趟收益品质**"两维：**秘境掉落品质** + **机缘品质**
- **核心抉择**：历练值投修为（能走多深·扛得住）vs 投灵脉（每趟捞得更好）
- **正循环**：高灵脉让深层更值得去，高修为让深层去得起 → 互相拉动

**🎲 洞府机缘事件**（核心产出：天赋分支解锁）
- 每次回府按灵脉等级概率触发（枯脉 5% ~ 洞天 30%，保底 5 次必触发）
- **核心价值**：高级机缘（需福地+）产出**天赋分支解锁令**——天赋树的隐藏分支只能通过机缘发现
- 部分事件链式触发（帮散修 → 3 局后带秘传回来 → 解锁天赋分支）
- 选项联动道心/因果

**🧘 天赋树**（v0.5.3 渐进解锁）
- 每化身初始只有 1 条基础分支（3~4 节点）
- 隐藏分支（2~3 条/化身）通过机缘事件 / 剧情 / 成就解锁
- 悟性用来"点亮"已解锁分支上的节点——分支靠发现，节点靠积累

**当前状态**：🔴 GDD 已设计（v0.5.3），代码待 Demo2 实施。

### 3.9 世界观与叙事 `[Demo3 愿景]`

**意义**：用**修仙路尽头的多结局抉择悬念**驱动长期游玩。

**方向**（v0.5.4 重写 · 纯修仙叙事）：
- 主角是一名拥有自己洞府的修仙者，立志在仙途上走得更远
- 修仙界散落着无数远古遗留的**秘境**，蕴藏机缘、灵物、功法
- **秘境陨落 = 残念被洞府牵引回**（合理化 Roguelike 死亡），并落下"道伤" debuff
- 秘境每次进入面貌不同（灵气不稳定态 → 天然 Roguelike）
- **道心 / 因果 / 缘分**累积驱动多结局抉择
- **最终谜题**：你的仙途走向何方？飞升 / 入魔 / 凡途 / 真道？
- 多结局 / 真结局 / 隐藏 Boss
