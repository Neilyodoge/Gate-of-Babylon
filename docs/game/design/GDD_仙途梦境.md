## 1. 游戏概述

### 1.1 一句话描述

> 一款修仙题材的 Roguelike Top-down 3D ARPG（参考《梦之形》视角风格），玩家在梦境与现实的双线叙事中，通过自由组合灵物和功法构建无限可能的 Build，探索仙途的终极真相。

### 1.2 核心卖点

| 卖点 | 说明 |
|------|------|
| **以撒式自由 Build** | 无固定流派，150+ 灵物自由组合，Build 自然涌现 |
| **机制型 Synergy** | 灵物不只是数值加成，而是改变技能机制（区别于《梦之形》的数值宝石） |
| **灵根 = 规则修改器** | 不同灵根改变游戏基础规则，同一道具不同灵根体验完全不同 |
| **梦境×修仙双线叙事** | 梦境线（局内战斗）+ 现实线（局外成长），终极悬念驱动长期游玩 |
| **100+ 隐藏组合** | 发现道具间的化学反应是核心乐趣，社区讨论热点 |

### 1.3 参考作品分析

**《Shape of Dreams / 梦之形》的不足（我们要解决的问题）：**

| 问题 | 我们的解决方案 |
|------|--------------|
| Build 多样性有限，几局后见过所有东西 | 150+ 灵物 + 100+ 隐藏组合，理论 Build 数近乎无限 |
| 宝石系统偏数值，缺乏机制深度 | 灵物附着到技能上改变机制，而非单纯加数值 |
| 敌人与 Boss 设计单一 | *（TODO：敌人/Boss 设计）* |
| 叙事/世界观薄弱 | 梦境×修仙双线叙事，碎片化剧情 + 终极悬念 |
| 缺乏长期目标（Meta Progression） | 完整的局外成长系统：感悟天赋树 + 居所建设 + 秘术解锁 |

## 2. 世界观与叙事

### 2.1 核心设定（方案E：梦入仙途）

主角是一个生活在凡间的普通人，每晚入睡后会进入一个名为 **"仙途"** 的梦境世界。

梦中的一切都无比真实——修炼、战斗、法宝、妖兽……  
梦中死亡 = 惊醒，但修炼的"感悟"会留在记忆中。  
每次入梦，仙途的面貌都不同（Roguelike 随机性）。

随着入梦次数增加，主角逐渐发现：
- 梦境和现实的边界在模糊
- 现实中开始出现不可思议的事情
- 仙途可能不是梦，而是另一个真实的世界
- **最终谜题：到底哪边才是"梦"？**

### 2.2 双线结构

| 线 | 对应 | 内容 |
|----|------|------|
| 🌙 梦境线（局内） | Roguelike 战斗 + 探索 | 随机秘境、灵物获取、Boss 战、境界突破 |
| ☀️ 现实线（局外） | 成长 + 叙事 + 经营 | 感悟天赋树、居所建设、剧情推进、秘术解锁 |

**双线互动：**
- 梦境中获得的资源 → 影响现实（解锁能力、推进剧情）
- 现实中的选择 → 影响梦境（改变秘境内容、难度、事件）

### 2.3 叙事设计优势

- **致敬原作**《梦之形》的梦境主题
- **死亡毫无违和感**——做梦醒了而已
- **双线叙事拓展空间极大**——现实线可以做轻度经营/社交/剧情
- **终极悬念**驱动长期游玩——"真相是什么？"

## 4. 灵根系统（角色选择）

### 4.1 设计哲学

> **灵根不是"属性加成"，而是一条独特的"游戏规则"。**  
> 它不会限制你拿什么道具，但会影响你怎么玩。  
> 类比以撒：灵根 ≈ 角色选择（不同角色 = 不同起始道具 + 不同被动规则）。

### 4.2 基础灵根（初始可选）

| 灵根 | 被动规则 | 起始灵物 | 设计意图 |
|------|---------|---------|---------|
| **金灵根** | "锐金之体"：所有攻击附带微量穿透（穿过第一个敌人，对后方敌人造成50%伤害） | 锈铁飞剑 | 适合新手，直觉式强化 |
| **木灵根** | "生生不息"：每清完一个房间回复5%生命；但最大生命值-20% | 聚灵草 | 鼓励快速清怪，高风险高回报 |
| **水灵根** | "上善若水"：受到伤害时，伤害的20%转化为对攻击者的反伤 | 水盾符 | 防御反击型玩法 |
| **火灵根** | "燎原之火"：击杀敌人后3秒内攻击力+15%（可叠加3层） | 火灵珠 | 鼓励连续击杀，滚雪球 |
| **土灵根** | "厚德载物"：每持有5件灵物，获得一层"地脉护盾"（吸收一次伤害） | 岩甲符 | 鼓励大量收集道具 |

### 4.3 变异灵根（局外解锁，规则更极端）

| 灵根 | 被动规则 | 起始灵物 | 解锁条件 |
|------|---------|---------|---------|
| **雷灵根** | "天雷淬体"：移动速度+30%，但站立不动超过2秒会受到自伤 | 紫霄雷印 | 累计移动距离达到100km |
| **冰灵根** | "绝对零度"：所有攻击附带减速；但自身也被减速10% | 寒玉髓 | 累计冻结敌人500次 |
| **暗灵根** | "噬魂"：击杀敌人回复灵力，但商店价格+50%，且无法回血（只能靠护盾） | 蚀骨珠 | 不回血通关1次 |
| **混沌灵根** | "万象"：每进入一个新房间，随机获得一个临时灵物（离开房间消失） | 混沌珠 | 单局获得20件以上灵物 |
| **无根之体** | "凡人之躯"：没有任何被动规则，但初始3件灵物可自选 | 自选×3 | 通关10次 |

### 4.4 灵根专属灵物

每个灵根有 **2-3 件专属灵物**，只有该灵根能激活。这些灵物和灵根的被动规则产生强烈的化学反应：

**金灵根专属：**

| 灵物 | 效果 | 与灵根被动的化学反应 |
|------|------|-------------------|
| 破军星辰 | 穿透的敌人数量越多，伤害递增而非递减 | 穿透从"微量"变成核心输出方式 |
| 金精蚕丝 | 穿透的弹道之间产生连线，连线切割敌人 | 多发攻击+穿透=满屏切割线 |

**木灵根专属：**

| 灵物 | 效果 | 与灵根被动的化学反应 |
|------|------|-------------------|
| 生死簿 | 每击杀10个敌人，永久+1%最大生命值 | 虽然最大生命-20%，但可以通过击杀"种"回来 |
| 枯荣诀 | 生命>70%时攻击+30%；生命<30%时回血速度x3 | 和"清怪回血"形成节奏循环 |

**水灵根专属：**

| 灵物 | 效果 | 与灵根被动的化学反应 |
|------|------|-------------------|
| 镜花水月 | 反伤的伤害也会触发灵物效果（灼烧、冰冻等） | 反伤不再是纯数字，Build 可能性暴增 |
| 潮汐之心 | 反伤积累到一定量后释放"潮汐波"（全屏水属性伤害） | 被打越多→潮汐波越强 |

**火灵根专属：**

| 灵物 | 效果 | 与灵根被动的化学反应 |
|------|------|-------------------|
| 业火种 | 连杀叠加的攻击力加成不再有上限，但每层额外增加1%受伤 | 理论无限叠攻击力，但越叠越脆 |
| 焚天令 | 连杀达到10连时触发"天火"（巨大范围高伤害），重置连杀 | "攒连杀→爆发→再攒"的节奏循环 |

**土灵根专属：**

| 灵物 | 效果 | 与灵根被动的化学反应 |
|------|------|-------------------|
| 万宝囊 | 每获得一件灵物时，随机复制一件已有灵物效果（持续当前房间） | 疯狂鼓励拿更多灵物 |
| 聚宝盆 | 商店额外出现1件灵物；灵物价格-20% | 更容易堆数量，强化核心被动 |

### 4.5 灵物变体

某些通用灵物，不同灵根拿到后有额外效果：

| 灵物 | 通用效果 | 金灵根变体 | 火灵根变体 | 水灵根变体 |
|------|---------|-----------|-----------|-----------|
| 混沌珠 | 每5件灵物全属性+5% | +穿透距离翻倍 | +连杀加成也提升暴击率 | +反伤比例额外+10% |

## 5. 灵物系统（道具体系）

### 5.1 设计哲学

> **所有东西统一叫"灵物"，获取后自动生效，没有装备栏的概念。**  
> 就像以撒一样：捡到就生效，叠加就完事。  
> 没有"装备"和"套装"的区分——灵物可以无限叠加（功法除外，最多3个）。

### 5.2 灵物分类

分类仅用于内部标签和掉落权重，玩家不需要关心分类：

| 分类 | 说明 | 示例 |
|------|------|------|
| ⚔️ 攻伐灵物 | 改变/增强攻击方式 | 飞剑·锈铁、紫霄雷印、火符、冰锥 |
| 🛡️ 护体灵物 | 防御/生存 | 玉佩、金钟、龙鳞、寒玉髓 |
| 👟 身法灵物 | 移动/闪避 | 风灵珠、缩地符、御风羽 |
| 🔮 异变灵物 | 改变游戏规则的特殊效果 | 轮回木、因果丝、混沌珠、天道之眼 |
| 💊 丹药 | 一次性消耗 or 被动触发 | 回灵丹、破障丹、筑基丹 |
| 📜 功法 | 主动技能，最多携带3个 | 御剑术、天罡阵、落石术 |

### 5.3 灵物品阶

| 品阶 | 颜色 | 出现概率 | 强度 | 数量目标 |
|------|------|---------|------|---------|
| 凡品 | ⚪白 | 50% | 基础 | 60+ |
| 灵品 | 🟢绿 | 30% | 中等 | 40+ |
| 玄品 | 🔵蓝 | 15% | 强力 | 25+ |
| 地品 | 🟣紫 | 4% | 极强 | 15+ |

### 5.5 叠加规则

同一灵物可以重复获取，效果叠加：

**线性叠加：**
- 火灵珠 ×1：攻击附带灼烧，每秒5点伤害
- 火灵珠 ×2：灼烧伤害变为每秒10点
- 火灵珠 ×3：灼烧伤害每秒15点 + 灼烧扩散至周围敌人

**质变叠加（达到一定数量触发质变）：**
- 锈铁飞剑 ×1：1把飞剑
- 锈铁飞剑 ×3：3把飞剑 + 飞剑自动旋转护体
- 锈铁飞剑 ×5：5把飞剑 + 触发"剑雨"（每5秒天降剑雨）
- 寒玉髓 ×1：受击15%冻结敌人
- 寒玉髓 ×3：受击45%冻结 + 冻结敌人碎裂时伤害周围
- 寒玉髓 ×5：受击必定冻结 + 角色周围永久寒气场

## 6. 主动技能系统（功法）

### 6.1 操作模型

```
【普通攻击】—— 自动/半自动，由灵物被动改变形态
  → 默认武器为法杖，鼠标瞄准方向进行远程攻击（发射灵力弹）
  → 灵物改变攻击形态（穿透、分裂、连锁、追踪等）
  → 不同武器类型可改变攻击方式（法杖远程 / 飞剑中距 / 拳套近战等）

【主动技能】—— 玩家手动释放，有CD，最多装备3个
  → 技能1（Q）：攻击型
  → 技能2（W）：辅助/位移型
  → 技能3（E）：大招/终极技能

【闪避/身法】—— 固定操作，灵物可以改变闪避效果
  → Space/右键：短距离闪避，有无敌帧
  → 灵物可以让闪避附加效果（留下火焰、冰冻轨迹等）
```

### 6.2 攻击型功法（技能1槽位）

| 名称 | 品阶 | 效果 | CD | 特殊交互 |
|------|------|------|----|---------|
| 落石术 | 凡品 | 指定位置召唤巨石砸落，AOE伤害 | 8秒 | 目标在冰冻状态→巨石碎裂成冰刺（范围+伤害翻倍） |
| 三昧真火 | 灵品 | 向前方喷射锥形火焰，持续3秒 | 12秒 | 火灵根使用时范围扩大50%；点燃的敌人被冰攻击命中会蒸汽爆炸 |
| 天雷引 | 玄品 | 标记区域，2秒后天雷轰下，高伤害+麻痹 | 15秒 | 目标在水面/被水属性减速→伤害x2+麻痹扩散 |
| 万剑诀 | 地品 | 召唤大量飞剑从天而降覆盖大范围 | 20秒 | 每持有1件飞剑类灵物，飞剑数量+3 |
| 混沌吞噬 | 天品 | 制造黑洞，吸引并持续伤害范围内敌人，持续5秒 | 30秒 | 黑洞吸收敌人投射物，结束时反射 |

### 6.3 位移/辅助型功法（技能2槽位）

| 名称 | 品阶 | 效果 | CD | 特殊交互 |
|------|------|------|----|---------|

## 7. 隐藏组合系统（Synergy）

### 7.1 设计哲学

> **没有"流派"这个概念。没有"你是剑修"这种标签。**  
> 只有：灵物 + 灵物 = 效果，效果 + 效果 = Build。  
> 玩家的 Build 是自然涌现的，不是选择出来的，而是"拼"出来的。

### 7.2 组合触发规则

| 触发类型 | 说明 | 示例 |
|---------|------|------|
| 特定道具触发 | 指定的2-4件灵物同时持有 | 锈铁飞剑+磨剑石→"十年磨一剑" |
| 标签触发 | 集齐特定五行标签组合 | 5种五行各1件→"五行归一" |
| 数量触发 | 同类灵物达到一定数量 | 4件飞剑→"万剑归宗" |
| 条件触发 | 满足某种游戏状态 | 连续3房间没拿灵物→"否极泰来" |

## 8. 境界系统（局内成长线）

### 8.1 境界阶段

```
练气期 → 筑基期 → 金丹期 → 元婴期 → 化神期 → 渡劫期
```

每个境界解锁更多能力和灵物容量，是局内的 power 曲线控制器。

### 8.2 境界效果

| 境界 | 解锁效果 |
|------|---------|
| 练气期 | 基础状态，可触发1个隐藏组合 |
| 筑基期 | 可触发2个隐藏组合，灵物掉落率+10% |
| 金丹期 | 可触发3个隐藏组合，解锁"金丹特效"（全属性+10%） |
| 元婴期 | 可触发4个隐藏组合，元婴分身（自动战斗辅助） |
| 化神期 | 可触发5个隐藏组合，神识扫描（显示全图） |
| 渡劫期 | 所有隐藏组合效果翻倍，触发天劫 Boss 战 |

## 9. 局外成长系统

### 9.1 总体结构

```
🏠 现实线（局外Hub）

├── 📊 感悟系统（永久天赋树）
│   ├── 通用感悟：生命+5%、攻击+3%、移速+2%...
│   ├── 五行感悟：增强五行相关灵物效果
│   └── 秘术感悟：解锁特殊机制（见秘术系统）
│

│   ├── 炼丹房：局前选择携带1颗丹药入场

│
├── 📖 记忆碎片（剧情/图鉴）
│   ├── 每次通关/死亡解锁一段记忆碎片

### 9.2 秘术系统

### 📌 Demo2 规划（资源系统 · 灵力觉醒）

> **Demo1 采用纯 CD 模型**，不涉及任何资源消耗。以下内容全部归入 Demo2 阶段实现。

#### 核心概念

- **局外解锁**：玩家凑齐第一组完整记忆碎片后，在秘术系统中解锁"灵力觉醒"
- **可开关**：解锁后玩家可在居所·轮回池中自由开启/关闭，关闭则回到纯 CD 模型
- **觉醒后变化**：功法增加灵力消耗，CD 整体缩短约 30%；操作上限更高，更考验资源管理

#### 灵力基础规则（觉醒后默认资源）

| 要素 | 规则 |
|------|------|
| 灵力上限 | 基础 100，随境界提升（练气100→筑基120→金丹150→元婴200→化神250→渡劫300） |
| 灵力回复 | 自动回复（每秒3点）+ 普攻命中（+2）+ 击杀（+5） |
| 功法消耗 | 攻击型 15-30 / 辅助型 20-30 / 大招型 40-80 |
| 空蓝状态 | 功法变灰不可用，普攻不消耗灵力且是回蓝手段 |

#### 灵脉系统（资源类型覆写）

> **灵脉作为独立槽位**（类似被动位置），不占用灵物/功法栏位。  
> 通过获取特定"灵脉灵物"来改变资源条类型，同一时间只能激活一种灵脉。

| 资源类型 | 灵脉灵物 | 品阶 | 回复方式 | 消耗规则 | 特殊效果 | 设计风格 |
|---------|---------|------|---------|---------|---------|---------|
| **灵力**（默认） | — | — | 自动+普攻+击杀 | 释放功法消耗 | 无 | 稳定均衡型 |
| **怒气** | 修罗心脉 | 玄品 | 仅受伤和击杀回复 | 消耗量-30% | 怒气满→"修罗状态"：攻击+50%持续5秒后清空 | 近战激进型 |
| **充能** | 天机齿轮 | 玄品 | 仅时间自动回复（较快） | 释放功法消耗全部充能，伤害随充能量线性增长 | 充能满时功法伤害x2 | 节奏蓄力型 |
| **剑意** | 剑心通明 | 地品 | 每次普攻命中+1层（上限30） | 功法消耗剑意层数 | 30层→"剑心通明"：下一功法无消耗+伤害x3 | 精准操作型 |
| **因果** | 因果天秤 | 地品 | 造成伤害+因果，受到伤害-因果 | 功法消耗因果 | 溢出→护盾；耗尽→受伤x1.5 | 高风险博弈型 |
| **混沌** | 混沌灵脉 | 天品 | 随机在0-100波动，不受行为影响 | 固定消耗 | >80功法随机强化；<20功法随机弱化/变异 | 赌狗狂欢型 |

**灵脉灵物副属性**：未激活为灵脉时，仍提供被动效果（修罗心脉→受伤时攻击+5%等），不会浪费。

#### 技术架构建议

采用**策略模式**，功法只调用 `ConsumeResource(amount)` / `HasEnoughResource(amount)`，不关心具体资源类型。新增资源类型只需新增实现类，零侵入。

以下是一局完整游戏的 Build 形成过程示例：

```
【局前准备】（现实线）
  选择灵根：金灵根（穿透规则）
  携带丹药：破障丹（免死一次）
  初始功法：无（藏经阁未建造）
  初始灵物：锈铁飞剑（金灵根起始）

  → 暂未触发组合（需要更多飞剑）
  获得功法：落石术（装备到Q槽位）

【第2层·筑基期】
  获得灵物：火灵珠[火]
  → 普攻附带灼烧

  → 选飞剑：4把飞剑 → 触发"万剑归宗"！飞剑自动追踪！
  
  玩家选择：第4把飞剑 → ✨ 万剑归宗触发！

【第5层·化神期】
  获得灵物：磨剑石

  → 所有组合效果翻倍

  → 通关！飞升成功！大量感悟奖励！
