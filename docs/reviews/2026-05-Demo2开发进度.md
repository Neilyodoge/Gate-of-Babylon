## ✅ 已完成系统索引

### 搜打撤主循环
```
洞府 ─▶ 入梦（带 0~3 颗丹药）─▶ 战斗+搜素材+悟性 ─▶ 通境界
                                                    ├─ 撤离（西） → 带回素材 + 50%悟性永久
                                                    ├─ 渡劫（北） → 破劫者 buff（局内）
                                                    └─ 闯关（东） → 下一境界
死亡 ─▶ 失去全部素材（10% 残魂转灵气）+ 悟性散尽 + 3h 魂伤
```

## 📝 决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| 存档方案 | JSON 文件（`PersistentDataPath/save_v1.json`） | 简单可读、Unity 原生支持 |
| 灵物分类 | `ItemScope` 枚举（RunOnly / CaveMaterial） | 不破坏现有 17 件灵物，新加 6 类素材 |
| 经济货币 | 拆分 `PlayerResources.SpiritShards`（局内）+ `CaveEconomy.Qi`（跨局） | 角色定位明确，避免单价混乱 |
| 洞府场景 | 在 VillageHub 上扩展（不新建场景） | 复用 NpcHeadCard + TriggerBridge 范式 |
| 时间机制 | `GameTime` 单例（与 Unity Time 解耦） | 支持加速/暂停，灵田炼丹必备 |
| 顿悟资源 | 双层（局内积累 + 撤离 50% 转永久） | 战斗有即时反馈，永久投资目标明确 |
| 渡劫位置 | 房间正北，与撤离点（西）+ 传送门（东）共存 | 玩家三选一决策，不强制 |
| 携丹上限 | 3 颗 | 不抢局内 build 重要性，做"安全网" |
| 灵气浓度 | 4 级（Sparse 15% / Normal 55% / Rich 25% / Vein 5%） | 灵脉房稀有性 + 高阶境界小幅提升 |
