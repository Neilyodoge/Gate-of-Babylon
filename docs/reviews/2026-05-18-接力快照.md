### Week 7 · 土化身"山岳承负"重设计（2026-05-17 最新）

**机制完整度由 4/5 → 5/5。** 把原本只有"地脉护盾"的土化身升成 3 套联动机制 + 全 procedural 视觉。

| 模块 | 说明 |
|---|---|
| 🪨 地脉烙印 | 普攻 +1 层（最多 5）→ 技能命中带印敌人引爆：`攻击力 × 0.6 × 层数` 真伤 + 定身 `0.8 + 0.4×层数` s + 1.8m AOE 连锁 +1 层 |
| 🪨 扎根状态 | 站立 ≥ 1.5s 不动 → 攻击 +25% / 减伤 +30%（OnDamage 钩子）/ 移速 -50%；移动即解 |
| 🪨 护盾岩石板 | 旧 status 层数 → N 块旋转土黄岩石板围绕玩家；破盾时该块炸成 6 块碎片飞散 |
| 🎨 八卦阵 | 外八角 + 内圆 32 段 + 中心阴阳鱼 25 段 S 曲线，自转 + 颜色呼吸 |
| 🎨 上飘土块 / 气场 / 烟雾 | 4 块上飘小立方体 + α=0.10 半透土黄大球 + 4 缕地起烟雾 emitter |
