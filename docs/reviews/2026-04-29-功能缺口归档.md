## 1. 战斗维度

### 1.1 跨元素反应系统（GDD 5.6）—— **🚫 已撤销（v0.3.1 / 2026-05-06）**

- **历史**：v0.3 曾写入"火+冰=蒸汽爆炸 / 火+雷=过载 / 冰+雷=感电 / 风+火=烈焰扩散 / 木+火=燃烧蔓延 / 水+雷=导电领域"完整反应表，原计划在 v0.4 实装。
- **撤销决策（2026-05-06）**：
  - 反应表与"质变 / 协同 / 槽位修饰"边界不清，玩家难以分辨是哪条规则在生效。
  - 工程成本高（敌人元素附着列表 + 反应触发器 + 同帧防爆链 + 反应 AOE 走统一伤害管线），与 v0.3 阶段"先验证基础化身/槽位修饰/境界突破"的目标错位。
- **替代方向（暂不实施）**：
  - 若仍需"火+冰=爆炸"类化学反应感，**改放进 7 章「隐藏组合」**：携带双系/多系灵物时普攻按概率触发一次性效果（直接走协同管线，不依赖跨元素状态机）。
  - `StatusEffect.elementTag` 字段保留，作为协同检测、UI 分类、技能修饰判定（GDD 6.5）的元数据，**不再驱动反应触发**。
- **优先级**：🚫 不做。

### 1.2 处决（finisher）

- **现状**：未实现。
- **决策**：用户表态"弹反不要"，处决未明确，**默认保留作为可选项**。
- **建议**：等敌人血量 <10% 时按 V 处决，附带飘字 + hitstop。MVP 不超过半天工作量。
- **优先级**：🟡 中（视战斗节奏体感再决定）。

### 1.3 弹反 / 格挡

- **决策**：**不做**（已在 GDD 6.7.3 明确）。

### 1.4 重击 / 蓄力普攻

- **决策**：暂不做（已散落在部分技能的"蓄力 Lv1/2/3"中）。

### 1.5 召唤物 +% 协同 / 质变加成生效

- **现状**：`BuildSummonDamage` 当前只继承"基础攻击 + 暴击"。
- **缺口**：协同的 +% 词条（如金钟罩+10% 攻击）在玩家本体生效，召唤物的 `attackDamage * ratio` 已读取最终值，但**还没有"召唤物专属乘区"**（例如"九幽冥旗鬼兵在冥河中攻击力 ×3"）。
- **决策**：先观察是否真的会成为体验瓶颈。
- **优先级**：🟢 低。

### 1.6 元素附加的"地形"（GDD 6.7.1）

- 例如"岩浆河"、"冰面"等地形 StatusEffect（不再依赖已撤销的跨元素反应触发，改为由特定技能 / 灵物直接落地形）。
- 当前 `SkillZoneEffect` 只是单个落点，**还没有"持久地形"**（地图上一直存在直到房间结束）。
- **优先级**：🟢 低。

### 1.7 技能数值过高 + 普攻↔技能联动太弱（2026-05-12 提出）—— **🟡 v0.3.3 已落地核心架构（融合层维度一·A + 金/木印记），数值平衡 pass 留待 v0.4**

- **现象（2026-05-12 提出）**：技能 Q/E/R 数值过高，玩家"先 Q 再 E 再 R 然后等 CD"，普攻沦为填充。两套系统并列而非耦合。

- **解法（v0.3.3 / GDD 6.7.4 已落地为系统层架构，2026-05-12 完成）**：

  「普攻↔技能融合层」三维设计，各维度落地阶段：

  | 维度 | 子方案 | 阶段 | 备注 |
  |------|--------|------|------|
  | 一·A | **三段连招减 CD（全局通用）** —— Attack3 命中随机减 1 个 CD 中技能 10% | 🔴 v0.4 优先 | 所有化身共享，工作量小 |
  | 二·A | **化身印记 + 引爆**（5 化身全部补全融合点） | 🔴 v0.4 与机制版同步 | 见下表 |
  | 二·B | 技能附魔普攻（6.5 修饰扩展 `affectsBasicAttack`） | 🟡 Demo1+ | 依赖 6.5 修饰系统 |
  | 一·B | 灵力潮汐 | 🟢 Demo2 | 10 章灵力觉醒 |
  | 三 | 连招派生（Combo Extension） | 🟢 Demo2+ 愿景 | 工作量大 |

  **5 化身融合点（v0.3.3 已写入 GDD 4.3.x）**：

  | 化身 | 印记 / 触发条件 | 引爆 / 收割机制 |
  |------|---------------|---------------|
  | 金 | 主动技能后必现灵压窗口 | 完美收刀爆发 + 御剑回锋 30% 重置 CD 20% |
  | 木 | 普攻播种【寄生种子】 | 任意技能引爆所有种子 ×0.5/颗 AOE |
  | 水 | 影息斩留【水痕印】 | 技能命中带水痕 ×1.5（消耗水痕） |
  | 火 | 技能命中回 +5 怒气 | 狂火期间所有技能 CD ×0.7 |
  | 土 | 玩家释放技能事件 | 傀儡同步释放该技能 ×10% 强度 |

- **数值层调整决策（v0.4 实装后再做）**：
  - 三维融合层落地后，主观估计能把"技能 vs 普攻"伤害占比从当前的 20% / 80% 拉到 40% / 60% 左右。
  - 若仍有失衡，再做一次诊断 pass（录一局通关 / 统计占比 / 检查 outliers / 调倍率）。

- **诊断 checklist（v0.4 实装后立即执行）**：
  - [ ] 录一局完整通关，统计 **普攻伤害占比 vs 技能伤害占比**（理想 ≈ 35%~50% / 50%~65%）。
  - [ ] 列出当前 5 个主动技能（Q/E/R）的基础倍率，对比普攻三段（1.0 / 1.2 / 1.5）。
  - [ ] 检查 `SkillData` / `RealmRewardLibrary` / `SynergyEffects` 数值表，找 outliers。
  - [ ] 调整后重测一局，看玩家手感是否符合"普攻铺垫→技能爆发→普攻清扫"的循环。

- **优先级**：🔴 高（与 2.2 / 2.3 化身机制版合并到 v0.4 主路径里）。

## 3. 灵物 / 协同 / 内容

### 3.1 灵物总数 vs GDD 目标

- **现状**：实际 17 个 ItemData，GDD 目标 150+。
- **缺口**：
  - 攻伐类（飞剑/雷印/火符/冰锥）：还差大量
  - 异变类（轮回木 / 因果丝 / 混沌珠 / 天道之眼）：完全没有
  - 丹药类（破障丹 / 筑基丹 / 金丹碎片）：完全没有
- **优先级**：🟡 中（按"先验证机制再补内容"的节奏）。

### 3.2 ItemData 的 modTag 字段需要回填

- **现状**：`modTag` 字段刚加，所有现有 ItemData SO 都是 `None`。
- **缺口**：把 17 个已有 SO 按"火灵珠=Fire / 寒冰玉髓=Ice / 雷灵珠=Thunder / 风灵珠=Wind / 锈铁飞剑=Pierce / 灵藤草=Life"等填好。
- **优先级**：🔴 高（不填，技能-灵物联动 MVP 完全不会触发）。

### 3.3 SkillData 的 modifierDefs 需要配置

- **现状**：`modifierDefs` 字段刚加，所有现有 SkillData SO 都是空数组。
- **缺口**：先按 GDD 6.5.4 给"落石术 / 土遁术 / 金钟罩"各配 2~3 个 modifier。
- **优先级**：🔴 高（同上）。

### 3.4 cube 临时特效替换

- **现状**：`SkillModifierApplier.SpawnCubeVfx` 是程序化创建 Cube。
- **缺口**：替换为正式 VFX prefab。
- **优先级**：🟢 低（等美术）。

### 3.5 协同库扩充（GDD 7.3）

- **现状**：`SynergySystem` 只实现了少数几个组合。GDD 目标 100+。
- **缺口**：飞剑系 / 元素互动系 / 防御系 / 异变系。
- **优先级**：🟡 中。

### 3.6 灵物图鉴 / 协同记录 UI

- **现状**：完全无。
- **缺口**：本局拥有的灵物 / 已触发协同 / 当前 BUFF 集中显示页（按 Tab 打开）。
- **优先级**：🟡 中。

### 5.4 详细属性面板

- **现状**：HUD 只有血条 / 充能条 / BUFF 条。
- **缺口**：按 C / Tab 打开角色页，显示当前所有 stats、协同、化身、突破奖励。
- **优先级**：🟡 中。

### 5.5 小地图扩展

- **现状**：基础 Minimap 已实现。
- **缺口**：当前层 vs 当前房间区分；房间类型 icon。
- **优先级**：🟢 低。

### 5.6 BaseVFXGUI（之前修过的编辑器扩展）

- **现状**：已修复 `#if UNITY_EDITOR` 包裹问题。
- **缺口**：无。仅记录"已修"。

### 5.7 音效 / 音乐

- **现状**：基础 AudioConfig 存在。
- **缺口**：BGM 切换（按层 / 战斗 / 商店）、Boss 战专属 BGM。
- **优先级**：🟡 中。

### 5.8 配置外移到 ScriptableObject

- **现状**：`SpiritRootRegistry` / `RealmRewardLibrary` 是硬编码静态注册表。
- **缺口**：转 SO，让美术 / 策划在 Inspector 里调。
- **优先级**：🟡 中（数据稳定后再迁移）。
