## 1. 战斗维度

### 1.1 元素反应实装（GDD 5.6）—— **代码侧待落地**

- **现状**：GDD 5.6 已写入完整反应表（蒸汽爆炸 / 过载爆裂 / 感电 / 烈焰扩散 / 燃烧蔓延 / 导电领域）。
- **缺口**：
  - 敌人侧没有"元素附着 StatusEffect"列表（当前火/冰是各自独立 MonoBehaviour）。
  - 没有反应触发器：命中时检查目标身上已有元素 → 触发反应。
  - 反应自身的 AOE 伤害也需要走 `BuildSummonDamage` 统一管线。
- **决策**：v0.4 优先级第一档。已经有 `ElementTag` 枚举 + `StatusEffect` 框架做基础，落地路径清晰。
- **优先级**：🔴 高。

### 1.2 处决（finisher）

- **现状**：未实现。
- **决策**：用户表态"弹反不要"，处决未明确，**默认保留作为可选项**。
- **建议**：等敌人血量 <10% 时按 V 处决，附带飘字 + hitstop。MVP 不超过半天工作量。
- **优先级**：🟡 中（视战斗节奏体感再决定）。

### 1.3 弹反 / 格挡

- **决策**：**不做**（已在 GDD 6.7.3 明确）。

### 1.4 重击 / 蓄力普攻

- **决策**：暂不做（已散落在部分技能的"蓄力 Lv1/2/3"中）。

### 1.5 召唤物 +% 协同 / 质变加成生效

- **现状**：`BuildSummonDamage` 当前只继承"基础攻击 + 暴击"。
- **缺口**：协同的 +% 词条（如金钟罩+10% 攻击）在玩家本体生效，召唤物的 `attackDamage * ratio` 已读取最终值，但**还没有"召唤物专属乘区"**（例如"九幽冥旗鬼兵在冥河中攻击力 ×3"）。
- **决策**：先观察是否真的会成为体验瓶颈。
- **优先级**：🟢 低。

### 1.6 元素附加的"地形"（GDD 5.6 / 6.7.1）

- 例如"导电水域"、"岩浆河"等地形 StatusEffect。
- 当前 `SkillZoneEffect` 只是单个落点，**还没有"持久地形"**（地图上一直存在直到房间结束）。
- **优先级**：🟢 低（等元素反应实装后顺势）。

## 2. 玩家成长

### 2.1 局外永久成长（GDD 第 9 章）

- **决策**：**整章延后到 Demo2**（用户明确）。
- 包含：
  - 感悟（永久天赋树）
  - 居所建设（炼丹房 / 藏经阁 / 兵器库 / 灵兽园 / 轮回池 / 天机阁）
  - 记忆碎片
  - 秘术系统（梦醒残留 / 元婴二命 / 道身分离 / 轮回残影 / 因果轮转 / 天劫淬体 / 心魔具现 / 时光倒流）

### 2.2 灵根专属灵物（GDD 4.4）

- **现状**：未实现，文字描述已在 GDD 中。
- **缺口**：每灵根 2-3 件专属灵物（如金灵根「破军星辰」、火灵根「业火种 / 焚天令」）。
- **决策**：**暂缓**。先验证基础 5 灵根的差异化是否有趣。
- **优先级**：🟡 中（等首批基础灵根游戏体验跑通）。

### 2.3 灵物变体（GDD 4.5）

- 同一件灵物在不同灵根下表现不同（混沌珠 / 月光石 / 轮回木）。
- **决策**：**暂缓**到 Demo2。
- **优先级**：🟢 低。

### 2.4 变异灵根（雷 / 冰 / 暗 / 混沌 / 无根之体，GDD 4.3）

- **决策**：**Demo2 周目解锁**。
- **优先级**：🟢 低。

### 2.5 灵根选择 UI 美化

- **现状**：当前 `SpiritRootSelectUI` 是 IMGUI 临时面板。
- **缺口**：替换为 UGUI 卡牌式面板，加灵根 icon、起始灵物预览、动效。
- **优先级**：🟡 中（美术资源到位后再做）。

### 2.6 起始灵物自动入背包

- **现状**：`SpiritRootRegistry` 只在文本上写了"起手携带：xx"，**还没真的把起始灵物加进玩家背包**。
- **缺口**：`SpiritRootController.Select` 应顺带把对应 ItemData 加入 `ItemInventory`。
- **优先级**：🔴 高（很容易做，但目前是空缺）。

### 2.7 境界突破奖励池扩充

- **现状**：`RealmRewardLibrary` 只有 10 个。GDD 8.2 规划是 50+ 的奖励池。
- **缺口**：补到 30+，特别是"机制类"（灵物槽位 +1、协同激活阈值 -1、闪避充能 +1 等）和"风险类"。
- **优先级**：🟡 中（先有 10 个跑流程，后续按数据反馈补）。

## 3. 灵物 / 协同 / 内容

### 3.1 灵物总数 vs GDD 目标

- **现状**：实际 17 个 ItemData，GDD 目标 150+。
- **缺口**：
  - 攻伐类（飞剑/雷印/火符/冰锥）：还差大量
  - 异变类（轮回木 / 因果丝 / 混沌珠 / 天道之眼）：完全没有
  - 丹药类（破障丹 / 筑基丹 / 金丹碎片）：完全没有
- **优先级**：🟡 中（按"先验证机制再补内容"的节奏）。

### 3.2 ItemData 的 modTag 字段需要回填

- **现状**：`modTag` 字段刚加，所有现有 ItemData SO 都是 `None`。
- **缺口**：把 17 个已有 SO 按"火灵珠=Fire / 寒冰玉髓=Ice / 雷灵珠=Thunder / 风灵珠=Wind / 锈铁飞剑=Pierce / 灵藤草=Life"等填好。
- **优先级**：🔴 高（不填，技能-灵物联动 MVP 完全不会触发）。

### 3.3 SkillData 的 modifierDefs 需要配置

- **现状**：`modifierDefs` 字段刚加，所有现有 SkillData SO 都是空数组。
- **缺口**：先按 GDD 6.5.4 给"落石术 / 土遁术 / 金钟罩"各配 2~3 个 modifier。
- **优先级**：🔴 高（同上）。

### 3.4 cube 临时特效替换

- **现状**：`SkillModifierApplier.SpawnCubeVfx` 是程序化创建 Cube。
- **缺口**：替换为正式 VFX prefab。
- **优先级**：🟢 低（等美术）。

### 3.5 协同库扩充（GDD 7.3）

- **现状**：`SynergySystem` 只实现了少数几个组合。GDD 目标 100+。
- **缺口**：飞剑系 / 元素互动系 / 防御系 / 异变系。
- **优先级**：🟡 中。

### 3.6 灵物图鉴 / 协同记录 UI

- **现状**：完全无。
- **缺口**：本局拥有的灵物 / 已触发协同 / 当前 BUFF 集中显示页（按 Tab 打开）。
- **优先级**：🟡 中。

## 4. 关卡 / 房间 / 敌人

### 4.1 敌人种类

- **现状**：基础敌人 + 1 个 Boss。
- **缺口**：
  - 普通敌人按五行属性分类
  - 精英怪（特殊机制 + 必掉灵物）
  - 远程敌人（射手 / 法师）
  - 召唤型敌人
  - 飞行敌人
- **优先级**：🟡 中。

### 4.2 五行属性克制

- **现状**：完全无。
- **缺口**：敌人 elementTag + 玩家攻击 elementTag 之间的 1.5×/0.7× 倍率。
- **优先级**：🟢 低（等元素反应稳定后）。

### 4.3 渡劫天劫 Boss

- **现状**：有 EnemyBoss 但非"天劫"专属设计。
- **缺口**：多阶段 / 与 Build 互动 / 雷劫机制。
- **优先级**：🟡 中（Demo1+ 里程碑）。

### 4.4 关卡主题（秘境）

- **现状**：所有房间视觉一致，只有难度递增。
- **缺口**：每层一个主题（火山 / 雪原 / 雷泽 / 冥府）+ 视觉区分。
- **优先级**：🟢 低（美术工作量大）。

### 4.5 事件房 / 心魔房

- **现状**：无（GDD 9.2 心魔具现是 Demo3 内容）。
- **优先级**：🟢 低。

## 5. 系统 / UI / 工程

### 5.1 暂停菜单

- **现状**：无。当前 ESC 仅在某些 UI 里有响应。
- **缺口**：暂停菜单（继续 / 设置 / 重开 / 退回主菜单）。
- **优先级**：🔴 高（基础体验缺失）。

### 5.2 主菜单 / 设置面板

- **现状**：直接进游戏。
- **缺口**：开始 / 继续 / 设置 / 退出，以及音量 / 画质 / 键位。
- **优先级**：🟡 中。

### 5.3 死亡结算 / 重开界面

- **现状**：死亡只是 Debug.Log。
- **缺口**：结算面板（本局击杀 / 灵物收集 / 时间），点击重开。
- **优先级**：🔴 高。

### 5.4 详细属性面板

- **现状**：HUD 只有血条 / 充能条 / BUFF 条。
- **缺口**：按 C / Tab 打开角色页，显示当前所有 stats、协同、灵根、突破奖励。
- **优先级**：🟡 中。

### 5.5 小地图扩展

- **现状**：基础 Minimap 已实现。
- **缺口**：当前层 vs 当前房间区分；房间类型 icon。
- **优先级**：🟢 低。

### 5.6 BaseVFXGUI（之前修过的编辑器扩展）

- **现状**：已修复 `#if UNITY_EDITOR` 包裹问题。
- **缺口**：无。仅记录"已修"。

### 5.7 音效 / 音乐

- **现状**：基础 AudioConfig 存在。
- **缺口**：BGM 切换（按层 / 战斗 / 商店）、Boss 战专属 BGM。
- **优先级**：🟡 中。

### 5.8 配置外移到 ScriptableObject

- **现状**：`SpiritRootRegistry` / `RealmRewardLibrary` 是硬编码静态注册表。
- **缺口**：转 SO，让美术 / 策划在 Inspector 里调。
- **优先级**：🟡 中（数据稳定后再迁移）。
