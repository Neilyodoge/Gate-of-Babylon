# 🎮 GameConfig 配置说明

> 全局游戏配置文件，集中管理所有可调数值。
> 文件位置：`Assets/1Game/Resources/GameConfig.asset`
> 代码定义：`Assets/1Game/Scripts/Core/GameConfig.cs`

---

## 打开方式

| 方式 | 操作 |
|------|------|
| **菜单** | `仙途秘境` → `选中游戏配置` |
| **工具搜索** | F1 → 搜索 "GameConfig" → 点击 "选中游戏配置" |
| **手动** | Project 窗口 → `Assets/1Game/Resources/GameConfig.asset` |

---

## 字段分类说明

### 一、玩家基础属性

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 玩家最大生命值 | 100 | 血量上限，归零死亡。灵物可额外增加 |
| 玩家攻击力 | 10 | 普攻基础伤害，三段连招各段乘以对应倍率 |
| 玩家攻击速度 | 1.0 | 普攻动画播放速度倍率（0.5~3.0） |
| 玩家移动速度 | 6.0 | 角色移动速度（单位/秒，2~15） |
| 玩家暴击率 | 0.05 | 暴击概率（0~1，0.05=5%） |
| 玩家暴击伤害 | 1.5 | 暴击伤害倍率（1~5，1.5=150%伤害） |
| 玩家减伤比例 | 0 | 受伤减免比例（0~0.9，上限90%） |

### 二、闪避

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 闪避距离 | 5.0 | 闪避位移总距离（2~10） |
| 闪避持续时间 | 0.2 | 闪避位移持续秒数（0.1~0.5，越短越灵敏） |
| 闪避冷却时间 | 1.5 | 两次闪避间隔（0.5~5） |

### 三、敌人基础属性

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 敌人基础血量 | 30 | 普通小怪基础血量，不同类型有系数（法师×0.8、冲锋×1.5、Boss×8） |
| 敌人基础攻击力 | 5 | 普通小怪基础攻击力 |
| 敌人移动速度 | 3.0 | 所有敌人共用移速 |
| 敌人检测范围 | 12.0 | 发现玩家的最大距离 |
| 敌人攻击范围 | 1.5 | 进入此范围开始攻击 |
| 敌人攻击间隔 | 1.5 | 两次攻击间隔秒数 |

### 四、难度曲线

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 基础敌人数量 | 3 | 第一层战斗房间的敌人数 |
| 每层增加敌人数 | 2 | 每深入一层额外增加的敌人数 |
| 每层血量倍率 | 0.3 | 每层敌人血量增长系数（0.3=每层+30%） |
| 每层伤害倍率 | 0.2 | 每层敌人伤害增长系数 |

### 五、房间尺寸

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 基础房间大小 | 30 | 第一层房间边长 |
| 每层房间增大 | 5 | 每层增加的边长 |
| 最大房间大小 | 55 | 房间边长上限 |

### 六、掉落概率

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 凡品掉率权重 | 50 | 白色品阶权重 |
| 灵品掉率权重 | 30 | 绿色品阶权重 |
| 玄品掉率权重 | 15 | 蓝色品阶权重 |
| 地品掉率权重 | 4 | 紫色品阶权重 |
| 天品掉率权重 | 1 | 金色品阶权重 |
| 敌人掉落概率 | 0.15 | 每只敌人死亡掉落灵物的基础概率 |
| 每层掉率增加 | 0.03 | 每层额外增加的掉落概率 |
| 通关额外掉落数 | 1 | 通关战斗房间后额外掉落灵物数 |

### 七、近战攻击

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 近战攻击范围 | 2.5 | 普攻判定半径 |
| 近战攻击角度 | 120 | 普攻扇形角度（360=全方位） |
| 第一段伤害倍率 | 1.0 | 连招第1段伤害系数 |
| 第二段伤害倍率 | 1.2 | 连招第2段伤害系数 |
| 第三段伤害倍率 | 1.5 | 连招第3段（终结技）伤害系数 |

### 八、技能释放

| 字段 | 默认值 | 说明 |
|------|--------|------|
| 技能释放速度 | 1.0 | 全局默认技能动画速度倍率（可被单技能覆盖） |

## 调参建议

### 快速调整难度
- **降低难度**：减少 `基础敌人数量`、降低 `每层血量倍率`、提高 `敌人掉落概率`
- **提高难度**：增加 `每层增加敌人数`、提高 `每层伤害倍率`、降低 `敌人掉落概率`

### 调整战斗手感
- **更快节奏**：提高 `玩家攻击速度`、缩短 `闪避冷却时间`、提高 `玩家移动速度`
- **更重打击感**：提高 `第三段伤害倍率`、降低 `玩家攻击速度`（配合顿帧效果）

### 调整掉落体验
- **更多灵物**：提高 `敌人掉落概率` 和 `通关额外掉落数`
- **更稀有体验**：降低 `地品掉率权重` 和 `天品掉率权重`

## 代码访问方式

```csharp
// 通过单例访问（自动从 Resources 加载）
var config = GameConfig.Instance;
float hp = config.玩家最大生命值;

// 应用到玩家属性
config.ApplyToPlayerStats(playerStats);

// 应用到敌人属性
config.ApplyToEnemyStats(enemyStats);

// 按权重随机品阶
ItemRarity rarity = config.RollRarity();
```
