# 🛠️ 数据创建工具说明

> 本文档说明 Demo1DataCreator 编辑器工具的使用方法。
> 代码位置：`Assets/1Game/Scripts/Editor/Demo1DataCreator.cs`

---

## 一、概述

`Demo1DataCreator` 是一套 Unity 编辑器菜单工具，用于**一键创建和配置** Demo1 阶段所需的所有数据资产和场景设置。所有操作通过 Unity 顶部菜单栏 `仙途梦境` 访问。

---

## 二、菜单命令一览

按照推荐的执行顺序排列：

| 序号 | 菜单路径 | 功能 | 说明 |
|------|---------|------|------|
| ① | `仙途梦境/配置 Tags 和 Layers` | 设置项目 Tags & Layers | 添加 Enemy Tag/Layer，配置物理碰撞矩阵 |
| ② | `仙途梦境/创建 Demo1 测试数据` | 批量创建 SO 资产 | 在 `Data/Items/` 和 `Data/Skills/` 下生成灵物和功法数据 |
| ③ | `仙途梦境/创建 Animator Controller` | 创建动画状态机 | 在 `Data/` 下生成 `PlayerAnimatorController.controller` |
| ④ | `仙途梦境/自动配置 Demo1 场景` | 绑定数据到场景 | 将 SO 资产自动绑定到 Demo1Setup 的 Inspector 字段 |
| ⑤ | `仙途梦境/创建 Demo1 场景文件` | 创建场景 | 在 `Scenes/` 下生成 `Demo1.unity` |
| ⑥ | `仙途梦境/创建怪物预制体配置` | 配置怪物 Prefab | 创建 `MonsterPrefabs.asset` 配置 |

### 首次搭建项目

如果是全新项目，按 ①→②→③→⑤→④→⑥ 的顺序依次执行即可完成整个 Demo1 的数据搭建。

### 日常更新数据

如果只是新增/修改灵物或功法，只需执行 ② 和 ④：
1. `仙途梦境` → `② 创建 Demo1 测试数据`（更新 SO 资产）
2. `仙途梦境` → `④ 自动配置 Demo1 场景`（重新绑定到场景）

## 四、如何新增灵物/功法

### 步骤

1. 打开 `Assets/1Game/Scripts/Editor/Demo1DataCreator.cs`
2. 参照已有方法添加新的创建函数
3. 在 `CreateAllDemo1Data()` 方法中调用新函数
4. 执行菜单 `仙途梦境` → `② 创建 Demo1 测试数据`
5. 执行菜单 `仙途梦境` → `④ 自动配置 Demo1 场景`

### 新增灵物模板

```csharp
private static void Create新灵物名()
{
    var item = ScriptableObject.CreateInstance<ItemData>();
    item.itemName = "灵物名";
    item.description = "灵物描述";
    item.rarity = ItemRarity.Ling;           // 品阶
    item.category = ItemCategory.Attack;      // 分类
    item.stackable = true;                    // 可叠加
    item.qualitativeThresholds = new[] { 3, 5 }; // 质变阈值

    // 数值效果（按需填写）
    item.attackBonus = 5f;
    item.critRateBonus = 0.05f;

    SaveAsset(item, ITEM_PATH + "灵物名.asset");
}
```

### 新增功法模板

```csharp
private static void Create新功法名()
{
    var skill = ScriptableObject.CreateInstance<SkillData>();
    skill.skillName = "功法名";
    skill.description = "功法描述";
    skill.rarity = ItemRarity.Ling;
    skill.skillType = SkillType.AreaDamage;   // 技能类型
    skill.baseDamage = 30f;                   // 基础伤害
    skill.damageScaling = 0.5f;               // 攻击力缩放
    skill.cooldown = 8f;                      // CD
    skill.castSpeed = 1f;                     // 释放速度
    skill.aoeRadius = 3f;                     // AOE 半径

    SaveAsset(skill, SKILL_PATH + "功法名.asset");

    // 如果需要创建对应的灵物（用于掉落拾取）
    var item = ScriptableObject.CreateInstance<ItemData>();
    item.itemName = "功法名";
    item.description = "功法描述";
    item.rarity = ItemRarity.Ling;
    item.category = ItemCategory.Skill;
    item.stackable = false;                   // 功法不可叠加
    item.linkedSkill = skill;                 // 关联功法数据

    SaveAsset(item, ITEM_PATH + "功法名.asset");
}
```

## 五、自动配置场景（④）的工作原理

执行 `④ 自动配置 Demo1 场景` 时，工具会：

1. 扫描 `Assets/1Game/Data/Items/` 下所有 `ItemData.asset`
2. 扫描 `Assets/1Game/Data/Skills/` 下所有 `SkillData.asset`
3. 找到场景中的 `Demo1Setup` 组件
4. 将所有灵物数据填入 `Demo1Setup.itemPool` 数组
5. 将功法数据填入 `Demo1Setup.testSkillQ` / `testSkillE` 等字段

这意味着：**新增灵物/功法后只需重新执行 ② 和 ④，无需手动拖拽绑定**。

## 七、常见问题

**Q: 执行 ② 后灵物没有出现在游戏中？**
A: 需要再执行 `④ 自动配置 Demo1 场景`，将新数据绑定到场景。

**Q: 修改了灵物数值但游戏中没变化？**
A: 如果是直接修改 `.asset` 文件的 Inspector，保存后立即生效。如果是修改 `Demo1DataCreator.cs` 中的代码，需要重新执行 ②。

**Q: 可以在运行时动态添加灵物吗？**
A: 当前不支持。所有灵物数据在启动时通过 `itemPool` 数组加载，运行时不会动态加载新的 SO。

**Q: 如何删除一个灵物？**
A: 从 `Demo1DataCreator.cs` 中移除对应的创建方法调用，然后手动删除 `Data/Items/` 下的 `.asset` 文件，最后重新执行 ④。
