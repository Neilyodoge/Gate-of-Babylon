# 工具搜索面板 使用说明

> 一站式工具检索面板，快速定位项目中的所有编辑器工具、脚本和资产。

---

## 打开方式

| 方式 | 操作 |
|------|------|
| **菜单** | Unity 顶部菜单栏 → `nTools` → `工具搜索` |
| **快捷键** | `F1`（全局快捷键） |

---

## 功能概览

### 三个 Tab 页

| Tab | 说明 |
|-----|------|
| **通用工具** | `Assets/Tools/Editor` 下的编辑器工具，按子目录分组（美术工具 / TA工具 / 性能优化） |
| **专用工具** | `Assets/1Game/Scripts/Editor` 下的项目专用工具（核心系统 / 战斗 / 玩家 / 敌人 / 灵物 / 房间 / UI / 文档） |
| **个人收藏** | 点击 ★ 收藏的工具，跨会话持久保存 |

### 搜索栏

- 输入关键词即可实时过滤工具列表
- 支持按工具名称、分类名、描述内容模糊匹配

### 工具条目操作

| 操作 | 说明 |
|------|------|
| **点击名称** | 执行工具（打开菜单命令 / 定位脚本 / 选中资产） |
| **★ / ☆ 星标** | 切换收藏状态，收藏后在「个人收藏」Tab 中显示 |
| **? 帮助按钮** | **仅在填写了 Description 时显示**，悬停查看 Tooltip，点击定位到关联脚本 |

## 配置方法

### 添加新工具

编辑 `Assets/1Game/Scripts/Editor/ToolSearchWindow.cs` 中的 `ToolRegistry.BuildToolList()` 方法：

```csharp
list.Add(new ToolEntry
{
    Name = "你的工具名称",           // 显示名称（必填）
    Category = "ArtTools",          // 分类（必填），见下方分类列表
    OnClick = () => { ... },        // 点击时执行的逻辑（必填）
    ScriptPath = "Assets/...",      // 关联脚本路径（可选，帮助按钮定位用）
    Description = "工具描述文字",    // 工具描述（可选，填写后才会显示 ? 帮助按钮）
    IsSpecialized = false           // false → 通用工具Tab，true → 专用工具Tab
});
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `Name` | ✅ | 工具显示名称 |
| `Category` | ✅ | 所属分类，决定在哪个折叠组下显示 |
| `OnClick` | ✅ | 点击时执行的 Action |
| `ScriptPath` | ❌ | 关联脚本路径，点击 ? 按钮时定位用 |
| `Description` | ❌ | 工具描述，**填写后才显示 ? 帮助按钮**，不填则只有名称和星标 |
| `IsSpecialized` | ❌ | 默认 false（通用工具Tab），设为 true 放入专用工具Tab |

### 分类列表

**通用工具分类（IsSpecialized = false）**：

| Category | 显示名 | 说明 |
|----------|--------|------|
| `ArtTools` | 美术工具 | 对应 Tools/Editor/ArtTools |
| `TATools` | TA工具 | 对应 Tools/Editor/TATools |
| `OptimizeTool` | 性能优化 | 对应 Tools/Editor/OptimizeTool |

**专用工具分类（IsSpecialized = true）**：

| Category | 显示名 |
|----------|--------|
| `Core` | 核心系统 |
| `Combat` | 战斗系统 |
| `Player` | 玩家 |
| `Enemy` | 敌人 AI |
| `Items` | 灵物系统 |
| `Room` | 房间与关卡 |
| `UI` | UI 系统 |
| `Docs` | 文档 |

### 添加新分类

需修改同文件中的以下位置：

1. **`CATEGORY_NAMES` 字典** — 添加分类英文 key 到中文显示名的映射
2. **`GetCategoryOrder()` 方法** — 添加分类的排序权重（数字越小越靠前）

### 常用 OnClick 写法

```csharp
// 1. 执行 Unity 菜单命令
OnClick = () => EditorApplication.ExecuteMenuItem("nTools/美术工具/批量重命名"),

// 2. 选中并高亮某个资产
OnClick = () => {
    var obj = AssetDatabase.LoadAssetAtPath<Object>("Assets/路径/文件.asset");
    if (obj != null) { Selection.activeObject = obj; EditorGUIUtility.PingObject(obj); }
},

// 3. 在 Project 窗口中定位脚本
OnClick = () => {
    var obj = AssetDatabase.LoadAssetAtPath<Object>("Assets/路径/脚本.cs");
    if (obj != null) { EditorGUIUtility.PingObject(obj); Selection.activeObject = obj; }
},
```

## 常见问题

**Q: 收藏数据保存在哪里？**
A: 使用 `EditorPrefs` 保存，key 为 `XianTu_ToolSearch_Favorites`，跨项目持久化。

**Q: 工具列表没有更新？**
A: 点击 Tab 栏右侧的刷新按钮，或重新打开面板。

**Q: 为什么有的工具没有 ? 按钮？**
A: 只有在注册工具时填写了 `Description` 字段的工具才会显示帮助按钮。不填则只显示名称和收藏星标。
