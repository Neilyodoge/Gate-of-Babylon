# 🔮 灵物配置指南

> 本文档说明如何创建和配置灵物（Item）ScriptableObject 数据资产。
> 代码定义：`Assets/1Game/Scripts/Items/ItemData.cs`
> 数据目录：`Assets/1Game/Data/Items/`

---

## 一、创建方式

### 方式一：编辑器菜单一键创建（推荐）

Unity 菜单栏 → `仙途梦境` → `② 创建 Demo1 测试数据`

此操作会调用 `Demo1DataCreator.cs`，在 `Assets/1Game/Data/Items/` 下批量创建所有预定义的灵物 `.asset` 文件。

### 方式二：手动创建单个灵物

1. 在 Project 窗口中右键 → `Create` → `仙途梦境` → `灵物数据`
2. 重命名为灵物名称（如 `火灵珠.asset`）
3. 在 Inspector 中填写各字段

### 方式三：在代码中添加（可复现）

在 `Demo1DataCreator.cs` 中添加新方法，参照已有模式：

```csharp
private static void Create新灵物()
{
    var item = ScriptableObject.CreateInstance<ItemData>();
    item.itemName = "灵物名称";
    item.description = "灵物描述";
    item.rarity = ItemRarity.Ling;
    item.category = ItemCategory.Attack;
    item.stackable = true;
    item.qualitativeThresholds = new int[] { 3, 5 };
    item.attackBonus = 5f;
    // ... 其他字段
    SaveAsset(item, ITEM_PATH + "灵物名称.asset");
}
```

然后在 `CreateAllDemo1Data()` 中调用即可。

## 二、字段说明

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `itemName` | string | 灵物显示名称 |
| `description` | string | 灵物描述文本（支持多行） |
| `icon` | Sprite | 灵物图标（用于 UI 显示） |
| `rarity` | ItemRarity | 品阶（见下方品阶表） |
| `category` | ItemCategory | 分类（见下方分类表） |

### 叠加规则

| 字段 | 类型 | 说明 |
|------|------|------|
| `stackable` | bool | 是否可叠加。功法类设为 `false` |
| `qualitativeThresholds` | int[] | 质变阈值列表。如 `{3, 5}` 表示持有 3 个和 5 个时触发质变 |

### 效果参数（数值加成）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `attackBonus` | float | 攻击力加成（绝对值） | +5 攻击力 |
| `attackBonusPercent` | float | 攻击力加成（百分比） | 0.1 = +10% |
| `maxHpBonus` | float | 最大生命加成（绝对值） | +20 生命 |
| `maxHpBonusPercent` | float | 最大生命加成（百分比） | 0.15 = +15% |
| `moveSpeedBonusPercent` | float | 移速加成（百分比） | 0.1 = +10% |
| `damageReductionBonus` | float | 减伤加成（0~1） | 0.05 = +5% 减伤 |
| `critRateBonus` | float | 暴击率加成 | 0.05 = +5% 暴击 |
| `attackSpeedBonusPercent` | float | 攻速加成（百分比） | 0.15 = +15% |
| `pierceBonus` | int | 穿透次数加成 | 1 = 多穿透 1 个敌人 |
| `projectileSpeedBonusPercent` | float | 投射物速度加成（百分比） | 0.2 = +20% |

### 特殊效果

| 字段 | 类型 | 说明 |
|------|------|------|
| `burnDamagePerSecond` | float | 攻击附带灼烧（每秒伤害值） |
| `freezeChance` | float | 受击冻结概率 |
| `healOnKill` | float | 击杀回复生命值 |

### 功法关联

| 字段 | 类型 | 说明 |
|------|------|------|
| `linkedSkill` | SkillData | 关联的功法数据（拾取后可装备到技能槽位） |

### 灵物槽位

| 字段 | 类型 | 说明 |
|------|------|------|
| `requiresSlot` | bool | `false`=拾取即生效，`true`=需要放入槽位才生效 |
| `isSkillSpecific` | bool | `true`=针对同槽位技能生效，`false`=全局生效 |

### 拾取表现

| 字段 | 类型 | 说明 |
|------|------|------|
| `pickupVfxPrefab` | GameObject | 拾取时播放的特效 Prefab |

## 五、质变机制

当同一灵物的持有数量达到 `qualitativeThresholds` 中定义的阈值时，触发质变效果。

### 质变阈值配置示例

```
qualitativeThresholds = {3, 5}
```
- 持有 3 个时 → 触发第一次质变（小质变）
- 持有 5 个时 → 触发第二次质变（大质变）

### 各分类质变效果

| 分类 | 小质变（3个） | 大质变（5个） |
|------|-------------|-------------|
| 攻伐 | 攻击附带剑气波 | 攻击力翻倍 |
| 护体 | 受击反弹伤害 | 生命值翻倍 |
| 身法 | 闪避后留残影 | 移速翻倍 |
| 异变 | 随机触发效果 | 全属性提升 |
| 丹药 | 击杀回复翻倍 | 持续回血光环 |

> ⚠️ 当前质变效果仅输出日志提示，具体游戏效果待实现。

## 八、数据流向

```
ItemData.asset (SO 数据)
    │
    ├── Demo1Setup.itemPool ──→ GameManager.itemPool
    │                              │
    │                              ├── BattleRoom (通关奖励)
    │                              ├── EnemyBase (敌人掉落)
    │                              ├── ShopRoom (商店商品)
    │                              └── TreasureRoom (宝箱奖励)
    │
    ├── ItemPickup (地面拾取物)
    │       │
    │       └── ItemInventory (背包管理)
    │               │
    │               ├── CombatStats (属性叠加计算)
    │               ├── SynergySystem (组合检测)
    │               └── 质变检测
    │
    └── InventoryUI (背包界面显示)
```
