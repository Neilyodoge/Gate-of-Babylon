# 📜 功法配置指南

> 本文档说明如何创建和配置功法（Skill）ScriptableObject 数据资产。
> 代码定义：`Assets/1Game/Scripts/Combat/SkillData.cs`
> 数据目录：`Assets/1Game/Data/Skills/`

---

## 一、创建方式

### 方式一：编辑器菜单一键创建（推荐）

Unity 菜单栏 → `仙途秘境` → `② 创建 Demo1 测试数据`

此操作会在 `Assets/1Game/Data/Skills/` 下创建所有预定义的功法 `.asset` 文件。

### 方式二：手动创建单个功法

1. 在 Project 窗口中右键 → `Create` → `仙途秘境` → `功法数据`
2. 重命名为功法名称（如 `御剑术.asset`）
3. 在 Inspector 中填写各字段

### 方式三：在代码中添加

在 `Demo1DataCreator.cs` 中添加新方法：

```csharp
private static void Create新功法()
{
    var skill = ScriptableObject.CreateInstance<SkillData>();
    skill.skillName = "功法名称";
    skill.description = "功法描述";
    skill.rarity = ItemRarity.Ling;
    skill.skillType = SkillType.Projectile;
    skill.baseDamage = 25f;
    skill.damageScaling = 0.8f;
    skill.cooldown = 6f;
    skill.castSpeed = 1.2f;
    // ... 其他字段
    SaveAsset(skill, SKILL_PATH + "功法名称.asset");
}
```

## 二、字段说明

### 基础信息

| 字段 | 类型 | 说明 |
|------|------|------|
| `skillName` | string | 功法显示名称 |
| `description` | string | 功法描述文本（支持多行） |
| `icon` | Sprite | 功法图标（用于技能栏 UI） |
| `rarity` | ItemRarity | 品阶（凡品~天品，影响掉落权重） |
| `skillType` | SkillType | 技能类型（见下方类型表） |

### 数值参数

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `baseDamage` | float | 30 | 基础伤害值 |
| `damageScaling` | float | 0.5 | 攻击力缩放比例（最终伤害 = baseDamage + 玩家攻击力 × damageScaling） |
| `cooldown` | float | 8 | 冷却时间（秒） |
| `castSpeed` | float | 1.0 | 释放速度倍率（0.5~3.0，越大越快） |

### 范围伤害参数（AreaDamage 类型）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `aoeRadius` | float | 3.0 | 范围伤害半径 |

### 投射物参数（Projectile 类型）

| 字段 | 类型 | 说明 |
|------|------|------|
| `projectilePrefab` | GameObject | 投射物 Prefab（为空时使用默认灵力弹） |
| `projectileSpeed` | float | 投射物飞行速度 |

### 表现参数

| 字段 | 类型 | 说明 |
|------|------|------|
| `vfxPrefab` | GameObject | 技能特效 Prefab（为空时自动创建 Debug 可视化） |
| `vfxDuration` | float | 特效持续时间（秒） |

## 三、技能类型

| 枚举值 | 类型名 | 说明 | 示例 |
|--------|--------|------|------|
| `AreaDamage` | 范围伤害 | 在目标位置造成 AOE 伤害 | 落石术、天雷引 |
| `Projectile` | 投射物 | 发射投射物飞向目标 | 御剑术 |
| `Dash` | 位移 | 角色快速位移 | 土遁术、缩地成寸 |
| `Buff` | 增益 | 给自身施加增益效果 | 金钟罩 |

### 各类型的伤害计算

```
AreaDamage:  最终伤害 = baseDamage + 玩家攻击力 × damageScaling
             作用范围 = aoeRadius 半径内所有敌人

Projectile:  最终伤害 = baseDamage + 玩家攻击力 × damageScaling
             命中方式 = 投射物碰撞检测

Dash:        位移距离由技能逻辑控制
             可附带伤害判定

Buff:        持续时间 = vfxDuration
             效果由技能逻辑控制（如金钟罩的减伤）
```

## 四、技能槽位系统

玩家有 3 个技能槽位：

| 槽位 | 按键 | 说明 |
|------|------|------|
| Q 槽位 | Q | 主技能槽 |
| E 槽位 | E | 副技能槽 |
| R 槽位 | R | 第三技能槽 |

### 技能装备流程

```
功法灵物掉落 → 地面显示功法拾取物
    │
    ├── 按 F 拾取
    │   ├── 有空槽位 → 自动装备到空槽
    │   └── 槽位已满 → 替换 R 槽位，旧技能掉落
    │
    └── 长按 F → 分解获得灵力碎片
```

### 功法与灵物的关联

功法通过 `ItemData` 的 `linkedSkill` 字段关联：

```
ItemData (category = Skill)
    │
    └── linkedSkill → SkillData
```

创建功法类灵物时：
1. 先创建 `SkillData.asset`（功法数据）
2. 再创建 `ItemData.asset`（灵物数据），设置 `category = Skill`，`linkedSkill` 指向功法数据
3. `stackable` 设为 `false`（功法不可叠加）

## 五、释放速度配置

功法释放速度采用两级配置体系：

| 层级 | 文件 | 字段 | 优先级 |
|------|------|------|--------|
| 全局默认 | `GameConfig.asset` | `技能释放速度` | 低 |
| 单技能覆盖 | `SkillData.asset` | `castSpeed` | 高 |

**优先级逻辑**：
- 如果 `SkillData.castSpeed` ≠ 1.0 → 使用技能自身的值
- 如果 `SkillData.castSpeed` = 1.0 → 回退到 `GameConfig.技能释放速度`

> 详细演进路线见 [技能播放速度配置方案](技能播放速度配置方案.md)

## 七、Debug 可视化

当功法的 `vfxPrefab` 为空时，系统会自动创建 Debug 可视化效果：

| 技能类型 | Debug 表现 |
|---------|-----------|
| AreaDamage | 黄色 Cube 从天而降 + 红色范围圈 |
| Buff | 金色半透明球体护盾包裹角色 |
| Projectile | 使用默认灵力弹 |
| Dash | 角色快速位移（无额外可视化） |

> 正式制作时替换为美术 VFX Prefab 即可，无需修改代码。
