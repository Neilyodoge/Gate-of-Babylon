## 1️⃣ GameConfig — 游戏数值配置

| | |
|---|---|
| **文件** | `Assets/1Game/Resources/GameConfig.asset` |
| **用途** | 玩家属性、闪避充能、敌人属性、难度曲线、房间大小、精英怪、可破坏物、掉落概率、功法掉落、近战参数、技能速度 |
| **打开** | F1 搜索 "GameConfig" → 点击 "选中游戏配置" |
| **详细文档** | [配置_GameConfig说明.md](配置_GameConfig说明.md) |

### 字段分组速查

| 分组 | 包含字段 |
|------|----------|
| 玩家基础属性 | `玩家最大生命值`、`玩家攻击力`、`玩家攻击速度`、`玩家移动速度`、`玩家暴击率`、`玩家暴击伤害`、`玩家减伤比例` |
| 闪避 | `闪避距离`、`闪避持续时间`、`闪避冷却时间`、`闪避充能层数`（默认2层） |
| 敌人基础属性 | `敌人基础血量`、`敌人基础攻击力`、`敌人移动速度`、`敌人检测范围`、`敌人攻击范围`、`敌人攻击间隔` |
| 难度曲线 | `基础敌人数量`、`每层增加敌人数`、`每层血量倍率`、`每层伤害倍率` |
| 房间尺寸 | `房间大小`（固定值，默认35m，不随层数变化） |
| 精英怪 | `精英怪最低层数`、`精英怪出现概率`、`精英怪血量倍率`、`精英怪伤害倍率` |
| 可破坏物 | `可破坏物数量`（每个战斗房间）、`可破坏物掉落概率` |
| 掉落概率 | `凡/灵/玄/地/天品掉率权重`、`敌人掉落概率`（固定5%）、`每层掉率增加`（已废弃=0）、`通关掉落概率`、`通关额外掉落数` |
| 功法掉落 | `功法掉落概率`（敌人死亡3%）、`通关功法掉落概率`（25%） |
| 近战攻击 | `近战攻击范围`、`近战攻击角度`、`第一/二/三段伤害倍率` |
| 技能释放 | `技能释放速度` |

### 常用调整

| 我想... | 修改字段 |
|---------|----------|
| 让玩家更肉 | `玩家最大生命值` ↑、`玩家减伤比例` ↑ |
| 让战斗更快 | `玩家攻击速度` ↑、`玩家移动速度` ↑ |
| 让掉落更多 | `敌人掉落概率` ↑、`通关掉落概率` ↑、`通关额外掉落数` ↑ |
| 让功法更多 | `功法掉落概率` ↑、`通关功法掉落概率` ↑ |
| 降低难度 | `基础敌人数量` ↓、`每层血量倍率` ↓ |
| 调整暴击 | `玩家暴击率` ↑、`玩家暴击伤害` ↑ |
| 增加闪避次数 | `闪避充能层数` ↑ |
| 调整精英怪 | `精英怪出现概率` ↑↓、`精英怪最低层数` ↑↓ |
| 调整可破坏物 | `可破坏物数量` ↑↓、`可破坏物掉落概率` ↑↓ |
| 调整高品质掉率 | 降低 `凡品掉率权重`、提高 `地品/天品掉率权重` |

## 2️⃣ AudioConfig — 音效资源配置

| | |
|---|---|
| **文件** | `Assets/1Game/Resources/AudioConfig.asset` |
| **用途** | 所有音效和 BGM 的 AudioClip 引用槽位 |
| **打开** | F1 搜索 "AudioConfig" → 点击 "选中音效配置" |
| **创建** | 菜单 `仙途梦境 → ② 创建 Demo1 测试数据`（自动创建） |

### 配置方法

在 Inspector 中将音频文件**拖入对应槽位**即可，所有槽位初始为空：

| 分类 | 槽位 | 说明 |
|------|------|------|
| **玩家·攻击** | `meleeAttacks[0~2]` | 三段连招各段音效 |
| | `meleeHits[]` | 近战命中音效（随机播放） |
| | `critHit` | 暴击命中 |
| | `killConfirm` | 击杀确认 |
| **玩家·动作** | `dash` | 闪避 |
| | `playerHurt[]` | 受伤（随机播放） |
| | `playerDeath` | 死亡 |
| **技能** | `skillCastDefault` | 通用技能释放 |
| | `projectileFire` | 投射物发射 |
| | `aoeExplosion` | 范围爆炸 |
| | `buffApply` | 增益施加 |
| **敌人** | `enemyHurt[]` | 敌人受击 |
| | `enemyDeath[]` | 敌人死亡 |
| | `bossAppear` | Boss 出场 |
| **灵物** | `itemPickup[0~4]` | 按品阶拾取（凡/灵/玄/地/天） |
| | `qualitativeTransmute` | 质变触发 |
| | `synergyActivate` | Synergy 组合激活 |
| **UI** | `uiClick` | 按钮点击 |
| | `shopBuy` / `shopFail` | 商店购买成功/失败 |
| | `realmBreakthrough` | 境界突破 |
| **环境** | `portalActivate` | 传送门激活 |
| | `chestOpen` | 宝箱打开 |
| | `trapSpike` / `trapFire` | 陷阱音效 |
| **BGM** | `bgmBattle[0~2]` | 战斗 BGM（按层数） |
| | `bgmBoss` | Boss 战 BGM |
| | `bgmShop` | 商店/休息 BGM |
| **音量** | `masterVolume` | 主音量（0~1） |
| | `sfxVolume` | 音效音量 |
| | `bgmVolume` | 音乐音量 |

## 3️⃣ MonsterPrefabs — 怪物模型配置

| | |
|---|---|
| **文件** | `Assets/1Game/Resources/MonsterPrefabs.asset` |
| **用途** | 5 种敌人类型的模型 Prefab 引用 |
| **打开** | F1 搜索 "怪物" → 点击 "选中怪物预制体配置" |
| **创建** | 菜单 `仙途梦境 → ⑥ 创建怪物预制体配置` |

### 配置方法

将怪物模型 Prefab 拖入对应槽位（为空则自动使用胶囊体）：

| 槽位 | 敌人类型 | 推荐模型 |
|------|---------|---------|
| `普通小怪Prefab` | 基础近战 | Creeper 系列 |
| `远程敌人Prefab` | 远程弓箭手 | Haunt 系列 |
| `冲锋敌人Prefab` | 冲锋型 | Lurker 系列 |
| `法师敌人Prefab` | AOE 法师 | Soul Mage 系列 |
| `Boss敌人Prefab` | Boss | Dragon Darkness 系列 |

## 4️⃣ 灵物数据（ItemData）

| | |
|---|---|
| **目录** | `Assets/1Game/Data/Items/` |
| **用途** | 每个灵物的属性、效果、品阶、分类 |
| **打开** | F1 搜索灵物名（如 "火灵珠"） |
| **新增** | 菜单 `仙途梦境 → ② 创建 Demo1 测试数据`，或右键 `Create → 仙途梦境 → 灵物数据` |
| **详细文档** | [资源_灵物配置指南.md](资源_灵物配置指南.md) |

### 核心字段速查

| 字段 | 说明 |
|------|------|
| `itemName` / `description` | 名称和描述 |
| `rarity` | 品阶（Fan/Ling/Xuan/Di/Tian） |
| `category` | 分类（Attack/Defense/Movement/Anomaly/Pill/Skill） |
| `attackBonus` / `attackBonusPercent` | 攻击力加成（绝对值/百分比） |
| `maxHpBonus` / `maxHpBonusPercent` | 生命加成 |
| `critRateBonus` | 暴击率加成 |
| `burnDamagePerSecond` | 灼烧伤害 |
| `pierceBonus` | 穿透次数 |
| `healOnKill` | 击杀回复 |
| `linkedSkill` | 关联功法（功法类灵物必填） |
| `pickupSFX` | 自定义拾取音效（为空用通用音效） |

## 5️⃣ 功法数据（SkillData）

| | |
|---|---|
| **目录** | `Assets/1Game/Data/Skills/` |
| **用途** | 每个功法的类型、伤害、CD、VFX |
| **打开** | F1 搜索功法名（如 "落石术"） |
| **新增** | 同上，或右键 `Create → 仙途梦境 → 功法数据` |
| **详细文档** | [资源_功法配置指南.md](资源_功法配置指南.md) |

### 核心字段速查

| 字段 | 说明 |
|------|------|
| `skillName` / `description` | 名称和描述 |
| `skillType` | 类型（AreaDamage/Projectile/Dash/Buff/Heal/Summon） |
| `baseDamage` | 基础伤害 |
| `damageScaling` | 攻击力缩放比例 |
| `cooldown` | CD 秒数 |
| `maxCharges` | 最大充能层数（默认1，>1则为充能型技能） |
| `chargeTime` | 每层充能恢复时间（秒） |
| `castSpeed` | 释放速度倍率（1.0=默认） |
| `aoeRadius` | AOE 半径（范围伤害类型） |
| `vfxPrefab` | 技能特效 Prefab（为空用 Debug 可视化） |
| `castSFX` | 自定义释放音效（为空用通用音效） |
| `hitSFX` | 自定义命中音效 |

## 6️⃣ Demo1Setup — 场景配置

| | |
|---|---|
| **位置** | 场景中 `Demo1Setup` 组件的 Inspector |
| **用途** | 绑定灵物池、技能、角色模型、特效 Prefab |
| **打开** | 打开 `Demo1.unity` 场景 → 选中挂载 Demo1Setup 的 GameObject |
| **自动配置** | 菜单 `仙途梦境 → ④ 自动配置 Demo1 场景`（自动绑定所有数据） |

### Inspector 字段

| 字段 | 说明 | 必填？ |
|------|------|--------|
| `itemPool` | 灵物数据数组（掉落池） | 可选（自动配置会填入） |
| `testSkillQ/E/R` | Q/E/R 槽位默认技能 | 可选（有兜底） |
| `playerModelPrefab` | 角色模型 Prefab | 可选（为空用胶囊体） |
| `animatorController` | 动画控制器 | 可选（自动创建） |
| `slashVFXPrefab` | 刀光特效 | 可选 |
| `hitVFXPrefab` | 打击特效 | 可选 |
| `projectilePrefab` | 投射物 Prefab | 可选（自动创建） |

## 🚀 快速上手流程

### 首次搭建（从零开始）

```
① 仙途梦境 → 配置 Tags 和 Layers
② 仙途梦境 → 创建 Demo1 测试数据      ← 创建所有 SO 资产
③ 仙途梦境 → 创建 Animator Controller
④ 仙途梦境 → 创建 Demo1 场景文件
⑤ 仙途梦境 → 自动配置 Demo1 场景       ← 自动绑定数据
⑥ 仙途梦境 → 创建怪物预制体配置
⑦ 点击 Play 即可运行
```

### 日常调整

| 我想... | 操作 |
|---------|------|
| 调数值 | 选中 `GameConfig.asset` → 修改 Inspector |
| 加灵物 | 在 `Demo1DataCreator.cs` 中添加 → 执行 ② 和 ⑤ |
| 加功法 | 同上 |
| 配音效 | 选中 `AudioConfig.asset` → 拖入音频文件 |
| 换怪物模型 | 选中 `MonsterPrefabs.asset` → 拖入 Prefab |
| 换角色模型 | 场景中 `Demo1Setup` → 拖入 `playerModelPrefab` |

### F1 工具搜索面板快捷入口

按 **F1** 打开工具搜索面板，搜索以下关键词可快速定位：

| 搜索词 | 定位到 |
|--------|--------|
| `GameConfig` | 游戏配置 .asset |
| `AudioConfig` | 音效配置 .asset |
| `怪物` | 怪物预制体配置 .asset |
| `火灵珠` / `落石术` 等 | 对应灵物/功法 .asset |
| `配置速查` | 本文档 |
