# 🎯 灵物与功法设计框架

> **设计理念**：构建一个深度可组合的修仙Roguelike系统，强调策略搭配和build多样性

---

## 一、设计目标与核心理念

### 1.1 设计目标
- **策略深度**：通过灵物组合和功法搭配创造丰富的build玩法
- **成长曲线**：平滑的数值成长与质变机制相结合
- **视觉表现**：清晰的品阶区分和特效反馈
- **平衡性**：确保不同build路径的可行性

### 1.2 核心理念
- **组合优先**：鼓励玩家探索灵物间的协同效应
- **质变体验**：关键数量节点触发质变，提供爽快感
- **风险回报**：高风险高回报的build选择
- **渐进解锁**：随着游戏进程解锁更强大的灵物和功法

### 2.3 质变机制设计

#### 质变阈值规则
- **小质变**：3个同种灵物
- **大质变**：5个同种灵物
- **超质变**：7个同种灵物（预留）

#### 各分类质变效果设计

**攻伐类质变**
- 3个：攻击附带剑气波（范围伤害）
- 5个：攻击力翻倍，剑气波升级
- 7个：攻击附带连锁闪电

**护体类质变**
- 3个：受击反弹30%伤害
- 5个：生命值翻倍，反弹伤害提升
- 7个：获得无敌护盾（短暂）

**身法类质变**
- 3个：闪避后留残影（迷惑敌人）
- 5个：移速翻倍，残影持续时间延长
- 7个：获得短暂飞行能力

**异变类质变**
- 3个：随机触发一种特殊效果
- 5个：全属性提升20%
- 7个：获得元素掌控能力

### 2.4 数值平衡框架

#### 基础属性加成标准
```
凡品：+3~5 基础属性 或 +5%~10% 百分比加成
灵品：+6~10 基础属性 或 +10%~20% 百分比加成  
玄品：+11~20 基础属性 或 +20%~30% 百分比加成
地品：+21~40 基础属性 或 +30%~50% 百分比加成
天品：+41~80 基础属性 或 +50%~100% 百分比加成
```

#### 特殊效果强度标准
- **灼烧伤害**：凡品1/s，灵品2/s，玄品3/s，地品5/s，天品8/s
- **冻结概率**：凡品5%，灵品10%，玄品15%，地品20%，天品25%
- **击杀回复**：凡品3，灵品5，玄品8，地品12，天品20

## 三、功法系统设计

### 3.1 技能类型体系

| 类型 | 释放方式 | 核心玩法 | 平衡要点 |
|------|----------|----------|----------|
| **范围伤害** | 目标位置AOE | 清场能力 | 伤害半径 vs CD平衡 |
| **投射物** | 直线发射 | 远程输出 | 飞行速度 vs 伤害平衡 |
| **位移** | 角色移动 | 机动性 | 距离 vs CD平衡 |
| **增益** | 自身buff | 状态强化 | 持续时间 vs 效果强度 |
| **治疗** | 恢复生命 | 生存能力 | 治疗量 vs CD平衡 |
| **召唤** | 召唤单位 | 战术辅助 | 召唤物强度 vs 数量限制 |

### 3.2 功法品阶与强度

#### 基础伤害标准
```
凡品：20-30 基础伤害，0.3-0.5 攻击力缩放
灵品：30-50 基础伤害，0.5-0.7 攻击力缩放  
玄品：50-80 基础伤害，0.7-0.9 攻击力缩放
地品：80-120 基础伤害，0.9-1.2 攻击力缩放
天品：120-200 基础伤害，1.2-1.5 攻击力缩放
```

#### 冷却时间标准
- **短CD技能**：3-6秒（位移、低伤害技能）
- **中CD技能**：6-12秒（标准输出技能）
- **长CD技能**：12-20秒（大招、强力控制）

### 3.3 充能机制设计

#### 充能类型
- **单次充能**：标准技能，CD结束后可用
- **多层充能**：可存储多次使用机会
- **持续充能**：随时间自动充能

#### 充能平衡规则
```
1层充能：标准CD
2层充能：CD × 1.5倍
3层充能：CD × 2倍
```

### 3.4 技能强化系统（单次强化）

#### 设计理念
每个技能**只能强化一次**，玩家需要在多个强化选项中选择最适合自己build的方向

#### 强化获取方式
- **技能等级解锁**：技能达到特定等级时解锁强化选项
- **资源消耗**：消耗技能点数激活强化
- **永久选择**：一旦选择无法更改，增加决策重要性

#### 强化选项设计（每个技能2-3个选项）

**示例：火球术强化选项**
1. 🎯 **蓄力火球**：长按蓄力，伤害+50%
2. 🌪️ **爆裂火球**：范围+30%，但CD+2秒  
3. 🔥 **连发火球**：可快速连发3次，但单发伤害-30%

**示例：冰霜新星强化选项**
1. ❄️ **极寒新星**：冻结时间+2秒
2. 💫 **脆弱新星**：命中敌人防御-20%
3. 🌪️ **扩散新星**：作用范围+40%

#### 平衡原则
- **操作难度补偿**：操作要求高的强化收益更高
- **风险回报平衡**：有负面效果的强化正面效果更强
- **build协同性**：强化选项与不同build方向匹配

#### 实施要点
- 每个技能的强化选项应具有明显的差异化
- 避免出现"必选"的通用强力选项
- 强化效果应视觉上可辨识
- 提供足够的预览和信息说明

## 四、组合系统设计

### 4.1 Synergy组合规则

#### 触发条件类型
- **分类组合**：特定分类的灵物数量达到阈值
- **品阶组合**：特定品阶的灵物数量达到阈值
- **特定组合**：特定灵物的组合

#### 组合效果强度
- **2件套**：中等效果，build方向引导
- **3件套**：强力效果，build核心
- **4件套**：终极效果，build完全体

### 4.2 预设组合设计

#### 输出向组合
- **风火轮**：攻伐×2 + 身法×1 → 攻击力+30%，移速+20%
- **嗜血狂魔**：攻伐×2 + 异变×1 → 暴击率+15%，击杀回复翻倍 *（v0.5.1：原丹药→异变）*
- **元素大师**：异变×3 → 所有元素伤害+50%

#### 生存向组合
- **金刚不坏**：护体×3 → 减伤+25%，最大生命+20%
- **生生不息**：丹药×2 + 护体×1 → 持续回血，受击减伤

#### 全能向组合
- **天人合一**：5种分类各1个 → 全属性+15%
- **大道至简**：天品×1 + 任意×2 → 获得特殊能力

## 六、平衡性考量

### 6.1 风险回报平衡
- **高风险build**：依赖特定组合，成型后极强但难成型
- **稳定build**：通用性强，成长平滑但上限较低
- **混合build**：平衡发展，适应性强

### 6.2 数值平衡检查点
- **DPS平衡**：不同build的秒伤应在合理范围内
- **生存平衡**：不同build的生存能力应有差异但都可行
- **机动性平衡**：位移技能与移速加成的平衡

### 6.3 反制机制
- **敌人类型克制**：某些敌人对特定build有抗性
- **环境限制**：某些房间限制特定类型的build
- **资源限制**：高级灵物和功法的稀有度控制

## 十、蓄力系统设计

### 10.1 核心机制

蓄力是一种**可选的技能释放方式**，支持蓄力的技能可以通过长按技能键来增强释放效果。

#### 蓄力等级

| 等级 | 操作 | 效果 | 视觉反馈 |
|------|------|------|----------|
| **Lv1** | 短按释放 | 100%伤害，标准效果 | 普通特效 |
| **Lv2** | 长按0.5秒 | 150%伤害，效果增强 | 特效变亮，角色发光 |
| **Lv3** | 长按1.5秒 | 250%伤害，范围+30% | 特效最大化，屏幕震动 |

#### 蓄力约束
- 蓄力期间**移速降低60%**（可被灵物缓解）
- 蓄力期间**不能闪避**
- 蓄力满Lv3后可继续持有，松开释放
- 不是所有技能都支持蓄力（需要在SkillData中配置 `canCharge = true`）

#### 蓄力适用技能类型
- ✅ 范围伤害（AOE）：蓄力增加伤害和范围
- ✅ 投射物：蓄力增加伤害
- ⚠️ 位移：不建议蓄力（节奏不匹配）
- ⚠️ 增益/治疗：不建议蓄力（即时生效类）
- ✅ 召唤：蓄力增加召唤物强度

### 10.2 蓄力与灵物联动

灵物可以通过以下属性影响蓄力：
- **蓄力速度加成**（`chargeSpeedBonusPercent`）：缩短蓄力所需时间
- **蓄力伤害加成**（`chargeDamageBonusPercent`）：额外增加蓄力伤害
- **充能层数加成**（`skillChargeBonus`）：增加技能充能上限

### 11.2 灵物数值平衡

#### 充能层数加成规则
- 每个技能的充能上限硬性限制为 **3层**
- 基础充能（SkillData.maxCharges）+ 灵物加成 ≤ 3
- 灵物充能加成仅对**同槽位技能**生效（放在Q下方的灵物只影响Q技能）

#### 蓄力速度加成规则
- 蓄力速度加成为百分比叠加
- 例：基础Lv2需0.5秒，+20%蓄力速度后实际需 0.5/1.2 ≈ 0.42秒
- 上限：蓄力速度加成最高100%（蓄力时间减半）

#### CD缩减规则
- CD缩减为百分比叠加
- 上限：CD缩减最高50%（避免无限连发）
- 例：基础CD 8秒，-15%后实际CD = 8 × 0.85 = 6.8秒

### 11.3 充能灵物与build联动

#### 连发流（充能向）
- 核心：蓄灵珠 + 聚灵阵盘 → 充能3层
- 搭配：回气散/灵脉玉 → CD缩减
- 玩法：快速连发技能，高频输出

#### 蓄力流（蓄力向）
- 核心：引雷珠 + 凝气诀 → 蓄力速度大幅提升
- 搭配：破阵符 → 蓄力伤害加成
- 玩法：蓄力Lv3一击必杀，高爆发

#### 混合流
- 核心：天罡聚灵瓶 → 充能+蓄力双修
- 搭配：太虚灵鼎 → 全面强化
- 玩法：灵活切换连发和蓄力
